# 模型选择器只列非隐藏型号

2026-10-22，用户提出功能调整：“模型选择器只能选择非隐藏的模型”。本文登记口径、现状差距和实施边界，不改原型，不实施代码。

## 口径

“隐藏”指该型号不在上游选择器可见集合里，即读取快照的 <code>order.pickerAvailable</code>。该字段由运行时按下列规则算出（<code>runtime/opencodex/src/codex/catalog/model-visibility.ts</code> 的 <code>filterCatalogVisibleModels</code> 与 <code>subagent-model-routes.ts</code> 第 49 行）：

- 型号在全局 <code>disabledModels</code> 中；
- 所属渠道 <code>disabled === true</code>；
- 渠道有非空 <code>selectedModels</code> 白名单且该型号不在其中；
- 渠道 <code>initialModelSelectionPending</code> 为真；
- Antigravity 族被整体停用。

因此“非隐藏”= 出现在 <code>pickerAvailable</code> 里。本机快照实测 243 个型号中 78 个在集合内，其余 165 个隐藏。

## 现状差距

执行模型目录 <code>apps/desktop/tauri/src/modules/model_config/execution_directory.rs</code> 目前**故意包含隐藏型号**，且有一条测试固定了这个行为：<code>full_execution_directory_is_stable_includes_selector_hidden_models_and_explains_native_binding</code> 断言隐藏型号 <code>model.enabled == true</code>。这是为满足 <code>公共渠道模型选择器交互方案</code> 第 343 行“包含主选择器隐藏项”的旧口径。

按本机最新快照与当前草稿计算：

| 项 | 数量 |
| --- | --- |
| 型号行总数 | 243 |
| 当前可选（<code>enabled</code> 且无 <code>unavailableReason</code>） | 122 |
| 其中实为隐藏、应被排除 | 58 |
| 因型号级 <code>disabled: true</code> | 45 |
| 因渠道白名单未包含 | 13 |
| 调整后可选 | 64 |

58 个需排除项分布：Ciii-1 5、Ciii-2 5、FeiMao-Claude 7、GZGG-NewApi 13、Input-1 10、Input-2 10、Krill-1 4、Krill-2 4。

另核对：除 A6api 与原生外，草稿公开范围与上游 <code>pickerAvailable</code> 在全部可执行渠道上一致（122 项对 122 项，0 处分歧），说明这 58 项属于“管理侧仍可选、上游已隐藏”的真实不一致，不是统计口径差。

## 实施边界

- 判定放在后端 <code>execution_directory::build</code>，按 <code>pickerAvailable</code> 直接排除隐藏行，前端 <code>ModelPicker</code> 不再收到它们；不用前端过滤，避免其他消费者漏改。
- 排除项不进入“已选模型”缓冲；若某已保存执行设置指向隐藏型号，选择器应明确提示“型号已隐藏，请重新选择”，不静默换型号。
- 渠道停用、原生未绑定、待首次确认等既有 <code>unavailableReason</code> 继续按原样解释；隐藏是新的独立原因。
- 需同步改写上述既有测试：原断言“隐藏型号可选”与本次要求冲突，改为断言隐藏型号不在目录中。
- <code>公共渠道模型选择器交互方案</code> 第 343 行“包含主选择器隐藏项”须一并修订，否则规格与实现矛盾。
- 预览选择器走草稿投影（<code>modelApi.project</code>），展示的是“计划发布结果”，与执行选择器的可选集合是两个用途；本次只改可执行选择器，预览视图是否同步收紧待单独确认。

## 未验部分

以上数量来自本机快照与草稿的只读重算，未启动应用点击选择器，也未修改任何代码或设置。实施后须在隔离 fixture 中核对：选择器列表条数、隐藏型号不可见、已保存设置指向隐藏型号时的提示、以及 <code>pickerAvailable</code> 缺失时的降级行为。
