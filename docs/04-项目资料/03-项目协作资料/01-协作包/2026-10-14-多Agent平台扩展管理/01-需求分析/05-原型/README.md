## 评审与验收边界

第一轮用内存 mock，不读取本机 Skills、客户端配置或凭据，不启动 MCP、不调用真实模型、不写设置。取消只撤销本次草稿，移除只演示受管投影；共享目录仍可见时继续说明。资源与客户端视图使用同一份状态。

设计方向和单一入口已确认；第一轮交互与布局检查已完成，具体界面待用户评审。原型通过不能作为客户端适配、生产读写、升级迁移或发布验收。

## 第一轮实际检查结果

方法：在已有本地服务中打开总原型的 design=extensions 范围，以浏览器控件实际操作，读取 DOM / 可访问性状态与几何尺寸，保存截图。浏览器视口临时使用 1720 × 1000 容纳评审外壳，产品窗口分别设为 1180 × 760 与 900 × 600。

| 检查组 | 实际结果 |
|---|---|
| 独立范围与上下文 | models / conversations 显示原扩展界面，extensions 显示新界面；对话菜单及工具卡按范围切换 |
| Skills 与 MCP | 两类资源列表、摘要、详情及目标入口可用；MCP 定义只读，不执行命令 |
| 平台 / 资源搜索 | 平台筛选增加搜索，Cursor 筛选可见共享资源；客户端搜索无结果正确展示 |
| 单条草稿与取消 | 选择 Cursor 后取消，资源目标数不变；焦点回原入口 |
| 目标搜索与全部目录 | 搜索不隐藏全部已选数；Claude Desktop 待核实项禁用；空结果保留四个已选目标 |
| 更新与预览 | 已失败 Gemini、待更新 OpenCode 进入更新计划；新增明确列出资源、目标和落点 |
| 执行中 | 展示冻结的变更数，确认与取消禁用，执行目标固定 |
| 部分成功与重试 | 显示成功 / 失败计数；单独重试失败项后全部完成，列表同步更新 |
| 批量增加 / 移除 | 两个资源增加 Cursor 保留已有目标；移除只撤销 Cursor 受管投影 |
| 共享目录 | 批量移除结果继续说明共享可见；Cursor 详情受管资源为 0，六个共享资源仍可见 |
| 客户端视角 | 展示能力与落点，Cursor 详情可反向进入 Skills / MCP 筛选列表 |
| 空 / 加载 / 读取失败 | 三种状态可演示；错误重试回正常并同步右侧场景控件 |
| 冲突与不支持 | Hermes 冲突计划禁止提交；示例不支持场景下目标禁用并说明原因 |
| 6 / 24 / 50 容量 | 客户端行数分别为 6 / 24 / 50；50 项在 900 × 600 下列表、主区域横向溢出均为 0 |
| 宽窄与主题 | 默认深色、最小浅色目检通过；列表与弹窗无明显重叠，确认按钮在窗口内 |
| 键盘 / 焦点 | 弹窗末项 Tab 返回搜索，Shift+Tab 返回确认；取消后回原资源入口 |
| 资源与控制台 | 三份修改脚本 node --check 通过，10 项公共 Tab 回归通过；浏览器控制台 error 为空 |

上述为 17 组人工浏览器 / 静态检查，不是新增自动化测试套件，也不是正式生产验收。

材料检查：本包 12 份 Markdown、40 个相对链接和 6 张截图均可定位；新增 JS / CSS 只在唯一 index.html 各注册一次，修改索引 git diff --check 通过。

## 缺口与下一步

界面尚待用户评审；平台官方能力与模拟写入严格区分。项目 / profile / 远端写入、任意平台适配、真实资源读取、格式迁移、备份 / 同步协议及客户端热生效未实施。原有更新、仓库、导入、恢复、MCP 编辑等工作流在其他设计范围的旧扩展界面保留；本轮新视图聚焦分发与客户端管理，这些工具如何迁入新列表需下一轮逐项补绘，不能因新摘要已完成就视为全部扩展管理改版完成。

第一轮没有新增总原型目录、生产代码或发布版本。下一步由用户评审本包界面，再调整剩余扩展工具入口和各平台适配范围。
