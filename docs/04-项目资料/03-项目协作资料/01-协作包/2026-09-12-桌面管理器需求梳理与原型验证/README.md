## 约定

1. **一级目录 = 生命周期阶段**，阶段内再分「输入 / 过程 / 产物」，不把不同阶段的产物平铺在包根。
2. **`输出/` 只放派生交付物**：HTML、导出图、导出报告；源材料与导出物并列，便于追溯。
3. **归档与活跃显式分离**：标注「归档 / 不参与构建」的目录仅作历史来源，不作为当前结论。
4. **每个阶段和子区都有 `README.md`** 做索引。
5. **稳定 ID 前缀**：`COL-`、`DMD-`、`IMP-`、`TASK-`、`MNT-` 等，外部引用优先用 ID 指向对象入口，不跟内部文件名走。
6. 协作包关闭后的维护工作以 `05-运行维护/` 的 `MNT-*` 附件承接，**不重开本协作包**。
