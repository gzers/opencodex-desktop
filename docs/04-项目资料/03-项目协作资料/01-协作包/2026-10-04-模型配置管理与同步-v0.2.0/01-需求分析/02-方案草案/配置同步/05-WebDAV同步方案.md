# WebDAV 同步方案

独立“同步 → WebDAV 同步”维护连接、当前设备范围和凭据策略，复用文件同步的清单和应用服务。现有两个管理器文件是旧能力；不能只把模型 / 账户文件名加进上传列表就算完成。

## 每设备范围

一份持久范围同时约束本机上传和接收。保存范围不会立刻应用远端配置；先检查变化。只上传已提交状态与精确依赖，不上传未保存草稿、失败 staging、机器绑定、日志或“本机已验证”标志。

第一次开启和新类别加入时明确展示范围。新用户默认全部可移植配置，已选账户包含可迁移登录状态，列表明确提示；渠道 Key 与扩展凭据另选。分享预设不含任何凭据，账户详情可选仅账户信息。已有用户的范围升级时保持原范围，旧账户范围保留仅账户信息，待用户明确选择携带登录状态；新敏感类别不自动加入，旧设置授权不能扩展为登录态授权。

取消勾选只停止本设备参与。部分上传以对象级补丁或保留原远端对象的合并快照执行，不能用子集覆盖远端全集。缺少文件不是上传空对象或远端删除；删除 / 清理另有明确范围与确认。

## 传输与采用

检查远端 manifest 和本机已提交快照 → 按范围解析依赖 → 展示上传 / 下载 / 冲突 → 在本机解密受保护部分 → 下载为待审候选 → 明确采用 → 备份与应用 → 读回及自动账户恢复 / 可用性检查。

首次采用、覆盖既有设置、凭据替换、同身份的不同登录态，以及外部漂移都需比较。定时同步即使开启，也只传输已授权的已提交内容并产生待审下载，不能默认为新增敏感对象或运行配置自动覆盖授权。

模型同 revision 异内容不能静默合并；策略与所需精确模版版本必须同批验证。缺依赖保留候选与原运行态。重复 manifest / 已接受 digest 不重复应用，不把远端主版本自动设成本机主版本。

已选账户的登录状态自动检查，不要求用户另点核对按钮。两端登录状态冲突仍由用户选择保留本机、采用远端或跳过；已失效的远端状态不能采用，提示需重新登录。仅账户信息不产生登录态采用或恢复。令牌以账户授权身份、来源设备、刷新世代 / 状态版本处理冲突，不能 last-modified 较大就覆盖。已撤销、已轮换的旧令牌不能被历史快照再次激活；是否可移植、可并行使用和刷新均由账户适配器核验。

## 远端隔离与凭据

建议新对象域使用独立版本化目录 config-sync/v1/，覆盖全配置专题，取代旧的仅 model-config/v1/ 双文件提案。实际命名在协议冻结时确认；主原型路径是演示值。与旧 manager-state 快照域隔离，复用端点锁与 runner 协调，payload 完整后最后发布 manifest。

旧客户端只处理已知旧域；必须实测旧清理 / 恢复不会删除新域。不同域不是单一原子事务，不能把偏好上传成功报告为完整同步成功。

含凭据先在应用层加密；口令独立于 WebDAV 登录密码，解密材料留在本机或由用户带到另一设备。关闭凭据后只影响未来范围，不会追溯删除远端加密历史；历史清理与保留策略单独显示，避免误导。

活动连接及本设备 scope 不随同步内容自覆盖，避免下载配置将自己切到另一服务器或突然扩大范围。文件同步默认勾选 WebDAV 配置并携带密码，详情可选仅配置，分享预设排除密码；导入配置为未启用项。WebDAV 配置不进入本设备 WebDAV 同步范围，连接密码不充当同步加密口令。

## 结果

分别报告“已上传”“已下载待审”“配置已写入 / 待读回”“登录态已恢复 / 待核对”“账户可用”“部分失败”“待依赖 / 待映射”。传输完成不等于所有对象已应用，更不等于账户免登录成功。

连接失败、权限不足、锁冲突、ETag / 基准变化、解密失败、无变更均有准确状态及重试出口；重试沿用 planId / 操作去重，不重复创建账户或渠道。
