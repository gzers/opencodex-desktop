# 文件同步与导入导出方案

## 导出

入口统一为“同步 → 文件同步”。模型 / 模版原入口只传入范围，不维护另一份导出格式或凭据策略。

流程：选择类别和对象（账户默认含可迁移登录状态，WebDAV 配置默认勾选并含密码）→ 按需设为仅账户信息 / 仅 WebDAV 配置，另选渠道 Key / 扩展凭据 → 解析精确依赖 / 检查未知内容 → 预览冻结清单 → 必要时设置独立加密口令 → 生成文件并报告结果。

默认来源为已提交渠道策略、已保存模版版本和已提交原有配置。未保存草稿不自动进入。如果后续保留“导出草稿”，必须显式标为未提交候选，与可直接接收的已提交配置区分，也不进入自动 WebDAV 上传；本轮原型仅演示已提交来源。

清单记录格式 / 结构版本、对象类型及稳定 ID、来源版本、精确依赖、作用域、是否携带秘密和完整性信息。摘要不能用于冒充真实性认证。包含 Key、登录态、扩展凭据与 WebDAV 密码只列对象和数量，不列值。全局字段另选，局部包不扩大影响范围。

## 导入

流程：选择文件 → 格式 / 大小 / 结构检查 → 如需则解密 → 仅展示包内可导入项 → 勾选子集（账户默认采用包内可迁移登录状态，可选仅账户信息）及其他凭据采用范围 → 依赖 / 身份映射 → 前后差异 → 备份 → 应用 → 读回 → 自动恢复并检查账户可用性。

导入可少于导出范围；包带了凭据不等于必须采用。没有秘密的包也可用于更新已有本机渠道，匹配身份时保留本机 Key。账户登录状态随账户选择，账户详情可选择仅账户信息；渠道 Key 开关不改变该选择。设备绑定或恢复检查失败显示“需重新登录”，不增加手动核对按钮。

默认合并。替换仅影响明确 scope，未包含 section / 对象不是删除，保留本机无关对象和字段。渠道同名异 ID、同 ID 异端点、账户不同授权身份、同模版 revision 异 digest 分别要求映射或冲突处理。

模板只导入版本时保存候选，不自动设主版本或切策略引用。渠道 / 模型进入统一待审计划，确认采用后经过现有预算、漂移、备份、编译与读回约束；“已接收”和“已应用”分开。模型页既有草稿保留，重叠字段需三方比较，不把收到的文件直接覆盖两个工作文件。

WebDAV 配置默认采用包内连接密码，也可选仅配置；没有密码的包不提供密码选项。同身份仅配置保留本机密码，新连接待补密码，不以空值覆盖。导入为未启用连接，需用户选择启用，不能改写正在承载这次同步的端点、凭据、目录或当前设备范围。

## 格式兼容

采用统一逻辑清单，但文件容器格式版本、对象 schema 版本、远端同步协议版本分别演进。现有 strict / deny_unknown_fields 容器不能仅塞入新字段就宣称兼容，新增格式应显式版本化。

新客户端支持读取旧版受支持容器；老容器没有模型 / 账户 / 资源部分时保持本机值，UI 说明实际内容。旧 Skill 名称、MCP 名称或 Keychain 引用不能显示成完整扩展 / 账户已恢复。旧客户端遇新格式明确拒绝，不能截断后再保存。

压缩包需验证大小、数量、路径穿越、链接逃逸和解压总量。损坏、错误口令、未知版本、重复身份、缺依赖必须在写入前失败并保留当前状态。完整应用流程与补偿见 [异常恢复](06-兼容与异常恢复.md)。
