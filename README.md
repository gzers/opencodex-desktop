# OpenCodeX-Desktop

[English](README.en.md) | 简体中文

> 面向 OpenCodex 的独立桌面管理器：把命令行里的发现、启停、状态观测、配置迁移、同步与扩展管理，收进一个图形界面。

**状态：需求阶段已完成，尚无实现。** 本仓库当前只包含需求、原型与治理文档。实施契约（IMP）尚未创建，没有可运行的程序，也没有可安装的构建产物。

---

## 这是什么

OpenCodex 目前主要通过命令行启动和观察。**OpenCodeX-Desktop** 是一个基于 **Tauri v2 + Rust** 的桌面壳（第一阶段以 macOS 为主），负责：

- 发现本机已安装的 OpenCodex，展示路径、版本与可执行校验结果；
- 托管官方的 `ocx start / stop / restart` 子进程，并把运行状态、端口、进程标识与最近错误汇总到界面；
- 提供日志、运行环境诊断与通知中心；
- 完成加密的配置导出/导入与 WebDAV 同步；
- 统一管理 **Skills** 与 **MCP** 两类扩展配置，并分发到多个客户端；
- 提供托盘、原生菜单与一条可选的命令行控制面。

**它不是** OpenCodex 官方项目的一部分，与官方及其权利人**不存在隶属、授权或背书关系**。详见 [`LICENSE`](LICENSE) 与下方「归属与许可」。

## 核心能力

| 能力 | 说明 |
|---|---|
| **安装发现** | 只发现、展示、校验已有的 npm 安装形态；**不管理 npm**，不代装、不卸载、不解析依赖 |
| **数据目录** | 支持选择或切换 `OPENCODEX_HOME`；管理器自身产物统一放在可自定义的数据根中按结构划分。切换采用**引用优先、迁移可选**，迁移前强制备份、失败可回滚 |
| **运行托管** | 直接托管官方启停子进程；不安装或管理 launchd，不接管 `codex-shim` |
| **状态观测** | 状态拆成**运行 / 连接 / 操作**三个维度，可同时成立；动作按状态渲染，不做无解释的禁用按钮 |
| **日志与诊断** | 日志只读、敏感值掩码；展示官方 `ocx doctor` 的**只读**摘要；代理离线时明确说明实时日志不可用 |
| **官方面板** | 嵌入官方 Web 面板的源码级快照视图；只承载官方 GUI，不重绘内部、不注入控件 |
| **通知中心** | 与「诊断中心 → 通知历史」共用同一份数据；支持详情弹窗与单条删除 |
| **配置迁移** | 全量导出（含敏感内容）必须进入**用户口令保护的加密容器**；导入前完成格式/版本/完整性校验、自动备份与显式确认，失败回滚 |
| **WebDAV 同步** | 全量内容**客户端加密**后上传；覆盖前生成可恢复备份；冲突先入待处理，不静默覆盖 |
| **扩展管理** | Skills 发现/导入/更新/卸载/恢复；MCP 服务器导入/新增/编辑/删除；支持多客户端落点 |
| **双版本升级** | OpenCodex 本体走官方 `ocx update` 引导；套壳应用自身更新独立，签名校验、重启生效、失败可回滚 |
| **托盘与菜单** | 托盘菜单动作限定在管理器自有域，并用图标与颜色表达运行状态；提供 macOS 原生菜单入口 |
| **CLI 控制面（可选）** | `ocxd` 命令，**默认关闭**；启用后作为运行中实例的客户端，经本机 IPC 委托执行 |

## 安全边界：明确不做的事

- 不重写 OpenCodex 核心，不绕过官方 API。
- 不接管 npm 包管理器，不替代官方 `ocx update` 的更新事务。
- 不接管 `codex-shim`，不安装或管理 launchd。
- **不写入 provider、路由、模型映射等 OpenCodex 核心运行配置**——这类变更一律走官方 CLI。
- 不自动覆盖外部 provider 托管的配置；只检测、解释并在用户确认后引导官方 `restore`。
- 任何凭据不得进入仓库、Markdown、日志、命令行参数或未加密文件。
- WebDAV 远端一律视为**不可信**；TLS 证书校验失败默认拒绝，不提供"忽略证书"选项。

### 扩展管理的写入边界

| | 范围 |
|---|---|
| **允许写入** | Skills 目录同步；各客户端的 MCP 服务器节点 |
| **禁止写入** | provider、路由、模型映射，以及 OpenCodex 核心运行配置 |

写入前强制备份、采用临时文件 + 原子替换、失败回滚；删除类操作可恢复；`env` / `args` / `headers` 一律按敏感值掩码；写入持有**跨进程文件锁**并检测外部改写。
