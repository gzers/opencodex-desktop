## 存储与绑定

- macOS 默认 `~/Library/Application Support/com.gzers.opencodex.desktop`；Windows 新装 `<实际安装目录>\data`，不能由 cwd、固定盘符或临时更新目录推导。旧 AppData 与显式自定义根优先保留。
- 启动先解析有效绑定，再创建偏好、通知、运行来源、进程 HOME、日志、缓存及 IPC；同一运行世代只使用一个活动根。绑定循环、过新结构、相对路径、损坏与不可写均拒绝，不静默换根。
- 受控分区：`manager-state/`、`opencodex-home/`、`backups/`、`logs/`、`exports/`、`cache/`、`sync-state/`、`runtime/`。系统凭据、WebView 系统文件、外部已有面板和用户选定导出目录单列例外。
- reference-only 不复制，必须保留外置 HOME 并完成全存储重新绑定；可采用停写后重启生效，但必须明确 pending-restart、拒绝新写事务、停止在途写者并验证重启回读。仅改变字符串或临时 context clone 不算实现。d8d5456d 已接入 RAII 全局写者计数与冻结门，要求运行状态新鲜停止 / 未发现、无安装或待重启、无在途写者；忙则拒绝，不自动取消 / 等待清空。失败或无变化解除冻结，成功变更后本进程冻结直到退出；状态读取 / 列表 / 安全打开不被误禁，OS 缓存、Unix IPC 退出清理、外部编辑单列例外。3f7dce76 / 1ef59403 已接通 MigrateData：原子绑定提交后立即冻结并保留目标锁，重启锁内清单核对才准入；提交结果不确定保持待核对。UI 捕获并转义目标，不在重启前改变旧活动路径显示。迁移使用隔离数据测试，复制校验失败保留旧根与旧绑定；真实用户迁移另确认。

## 调度与来源

- 首屏就绪后 45s 开始到期评估；stable 24h、beta 6h、面板 24h。一个 nextDue timer，多源唤醒合并、自动串行、每对象 single-flight。手动复用在途请求；关闭自动不影响手动。安装 / 根切换时延后。
- 退避 5min → 30min → 2h → 正常周期；休眠恢复不补跑历史周期，导航 / 网络恢复不绕过退避。管理器切通道不触碰面板缓存、退避或事务。
- `manager-state/update-schedule.json`：schema=1，最多三对象、16KiB；`cache/updates/{manager-stable,manager-beta,panel-latest}.json` 可丢弃，清缓存保留调度状态。查询前持久预留，完成按捕获的根、对象和世代落盘。
- 面板一次 `npm view ... version dist.integrity --json`，总超时、有界 16KiB 输出、版本 128 字符、完整性 4096 字符；取消 / 超时清理自有进程及子进程。Windows 进程树收尾仍需实现取证。更新说明按精确候选版本按需获取，无详情如实提示。4cc0628f 将 npm cache 归到活动根 cache/npm，不改真实 HOME / USERPROFILE。
- 性能预先预算：缓存命中 100 次切页 / 10 次重启为零网络与查询子进程；与同机 0.1.9 配对，启动可交互 p95 增量 ≤100ms 且 ≤5%，闲置 CPU 增量 ≤0.5 百分点、RSS 增量 ≤10MiB，检查不产生 >50ms 主线程任务。至少 20 次冷 / 热启动分别取样，空闲 10min、慢网 / 离线 / 单次检查各取样。阈值是待测预算，不是结果；超预算修复或明确审阅原因，不测后降低门禁。真实 stable 24h / beta 6h 周期另取证。

## 事件与树表

- triggers / jobs / events / notifications 分开注册；一次性、状态、周期及其时间策略显式，非更新任务周期保持 planned。未知投递拒绝，进度 tick 不通知，导航 / 筛选 / 展开 / 已读不通知。
- 恢复匹配对象、动作、阶段、通道 / 候选及真实成功证据；检查成功不能解除安装失败，切通道不能解除失败。脱敏，不持久原始异常、凭据、账户名或完整路径。
- 树表采用语义 table + 可访问按钮，稳定 ID、缩进、可选 mixed / disabled checkbox、箭头或叶占位、图标、文字及列 slot。第一行统一垂直中心，展开 / 选择独立，级联由调用者决定，刷新保留展开和焦点。外层永远展开；初始显示到月份，月份下级折叠。
