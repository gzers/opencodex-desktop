## 3. 页面组织建议

2026-10-27 当前确认：侧栏“对话”直接进入项目与对话，原“全局设置”整页迁到“设置 → 对话策略 → 模型与工具”；上下文与连接是策略页另外两个分组。取消对话页双 Tab，作用域优先级、存储与字段语义不变。

### 3.1 菜单与操作归属

按用户要求，组织表增加菜单结构一列。下列路径包含侧栏菜单、页内 Tab、对象和内容分区，不表示每一级都新增菜单。WebDAV 范围和本地重装恢复的正式入口统一在同步菜单；对话页只提供带入当前范围、可返回原编辑位置的快捷操作。

| 操作 | 菜单结构 / 正式位置 | 交互安排 |
|---|---|---|
| 全局默认 | 设置 → 对话策略 → 模型与工具 | 命名模型、搜索和子 Agent 默认设置；命名行为沿用 Codex |
| 项目配置 | 对话 → 项目与对话 → 选中项目 | 显示有效值及来源，仅保存项目覆盖 |
| 对话配置 | 对话 → 项目与对话 → 展开项目 / 未分配 → 选中对话 | 显示继承项目与专属覆盖，保存当前对话 |
| 字段编辑 / 恢复继承 | 对话 → 当前对象详情 → 联网搜索 / 子 Agent；命名模型仅全局 | 当前对象共用一个保存动作，切换保留输入 |
| 保存与采用反馈 | 对话 → 当前对象详情 → 保存区 / 采用详情 | 配置保存与执行采用分别显示，不额外建状态菜单 |
| 更新对话标题 | 对话 → 项目与对话 → 选中对话 → 标题操作区 | 修改标题；按当前内容重新命名 → 预览 → 采用，生成使用已保存的全局命名模型 |
| 配置导出 / 导入 | 同步 → 文件同步 → 对话配置范围 | 仅携带配置；从对话页“配置工具”进入时带入当前对象 |

### 3.4 对象列表与详情

- 全局设置直接展示连续配置表单；只有一个数据源时默认使用当前来源，多个来源再显示可选来源及实际影响范围。原 OpenCodex 全局字段如作用于整个连接实例，应说明真实范围，不能伪装成仅某项目生效。
- 项目与对话在宽窗口使用对象列表与详情并排。项目行用于进入项目配置，展开箭头用于加载对话；点击对话行进入其专属配置，未分配项目的对话有独立容器。显示当前对象类型、名称、项目关系及必要来源，完整 ID / 路径放详情，不当作首屏主要内容。
- 全局详情展示命名模型、联网搜索、子 Agent；项目和对话详情只展示搜索与子 Agent。首轮不同时常驻对象树、第二列分区导航和第三列表单，按内容需要再加轻量锚点，不叠三层 Tab。
- 窄内容区使用对象列表 → 详情，提供“返回项目与对话”，恢复之前搜索、分页和滚动；不强行把树和表单压到两个不可用窄列。实际断点按可用内容宽度在 1180 × 760 / 900 × 600 原型中核对，不以固定截图猜测。
- 日常对象选择不显示导出复选框，选中项目不等于全选它的对话。复选框用于恢复包多选范围，展开箭头、当前编辑对象和批量选择分别表达。

列表提供搜索、手动刷新、仅看有专属设置及归档筛选，首屏默认未归档；搜索只改变查看范围，不重置配置。展开项目按需加载下一页，子 Agent 对话默认收起或显示数量后查看，不开页扫描全部记录。

第一次进入对话页显示项目与对话；全局默认从策略快捷入口进入。后续返回同一页面恢复上次对象和位置，目标无法定位时保留编辑并说明待核对，不静默套到另一个同名对象。该默认为本轮建议，非已经落盘的产品行为。

## 4. 字段与编辑缓冲

模型与枚举字段直接展示选择器，首项是“继承：具体值（来源）”，例如“继承：NewApi / gpt-5.4（项目 · 桌面管理器）”。点击其他模型自动成为本层自定义；选择继承项或点击恢复继承只清当前字段覆盖。下方常驻“当前有效模型 / 来源”，不把型号藏在模式切换后。

推荐模型使用多选，不要求手填 ID。数值与指令直接可编辑，显示继承 / 自定义标识；高级区字段变化后保持展开，切换对象保留各自状态。明确关闭和继承仍分开，保存语义不变。推理选项按所选模型提供，不兼容值可见、不静默换档。

正式实现无法确定继承模型时显示“尚未读取 / 未知”，不能用演示默认冒充实际读回；当前原型目录与来源是 fixture。

全局没有项目上层时显示“沿用 Codex / OpenCodex 默认”等实际来源。模型能力页提供可选范围，本页选择任务实际用值；改变本项目子 Agent 档位不会改模型模版或制模助手偏好。模型规则详情从本页可前往查看，回来保留当前输入。

切换对象、分区或临时前往模型页，按对象保留未保存缓冲；回到对象继续原编辑。不强制每次切换都弹保存确认，也不自动保存多个作用域。当前标题 / 保存区显示“本项目有未保存修改”，其他对象如也有草稿，只显示可定位的计数提醒；不把别处草稿一起写入。应用关闭 / 刷新后如何恢复草稿仍由实施确定，首轮内存 mock 不承诺持久化。

保存当前作用域覆盖，当前对象的功能分区共用一个保存动作。“恢复继承”先成为该对象的可撤销编辑，保存后生效，不删除上层配置。常规保存不二次确认；全局页可恢复命名模型的原配置，项目 / 对话没有命名字段。跨源部分成功分别反馈，区别于模型页整批渠道保存确认。

导出默认收集已保存配置。当前范围存在草稿时在范围预览提供“保存后导出 / 仅导出已保存 / 返回编辑”，不要无提示导出旧值或自动保存其他对象；选择保存后导出只处理用户已明确选择且可保存的相关草稿，失败不伪称包已包含新配置。

### 4.1 对话期间更新标题

用户已选择手动点击“按当前内容重新命名”。对话标题区提供“修改标题”和“按当前内容重新命名”；后一项读取当前可确认内容，使用已保存的全局命名模型生成候选，用户可编辑、取消或采用。取消保持原标题；采用后刷新标题与对象列表，身份、项目归属、模型覆盖和未保存草稿不变。

此操作不与“保存对话配置”混用，不写入局部命名模式、提示词或开关。自动首次命名仍由 Codex 持有，当前内容重命名是显式命令，不是后台每轮任务。产生标题候选的执行服务及原生回写尚未接入，原型只模拟生成 / 采用。

晚回结果不能自动覆盖手动输入，候选期间当前标题发生变化时重新核对；失败保留原标题，数据源未连接时输入保留但不宣称回写成功。无需停止主对话或重启才能设计标题操作；实际运行接入仍需验证。

## 5. 三项功能的第一轮内容

| 分区 | 常用字段与首轮默认 | 按需展示 |
|---|---|---|
| 命名模型（仅全局） | 仅选择全局模型或沿用原配置，命名触发继续交给 Codex | 查看真实辅助调用范围及未接通状态；不提供命名模式、提示词、开关或局部覆盖 |
| 联网搜索 | 先显示当前搜索路径，再显示适用的模型与推理；明确项目 / 对话覆盖是否接通 | backend 细节与支持范围；无模型参数的搜索服务不摆无效 LLM 下拉，原生 hosted search 不冒充 sidecar |
| 子 Agent | 默认模型意图、推理档位；推荐模型与默认模型分开显示，现有并发 / 公共指令按支持情况展示 | 已有角色、深度 / cap、V1 / V2 与权限说明；新角色 / 新权限不包装成已支持的通用编辑器 |

未接通字段可以保存已有对象的意图，具体说明哪个功能受影响，不能将全部表单禁用。命名、搜索、子 Agent 不各自建立第二套渠道 / 密钥输入。

## 6. 保存与实际采用反馈

界面分别显示配置保存结果与执行状态。命名模型仅在全局页报告路由接收 / 观察，Codex 继续按原有流程触发；项目页不出现命名状态。搜索和子 Agent 说明真实读取点，执行器未连接时不宣称必然生效；一个分区已采用不代表整页采用。

采用详情默认折叠，用户需要时查看对象、来源、实际模型和时间。普通成功用就地状态或短反馈，持续应用失败再进入通知中心。版本、schema、策略摘要、内部世代不成为常用表单字段。只有具体字段确需重启才出现对应提示。

刷新列表或连接状态不抢输入焦点，不清除当前对象。归档事件到达时，按已定清理规则收起编辑并说明“专属配置已清理”；如该对象存在未保存草稿，停止向归档对象保存，保留当前屏幕的临时草稿供复制或另存到有效对象，默认不恢复活动覆盖。它是短暂待处理输入，不是永久归档配置。取消归档继承上层，旧清理不删除后来新建覆盖。

## 7. 本地重装恢复与同步

对话页“配置工具”提供导出配置、导出重装恢复包、导入恢复包。配置导出只带设置；恢复包带所选历史与关联设置。入口复用同步页文件流程和树表，带入当前对象及返回位置，不新增另一套 WebDAV 页面，也不把恢复包藏在常规字段中。设置 → 数据与备份可以提供同一流程快捷入口，现有偏好备份范围仍独立。

范围较大时在完整文件工作区中预览，不使用多层弹窗嵌套对象树和映射表。流程分为：

1. 选择项目 / 对话与内容：未归档为默认候选范围，归档另选；当前选择带入，主 / 子记录、上层配置与附件依赖明确列出。
2. 预览大小与目的地：显示原始量、大记录、额外附件、目标位置及压缩后待计算；没有准确值时不显示虚构比例。目的地应能在重装后访问。
3. 导出进度与结果：可取消、失败保留选择并重试；完成显示包位置与包含范围，不自动执行卸载。
4. 导入读取与恢复：读取包 → 核对项目 / 工作目录 / 模型对应 → 恢复 → 结果。空环境恢复为主场景；已有数据时预览冲突和需要的新身份映射，不默认覆盖活动记录。

原生策略是保留身份还是生成新身份，由目标执行器实际恢复路径决定并反馈。已有探针证明新 ID 链路，不证明所有重装场景必须改 ID，也不据旧原 ID 声称已恢复；恢复关键是记录、项目关系和配置准确关联。部分完成分别显示记录恢复、配置绑定和可继续情况，重试不重复建对象，导入不自动开始模型任务。

同步页使用 **对话配置 / 对话历史** 两个独立范围，默认未选。选择配置不隐含上传内容，本地恢复包主动选历史不影响 WebDAV 的本机范围。新建连接、缺字段升级、预设重置及导入均不自动勾选。现有“全部配置”预设不能悄悄包含默认排除模块；增加类目时配套调整默认收集和 UI 文案。首批不要求实现 WebDAV 历史交换；未接入时说明并将恢复入口指向本地文件，不显示可上传成功的假功能。

## 8. 还有哪些未定项

没有需要等待用户回答的原型开工问题。下列事项保留为首轮可比较的建议，不将默认建议记作用户已批准：

| 未定项 | 首轮建议安排 | 后续收敛方式 |
|---|---|---|
| 全局命名模型接入范围 | 触发已确定沿用 Codex，仅配置模型 | 验证是否只匹配标题；不再要求用户选择命名执行者 |
| 子 Agent 高级范围 | 基础模型 / 推理及已知支持的并发 / 指令可见；已有角色按需展开，新角色 / 权限留待核对 | 用户查看原型后确定优先需要的高级项；执行器验证分别跟进 |
| 恢复的目标环境 | 首轮主线为重装后空环境；已有数据时保留冲突 / 部分完成场景，不默认覆盖 | 以隔离恢复证明身份、关系和设置能准确关联后确定正式恢复行为 |
| 多来源和全局影响范围 | 默认当前本机来源；只在确有多个来源时显示切换，官方实例级全局范围如实说明 | 实际适配能力决定可编辑范围；不凭 UI 将全局值伪装成局部 |

顶部两入口、窄窗列表进入详情和普通保存一次提交，也属于本轮设计判断，可在第一轮原型中直接检验。用户不需要先回答布局、控件或每项 schema 细节。

## 9. 第一轮原型交付与检查

后续直接在唯一总原型集成“对话”路由，登记本包“版本未定”范围，保留模型 0.2.0 及现有所有页面。原型使用虚构对象和容量数据；失败、归档与连接切换由右侧原型工具板驱动，产品页不放测试场景选择器。
