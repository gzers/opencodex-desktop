# 确认与回写

## 2026-09-12 确认结论

- 技术选型确认：Tauri v2 + Rust。
- 安装语义确认：只发现/展示/校验现有 npm 安装，不管理 npm。
- 数据根确认：支持选择/切换 `OPENCODEX_HOME`；管理器产物统一到自定义数据根并按结构划分；升级前备份。
- 启停确认：P0 直接托管 `ocx start / stop / restart` 子进程；不使用 launchd，不接管 `codex-shim`。
- 外部路由器结论：AiMaMi 等接管问题归 OpenCodex CLI 本身；桌面壳只检测、解释并引导用户确认后的官方 restore。
- 状态与日志确认：复用官方状态能力，状态枚举明确，日志只读、脱敏，离线时说明能力不可用。
- 配置迁移确认：全量导出，包括敏感内容；敏感内容必须进入加密容器；导入前校验、备份并确认。
- WebDAV 确认：全量同步，包括敏感内容；客户端加密；允许用户确认覆盖；覆盖前备份；冲突提示。
- 升级确认：不接管 npm，不替代官方 `ocx update`；升级前备份并引导官方更新。
