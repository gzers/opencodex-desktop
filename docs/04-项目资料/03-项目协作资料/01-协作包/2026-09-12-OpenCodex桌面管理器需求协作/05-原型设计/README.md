# P0 原型设计包

## 定位

本包用于验证 `DMD-OPENCODEX-DESKTOP-MANAGER` revision 2 的 P0 交互方向。原型只表达界面结构、状态流转和文案边界，不进入实施代码。

## 约束

- 只使用 mock 数据。
- 不调用真实 `ocx`。
- 不读取真实 OpenCodex 配置。
- 不触发真实启停、restore、备份或文件选择。
- 原型中的真实页面是官方 GUI 渲染后的源码级快照：保留真实 DOM、CSS、文案与层级，用于视觉对照；不请求运行态 API，不构成生产嵌入方案。
- 不记录、展示或同步任何真实凭据。
- 稳定交互结论后续进入 IMP 输入；本包不替代 DMD。
- 视觉与颜色体系向 OpenCodex 官方面板对齐，避免嵌入面板后割裂；OpenCodex 品牌色只做轻量识别。
- 根入口为 `index.html`，使用 hash 路由串联页面；原型按 1180 × 760 macOS 应用窗口表达。官方面板视图进入真正的全幅沉浸层：隐藏管理器标题栏与侧栏，让官方页面占满窗口内容区，仅保留最小悬浮操作。配置迁移、WebDAV 和升级为独立路由。
- 风格基准优先使用官方 GUI 构建产物中的设计 token 与源码级快照；截图仅作为视觉 QA 证据，不用作样式来源。

## 产物

| 产物 | 用途 |
|---|---|
| `index.html` | 可交互 P0 原型根入口；hash 路由串连概览、官方面板、安装与数据根、进程控制、日志、配置迁移、WebDAV 和升级 |
| `官方页面快照/` | 官方 GUI 渲染后的源码级快照与官方 CSS |
| `风格基准/design-tokens.md` | 从官方 GUI 构建产物提取的 P0 对照 token |
| `风格基准/官方截图/` | 官方源码级快照的 light / dark 渲染截图 |
| `风格基准/原型截图/` | 原型概览与全幅面板 light / dark QA 证据 |
| `p0-prototype.html` | 旧入口别名，自动跳转到根入口 |
| `state-and-flows.md` | 状态机、场景与交互说明 |
| `design-qa.md` | 设计 QA 与待确认项 |

## 覆盖范围

- OpenCodex 发现与安装状态。
- 统一数据根与 `OPENCODEX_HOME`。
- 启动、停止、重启。
- 健康、at-risk、外部 provider 接管、不可达、启动失败。
- 最近错误摘要。
- 日志查看与全幅官方面板视图。
- macOS 原生菜单结构示意。
- 管理器产物分区展示。

## 非目标

- 不完成 P1 配置迁移的最终交互。
- 不完成 P2 WebDAV 的最终交互。
- 不冻结 Rust 接口、状态字段名或真实目录名。
