    运行环境诊断

    调用官方 ocx doctor：默认只读，不修改配置、不设置代理、不改网络。

    尚未运行。Doctor 用于解释「为什么状态不对」：路径、WSL 挂载、代理环境变量、ChatGPT 可达性、Codex runtime 与 shim 状态。

    写入型修复（--reclaim-response-temps、--recover-zero-byte-coordinator --yes）需要先停止代理并显式确认，本原型只展示只读摘要。

    桌面壳偏好

    管理器自有行为、面板承载与通知。

    界面缩放
    外壳与官方面板使用同一缩放因子；支持 50%–200% 自定义，默认 100% 保持 1:1 CSS 像素。
    启动时打开主界面
    默认打开；关闭后仅启动代理托管，不自动显示主窗口。
    启动后自动打开面板
    默认开启；启动后直接载入官方面板，便于查看代理状态。
    面板打开方式
    默认内嵌到 App 窗口；加载异常时提供浏览器兜底入口。
    关闭窗口后保持代理运行
    桌面壳只隐藏窗口，不自动停止官方 OpenCodex 子进程。
    启停结果通知
    通知启动、停止、重启和失败结果；不展示敏感配置。
    同步冲突提醒
    检测到本地与远端冲突时暂停覆盖，并要求显式确认。

    官方共享配置

    与官方 OpenCodex 使用同一配置源；模型、路由与 provider 仍由官方面板或官方 CLI 管理。

    随 Codex 启动 OpenCodex 官方共享
    与官方面板同一配置；开启后 Codex 启动时自动运行官方 shim ocx ensure。修改会同步到官方配置，不做旁路写入。

    运行环境与安装发现

    只发现 / 展示 / 校验现有环境与安装。

    数据目录与 OPENCODEX_HOME

    自动发现当前路径，可在同一处统一修改。

    路径用途操作
    数据目录
    OPENCODEX_HOME

    数据目录分区

    分区名待 IMP 冻结；点击路径可复制，右侧可直接打开。

    路径用途操作
    桌面壳设置与偏好
    升级、导入、同步覆盖前备份
    管理器与运行日志
    加密导出容器
    可丢弃缓存
    同步与冲突摘要

    数据与备份

    备份边界基于安装配置里的数据目录。

    升级前自动备份
    进入官方升级引导前先生成可定位备份。
    导入前自动备份
    导入校验通过后先备份当前配置，再进入最终确认。
    同步覆盖前自动备份
    任何覆盖动作都保留被覆盖侧的可恢复历史。
    备份保留策略
    保留最近 10 份；超出的备份必须由用户显式清理。
    备份完整性校验
    生成备份后写入校验摘要；恢复前先校验。

    日志与通知清理

    自动清理只作用于管理器本地记录；不会清理官方 OpenCodex 服务日志。

    日志自动清理
    本地日志超过上限或保留期后自动截断；原始错误先保留摘要。
    通知自动清理
    已读通知超过保留期后自动清理；未读和 danger 通知不自动删除。
    启动时清理
    应用启动时按策略执行一次轻量清理，不阻塞主窗口。
    清理前备份摘要
    danger 日志和重要通知会先生成脱敏摘要，再进入自动清理。

    Skills 管理

    控制 Skills 源目录、同步与资产参与范围。

    Skills 源目录
    优先读取 cc-switch / Agent Skills 标准目录；也可选择自定义目录。
    同步方式
    软链接节省空间并实时联动；复制更稳定，适合迁移和备份快照。
    备份包含 Skills 目录
    升级前、导入前和显式备份时纳入 Skills 快照；软链接按解引用复制。
    导出包含 Skills 目录
    配置迁移导出时纳入 Skills；导入前先生成可恢复快照。

    MCP 管理

    统一管理 MCP 写入策略与目标。

    同名冲突策略
    目标客户端已有同名 MCP 时暂停写入，展示差异并要求确认。
    MCP 配置落点
    按客户端适配器写入各自 MCP 配置节点。
    敏感值脱敏
    URL token、headers、env 和 API key 默认掩码展示。
    备份包含 MCP 配置
    备份快照纳入受管 MCP 定义；凭据仍进入加密容器。
    导出包含 MCP 配置
    迁移导出纳入 MCP 定义；导入前先备份目标客户端配置。

    配置迁移

    全量导出 / 导入；敏感凭据只进入加密容器。

    导出范围
    provider、路由、模型映射、启动相关设置与凭据全量导出。
    导出加密
    使用用户口令保护容器；具体算法待安全评审后冻结。
    导入流程
    校验容器 → 备份当前配置 → 展示掩码摘要 → 用户确认。

    WebDAV 同步

    端点、凭据与冲突策略集中在设置里维护。

    冷同步
    运行中不直接写关键文件；覆盖前需要用户确认。
    客户端加密
    含敏感内容的对象先在本地加密，再上传到 WebDAV。
    覆盖前备份
    保留被覆盖侧快照，冲突时可恢复。

    CLI 控制面

    让终端、脚本或 AI 代理控制本应用的自有域；不提供改写 OpenCodex 配置的通道。

    启用 CLI 控制面
    默认关闭；开启后注册本机命令入口。CLI 仅作为运行中实例的客户端，经本地 IPC 委托执行。
    运行中实例
    GUI 正在运行时才接受状态变更；实例未运行时只读命令明确报错，不做旁路写入。
    在线
    Agent 提示
    管理器用 ocxd；OpenCodex 自身配置仍用官方 ocx。命令能力先 ocxd --help。

    开放能力

    发现与只读状态、启停、数据目录、备份、加密导出 / 导入、WebDAV 同步、自更新检查。

    明确不开放

    provider、路由、模型映射等 OpenCodex 配置仍走官方 CLI（ocx）；管理器 CLI 不做第二个写入者。常用入口见下方「OpenCodex 配置 · 官方 CLI」。

    先看帮助

    ocxd --help
ocxd status --json

    --help 列出当前版本实际支持的命令与参数；脚本和 Agent 用它自发现能力，不硬编码命令集。

    管理器自有域示例 · 非最终契约

    ocxd status --json
ocxd start --json
ocxd stop --json
ocxd restart --json
ocxd backup create --json
ocxd export --confirm --json
ocxd import --confirm --json
ocxd sync run --json

    变更层命令需运行实例与显式确认；破坏性操作必须带确认标志，备份语义与 GUI 一致。命令集待 IMP 冻结，当前仅为 mock 示例。

    OpenCodex 配置 · 官方 CLI 速查 · 非最终契约

    ocx --help
ocx status --json
ocx restore
ocx update

    provider、路由、模型映射等自身配置不属于管理器 CLI；桌面壳只展示入口和检测到的接管 / at-risk 状态，不代理或包装写入动作。

    管理器 CLI：ocxd（先 ocxd --help；仅限管理器自有域）
官方 CLI：ocx（provider / 路由 / 模型映射）
规则：变更先确认；破坏性操作带确认标志；用 --json 校验输出。
