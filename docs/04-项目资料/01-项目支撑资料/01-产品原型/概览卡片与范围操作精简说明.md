# 概览卡片与范围操作精简说明（0.2.18 · 2026-10-31）

本说明只覆盖概览三张卡与同步范围工具栏的本轮原型调整，供评审与后续开发对齐。原型仍为内存演示，不读写真实文件、不连接 WebDAV、不执行加密。

## 判断依据

用户连续提出三点：卡片上的固定说明（“可选对象 / 独立选择”“较新覆盖”）没有信息量；“有可用更新”看不出具体版本；范围工具栏的预设下拉与“清空选择”和“记住最后一次勾选”重复。结论是概览只承担状态与直接动作，规则说明进“原型”标签。

## 三张卡

### 版本升级

- 左侧只写对象名（管理器 / 面板），右侧只写最新线上版本，例如「管理器 …… 0.1.10」；未检查时版本位显示「—」，不使用「当前 → 最新」的双版本写法，也不再写「有更新 / 已最新」这类短语（2026-10-31 用户更正）。
- 状态点紧跟版本，按统一语义取色（2026-10-31 二次更正）：ok 绿=有更新、idle 灰=已一致、info 蓝=进行中、error 红=失败；**未检查不画点**，右侧只留「—」，不写「尚未检查」。当前版本、候选差异等完整信息仍在原更新结果与详情里。
- 点击整行仍进入原更新详情；头部不再重复一枚「有更新」标签，避免与行内状态重复。

### 文件同步

- 只显示“最近导入”“最近导出”，值为“HH:mm · N 项”，失败时追加“未完成”；首次为“尚未导入 / 尚未导出”。
- 动作收敛为「导入」「导出」两颗按钮，都用已记住的范围直接执行；不再有「选择同步范围」，避免从卡片跳走。
- 导入 / 导出完成后由同步模块派发 prototype:sync-activity，卡片只更新事实，不写规则文案。
- 固定规则（范围、凭据、默认不加密、演示口令）收进“原型”标签。

### WebDAV

- 只显示两行：连接状态、线上版本。线上版本行为「线上版本 …… ● 11:02 · 双向更新」，方向与时间合并在同一行，不再单独占一行（2026-10-31 用户更正）。
- 方向：绿 ↑ 待上传、蓝 ↓ 待下载、蓝 ↑↓ 双向更新、灰 ● 已一致、琥珀 未完成；由所选对象新旧自动判定，不额外确认。窄卡内整行锁单行，不折行。
- **未配置 / 未连接 / 连接失败时，线上版本只写「—」，不画点、不写「未连接」** —— 没有数据不等于一种状态。

### 状态色（唯一口径）

| 语义类 | 令牌 | 用途 |
| --- | --- | --- |
| ok | `--green` | 有可用更新、待上传 |
| info | `--blue` | 进行中、待下载、双向更新、待重启 |
| warn | `--amber` | 部分完成、未完成 |
| error | `--red` | 失败、连接失败 |
| idle | `--muted` | 已一致、未连接、无操作 |

已写入 `docs/02-项目核心/UI规范.md` §2.5，作为全项目唯一口径：一个语义一个色；一个状态一行最多一个 7px 圆点；未加载只显示占位「—」；正文标签保持 `--muted`，只有数值与状态短语吃语义色；不得为某个页面新增局部色值。

 - **侧栏与卡片标记（2026-10-31 三轮反馈）**：`.nav button.active` 不再加 `font-weight:600`，改用底色 + 文字色区分选中——两字中文标签加粗后会被读成“字号偏大”，实测 8 项统一 14px/400/21px；`.mod-head` 的 12px 上内距已移除，「原型」标记改为相对整张卡片绝对定位（`#mods .mod{position:relative}`、`.mod-head{position:static}`），浮在卡片上沿，既不把标题行顶下去，也不压住右上角 ⋯。- 排版：三张卡状态区只有一种字号、字重、字色（`.mod-status *` 统一 `font-size:inherit` + `font-weight:400` + `color:var(--text)`；紧凑窗同为 11px）。标签与数值靠左右位置分主次，不再用字重或灰度区分 —— 中文 Semibold 在近黑底上会明显显大，这是本轮“字体大小不一致”的真正原因。版本行不再写死字号，圆点与文字同 18px 行高垂直居中。
- 主按钮统一为「同步」；未配置时只留「配置 WebDAV」，连接失败只留「重试连接」。
- 状态测试器新增待上传 / 待下载 / 双向更新三档，其余档位保留，便于评审逐一查看颜色与文案。

## 范围工具栏

- 删除预设下拉（默认 / 分享 / 换设备 / 自定义）与「清空选择」。
- 保留搜索框与表头复选框（全选 / 取消当前搜索结果的勾选）。
- 文件导出范围与 WebDAV 范围分别自动记住最后一次勾选及凭据选择，再次进入直接沿用。
- 勾选变化仍会清理失效项（对象被移除后的残留 ID），这是数据一致性，不是额外确认步骤。

## 验证

- 新增 overview-cards.test.cjs 覆盖：卡片只显示最近事实、导入/导出后写时间与项数、WebDAV 五档方向与颜色类、工具栏只剩搜索与表头全选、最后一次勾选沿用。
- 相关回归：maintenance-ui.test.cjs、sync-file-authority.test.cjs、prototype-annotation-contract.test.cjs、component-topic.test.cjs，合计 76 项通过。
- 实屏：Chromium 与 WebKit 在 1180×760 浅色、900×600 深色下，三档画质各 72 项状态色与排版检查通过（含未加载只显示—、三卡同一字号字重字色、圆点与文字同心、颜色取自令牌），无页面错误；卡片等宽、无溢出，“原型”标记不再压住标题与状态。

## 边界

- 本轮只改原型与清单；正式软件、真实文件/WebDAV、Windows 原生、通知持久化均未执行。
- 概览“线上版本时间”为演示快照时间，不代表真实远端时间可读；方向仍按所选范围自动判定，没有新增手选冲突侧。
