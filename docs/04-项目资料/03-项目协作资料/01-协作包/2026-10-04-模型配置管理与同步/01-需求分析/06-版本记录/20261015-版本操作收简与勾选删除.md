# 版本操作收简与勾选删除

日期：2026-10-15（延续 2026-10-14 讨论）。项目：opencodex-desktop。产品：OpenCodex 桌面管理器，模型配置 0.2.0。

用户已同意取消过多的版本维护概念，只留查看／编辑、设为默认及删除。唯一入口：[总原型 #models](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。本轮落实界面、操作逻辑与规格，未修改生产代码。

## 页面与变化

| 入口 | 调整与边界 |
|---|---|
| 版本管理每行 | 只显示查看／编辑、设为默认、删除；移除归档、手动保留和相关旧事件 / 元数据限制 |
| 查看／编辑 | 直接打开选中保存版本的编辑页；正文修改后另存新版本，不改变默认、采用或渠道策略 |
| 设为默认 | 单独确认后决定以后采用时的预选；已有配置继续引用原精确版本，当前编辑版本不因设默认而被替换 |
| 删除 / 删除所选 | 每行勾选，顶部全选当前结果中可删除的版本；搜索外勾选保留，批量确认展示全部准确名单；取消不删，确认时整个基准 / 依赖计划重新核对，有变化整批拒绝 |
| 自动保护 | 系统初始 / 当前内置基线、默认、保存 / 草稿引用、恢复记录与编辑 / 待审 / 执行任务依赖仍保护；不可勾选，不提供绕过保护的整模版删除入口 |
| 版本数量与旧概念 | 移除普通版本10个清理阈值、清理入口和阈值提示；不按数量自动删除。短下拉仍最近5加当前/默认去重，版本管理查看全部。旧格式元数据的正式兼容另行冻结，本轮没有持久数据迁移 |
| 注释与文案 | 标签04 / 07 / 09 更新三类动作与自动保护规则；保护行仅显示必要说明，完整原因在提示中，仍沿公共折叠注释，无新通知 |

规格同步至[UI规范](../../../../../../02-项目核心/UI规范.md)、[数据与状态 §6](../../../../../../02-项目核心/数据与状态.md)、模型页交互细化与[0.2.0 开发范围](../../02-开发实施/README.md)。前序归档 / 保留 / 清理记录仅代表当时方案，当前以本轮规则为准。

## 实际验证与未完成项

调整已有版本列表与生命周期测试，覆盖三类动作、查看与默认指针区别、不可改写历史、直接 / 批量删除、取消、全选自动排除保护项、搜索外勾选、过期基准整批拒绝、最后一批无引用自建版本删除与旧动作失效。主模块语法与完整原型 Node 回归 223 项通过，沿 --jitless 串行 TAP；JS / CSS 资源标记 20261015-version-actions-simple，CSS 解析、新链接与 diff 格式检查通过。

浏览器文件访问限制仍在，未重试或绕行；布局、勾选与确认后的焦点恢复需补实屏验收。当前只有内存 mock，实际持久化、正式旧格式迁移和删除事务由 0.2.0 WP-02 / 03 / 05 实施与验证，不能由本轮原型测试推断完成。
