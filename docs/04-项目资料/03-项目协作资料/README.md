## 约定

1. **协作包命名**为 `<日期>-<主题>`：日期取协作开始日，主题描述这次协作要解决什么，不用项目名替代主题。
2. **包根只放一个 `COL-*.md`**，其余材料都在包内编号目录里。
3. **包内一级目录按软件生命周期阶段划分**：`01-需求分析` → `02-开发实施` → `03-测试验收` → `04-发布交付` → `05-运行维护`；阶段内再分输入、过程与产物。
4. **每阶段有 `README.md`** 做索引；未开始的阶段保留槽位并声明状态。
5. **协作包不是事实源**：稳定结论回写需求或项目核心，实施契约另建 `IMP`。
