# 0.2.1 UI修复验收矩阵

2026-10-21。状态：**修复条件已执行，实际结果见问题清单及源绑定回执**。实施顺序与范围以[IMP-22](../../../../../03-开发实施/IMP-OPENCODEX-DESKTOP-22.md)为准，编号与关闭状态只维护在[问题清单](../05-运行维护/20261021-0.2.1-UI问题清单.md)。本文件定义检查，不维护第二套通过状态；后续实际结果引用源绑定的执行证据，不预填PASS。

## 1. 逐问题的最小关闭条件

| 问题 | 必须观察的正式软件结果 | 必须保护的行为/补充用例 |
| --- | --- | --- |
| UI-001 渠道表 | 独立必要宽度的选择列；表头/行同列；模型数/启停/动作不被空白选择列挤坏 | 长渠道名与两/三位数量；选择≠启用；排序与完整结果不因列宽改变 |
| UI-002 模版表 | 选择框独立窄列，名称/来源/摘要有序，版本和动作有合理空间 | 内置/自建、长名称/版本、搜索后保留范围；不重新引入隐藏模版 |
| UI-003 图文按钮 | 收起导航及各操作的图标/文本居中、gap一致；加载/禁用不跳动，收起态无裁切 | 检查UiButton全部受影响调用点；键盘名称/提示、焦点、点击区域有效 |
| UI-004 卡片栈 | WebDAV上下外卡片及适用嵌套块有统一间隔，非靠各卡补重复margin | 与其他页面共用纵向布局；窄窗/缩放不贴合或双倍间隔 |
| UI-005 外层范围 | 文件/WebDAV主页面有预设/搜索/对象树/凭据区；WebDAV有连接摘要和按需设置 | 详见第4节，不能只验证范围弹窗仍能打开 |
| UI-006 动作归属 | 列表工具栏和详情动作按上下文显示，详情侧栏无顶部重复预览/保存 | 保存作用范围不变；草稿/未确认输入保护及返回上下文不丢 |
| UI-007 型号密度 | 搜索/筛选/结果/展开与排序按工具栏组合；同值显示名不重复，摘要紧凑 | 展开编辑、别名、公开范围、手动ID、筛选/完整排序、启停仍可达 |
| UI-008 版本身份 | 详情首屏可识别来源、所选版本/基准和当前编辑状态，并可达相应版本操作 | 脏缓冲切换受保护，默认/采用不跟着浏览版本改变，状态取真实值 |
| UI-009 摘要主次 | 连接/节点/默认配置先可理解当前概况，按需编辑，不用全量表单挤走型号主内容 | 凭据脱敏、安全连接确认/重新取清单/取消规则保留；不暴露Key |
| UI-010 字段组合 | 协议/能力/推理分组，继承/自定义/未知、单位和来源清楚，同类编辑器同源 | 字段null/空列表/未给值、默认档与人工锁、父层/单模型覆盖语义不变 |
| UI-011 执行配置 | 模版列表与设置有原型约定的常驻入口，助手/批量复用同一配置源 | 保存返回原输入、不改渠道草稿、不触发生成；未配/失效/禁用有真实状态 |
| UI-012 画质选项 | 高/中/低及WEBGL/CSS按公共分段配方直接可见，选择/焦点明确 | 即时生效与偏好恢复不变；窄窗降级有依据；不能默认改用户画质 |
| UI-013 Tab组合 | 分隔线覆盖Tab+动作区域，内部透明，主Tab/详情头滚动避让正确 | 换行/缩放/长标题复测；高中无彩色底纱，低档/无blur回退合法 |
| UI-014 侧栏保存 | 导航/辅助操作可滚；主保存与状态稳定可见/可达，展开收起保持当前位置 | 默认1180×760与紧凑窗；键盘可达；不靠顶部复制动作解题 |
| UI-015 概览信息行 | 同环境量取三卡同级字号/字重/行高；版本行文字/箭头到hover背景边缘有内距，普通行对齐 | 正常/hover/focus/disabled、长版本号、紧凑布局；增大仅调整相应公共文本层级，不无依据全局放大 |

## 3. 环境与状态覆盖策略

基准为1180×760、100%、亮色高档。生产渲染按真实窗口与实际缩放，不把2360px截图当2360逻辑宽，也不把原型缩放当生产缩放。

| 维度 | 最小安排 | 适用/边界 |
| --- | --- | --- |
| 主题/材质 | 所有受影响公共配方覆盖亮暗×高/中/低；至少各一实际消费者交叉检查 | 所有受影响页面基准对照；风险区域额外交叉，不跑全页全状态无意义乘积 |
| 尺寸/缩放 | 1180×760/100%全部问题；900×600/100%检查紧凑；150%检查模型详情/表格/同步/浮层 | 50%/200%在公共配方与溢出敏感消费者抽查；适用项仍不得裁切关键操作，写清未测组合 |
| 长内容 | 长中文/英文、ID、版本、渠道名、错误，空/未知/多值 | 长值有全文出口，不挤坏邻列；不把全部按钮文案拆字换行 |
| 交互状态 | normal/hover/focus/active/disabled/loading/read-only/error/empty的适用子集 | 相邻状态不跳动；键盘、可读label、Escape、焦点返回、收起/放大要实测 |
| 平台 | macOS原生应用的改动页面；Windows真实WebView/壳内的受影响布局与输入焦点 | CI构建不能替代可见检查；托盘/标题栏没有受影响则复用旧证据并写依据 |
| 材质回退 | 无blur支持/渲染失败时的合法实底及层级，至少代表组合 | 不能把低档实底报为偏差，也不能以全部降低档掩盖高档缺陷 |

原型对照图需同逻辑宽/缩放/主题/画质与相近数据状态，记录控件/区域差异及允许的数据差异。原型漏绘或截图未稳定须重拍；不得把截图缺失当产品缺功能。几何断言容差沿公共Token/字体环境量取后固定并记录，不能临时放宽到覆盖明显错位。

## 4. 同步外置及模型重排的必要功能回归

### 同步（UI-005）

1. 文件页直接可见范围，预设/搜索/全选与筛选外选择/清空行为一致；凭据默认及独立保护不变，选范围本身不写配置。
2. 文件导出按外层范围形成冻结清单；预览后改变范围/基准有明确重新准备行为，不混用快照；取消不导出/不改变运行态。
3. 导入先读取包，子集来自包内对象；缺section不清本机，外层导出范围不限制或扩大导入授权；依赖/冲突/必要解密与采用确认保留。
4. WebDAV区分编辑中的本机范围、已保存范围和实际传输/待采用；连接按需修改/测试/取消，不因范围改动发送请求或重置端点。
5. 下载成功≠应用成功，冲突/备份失败/取消/部分结果不虚报已同步；恢复及重新读取使用同一状态源，凭据只在原保护边界内参与。
6. 账户仅受支持信息，同平台/来源/多账户选择仍如实；不恢复免登录承诺。测试使用隔离目录和本机WebDAV fixture，禁止用户真实服务器/账户。

### 模型/版本/执行偏好（UI-006～UI-011、UI-014）

1. 列表/详情/Tab/锚点/侧栏/字段布局变化不清缓冲、已选集合、排序或未确认输入；脏缓冲切版本/对象按既有保护。
2. 详情侧栏保存、列表全集保存与模版保存仍是原有作用域，保留差异确认、冻结基准、备份、读回、待重启/待核对的真实结果；必要时用隔离fixture走一条实际保存链，不仅mock按钮。
3. 继承/自定义/默认推理/Fast、人工锁与来源展示读同一规则源，未知不补能力，布局组件不拥有解析/提交逻辑。
4. 共用执行设置从多个入口回读一致，取消/保存返回原输入，未配置/失效正常解释；不发送付费生成或真实外部任务。

以上只重跑受影响链路；不要求重复全部旧版模型、账户、长期性能和OTA测试。若实现改动触及服务/IPC，则相应扩大回归并说明依据。
