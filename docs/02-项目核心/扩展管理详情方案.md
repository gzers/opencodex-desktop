## 1. 目标与现状

扩展页列表每条只显示「名称 + 一行状态 + 两行描述」。而真实条目天然是长内容：

- Skills 的正文是 `SKILL.md`（Markdown：标题、列表、表格、代码块），描述只是其中一段；
- MCP 条目的关键信息是 `command` / `args` / 配置落点，属于[领域模型](领域模型.md) §12 的**待执行指令数据**，必须完整可见才能判断风险。

因此列表不足以支撑「看清这一条到底是什么」，需要一个**只读详情**入口；同时列表动作（更新 / 卸载 / 编辑 / 删除）必须能明确作用于**单条**。

当前实现状态：原型已完成该入口与详情弹窗（Skills 与 MCP 共用一套机制）；生产侧尚无「读 `SKILL.md` 正文」「统计目录文件数与体量」「回读 MCP 命令与落点」的读取器。

## 3. 交互规则

- **入口**：整块「名称 + 描述」单元格可点开详情，**不是整行**——行的其余区域归各客户端开关与行内动作，避免误触。
- **可点击提示**：只有指针变化 + **描述被截断时的底部颜色渐隐**（`mask-image`，只给真被截断的那条）；不加边框、外框、下划线与提示文字。
- **焦点**：单元格按 `role="button"` + `tabindex="0"` 处理，`Enter` / `空格` 与点击等价；关闭后焦点归还。焦点状态同样用「文字提亮」表达，不画外框。
- **弹窗结构**：标题（条目名，右上角为该条目的动作按钮）→ 描述面板 → 信息（两列）→ 各客户端同步状态 → 「关闭」。
  - 标题动作是**图标按钮**（Skills：检查 / 更新 + 卸载；MCP：编辑 + 删除），中文动作名走 `title` / `aria-label`；**描述只出现在正文面板内**，标题下不另起描述段。
  - 描述面板带外框与加深底色，**独立滚动**；弹窗用纵向 flex 让描述吸走剩余高度，信息 / 状态 / 底部操作固定，**只有一层滚动条**。
  - **不设区块小标题**：面板有框、信息区无框两列、状态区是格子按钮，形态本身已分区。
  - **信息区标签固定列宽**（`4em`），取值从同一列起；路径与长名单整行，MCP 的「环境变量」在取值框内自带滚动，避免撑高信息区。
- **Markdown 渲染**：描述面板按 Markdown 渲染（标题 / 有序与无序列表 / 引用 / 围栏代码 / 加粗 / 行内代码）。渲染前**先整体转义**，正文里的 HTML 不作为标签执行；链接只保留文字，不生成外链。
  - **frontmatter 不进正文**：`SKILL.md` 开头的 YAML frontmatter（`---` / `name:` / `description:`）由读取器剥离——`name` 与 `description` 已经在弹窗标题与信息区展示，作为正文渲染会与描述重复；剥离只在开头是完整 frontmatter 块时进行。
- **各客户端状态可切换**：格子在「已同步 / 未同步」间切换，并**写回列表行的同名开关**，同一份状态不出现两个说法。
  切换的作用域是**这一个客户端**：亮 = 建立/存在指向源 Skill 的链接，灭 = 断开该客户端的链接（源头只读，绝不删改源目录；见 `UI规范.md` §13）。
- **标题动作按条目类型给**，与行内动作同源：Skills = 检查 / 更新 + 卸载；MCP = 编辑 + 删除；动作**点名当前条目**。
- **单条与全部必须分开**：单条「检查 / 更新」**就地更新这一条**，不弹「全部 Skill」的窗；批量检查是独立入口，二者可更新名单同源。
- 详情为**只读**：不在详情内编辑配置；编辑仍走各自的编辑流程。

## 4. 读取与开销边界

- 列表**不预读**正文：进入扩展页只渲染列表字段，`SKILL.md` 正文只在打开详情时读取，且只读被打开的那一条。
- 正文设显示上限并标注截断；不做全文搜索、不建索引、不常驻缓存。
- 目录统计（文件数、体量）按需遍历，设条目数上限与超时；越界或超时如实报「未知」，不伪造数字。
- 不后台轮询、不监听文件系统、不在打开列表时批量读取 MCP 配置文件。
- 展示层**不执行**任何 MCP 命令；`command` / `args` 只是文本。

## 5. 安全与掩码

- `env` 值、`args`、`headers` 一律按潜在敏感值处理：详情展示同样掩码，**不因「查看」而放宽**；`env` 只展示键名。
- 详情不得进入日志、错误信息或通知正文的敏感值部分。
- 打开详情不构成任何写入授权；写入仍须备份、原子替换与显式确认（见 [集成与安全边界](集成与安全边界.md) 与 `AC-11`）。

## 6. 原型范围与验收

原型使用明确标记的虚构数据，不读取用户文件、不调用真实客户端配置。

- 原型必须覆盖：两类条目（Skills / MCP）都能点开详情；Markdown 渲染含标题、列表与围栏代码块；截断渐隐只在被截断时出现；单元格键盘可达；弹窗不越界、正文无横向溢出、**只有一层滚动条**；暗色主题；最小窗口 900×600 与默认窗口 1180×760；各客户端状态可切换并写回列表；标题动作与单条 / 全部语义；卸载 / 删除点名当前条目。
- 原型级验证记录与证据见 `04-项目资料/…/05-原型/README.md` 与 `文档/截图/原型-扩展Skills详情-20260923/`；**原型通过不等于生产验收**。

### 后续真实验收

1. 读真实 `SKILL.md`：确认按需读取、只读被打开的一条，正文渲染不执行内联 HTML。

6. 打开 / 关闭详情不产生常驻内存增长，也不新增后台任务。

## 8. 多平台管理的新设计（2026-11-04）

本节是用户在多平台专题中确认的新增设计，应用于后续双视图。前文六客户端的历史实施状态和逐 Skill 链接契约不据此认定已迁移；本节只有总原型，真实发现、文件与更新行为待专项实施。来源与证据见[多平台原型说明](../04-项目资料/03-项目协作资料/01-协作包/2026-10-14-多Agent平台扩展管理/01-需求分析/05-原型/README.md#2026-11-04-映射前置平台检测与手动安装路径)。

1. 安装识别是管理前置。未发现平台置灰，不参与 Skills / MCP 的行内、批量及资源详情操作，标题和配置路径可达。检测失败保留上次结果；当前平台消失时右侧锁定。
2. 检测不到允许指定该平台应用 / 可执行文件路径，先查路径、权限及程序身份；验证不自动加入，显式确认后加入。编辑路径撤销验证，重扫保留手动位置。身份不明和不支持的功能继续阻止。
3. Skills 还须目录映射。共享源映射到平台原目录；原目录须空，文件需先备份清空，其他链接或无权限均阻止，创建前再次检查。未映射不能切换进平台 Skills，平台详情可映射；MCP 按自身支持和安装状态管理。
4. 目录整体映射后已映射平台读取同一源，Skill 源状态变化对它们同步生效。实施须明确迁移旧逐条投影契约，保留备份和真实映射回读；不能把整体目录映射当成各平台独立单条开关。
5. 左侧无复选框和更多，标题查看详情。右侧平台表原始路径单列，图标跨名称与安装状态两行，左侧平台无图标。安装状态与映射状态分开。
6. 平台详情含身份图标、安装检测、版本读取 / 检查 / 确认更新、Skills 映射和配置。未安装禁用版本和映射；版本失败保留现有值，可重试。查看型右上关闭，受限内容单层滚动。
7. 原路径打开系统文件管理器。macOS / Windows 的实际路径、主目录展开与链接方式由 OS / 平台适配器解析，显示路径不得拼成 shell 命令。原型仅演示访达 / 文件资源管理器，不执行文件操作。

8. 资源列表按名称升序。平台先已发现（含手动加入）、后未发现，各组按名称升序；忽略字母大小写，数字按自然顺序。两视图与检测结果使用同一规则，搜索保持顺序；检测和手动加入改变发现状态后自动重排，当前对象按 ID 保留。


## 9. 拓展同步与本机接入边界（2026-11-04）

本节为本轮确认的多平台设计增量，仅总原型接入，不变更历史生产交付事实。来源、可操作入口与证据见[协作包同步记录](../04-项目资料/03-项目协作资料/01-协作包/2026-10-14-多Agent平台扩展管理/01-需求分析/05-原型/README.md#2026-11-04-拓展与同步共用数据及跨设备边界)。

- 传输 Skills 内容、相对路径资源、来源、版本和共享源启用状态；共享源只保存一份，映射目录不作为重复内容打包。MCP 同步统一定义、目标平台与启用关系，凭据独立选择。本机程序 / 文件目录引用使用可移植绑定，实际路径保留在各设备。
- Agent 平台首次默认选中全部已发现项，只显示本机已发现的平台，携带平台稳定 ID；后续沿用本机选择。Agent 平台范围同时决定本次 Skills / MCP 是否参与同步，无平台选择则排除这两类内容及凭据，其他配置仍可同步。界面仅选择本次范围，原始路径与是否映射是本机只读结果，不设作为目标配置。关联与本机已安装 / 已映射为不同事实。平台安装路径、手动路径、发现、安装版本、更新结果、权限、目录判定、映射链接和备份位置均留在本机。内置图标和平台适配随软件维护。
- 文件导入 / 导出与 WebDAV 共用同一拓展数据源。内容修改参与保存版本，检测和路径等本机变化不造成内容版本更新。预览冻结对象与来源内容，提交前校验内容 / 范围 / 连接变化，更新前备份，未选对象保持。
- 下载先保存内容及所选配置，再按本机平台支持、安装、Skills 映射及 MCP 路径检查可用性。缺条件不丢定义，不自动安装、更新或覆盖原目录；内容完成和平台接入待处理分别报告，提供拓展页处理入口。单项内容失败仍可重试。
- Skills 使用共享源统一启停，不传旧逐平台独立启用矩阵。旧包需显式版本转换，转换未实现时保留本机并报告；不能仅因解析成功就覆盖新状态。MCP 关联只在本机条件满足后参与管理。
- 当前 schemaVersion 2 是原型字段合同示意。生产协议、旧包兼容转换、实际载荷校验 / 秘密处理和原生资源写入须后续冻结实施，不由原型内存结果认定完成。



### Agent 平台选择与映射结果（2026-11-04 最新纠正）

同步页只选择本次传输的平台关联，不编辑“作为目标 / 不作为目标”。仅列本机已发现平台，逐平台显示原始路径及已映射 / 未映射结果；未发现不显示，检测消失从记忆范围移除，手动验证加入后重新出现且不自动勾选。拓展页保留完整平台目录，负责检测与手动接入。

平台映射不是内容同步前置：已发现而未映射可同步内容和关联，使用该平台 Skills 前再映射。至少选择一个 Agent 平台后才同步所选 Skill 内容；未映射仍不阻止内容保存。界面说明明确区分“同步无需先映射”和“使用 Skills 前需映射”。接收设备重新检查安装、路径与目录条件；原始路径和映射事实不跨设备复制，同步不创建或解除目录映射。

选择范围对应稳定平台 ID，原型字段为 schemaVersion 2 / kind=skill-platform / platformId，不携带 desired、安装或映射状态。原目标编辑和整份名单被本轮取代，旧对象需转换；生产协议与真实处理仍待实施。执行时部分平台消失仅跳过对应关联；所选平台全部消失时拓展内容也跳过，其他配置继续同步。来源与证据见[协作包最新纠正](../04-项目资料/03-项目协作资料/01-协作包/2026-10-14-多Agent平台扩展管理/01-需求分析/05-原型/README.md#2026-11-04-skills-平台只选择并显示本机结果)。


### Agent 平台作为拓展同步范围（2026-11-04）

Agent 平台首次默认选全部本机已发现平台，后续沿用记忆选择。Agent 平台和拓展内容是两层范围：前者决定涉及的平台，后者选择 Skills / MCP 对象。未选任何平台时两类内容和凭据不进入预览 / 导出 / 导入，禁用内容选择并说明；其他配置仍可同步。恢复平台后恢复先前内容选择，无需重新勾选，不改变本机映射。

平台范围随预览 / 执行冻结；未选平台的 MCP 启用关系保持，导出过滤、接收端按所选平台合并，不全量替换关联。Skills 是共享源，内容 / 源启用变化仍影响所有已映射平台，预览必须说明，不能承诺未选平台隔离。文件导入默认选择包内可用平台，取消全部平台时不导入 Skills / MCP；依据最新协作记录，此条取代此前默认不选和无平台也可同步内容的规则。真实安装、映射与路径仍留在本机。
