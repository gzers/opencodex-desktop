## 目录结构

| 位置 | 对象 | 内容 |
|---|---|---|
| `01-项目支撑资料/` | `EVD-*` 及产品原型 | 判断与追溯用的支撑证据、产品交互原型、非敏感访问边界与迁移审计 |
| `02-项目知识库/` | `KNOW-*` | 已稳定、可复用、可被后续需求或实施引用的知识材料 |
