## 决定与实现边界

已确认行为的唯一规范为 [UI 规范 §26](../../../../../../../02-项目核心/UI规范.md)，需求为 DMD Revision 15 的 REQ-32／AC-17，派生与持久化边界见契约字段 §9。原建议“保留系统降档并提示原因”及“增加独立动态选项”不再作为实施方向。

`4bc0a39` 确认的是旧实现为何停止动画；这一运行因果仍成立，不等于用户认可该策略。旧系统高降中逻辑现需按新决定修改，中档 WebGL 静态首帧取消仍须独立修复。CSS 硬边和下拉玻璃也不因取消系统降档而自动解决。

本轮仅修订需求和文档，未修改原型或应用源码、未实测 Windows、未产出修复安装包。现有通过结果不自动覆盖新规则；原文档和源码中系统减少动态处理需在后续实现时逐项核对，不可仅改设置文案。标题栏／Mica／菜单栏适配维持其独立维护范围。

## Windows 设备仍需完成的排查与复验

1. **下拉玻璃根因**：用隔离实例复现“界面特效”菜单清晰穿透下一行文字；记录 EXE 版本／提交／哈希、Windows 构建、WebView2、GPU、权限和缩放。采集菜单与祖先层的填充色、`backdrop-filter`、层叠上下文、裁剪及像素截图；对照两主题与三档，区分 CSS 声明存在和真正模糊合成，必要时与 macOS 同场景配对。不用原生 Mica 解释页面菜单玻璃。
2. **新策略实机复验（待代码修改后）**：系统减少动态开／关各测高／中／低 × WebGL／CSS。高档前台 SVG 与光场应真实推进，中档静态光场应可见并在状态／颜色／尺寸变化时按需重绘，低档实底无光场；档位切换／重启回读一致。系统设置不改变同档策略，隐藏／最小化／托盘及回到前台的暂停恢复正常。记录连续帧／视频和绘制证据，不以 rAF 心跳代替实际运动。优先在隔离实例模拟媒体条件，若要改变系统设置，先保存原值并结束后恢复。
3. **光场软边与性能（待修复后）**：CSS 渐变／遮罩在边界前透明，WebGL 另做配对；准备／就绪及九态、两主题验证无弧形或矩形裁切硬边。临时 `blur(20px)` 只是因果对照，不能直接替代性能验收；保留既定前台帧预算与后台暂停门禁。
4. **设备覆盖与交付**：当前证据是 Windows Server 2025，不能代替 Windows 10／11 验收；修复候选补普通／管理员、100%／150%／200% DPI 下菜单可读性、选择／关闭／键盘与首屏。必要 WebGL 失败／CSS 回退单独记录，不改写用户档位。证据与结论在 docs 分支，源码在实现分支；使用隔离数据根与 WebView 目录，不替换日常安装。发布仍另行确认。
