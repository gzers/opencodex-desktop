日期：2026-10-08（Asia/Shanghai）。状态：当前主原型已补绘，源码与资源 / 语法检查通过；视觉待验、未提交、待用户评审。产品版本继续为暂定 0.2.0，不新增已定稿设计轮次或固定 commit。

来源为用户对渠道管理侧栏的浏览器批注：侧栏过长，希望不滚动看完；获取模型列表放在右侧；说明“更多操作”的用途，减少预览 / 查看草稿的重复入口；未保存状态合并到保存按钮，保存前列出具体修改并再次确认。用户同时要求模型模版按同样方式考虑。

## 渠道详情

四区锚点继续为模型列表、渠道配置、协议端点、模型默认。导航下保留“配置工具”与设置图标，接带状态的保存按钮、激活数 /100；待确认编辑、收到候选和重启核对按需用辅助图标展示。侧栏取消独立滚动容器，通过紧凑间距和减少常驻按钮缩短内容；900 × 600 实屏无需滚动可达的目标仍待浏览器验证。

“获取模型列表 / 取消等待”和“预览选择器”移到右侧模型列表标题。配置工具明确包含导入、导出、应用记录、撤销、重做和丢弃草稿；导入 / 导出沿用并行更新的“同步 → 文件同步”入口并带入当前范围。没有恢复旧文件导入弹窗。

保存按钮合并提示已保存、有未保存修改、有待确认编辑、超出激活预算、正在保存、已保存待重启等状态。未修改、待确认行 / 连接、超预算或保存中禁用；处理入口及预算说明仍可达。移除单独查看草稿按钮与重复状态面板。

保存前按最近成功保存与完整全渠道草稿列出具体值，所有差异组默认展开，范围不受搜索或当前渠道限制。取消保留草稿；确认前复核冻结内容、基准和场景，确认后才进入模拟保存流程。连接差异不回显秘密输入。待重启与写入成功继续分开表达。

## 模型模版

五区锚点保持；导航下仅保留 Agent 自动填充、模版工具和带状态的保存候选。匹配预览放到右侧匹配范围标题；与主版本比较、复制、外部 Agent、同步配置、设置和取消编辑收进模版工具，缺主版本比较禁用并解释。移除重复页底保存栏，已有只读版本的编辑 / 采用操作保留。

保存按钮提示新模版未保存、有未保存修改或未修改且基于 vN。输入时只替换保存状态节点，保留标题输入的 DOM、焦点和选区。

保存候选先按实际基于版本比较基本信息、匹配规则、通用字段和版本或后缀 / 子项规则；稳定子项 ID 区分新增、删除和修改，名称与值转义。同内容保存明确说明仍会新增候选。弹窗打开后缓冲、模版或版本变化，旧确认拒绝。取消保留缓冲；确认只新增一个候选，不设主、不采用、不修改渠道引用。

预览与保存核对各有目的：选择器预览查看最终排列，匹配预览查看命中与排除；保存核对查看本次具体修改，合并原查看草稿用途。
