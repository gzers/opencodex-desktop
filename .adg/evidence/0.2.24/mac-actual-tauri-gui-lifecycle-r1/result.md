# Mac 实际 Tauri 应用实屏启停

固定 IMP229 的 0.2.24 ARM64 应用、源码 4799ac76c24d1222dfa0d881796fb32da15d7a86 与原样官方 OpenCodex 2.99.0。测试前后均核对原应用签名及可执行文件摘要。合成配置首次供应完成后，单次 GUI Start 的观察上界为 **6,968.216 ms**，预算 30,000 ms。界面显示「启动已完成」「运行状态：运行中」，Ready rev4 的回执、运行记录和实际监听对应 PID 76325 与 127.0.0.1:63304。

单次正常 Stop 为 **5,726 ms**，预算 10,000 ms。界面显示「停止已完成」。原生启动器与服务退出码为 0。同一票据进入 root_absent rev9，完成摘要与归还读回的原始字节计算值一致，客户端根回到原本不存在的状态。确认监听、服务、启动器、测试管理器、隔离目录及三份自有协调文件均已清理。测试期间阻止非回环连接。

本轮使用 stop-progress，实际范围为正常启停及原先不存在的客户端根。原探针的通用范围字段沿用取消场景描述，取消未在本轮执行。首版调用脚本的换行有误，已在创建运行目录及启动前修正。原始记录留在本机，Git 只存核验字段和 SHA-256。Mac 定向结果通过，整版 accepted:false。
