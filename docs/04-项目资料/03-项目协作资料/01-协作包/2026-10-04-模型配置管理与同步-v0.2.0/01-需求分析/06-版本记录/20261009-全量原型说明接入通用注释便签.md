# 全量原型说明接入通用注释便签

2026-10-09，参照 #annotations 打样方案，把原型说明从旧「当前页面说明」侧栏卡全量迁入通用注释便签组件；组件、样式与目录逻辑均为 annotation-cards 单一实现，未逐页重复造轮子。

- 覆盖范围：概览（运行摘要、最近事件、升级 / 文件同步 / WebDAV 三卡）、扩展管理（Tab 行与 Skills / MCP 卡头）、诊断中心（Tab 行与 Doctor 卡）、设置（Tab 行与通用 / 安装 / 备份 / 清理 / 扩展 / CLI / 升级 / 关于各面板）、托盘卡头、同步页（文件范围、凭据、WebDAV 连接条）与模型配置（工具条、设置分区）。
- 弹窗：openModal 默认在正文顶部注入通用注释卡（卸载 / 删除等确认弹窗自动携带）；同步与模型配置弹窗走 hideNote 不重复挂载，保持弹窗高度不变。
- 挂载方式：标记 absolute 定位挂在实际容器（卡头、Tab 行、按钮行、mod-head 等），随内容滚动；卡片半透明不占布局空间，不改滚动高度。环境门禁卡与 hidden 运行详情内不放注释，门禁态下相关条目随容器隐藏并自动退出目录。
- 工具板「本页注释」继续自动汇总当前页 / Tab / 弹窗可见注释，支持搜索与点击定位展开；windows / notify 专题保持空目录。打样页 33 条工具提示不受影响。
- 旧机制移除：routeNotes 数据与 renderPrototypeNote 调用、侧栏「当前页面说明」卡、启动宫格「注释卡片」入口全部删除；卡头不再注入锚点按钮，锚点跳转改走卡片 id 与 applyHashAnchor 原有链路。面板页（官方页面内嵌对照）未加注释：iframe 内容裁剪滚动，外部标记无法稳定定位，其说明保留在路由副标题。
- 区分口径：页内淡紫标记均为原型说明（演示边界、实现状态、交互约定），软件真实文案（按钮、状态、菜单）不含标记；已逐页核对未遮挡控件、未新增滚动高度。

本轮已通过 node --check 校验 5 个相关脚本，并完成源码级逐页核对（挂载点、Tab / 弹窗 / 门禁态可见性、目录计数、Esc / 外点收起、锚点跳转、滚动几何）；浏览器端逐页点击检查待下一次原型回归时补充。

## 2026-10-09 增补：标记样式组件统一（commit adc1265e，v28）

- 根因：sync 页 #sxPanel 渲染在 .sx-tabs 容器内，`.sx-tabs button`（特异性 0,1,1）无条件覆盖 `.annotation-marker`（0,1,0），同步页标记因此丢失淡紫底、小字号与圆角边框；设置页 #settingsTabs 内的标记同属命中范围。CSS 加载顺序无法解决，属特异性反向覆盖。

## 2026-10-09 增补：.btn 按钮盒模型组件契约（v32）

- 根因：概览页「更多」按钮是 details>summary 复用 .btn，而 .btn 原定义未声明 display，summary 的 UA 默认 display:list-item 使同一 .btn 在 summary 上呈现块级盒模型（左对齐、盒型与相邻 button 不一致），看起来"发虚/过透明"，并非单独写了样式。
- 方案：全局 .btn 组件契约补一条规则（inline-flex 居中、gap 6px、appearance:none），一处修改全站 .btn 生效；summary/a 复用时同样按按钮盒模型渲染。全仓检索确认 .btn 仅此一处 summary 复用，普通 button 默认 inline-block 本就接近该盒模型，无视觉回归。
- 浏览器实测（8907 服务）：summary.btn.ghost computed display 由 list-item 变为 inline-flex、内容居中，与「启动 OpenCodex」等相邻按钮一致；更多菜单面板项 justify-content:flex-start 与 100% 宽度保持；普通按钮（重试加载）inline-flex 正常。

## 2026-10-09 增补：ghost 底色对齐真实软件（v33）

- 根因：用户对照真实软件截图（重启 / 查看日志按钮实测底色 #dbe9ed 淡青蓝、文字 #0d0d0d 纯黑）指出原型 ghost 按钮过浅。原型 .btn.ghost 一直复用 --raised:#f4f4f4，缺少独立底色；文字色本就与真实软件一致，无需调整。
- 方案：新增组件级令牌 --raised-ghost:#e3e8ea（考虑原型环境光弱于真实软件，取略浅于 #dbe9ed 的青灰）与 hover 色 #dadfe2，.btn.ghost 改用该令牌，一处修改全站 60+ 处 ghost 按钮生效；深色主题同步给出 3a3a3a / 444444。同时补 .btn.ghost:hover 显式声明（同优先级且位于 .btn:hover 之前导致 hover 底色此前不生效）；sync-config.css 中 .sx-tabs .btn.ghost 的重复底色定义删除，只保留 border-color 还原，底色走组件层。
- 浏览器实测（8907 服务 + IAB 截图）：概览「更多 / 升级前备份」与同步「清空选择」渲染一致，按钮区不再泛白；演示态切换、按钮居中、hover 均正常。
