# COL-LOCAL-20261011-01 Codex 对话配置管理

2026-10-13 公共组件归属已明确：模型 / 可选推理选择器原型获用户基本确认，**0.2.0 开发由模型配置管理与同步包承接**。[归属决定](../../../01-项目支撑资料/01-产品原型/公共渠道模型选择器交互方案.md#12-纳入-020-开发范围)、[WP-07](../2026-10-04-模型配置管理与同步/02-开发实施/README.md#wp-07-公共渠道模型选择器020-已纳入范围)为当前入口。本包保留需求讨论来源，后续复用同一组件；对话配置及存储 / 导出 / 恢复仍独立、版本与生产开发时机未定。

## 目的与状态

用户希望先确认 OpenCodex 是否支持相关配置，再讨论 Desktop 是否需要承接配置管理。当前包用于独立记录需求、原生能力分析和实时生效边界。

2026-10-13 命名确认：侧栏“对话”、页面“Codex 对话配置”，资料包“Codex 对话配置管理”。包 ID 和来源输入 ID 保留，技术文件名及真实设置未迁移；功能仍未实现，版本与开发时机未定。

本包没有指定版本号、开发时间或交付承诺。用户本轮授权方案审计与 test/ 中的最小验证；已完成 8 项隔离原生验证。没有修改用户运行配置或生产应用源码，没有重启正在使用的应用、请求真实模型或执行发布。

## 范围

- 仅配置全局命名模型，触发与标题管理沿用 Codex；
- Web Search 使用的模型、推理档位和回退策略；
- 子 Agent 的模型、角色 / 执行类型、提示词、effort、并发和深度等配置；
- 全局、Codex 项目和单个对话 thread 的配置作用域及继承；
- 读取 Codex 项目 / 对话列表并建立稳定绑定；
- 配置保存后立即生效、下一次请求生效、刷新 / 重启和暂不支持的边界。
- 独立配置、本机来源绑定与运行状态的存储，以及按 0.1.10 底座适配事件、备份和按需刷新。
- 按项目分目录、对话覆盖按需建文件，配置随项目删除和对话归档 / 删除自动清理。
- 手动导出 / 导入与备份独立选择；WebDAV 默认不包含本包全局、项目和对话配置。
- 项目 / 对话内容导出及与策略的联合包、恢复时的对象映射；WebDAV 不自动包含历史。

## 关联与边界

本包与已有模型配置管理协作包分开维护。已有模型配置包负责渠道、模型、模型模版、选择器和模型同步；本包负责 Codex 协作行为和作用域配置。后续可以复用模型目录，但不能因为存在模型配置包就默认两个包必须同时开发。
