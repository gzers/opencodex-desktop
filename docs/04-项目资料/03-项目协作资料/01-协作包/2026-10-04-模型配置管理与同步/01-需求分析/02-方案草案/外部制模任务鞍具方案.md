# 外部制模任务鞍具方案

日期：2026-10-15。项目：opencodex-desktop。产品：OpenCodex 桌面管理器。用户明确外部任务是一套让Codex等外部执行者按软件规则制模的“鞍具”，并要求调整界面和文档。本文替代此前“生成外部任务＋独立导入外部结果”的主流程；正式命令、传输和存储契约仍待开发冻结。

活动入口：[唯一总原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models) → 模型模版 → 外部任务。列表和编辑侧栏均只有这一个入口。当前仅内存mock，不能向真实外部Agent分发可执行任务，也不会写本机配置。

## 1. 界面（2026-10-15收简）

用户进一步明确：只用一个弹窗，选择范围和预置场景就生成提示内容，结构资料与提示词一起复制，不做任务队列。此决定替代前轮“新建弹窗→任务详情、分别复制提示词/任务资料、会话任务列表”的设计。

弹窗从上到下为：**范围＋场景 → 可选补充要求 → 完整内容预览**。底部只有主操作“复制完整任务”和“关闭”。范围支持当前／勾选／全部／仅新建；修订时可明确“同时允许新增模版”。无需先点创建或生成按钮，选择/输入原位更新同一内容区，不切换第二个弹窗。

| 预置场景 | 指令重点 | 写入边界 |
|---|---|---|
| 从资料制模 | 按提供/实际检索资料组织匹配和能力，保留未知 | 根据范围新建或修订 |
| 更新型号资料 | 核对所选模版新型号、上下文和推理差异，保留人工字段 | 仅明确目标，新增另选允许 |
| 批量检查与修订 | 按对象检查遗漏/重叠/继承，并记录逐项依据 | 批量共同基准与全批校验 |
| 私有模型配置 | 以用户内部资料定义型号和接口，不要求凭据 | 根据范围新建或修订 |
| 按偏好调整 | 按补充要求调整支持字段，未要求内容保持 | 不绕过人工锁或合法字段 |
| 仅检查，不保存 | 返回问题/建议及依据 | 服务层禁止模版写入，报告不新增版本 |

只有已有目标的场景遇到“仅新建”范围时，原因收入原型标签，保留复制禁用与控件可读原因；不默默换范围。选择和输入只是准备，不写库、不登记未复制的提交；复制时冻结当前显示内容对应的准确基准。复制失败选中同一份完整内容供一次手工复制，不能退回两个分别复制的动作。

场景解释、复制操作说明/反馈和准备范围校验解释按用户要求放共享原型标签，不常驻弹窗正文；标签处于产品框外独立层，正文没有专门留白或重复脚注。动态说明随场景和复制更新，提交失败/保存回执/检查报告仍属于产品业务结果。共用归属与防占位机制以UI规范§36为准。

一份完整内容包括场景指令、补充要求、目标/版本/人工锁、字段/匹配契约、合法结构示例及提交/回执约定。内容继续按相关目标裁剪，不把全库/所有渠道目录塞回来，也不为减少字符丢失必要契约。外部Agent拿到这一份即可了解规则，不需要此前聊天或第二份资料。

取消用户可见的创建→详情流程、任务队列、会话列表、任务切换和新建/取消任务管理动作。提交返回在同一弹窗内可显示简洁结果/版本入口；关闭弹窗不代表撤销已经交给外部的任务。必要结果仍经既有通知中心恢复。提交服务只保留范围/基准/幂等回执所需的最小登记，不调度、不管理外部执行者，这不是产品任务队列。

正常主线不手动导入结果；前轮文件/JSON兼容回传路径只作适配测试边界，不恢复常驻按钮或第二步任务详情。未来如需跨环境回传，应复用同一提交协议及登记基准，不给上传资料自授权写库权限。

## 2. 外部执行者需要的最小信息

| 内容 | 必须提供 | 不默认附带 |
|---|---|---|
| 目标 | 新建/修订范围、要求、完成条件、允许新增的明确意图 | 无关模版和所有历史 |
| 基准 | 稳定目标ID、完整基准revisionId、规范化摘要、实际目标内容、人工缓冲基准和锁 | 整份模版库或其他用户编辑缓冲 |
| 契约 | 独立schema/契约版本、合法字段/类型/枚举、继承/省略/空值语义、匹配和型号后缀规则 | 仓库文档全文、生产实现细节 |
| 资料 | 实际来源、日期、适用型号；未知/矛盾项与补证出口 | 完整聊天、发现的全部模型和节点连接摘要 |
| 能力 | 读取任务、读取契约、按需查询资料、预检差异、按写入/只检查权限提交、查回执 | 对正式库、凭据、默认指针和运行配置的直接文件写权限 |

只传本次匹配范围明确引用的渠道ID/名称；一般制模不需要URL、Key、认证、所有节点和模型目录。确有字段解析依赖时，通过有范围的只读查询获得必要摘要，不为了“自包含”导出所有渠道配置。

场景指令保持简短，但对用户只提供一次复制的完整内容；契约由软件从与内置流程共用的机器定义生成并拼入同一份内容，不手写另一套长期字段说明。任务本机入口、跨环境可携带资料各有明确可达性；外部读不到本机文件时随附契约/目标资料，不能只给一个无法访问的路径。提示词若被用户要求或资料文本干扰，实际写入仍由范围/契约校验决定。

本轮旧mock单目标提示约63,236字符，约51,686字符来自包含19个渠道/305个模型的context。新原型将精简指令和必要结构资料合为一次复制的内容，当前任务不再携带全量模型/节点。字符数只是输入规模，不作为token成本或模型正确性证明；不设固定生产提示长度上限而截断必要目标信息。批量任务由可按目标读取的资料避免一次塞满上下文。

## 3. 共用执行与写入链

内置助手和外部执行者只在生成者身份及传输方式上不同。内容必须经过相同的字段契约、默认/继承解析、匹配器、人工锁、版本摘要、基准复核和保存服务；真实gallery/UI复用规则沿公共组件约束。人工编辑、内置生成和外部提交的最后保存入口须共享版本/事务服务，不能复制三个库写入器。

| 操作语义 | 输入与结果 |
|---|---|
| 读取任务 | 依据可信taskId读取范围、目标和只读基准；能力访问限定当前任务 |
| 读取契约/资料 | 返回任务支持的准确版本及相关字段；应用版本、数据契约版本、模版revision分别表达 |
| 预检 | 检查字段、合法能力、匹配冲突、人工锁及全部目标基准，返回差异/错误；不分配最终版本、不写库 |
| 提交 | 写入场景传taskId、稳定submissionId、契约版本、目标基准、完整预期内容和来源；软件复核后分配新版本并原子保存；只检查场景仅接受范围内报告，拒绝版本操作 |
| 查询回执 | 返回同一提交的处理中/已保存/无变化/拒绝/结果待核对等事实，以及实际保存身份和摘要；不能把请求收到当作写入成功 |

提交不接受外部指定新revisionId或修改旧版本。创建时可提出名字/建议ID，最终唯一身份与碰撞处理由服务负责。修订必须指明真实基准版本；短显示标识不能作为唯一身份。跨机身份、规范化digest和兼容旧schema由WP-01冻结，原型整数序号和FNV摘要均不是生产契约或安全措施。

相同submissionId＋相同内容重试返回原回执，不重复新建。相同ID不同内容拒绝；已完成任务收到不同结果须新建明确任务。提交中断先查询回执，再决定是否重试，不能拿新ID盲目重发。批量任一非法项、过期基准或锁冲突则全批不写，不能部分保存后报告整体失败。事务完成后读回验证；失败/超时/不确定结果保留真实阶段，恢复不得覆盖后续人工修改。

外部工作区应限制为任务资料和输出；正式库交由应用服务写入，凭据不可见。任务资料不是认证凭证，taskId也不单独构成授权。能力授权/生命周期、路径与符号链接/越界检查、最小文件权限、事务锁和备份恢复由真实宿主实施。若执行者仍有任意文件写权限，提示词无法保证不损坏其他文件，界面和文档不能承诺已有安全沙箱。

## 4. 通知与任务结果

注册事件model.template.external接入已有通知中心。待提交差异、字段错误或冲突需要处理时，同任务更新一条必要通知；步骤不持续产生未读。保存/无变化只作短反馈，已有待处理通知则更新为已解决；已读、解决、删除分开，删除后同任务晚更新不复活。

通知只携带taskId、枚举状态与非敏感版本身份，点击回同一任务。提示词、资料、模版正文、文件路径、URL和凭据不进通知。同一弹窗内结果是业务查看，不另造通知卡/宿主。原型已用应用层适配桥接现有宿主，生产公共publisher和任务持久化仍由WP-08/06承接。

## 5. 原型与正式开发边界

当前原型展示单弹窗范围/六场景/补充要求/完整内容一次复制及原位结果；预检、直接提交、只检查报告、冲突和幂等重试在服务mock中保留，不再有会话任务列表或产品队列。右侧工具板提供“模拟校验、模拟提交/重试、字段错误”，不放产品流程中。全部数据在内存；没有真实任务URL、CLI命令、文件写入、外部模型调用或权限隔离。

既有数字版本回传仅作为原型兼容路径核对；新的任务资料不要求外部计算版本。旧文件示例仍为历史候选，未被本轮自动升级为正式schema。外部任务接口不能直接引用原型脚本作为生产服务。

WP-01承接独立契约、身份与版本协商，WP-02承接人工/内置/外部共同的版本及事务服务，WP-03承接单弹窗预设场景与一次复制UI，WP-06承接真实外部操作能力/任务资料与执行环境对接，WP-08承接注册发布与必要提交回执恢复，WP-05承接验收。此方向进入0.2.0开发规划；真实Agent/CLI的交付拆分仍随WP-06冻结，不因原型存在声明已实现。对话/多平台新增业务保持独立版本。

验收重点：同一输入经人工/内置/外部保存得到相同标准化内容和校验结论，任务来源/时间/新身份可不同；验证契约错版、伪造字段、未知能力、锁值、过期/并发、范围越界、全批原子性、重复/乱序/取消晚回、断连后回执、持久恢复及真实文件权限。原型DOM和mock版本回归不能替代这些生产证据。
