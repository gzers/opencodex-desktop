## 2. 主要问题与整改优先级

| 编号 | 现有问题 / 证据 | 调整方向 |
|---|---|---|
| S01 | 原型有令牌无公共size类，各helper只拼btn/variant，页面用局部后代选择器改比例 | 复用正式sm/md/lg契约，原型有同义配方及显式调用，公共层拥有数值；不得新建另一套大小体系 |
| S02 | .mp-provider-actions>.btn / .mp-template-list-actions>.btn字号11、padding6px 9px，仍继承34px最小高 | 行内真正切到sm，完整覆盖高度下限、字号/行高、内距、图标；不能只缩文字再称小号 |
| S03 | .mp-template-nav>.btn写height28但继承.btn min-height34；.mp-rail-helpers .icon-btn写height28但继承icon-btn min-height32 | 同一尺寸配方必须处理min-height/height/width，图标键独立，不靠小height抵消较大min-height |
| S04 | index/base中.btn继承父级font；正文14px/1.5，局部父级不同可使相同md呈现不同尺寸 | md显式control字号/基准行高，sm/lg也完整定义；min-height不等于实际高度，要核对内容盒模型 |
| S05 | 概览、日志、设置和模型存在26/30/32px各处声明；同功能在不同容器中尺寸漂移 | 按用途选sm/md，并将批准的概览紧凑/选择字段等例外归所属公共组件，不再每页覆盖数值 |
| S06 | 通知24、普通小号28、图标32、下拉/Tab/标签操作都有button节点 | 通过组件身份区分；保留通知和非Button控件契约，禁止一次性把所有button调成同一高 |
| S07 | 前几轮把34px标准按钮口头称为大号，局部修补也未等价迁入公共size | 规格与用户说明只使用sm28/md34/lg40，不把primary、宽按钮或标准字号称大号 |

以根正文14px、1.5行高且无局部覆盖为计算示例：默认按钮内容21px+上下7px+2px边框可能达到37px；正式sm12px若继承1.5行高，18+10+2=30px，虽min-height=28也不会自动缩到28。此为CSS规则推演，不是实屏测量；正式计算值与文字缩放仍须验收。

## 4. 0.2.0 开发与未来原型要求

权威尺寸与用途规则见[UI规范§3.1](../../../../../../02-项目核心/UI规范.md#31-按钮尺寸使用规则2026-10-15确认)，版本范围见[公共样式调整](../../02-开发实施/README.md#020-公共按钮尺寸与样式统一已纳入开发调整)。WP-03承接公共配方/原型与现有页面迁移，WP-05负责源码门和实屏，WP-07/08分别核对模型选择器和通知控件。

- 复用正式UiButton与现有令牌，在原型使用同义size配方；默认md，行内sm，lg仅明确场景；按钮variant/density/surface/加载状态与size分别表达。
- 建立字号、基准行高、高度下限、内距、图标和组间距完整配方；通知专用24px及IconButton单独profile。不能只改padding或font-size、继续继承错误min-height。
- 业务页面只选择配方与排列，公共组件/令牌拥有尺寸值。纯布局、宽度和对齐由容器负责；对象选择、多行字段、菜单/Tab/树等专用控件有明确owner与可访问性依据，禁止以广域.panel button覆盖。
- 新原型即日起先选已有尺寸，缺失只在公共层补齐；例外说明用途与组件owner，不要求额外审批，也不能把“仅原型”当作散落任意尺寸的理由。允许行内布局与复合控件细节，不把所有像素值都机械判错。
- 涵盖已交付功能和本版新增模型/同步的尺寸接入；概览/面板虽然不执行Tab固定，但管理器按钮仍参与本轮样式核对，不覆盖官方嵌入页面。对话和多平台新增扩展适配只预登记，实际页面接入/验收随独立版本。
- 本轮未新增视觉方向，不改变保存/删除/通知/权限业务状态，不把touch44令牌冒充size API已实现，也不为整改一次性重画整个产品。

## 5. 待执行验收

1. sm/md/lg配方的最小高度/字号/行高/内距/图标一致，variant和loading/disabled不改变盒模型；md不再随父级font漂移。
2. 列表行内sm，页级/表单/Modal常规md，真实lg有显式size与理由；通知24px及图标/复合控件例外不受普通button后代覆盖。
3. 28/34/40为100%基准的控件指标；文本/界面放大时容器可增长，不截断焦点/文字，不固定小高度强压。颜色、材质与禁用语义沿既有令牌。
4. 窄窗、长中英文、图标+文案、组内换行/表格横滚/长名截断、保存状态框等高、焦点/键盘与通知宿主协调；Tab实际高度/双层标题锚点避让仍正确。
5. 公共组件gallery引用正式组件，原型配方作对应；源码门发现业务新增size覆盖和错误名称，记录白名单组件例外；不能把gallery有sm/lg当全页迁移已完成。
6. 每个域记录采用尺寸、例外、迁移与实屏结果，不把本轮源码盘点计入生产通过。
