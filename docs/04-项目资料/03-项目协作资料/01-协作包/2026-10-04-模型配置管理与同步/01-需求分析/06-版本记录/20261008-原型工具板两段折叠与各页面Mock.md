# 原型工具板：两段折叠与各页面专属 Mock

日期：2026-10-08 ~ 2026-10-09，Asia/Shanghai。归属：COL-LOCAL-20261004-01。状态：已补绘，当前未提交，待评审与浏览器视觉核对。

来源：用户 2026-10-08 要求右侧工具板有更清晰的结构设计——两个顶层菜单，上段所有页面共用、下段当前页面与 Tab 的演示，两段可点击展开 / 收起，默认上段收起、下段展开；两段名称要等长且可用加长措辞；同时工具板不跟随软件窗口高度，固定宽度、占满右侧。

## 当前行为

- 右栏固定宽度 360 px（`--proto-w`），**贴住视口上、下、右三边、不留任何缝隙**（`.desktop` 满高、外列间距与外边距归零，工具板 `height:100vh`、方角、只保留一条左侧分隔线，去掉圆角 / 外投影 / 悬浮留白）；窗口仍保持自身 1180×760 / 900×600 预设，在剩余区域居中。窄视口（≤1470 px）退回上下两段：窗口在上、工具板在下，右侧与底部同样贴边。
- 2026-10-09 按用户标注收紧：之前工具板四周仍有 22 px 外边距与圆角悬浮外观，本轮改为贴满右列并占满全高。
- 两个顶层折叠段都是 `<details>`：**全局评审条件**（导航 / 外观 / 窗口尺寸，默认收起）与**本页演示场景**（默认展开）。两段名称各 6 字等长；标题右侧显示「展开 ▾ / 收起 ▴」状态，键盘 Enter / Space 可切换。
- 原来「原型注释与测试器」标题改为「原型工具板」；右栏锚点「当前页面 Mock」改为「本页演示」；跳转全局分区时自动展开上段，避免滚到隐藏元素（`prototype-panel.js` 捕获阶段处理，仍不改产品路由）。
- 下半区每个页面与 Tab 各自提供专属 Mock 卡片：概览 / 面板 / 模型（渠道 / 模版）/ 拓展（Skills / MCP）/ 同步（文件 / WebDAV）/ 诊断（检查 / 日志 / 通知历史）/ 设置（通用 / 安装 / 备份 / 扩展管理 / 日志通知 / CLI / 升级 / 关于）/ 托盘 / 通知专题 / Windows。
- 本轮新增面板承载、Skills 列表、MCP 列表、通知历史、设置八个 Tab 的 Mock；卡片内部结构统一为「分区小标题（`.pctl-sub`）+ 控件（`.pctl-chips` / `.pctl-grid`）+ 说明（`.pctl-hint`）」，与页面 / Tab 无关，避免各页自建私有写法。
- 新 Mock 控件由 `prototype-panel.js` 统一接管：同一组内单选高亮、开关类 `role="switch"` 切换 `aria-checked`、只读动作只提示，全部走 `toast` 说明「只切 mock 投影」，不写配置、不调用命令、不访问磁盘。
- 概览 `motion-review` 注释卡移到全局段后不再常驻首屏，已从 `overview-dual.js` 移除，避免与两段折叠重复。
