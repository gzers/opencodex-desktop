| 技术选型 | 确认 Tauri v2 + Rust。 |
| 安装 | 不要求全局安装；支持发现/展示/校验现有安装；不管理 npm，只发现 npm。 |
| 数据目录 | 支持选择/切换 `OPENCODEX_HOME`；升级前支持备份；配置、缓存、备份等产物支持自定义路径并统一在一个位置按结构划分。 |
| 官方升级 | 不替代或包装官方 `ocx update`。 |
| 启停 | 桌面壳直接托管 `ocx start / stop` 子进程。 |

| startup at-risk | 按建议提供检测与引导，restore 需用户确认。 |
| 外部路由器 | AiMaMi 等属于 OpenCodex 本身的问题；桌面壳只检测与引导，不直接覆盖。 |
| 状态与日志 | 采用建议：复用官方状态命令、明确状态枚举、只读脱敏、离线说明能力不可用。 |
| 配置迁移 | 导出全量内容，包括敏感内容，避免手动输入；导入按校验、备份、确认流程执行。 |
| WebDAV | 同步全量内容，包括敏感内容，执行覆盖；冲突时提示。安全实现需客户端加密与备份。 |
| 后续 | 先写入 DMD 与协作包，暂不进入代码实施。 |
