- 用途：展示“环境就绪时并入运行详情、未就绪时由完整门禁替换三卡”的推荐布局；保留 A 页头入口、B 状态入口、C 四卡栅格作正常态对照。不修改当前产品规格或生产界面。
- 参与方：用户与 Codex；输入为概览现行规格、玻璃材质令牌和 2026-09-30 的布局讨论；输出为 HTML 效果稿与 `DESIGN.md`。
- 角色：本包是衍生探索材料，不是现行原型或事实源。无需长期保留运行日志；评审结束后按项目协作资料策略处置。

2026-10-01 已收敛：用户采用双形态思路，卡片尺寸和内部布局在正式原型另行优化。当前生产还原依据为正式软件原型、UI 规范 §25／§26 与 IMP-05，本包仅保留探索历史。

默认选中“推荐 · 双态概览”。顶部可切换原三案、五种环境状态、深浅主题和两种应用窗口尺寸。界面使用模拟状态，不读取本机环境、不执行安装或启动。

应用窗口固定为 **1180×760**，可手动切换到 **900×600**。尺寸包含模拟标题栏，按 CSS 像素、100% 浏览器缩放表示；不随浏览器高度拉长，不整体缩放。评审工具条位于应用窗口外，因此外部浏览器还需要留出评审栏空间。

右下角测量应用窗口的实际尺寸及内部内容滚动情况；外部浏览器太小时，评审页面可以滚动，应用窗口尺寸仍保持所选值。已通过 40 种“方案 × 环境 × 窗口尺寸”组合的 DOM 交互检查，未完成浏览器截图和排版验收。
