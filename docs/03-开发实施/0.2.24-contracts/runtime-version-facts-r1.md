## 三种事实及读取

runtime_version_facts分别读取实际current所定位的磁盘官方package.json、当前绑定H受认证的运行实例与D/runtime.json上次记录。磁盘版本是包名/合法版本声明，不执行磁盘新代码，不扫描旧路径；未准入的外部原地更新仍可显示其声明版本，但标changed/unknown，不能据此认定新代码可信。selectedVersion保留current选择，recordedVersion/recordedAt只属于历史。记录缺失/损坏不填造当前版本，观察不写回历史或修复原文件。

生产versioned official_project_facts改为实际磁盘只读观察，停止将每次查询的版本写回安装记录；非versioned旧夹具行为保持原状，不扩兼容工程。磁盘/记录/current/待处理事务在读取前后重核，变化即拒绝整次混合快照。路径/大小/单链接/严格JSON边界保持；确认摘要绑定I/D/原文件字节及原pending状态，不含观察时间，不因重复查询而自动变化。

运行版本独立从H内受保护runtime-port记录建立回环连接，两次新challenge HMAC健康响应在同一连接核对service/PID/port、合法且稳定的version、单调uptime和记录前后原字节；无需磁盘程序可执行或版本相同。不传管理令牌、不调用ready/stop，不发真实模型或同步请求。此结果只说明该受认证端点自报版本，不增加启停/服务就绪许可；没有记录仅no_record，不能推断服务已停止。不可读/错误证明/变化记录为unavailable。既有生命周期/状态health_proof仍要求自己已准入的精确版本，原保护不放宽。

## 展示、刷新与执行

更新窗口新增当前版本事实，显示磁盘包版本、运行实例版本及PID/端口、上次安装记录及时间、来源核对和本次核对时间；磁盘和进程版本不等明确提示尚未采用磁盘版本。请求失败保留旧显示时标“上次观察”，不能当新鲜事实比较。旧本地版本查询失败标记不覆盖该独立观察，最新事实失败/读取中/来源不一致不能启用面板更新。

打开更新窗口、返回前台/概览和明确检查时刷新本地事实；不因这些读取自动联网或安装。版本store按generation拒绝迟到原回执覆盖新失败，不另造历史缓存或信任mtime。说明/远端查询仍保持自己的来源，不被本地事实读失败抹除。

点击面板更新先保留原观察摘要，再重读磁盘/运行/记录；来源或摘要变化时在备份/安装前拒绝。备份等待期间仍使用原确认摘要，不采用晚到的新基线。install_official_update要求expectedObservation，先重核再查询远端候选；共同安装worker取得安装预约后，在版本化安装/配置保护前再次重核。require_confirmation除了展示级入口/关键文件一致，还执行完整镜像核验和最终原摘要读回，非关键新增/变更不能获得执行许可。原安装器后继源/候选/激活检查保持。
