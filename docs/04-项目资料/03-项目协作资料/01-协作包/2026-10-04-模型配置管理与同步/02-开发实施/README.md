## WP-07 公共渠道模型选择器（0.2.0 已纳入范围）

2026-10-13 用户已基本确认原型并明确归入本包 0.2.0。这是已登记开发范围，生产实施未开始。规格唯一入口：[公共渠道模型选择器交互方案](../../../../01-项目支撑资料/01-产品原型/公共渠道模型选择器交互方案.md)；打样：[同一总原型 #model-picker](../../../../01-项目支撑资料/01-产品原型/原型/index.html?design=models#model-picker)。

1. 实现共享选择组件：完整模型目录、左渠道 / 右表格、独立搜索、表头排序、单选唯一待选 / 主确认、启用推理 / Fast 时连续编辑失焦只收小浮层、多选临时缓冲 / 跨范围保留 / 确认取消，以及底部标签、键盘 / 焦点与玻璃浮层定位。
2. 定义调用方输入：用途与可选性、单选 / 多选、当前引用、是否允许推理、有序列表与推荐信息、支持档位和解析后的实际默认档位。关闭推理时只选模型；继承与来源继续由业务页负责。
3. 返回稳定 nativeModelId 或 channelId + modelId；显式选档才附 reasoningEffort。未覆盖时显示实际默认值、返回不固化该显示值；恢复默认清除覆盖，未知不猜测。组件不自动保存配置、开启渠道或调整模型白名单。
4. 接入本包执行模型选择以及已纳入本版的模型 / 制模助手字段。模型模版 Agent 的自动填充、单个更新、所选更新和全部更新共用本机一份执行偏好；其设置采用公共单选模型 / 推理 / 快速模式弹窗，主确认返回设置缓冲，保存才改共用值；移除独立 Fast 开关及渠道列表“高级模型配置”入口 / 弹窗，不另设全局 Fast 总开关；模型 Fast 能力声明继续保留。已有运行策略和独立 Fast 目录兼容字段先保留，实际客户端需求沿 WP-02 / WP-05 核实，选择器返回组合不以额外发布 --fast 条目为前提。显式关闭和再次打开的组合均保留。取消保留，实际默认和支持档位由已保存策略提供；原生未绑定、渠道停用 / 无额度 / 待绑定均解释原因，运行任务冻结旧参数。组件只提供选择能力，既有 Agent / CLI 业务的交付拆分继续按本包范围决定；公共组件不新增执行能力承诺。

## 外部制模任务鞍具（2026-10-15原型与开发输入）

用户要求外部Codex制模与内部添加走同一规则和保存链，界面收成“外部任务”单入口，详细依据见[鞍具方案](../01-需求分析/02-方案草案/外部制模任务鞍具方案.md)。本轮仅改原型与需求，真实Agent/CLI仍按WP-06拆分冻结，未启动生产开发。

- WP-01冻结独立任务/内容契约版本、目标revisionId、规范化digest、作用域、错误/回执形状；从同一机器契约生成内置编辑与外部资料，不让提示词成为第二套字段事实源。
- WP-02实现人工/内置/外部共同的校验、匹配/锁、服务分配版本、快照摘要、并发基准复核、全批原子保存和读回；提交去重及中断查询回执纳入真实事务，不以“已收到”冒充完成。
- WP-03实现一步弹窗：范围/六场景/可选补充要求原位生成完整任务，一次复制提示词与结构资料；不做创建→详情两步或产品任务队列，简洁结果在原弹窗展示。任务结果不自动切走用户对象；不恢复独立导入按钮或把技术路径塞进产品主流程。
- WP-06对接实际读取/契约查询/预检/提交/回执能力、可访问本机入口及跨环境可携带资料。限定任务工作区，正式库由服务写入，凭据和运行配置不可由任务直写；权限/能力撤销和路径越界须真实验证，不能只依赖“禁止写入”的提示词。
- WP-08复用注册事件model.template.external与公共publisher；待处理通知按任务更新、完成解除，taskId和submissionId不替代授权或真实终态证据。WP-05按现有AC-M52～54/86～87与G-11追加[专项验收](../03-测试验收/README.md#外部制模任务鞍具验收待执行)。

原型schema与FNV、演示操作名称均不作为正式CLI/API或安全协议。外部任务保持自身执行模型，不导出本机Agent偏好；预置场景的简短指令与按相关目标裁剪的资料合为一次复制的内容；仅检查场景在服务层关闭版本写权限。正式发布前需验证内部/外部同输入的标准化内容和校验一致，运行构建不依赖docs原型。


2026-10-15外部任务进一步收简：界面不提供会话任务列表、切换/排队、新建/取消任务管理；准备预览不登记执行，复制时只冻结提交范围与基准。后台必要的身份/幂等回执登记不能变成用户任务队列，也不主动执行外部Agent。复制说明不长期保护旧模版版本；若用户后来删除或修改基准，旧提交拒绝而不恢复/覆盖。仅检查使用只读报告契约，任何模版/版本操作必须被服务拒绝。实现与验收以鞍具方案最新§1为准，前轮两份复制或创建后跳详情不再实现。
