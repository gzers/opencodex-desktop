## 版本身份

版本标签示例：2026-10-13 14:32:08 · A7F2。北京时间固定显示，保存时间精确到秒，另外记录 UTC savedAt 和完整 revisionId。短标识来自完整身份，同秒或重复短标识时扩展，不能只用四字符定位版本。手工保存、Agent 更新及外部 Agent 候选均生成这种元数据；恢复不重新编号已保存版本。

每版记录来源、修改摘要与 basedOn；批量更新另登记 batchId。主指针、采用状态和确认记录是独立元数据，不原地改版本规则。列表不再用 v1 / v2 / v3 判断新旧。既有原型策略内部仍沿用数字 n 与 mock 精确引用，便于既有同步和导入 fixture 继续解析；生产阶段须由 WP-01 改为完整 revision 身份引用，不能将显示标签或 mock 整数当作跨机主键。

恢复记录保护对应旧版本，包括提交前 / 后依赖、当前渠道、草稿、更新基准及确认可用的快照。恢复默认只撤回该次提交影响且未被后续编辑的字段；完整确认快照恢复会明确列出后续已保存变化。恢复采用配置保持主指针，不以切换默认版本冒充切回实际渠道引用。

## 静态资料接入

[17 族 / 81 条调研资料](../02-方案草案/内置模型模版/README.md)仍为研究事实源。[model-template-seeds.js](../../../../../01-项目支撑资料/01-产品原型/原型/model-template-seeds.js)是由该资料筛出的原型 fixture，提供 41 条精确 API ID 的更新记录。显示名称未核实、权重身份、原厂下线、重定向和旧版条目不默认作为新增型号建议；某些族暂无可自动采用记录，如实显示资料不足。

族通用初始规则保持继承。具体型号只携带可在现有编辑器表达并已登记的字段；K/k/M 的模糊单位、最大输出、视频 / 文件组合、访问套餐和厂商特定思考限制仍由资料说明承接。原型未伪造这些字段的完整编译或实际请求适配。

## 同日补充：全部更新入口直接可见

用户反馈“我没有看到，另外之前说的一键全部更新呢？”，说明原先仅在 Agent 面板选择全部范围的入口不够明显。

模型模版列表顶部增加带标准边框的“检查全部更新”，无需先勾选或进入详情。点击保持当前列表，展开检查进度；检查完成且用户仍在该模块、没有其他弹窗时，自动打开全体差异。已有弹窗或离开页面时保留结果，不抢焦点。勾选后的“检查所选更新”同样一次点击检查并查看差异，范围只包含已勾选项。

首次执行先复用 Agent 设置，保存后自动继续所请求的检查；取消设置不执行，之后单独修改执行设置也不触发此前取消的任务。全部 / 所选检查以各模版最新已保存版本或当前编辑缓冲为基准，不因列表默认版本指针仍在旧版而重复生成已有新版本。

主入口的 model-config.js 资源标记更新为 20261013-2，避免沿用旧脚本标记。新增 3 项入口测试通过，更新测试合计 19 项通过；全原型 Node tests 现为 75 项通过。真实检索和浏览器访问限制沿用上方边界。
