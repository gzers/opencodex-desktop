## 导航与页面数量

左侧一级菜单新增“同步”，位于“拓展”之后、“诊断”之前。页内只有“文件同步”“WebDAV 同步”两个 Tab。文件同步在正文直接标明“导入与导出”，避免把功能限制为换机迁移。

| 类型 | 名称 | 可评审内容 |
|---|---|---|
| 主视图 P-S01 | 文件同步 | 分类列表、范围预设、搜索、凭据选项、导入 / 导出配置与结果 |
| 主视图 P-S02 | WebDAV 同步 | 连接摘要、每设备范围、凭据选项、保存范围 / 同步配置与结果 |
| 浮层 D-S01 | 配置对象详情 | 来源、字段、已选模型、连接地址、版本依赖与凭据状态 |
| 浮层 D-S02 | 导出确认 | 冻结内容清单、依赖、Key / 登录态 / 扩展凭据 / WebDAV 密码数量与加密口令 |
| 浮层 D-S03 | 导入预览 | 选择文件 / 解密、包内范围、冲突与身份映射、采用凭据及结果 |
| 浮层 D-S04 | WebDAV 连接 | 地址、目录、用户名、测试连接与保存连接 |
| 浮层 D-S05 | 同步差异 | 上传 / 下载、冲突处理、登录态版本核对与分项结果 |
| 浮层 D-S06 | 比较对象只读详情 | 从导入或 WebDAV 比较树打开第二层，逐字段比较本机与来源，关闭返回原位置 |

合计 **2 个主视图 + 6 类浮层**。导入的读取、比较、错误和完成属于同一流程状态，不增加产品侧栏页面。

模型页“配置工具”与模版列表的通用导入 / 导出进入 P-S01，带入所选对象；无勾选时详情带当前对象，列表带该类对象。模版详情“模版工具 → 同步配置”也进入同一页面。外部 Agent 的任务包与返回结果继续走制模专用流程。

设置中移除通用导入导出和 WebDAV 表单，保留“模型配置”的 Agent、Fast、文件状态职责。旧迁移 / 同步设置链接及旧 WebDAV 路由跳转新入口。

## 范围列表与凭据

主区域使用“类别 → 对象”两层可折叠列表：渠道与模型、模型模版、账户、Skills、MCP、桌面偏好，分组默认收起。WebDAV 配置仅在文件同步中提供，默认勾选且包含连接密码，导入后待启用；详情的收起同步选项可选“仅同步配置，不含密码”。展开分组后点击对象名称查看字段与文件来源，避免默认展示深层物理目录。

搜索只过滤显示，隐藏勾选保留；匹配类别自动展开并可手动收起，清除搜索恢复原展开状态。分类与总选框支持半选。渠道依赖的精确模版版本自动补齐，标明原因；补依赖不会带入凭据。两个 Tab 各自保留选择、展开状态和滚动位置，WebDAV 范围变更后先保存，再点击同步配置；取消勾选不代表删除远端。

文件同步与 WebDAV 同步均取消已选范围摘要区域；清空选择移到搜索框旁，未选任何对象时不可用。WebDAV 的保存本机范围移到顶部操作区，有修改时可用，保存后才能同步配置。同步页外部主内容区不滚动，配置对象表有独立滚动条和固定表头；勾选、展开重绘后保留内区位置。长结果在自身区域内滚动，导入 / 导出配置 / 同步配置入口保持可见。

默认“全部配置”，已选账户包含可迁移的登录状态与刷新材料，文件同步中的 WebDAV 配置默认携带密码。“分享配置 · 不含凭据”关闭全部受保护部分；“换设备 · 含可转移凭据”额外包含渠道 Key 与扩展凭据。账户列表显示“含登录状态”，点击账户名称后在默认收起的“同步选项”中可选“仅同步账户信息，不含登录状态”。右侧只保留渠道 API Key 与扩展凭据，不再重复设置账户开关。列表与凭据栏各自滚动，窄窗保留右侧凭据栏。设备绑定账户展示待验证 / 需登录，不伪装为已经支持免登录。

导出含任一凭据（包括 WebDAV 密码）时必须加密；账户登录状态由账户选择与仅账户信息选项决定，渠道 Key 另选。无凭据包导入相同身份时保留本机已有 Key；同名异端点需要新建或重新绑定。包未携带的凭据不能从导入页面勾选出来。WebDAV 导入默认采用包内密码，可选仅配置；同身份仅配置保留本机密码，新连接待补密码，导入结果为未启用连接。两个同步 Tab 删除页底原型说明。

## 可点击走查

文件同步入口使用“导出配置”。确认弹窗保留配置与凭据数量、加密选项和按需查看的内容清单，取消重复的扁平对象列表；口令标签为“加密口令（至少 8 位）”。同步弹窗不展示通用原型脚注，导出提示只保留未选凭据不会进入包或由依赖带入的规则。

窗口外工具板固定 360 px（--proto-w），贴住视口上 / 下 / 右三边、与视口等高、不留缝隙，整列单一滚动。顶层为两个等长折叠段：**全局评审条件**（导航 / 外观 / 窗口尺寸，默认收起）与**本页演示场景**（默认展开），标题改「原型工具板」，锚点改「本页演示」；跳转全局分区会自动展开上段。下半区每个页面与 Tab 都有专属 Mock，卡片统一为「分区小标题 + 控件 + 说明」；本轮补齐面板、拓展（Skills / MCP）、诊断通知历史与设置八个 Tab。文件同步的示例包选择和测试口令放在下半部分，WebDAV Tab 隐藏文件样例；应用失败场景随同步 Tab 显示。通知和 Windows 专题也保留公共区，并展示自己的测试器。工具锚点不改变产品路由。

导入弹窗按正式流程展示“选择文件 → 解密（加密包）→ 读取并比较 → 确认应用”。未选文件不能继续，非加密包不显示口令字段；示例选择器位于右栏。按用户要求，选择加密示例文件后，输入框下解释口令来自导出时的加密设置，并显示当前文件口令 demo-sync，与账户密码及 WebDAV 连接密码区分。右栏改变样例后需重新选择文件，已选文件不随 Mock 设置改变。

| 路径 | 操作 | 预期 |
|---|---|---|
| 不含凭据分享 | 文件同步 → 选择“分享配置 · 不含凭据”→ 调整对象 → 导出配置 | 清单展示所需模版版本，不含任何凭据 |
| 换设备 | 选择“换设备”预设 → 调整账户 / Key → 导出配置 | 强制加密；设备绑定账户不自动包含登录态 |
| 无 Key 导入 | 右栏文件 Mock 选择“不带 Key”→ 导入配置 → 选择文件 → 读取并比较 → 选择范围与处理冲突 | 同身份保留本机 Key；私有网关需显式新建或重新绑定 |
| 恢复登录态 | 右栏文件 Mock 选择加密完整包 → 导入配置 → 选择文件 → 解密口令 → 勾选账户 → 处理或跳过渠道冲突 → 应用 | 自动恢复并检查；设备绑定或失效显示需重新登录 |
| 仅账户信息 | 点击账户名称 → 展开同步选项 → 勾选仅账户信息 | 不携带登录状态；接收端保留已有登录，新设备需登录 |
| WebDAV | 切换 Tab → 连接设置 → 测试连接 → 调整范围并保存 → 同步配置 | 比较只涉及本机所选范围，未选远端保留 |
| WebDAV 配置迁移 | 文件同步 → 展开 WebDAV 配置 → 保持默认带密码或在详情选择仅配置 → 导出配置 / 导入 | 密码计入凭据与加密要求；导入连接待启用，当前连接不变 |
| 登录态冲突 | WebDAV 勾选账户 → 保存 → 同步配置（自动核对）→ 选有效远端 → 输入同步口令 | 不能只按时间较新自动采用登录态；连接密码不能代替同步口令 |

加密示例与 WebDAV 确认口令均为 **demo-sync**。导出口令可使用同一演示值，要求至少 8 位且两次一致。这只用于原型交互校验，请勿输入真实密码。

右栏“应用结果”下拉可切换正常、登录失效、备份失败和部分失败。登录失效时，导入提示需重新登录，WebDAV 阻止采用失效远端；后两种场景分别显示未应用 / 部分完成。刷新后所有演示状态重置。

## 导入与 WebDAV 共用比较树

比较采用与主页面相同的“类别 → 对象”树表，初始全部收起。分类和对象分别显示新增、更新、删除数量；表头、分类、单项复选框联动并支持半选。普通对象勾选即可应用，移除“保存候选”“合并新增”等重复处理标签。依赖渠道的精确模版版本自动补齐并锁定；未包含对象保持原样，只有明确删除记录可进入删除计划，且默认不勾选。

右侧操作列提供“查看详情”和凭据规则。表头可统一采用来源凭据，分类可统一设置，个别对象可独立覆盖并形成半选；WebDAV 使用“同步凭据”。渠道 Key 与 MCP 扩展凭据默认不覆盖，已选可迁移账户默认含登录状态，WebDAV 配置默认带密码；后两类可分别勾选“仅账户信息”“仅配置，不含密码”。未携带的凭据没有覆盖入口，身份未匹配的渠道不能直接采用 Key。只有同名异端点保留身份映射，两端冲突保留同步方向选择；未勾选的冲突不拦截其他对象。

“查看详情”打开第二层只读弹窗，以本机 / 配置包或远端两列显示字段差异，敏感值隐藏。详情不提供编辑与应用，关闭或 Escape 返回原比较树，保留选择、规则、同步方向、口令和滚动位置。

| 配置类别 | 只读详情内容 |
|---|---|
| 渠道与模型 | ID、地址、协议、Key 是否携带；模型增删、别名、上下文、启停、推理、Fast、顺序、精确模版引用 |
| 模型模版 | 版本、主版本、匹配规则、协议端点、能力、版本或后缀覆盖、来源 |
| 账户 | 身份、邮箱、提供方、授权范围；登录材料是否可迁移、有效性、采用规则 |
| Skills | SKILL.md 内容摘要、资源文件增删、启停、内容校验、明确删除记录 |
| MCP | 传输类型、地址、命令 / 参数、环境变量、授权是否携带、启停、本机绑定保留 |
| 桌面偏好 | 主题、语言、密度、选择器；本机绝对路径、窗口坐标、缓存与草稿保留 |
| WebDAV 配置 | 服务地址、目录、用户名、密码是否携带；导入后待启用、本机范围保留、同步口令不迁移 |

WebDAV 的“同步配置”先打开相同的比较树，确认后只处理勾选的变化；此按钮名称不表示点击即写入。

## 实现边界

本轮补绘位于共用 sync-config.js / CSS，通过既有路由、Select 和模态组件接入。模型清单取模型原型已保存的内存状态；OpenCodex 既有渠道、账户、Skill / MCP 为虚构 fixture。同步结果保留在独立演示状态中，取消或应用均不改模型页未保存草稿。

当前支持按渠道、模版、账户等对象选范围；渠道详情可查看模型 ID，尚无单个模型 / 字段的进一步勾选器。模版依赖显示 ID 与数字版本，正式 digest、缺依赖、跨机身份与多版本解析仍按需求方案实施。

导入读取示例包，不读取磁盘文件；导出展示清单和模拟结果，不序列化、不下载、不真实加密。WebDAV 连接测试与差异为模拟，不联网、不写运行配置或系统凭据库。正式加密容器、账户适配、令牌刷新、安全备份与恢复均待实现。账户目标仍是新设备可免交互登录并持续使用，不能用 fixture 核对通过作为上线证据。
