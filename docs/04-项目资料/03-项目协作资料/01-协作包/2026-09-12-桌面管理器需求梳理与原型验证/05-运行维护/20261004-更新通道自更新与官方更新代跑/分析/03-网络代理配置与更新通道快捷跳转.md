# 网络代理配置与更新通道快捷跳转

> 2026-10-04 分析／设计快照；当前归属与发布状态见 [维护摘要](../README.md)。

维护 ID：MNT-OPENCODEX-DESKTOP-20261004-03。登记日：2026-10-04。来源：用户在本轮提出——用户可能没有国内代理环境，需要一个可配置的网络代理，放到「通用」设置，参考 JetBrains 的 HTTP 代理配置项；并在「软件更新」tab 加一个配置网络的快捷跳转；网络请求行为另设独立配置文件灵活配置，目前不对用户开放，由开发规定。

> 用户 2026-10-04 确认：**本项纳入 0.1.3**；且**不使用系统钥匙串**。本文件登记需求与设计要点，不预写执行结果。

## 1. 问题

- 桌面管理器的网络请求（应用自更新检查/下载、官方远端版本查询、托管安装的 npm 拉取等）当前没有统一的代理入口；无代理环境的用户无法让这些请求走代理。
- 用户在「版本升级」里点「检查应用更新」遇到网络失败时，没有就近入口去配置网络。

## 2. 参考形态（JetBrains HTTP 代理，见用户截图）

| 段 | 选项 |
|---|---|
| 无代理 | 不配置代理 |
| 自动检测代理设置 | 勾选「自动代理配置 URL」（PAC，示例 `https://example.com/wpad.pac`）+ 「系统代理设置」按钮 |
| 手动代理配置 | HTTP / SOCKS 单选；主机名；端口号；「不为以下项使用代理」（`*.example.com, 192.168.*`）；代理身份验证（登录/密码/记住） |
| 检查连接 | 用当前配置做一次连通性检查 |

## 3. 拟定设计

### 3.1 设置入口

- 「通用」设置新增**网络**卡片，承载上述代理配置（沿用现有设置页控件风格：单选/输入/开关/按钮）。
- 「版本升级」tab 的「桌面管理器版本」卡新增**配置网络**快捷跳转，跳到「通用 → 网络」卡片；网络失败时可就近进入。

### 3.2 代理模型（类型化）

- 三个模式：`none` / `auto`（系统或 PAC）/ `manual`（`http` | `socks5`）。
- 手动模式的字段：`scheme`、`host`、`port`、`no_proxy`（例外列表）、`username`、`password`。
- **代理身份验证（用户名/密码）本版不做**：用户明确「不涉及钥匙串」，且不允许把明文口令写进配置文件。因此 0.1.3 的网络卡片只做 `无代理 / 自动 / 手动(HTTP|SOCKS5)` 的地址与例外配置，不含登录/密码字段。若日后需要代理鉴权，再单独裁决存储方式（不默认走钥匙串）。
- `socks5` 统一用 `socks5h://`（DNS 也走代理，避免本地泄漏，与托管安装既有一致）。
- 「检查连接」：用当前代理配置对一个固定、受控的探测地址做一次带超时请求，只回报成功/失败与原因，不改写任何状态。

### 3.3 生效范围（统一出站 HTTP 客户端）

- 由单一「出站网络客户端工厂」构造所有应用内 HTTP 请求，读取同一份代理配置：
  - 应用自更新（`tauri-plugin-updater` 支持 `proxy` / `no_proxy`，可在命令层按配置注入）；
  - 官方远端版本查询（U-03 新增的 `npm view` 类查询）；
  - 托管安装的 npm 拉取（现有 `ProxyConfig`，改为默认继承该代理配置，仍允许本次安装覆盖）；
  - 其它应用自有网络请求。
- WebDAV 同步的端点代理保持其现有专门配置，不并入本卡片，避免与「同步端点凭据」混淆。

### 3.4 独立网络行为配置文件（开发规定，暂不开放）

- 拟新增 `config/network.defaults.json`（与 `preferences.defaults.json` / `runtime.defaults.json` 同类）：构建期校验并嵌入，后端类型化读取。
- 承载网络请求的**行为策略**，不承载用户代理选择：超时、重试与退避、`User-Agent`、允许的域名/协议白名单、TLS 约束、并发上限等。
- **目前不通过界面或用户偏好开放**；修改属开发规定，随版本发布。可在诊断中只读展示生效来源。
- 代理选择（用户偏好）与网络行为（构建策略）分层：用户改代理不影响固定安全约束（证书校验、协议白名单）。

## 4. 边界与安全

- 公钥/端点不是代理配置的一部分；代理可配置，**TLS 证书校验不可关闭**。
- 本版无代理口令，因此不涉及口令存储；日志与命令行不出现任何疑似凭据。
- 「自动」模式需明确口径：读系统代理，或仅读 PAC——实施前定稿。
- 「检查连接」必须带超时且不改写本地状态，失败不误报成功。

## 5. 与既有分层的衔接

- 代理选择属**用户偏好**（数据根 `manager-state/preferences.json`，需新增分域字段，走 0.1.2 的读取即校验与迁移引擎）。
- 代理**不含**凭据：不使用钥匙串，也不写明文口令。
- 网络行为策略属**构建只读策略**（`config/network.defaults.json`，随版本发布）。
- 若 0.1.3 只做更新域，本项可拆为独立候选，避免一次改过多消费链路。
