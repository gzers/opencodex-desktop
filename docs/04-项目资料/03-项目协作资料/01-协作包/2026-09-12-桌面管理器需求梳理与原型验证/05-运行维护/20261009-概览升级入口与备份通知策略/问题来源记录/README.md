据此启动共用原型增量，将标准按钮取消高光追加到 0.1.10；保留按钮语义色与反馈。当时背景光仍属 0.1.9，修复目标现按下文最新要求调整。实施与发布授权不由原型候选推定。

## 2026-10-09 顶部覆盖追问

用户：“顶部是不是还是没办法超过边距？”附顶部横带与概览标题截图。

源码确认上一笔仅补左右，顶部仍按四组固定 top 定位，无法保证标题换行 / 尺寸变化后覆盖到 main 顶边。当前原型追加实际几何定位与 Logo 补偿；截图最上方窗口标题栏横带与 main 圆角描边属于外壳分层，不以删除该层替代面板内部消缝。生产实现和本次实屏消缝仍未验收。
