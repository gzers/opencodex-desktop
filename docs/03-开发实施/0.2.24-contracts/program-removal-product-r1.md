# 0.2.24 保留配置的卸载产品入口

revision: 1；2026-11-11。代码 main716020fac7f3410c41c8aa9305a599ec87fbdf76，承接program-removal-core、program-catalog-native及terminal-cli合同。实施状态归IMP-34，当前只声明Mac默认保留配置的运行程序卸载。

## 采用行为与入口

设置 → 安装配置 → 程序安装与卸载 →「卸载程序」。入口不依赖成功解析的runtime source，原操作移除一部分current/入口后仍可进入。预览显示实际I、已登记版本、保留的H、自有命令与Shell写集；取消只关闭。明确「确认卸载程序」才执行。发生中断时，后续进入显示原范围和「确认继续原卸载」，不从新的任意目录重新生成删除计划。

默认保留配置与备份，复用当前已采用post023原型。旧full/清空HOME/global npm范围及备份可关闭选项不在此默认窗口；程序删除前完整保护当前配置为必需。旧窗口代码/测试已由当前scope的设置集成回归替代，旧非版本化后端没有由此被取消测试。完整官方客户端清理/数据擦除仍是不同明确范围，未伪报已实现；不是把它们混入“保留配置”的默认确认。

用户先停止OpenCodex。执行确认仍核对原生当前H退出及Mac同UID所有命名程序不在用；Owned/Unknown、另一个H仍使用本I或原记录不可读都会拒绝，无强制结束进程的后备动作。默认不删除Desktop .app、其它工具、用户HOME或其它用户配置。

## 命令和确认

| 命令 | 输入 | 返回/写集 |
| --- | --- | --- |
| runtime_removal_preview | 无调用方路径、文件清单或服务PID | Option<Review>，含一次性随机id、原removal预览、是否继续、终端/Shell范围、绑定摘要；只读业务文件，服务端保存10分钟内存票据，不写配置备份或删除 |
| runtime_removal_apply | id与confirmationDigest，拒绝其它字段 | 原operationId、移除版本集合、configurationPreserved=true；失败时不由缺少pending推断成功 |

票据绑定启动上下文的I/D/H/profile/executable、同一Prepared原计划、终端登记原件及其预览摘要。执行一次后消费；错误ID/摘要、过期票据、配置位置改变不能提交。应用存储/安装预约和管理器更新排斥先行，原保护事务必须已核对；命令持有工作直到结束，IPC观察者关闭不会释放它。

执行前再次核对原终端内容。撤销只使用原预览已证明属于当前用户的入口及标记块；原来没有登记和reserved位置出现外部内容不同，后者拒绝。删除与恢复复用核心完整配置保护、逐文件核对和源登记revision绑定。不因重新读取而许可另一个命令或新目录。

中断读取使用program_removal::inspect_pending，核对原计划/登记、存活文件子集、原current/入口/来源的合法状态；不创建程序锁或删文件。完成标记已经创建但pending尚在的阶段，也优先继续原pending，不能误当“已完成”。新进程中的原计划继续用相同operationId，不需要旧内存票据，但仍重新核对后发新的一次性确认。

## 前端结果与观察

执行状态属于持久Pinia store，关闭/路由重挂载能观察同一个promise，不产生第二次删除。迟到预览不能重开已关闭确认；操作ID、版本集合或保留配置标记不匹配的回执不显示成功，必须再观察原状态。执行失败清除旧确认，提供「重新核对原操作」，不在错误后自动重试。

明确已经完成且没有pending返回null，页面只说明“本安装的运行程序已卸载，没有待继续的卸载”，不是伪造本次请求执行成功。成功回执后只刷新来源/路径，失败刷新不会撤销实际结果，也不静默改用户配置。
