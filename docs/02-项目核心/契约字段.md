# 契约字段

跨边界传递的数据长什么样。实体自身的字段见 `领域模型.md`；状态取值见 `数据与状态.md`。

本文件覆盖四条边界：**CLI ↔ 实例（本机 IPC）**、**容器 ↔ 磁盘 / 另一台机器（导出导入）**、**本机 ↔ WebDAV 远端（同步）**、**后端 ↔ 界面（状态上报）**。

> 除已确认的边界条款外，字段名与取值均为**设计约定，可在 IMP 调整**（标 ⏳）。IMP 冻结后本文件同步改写。

## 1. 导出容器

面向「跨机搬配置」这条边界。写出来的文件落在 `exports` 分区，按凭据文件处理（Unix `0600`）。

### 1.1 容器头

| 字段 | 类型 | 取值 / 约束 | 冻结 |
|---|---|---|---|
| `magic` | string | 容器格式标识串 | ⏳ |
| `format_version` | int | 容器格式版本；不兼容即拒绝 | ⏳ |
| `kdf` | object | 派生算法与参数（见 §1.2） | ⏳ |
| `aead` | object | 认证加密算法与 nonce | ⏳ |
| `created_at` | timestamp | 生成时间 | ✅ |
| `app_version` | string | 生成容器的应用版本，用于兼容判断 | ✅ |

### 1.2 KDF 与加密参数

| 字段 | 取值口径 | 冻结 |
|---|---|---|
| 派生算法 | 推荐 Argon2id | ✅ 方向已定 / ⏳ 参数待冻结 |
| 派生参数 | 盐、内存、迭代、并行度等；参数随容器头保存 | ⏳ |
| 认证加密 | 推荐 AES-256-GCM | ✅ 方向已定 / ⏳ 参数待冻结 |
| 口令来源 | 只经内存 / 标准输入；**不得进入命令行参数** | ✅ |

### 1.3 载荷与拒绝策略

| 项 | 要求 | 冻结 |
|---|---|---|
| 内容范围 | 全量配置，含敏感内容 | ✅ |
| 结构白名单 | 只接受白名单字段与合法路径 | ✅ |
| 未知字段 | 拒绝，不做"尽力而为"的解析 | ✅ |
| 越界路径 | 拒绝 | ✅ |
| 条目与大小上限 | 防 OOM 与超大对象 | ✅ 方向已定 / ⏳ 上限待冻结 |
| 完整性 | 认证加密自带；解密或校验失败即拒绝，**不部分导入** | ✅ |

> 容器内容只做**数据**，不做指令：不因容器里的内容执行任何本地程序。

## 2. 同步清单（manifest）

面向「本机 ↔ WebDAV 远端」这条边界。远端被视为**不可信**，真实性由客户端加密覆盖，清单里的哈希只用于检测传输损坏与回放。

| 字段 | 类型 | 取值 / 约束 | 冻结 |
|---|---|---|---|
| `format` | string | 清单格式标识串 | ⏳ |
| `version` | int | 协议版本；不符即拒绝并给出可读原因 | ⏳ |
| `compat_version` | int | 兼容版本，用于识别旧清单回放 | ⏳ |
| `snapshot_id` | string | 本次快照标识 | ⏳ |
| `created_at` | timestamp | 生成时间 | ⏳ |
| `device_name` | string | 生成设备名，便于冲突判断 | ⏳ |
| `artifacts` | map | 对象名 → `{ size, hash }`，逐件记录大小与哈希 | ⏳ |

### 2.1 传输与校验顺序

```text
上传：载荷逐个先传 → manifest 最后传
下载：先取 manifest → 校验格式与协议版本 → 逐件下载并按 manifest 校验（大小 + 哈希）→ 解密 → 应用
```

- **载荷先、manifest 后**：保证「半同步」不会被当成有效快照。
- 逐件校验通过后才应用；校验失败**不应用远端内容**，保持本地不变。
- 远端变更检测：记录上次同步的 manifest 哈希 + ETag，比对识别远端变化。
- 并发：**单端点单次同步**，同步互斥串行化。
- 上限：manifest 与单个对象均有大小上限；解压类载荷另有条目数上限（防压缩炸弹与路径穿越）。
- ⏳ 载荷切分与命名、时限与重试、备份保留待冻结。

## 3. 备份清单

每次备份登记一条 `BackupRecord`（字段见 `领域模型.md` §6）。清单文件本身的最小字段：

| 字段 | 类型 | 说明 | 冻结 |
|---|---|---|---|
| `backup_id` | string | 备份标识 | ✅ |
| `kind` | enum | `upgrade` `import` `sync_overwrite` `data_root_move` `extension_write` | ✅ |
| `target` | string | 被备份对象 | ✅ |
| `created_at` | timestamp | 生成时间 | ✅ |
| `content_hash` | string | 内容摘要（SHA-256） | ✅ 算法 / ⏳ 字段名 |
| `stored_at` | string | 备份落点（相对 `backups` 分区） | ✅ |
| `restorable` | bool | 是否已验证可恢复 | ✅ |

- 备份必须**可定位、可校验、可恢复**；备份失败阻断后续破坏性动作。
- 写入事务还会记录「目标、时间、备份位置、内容摘要」清单，用于冲突检测与恢复（`WR-06`）。

## 4. CLI 契约（`ocxd`）

面向「`ocxd` ↔ 运行中实例」这条边界。官方 CLI 仍叫 `ocx`；`ocxd` 是管理器自己的入口。

### 4.1 总则

| 项 | 要求 | 冻结 |
|---|---|---|
| 默认状态 | 关闭；启用后才注册入口 | ✅ |
| 执行方式 | 经本机 IPC 委托运行中实例，**不产生第二写入者** | ✅ |
| 能力范围 | 仅管理器自有域：发现与只读状态、启停、数据根、备份、加密导出/导入、WebDAV 同步、自更新检查 | ✅ |
| 明确不开放 | provider、路由、模型映射与 OpenCodex 核心运行配置的写入 | ✅ |
| 实例未运行时 | 只读命令降级说明；变更类命令报错，不绕过实例直接写状态 | ✅ |
| 机读输出 | 提供 `--json`，满足非交互与幂等要求 | ✅ 方向 / ⏳ 契约待冻结 |
| 破坏性操作 | 必须带确认标志，校验、备份与确认语义与 GUI 一致 | ✅ |
| 自发现 | `ocxd --help` 是能力自发现入口 | ✅ |

### 4.2 命令表

| 命令 | 层 | 需实例在线 | 破坏性 | 需确认标志 | 冻结 |
|---|---|---|---|---|---|
| 发现与只读状态 | 只读 | 否（降级说明） | 否 | 否 | ⏳ 命令名待冻结 |
| `start` / `stop` / `restart` | 变更 | 是 | 否 | 是（显式确认） | ⏳ 命令名待冻结 |
| 数据根查询 / 切换 | 只读 / 变更 | 查询否、切换是 | 切换是 | 切换需确认 | ⏳ 命令名待冻结 |
| 备份 | 变更 | 是 | 否 | 是 | ⏳ 命令名待冻结 |
| 加密导出 / 导入 | 变更 | 是 | 导入是 | 导入需确认 | ⏳ 命令名待冻结 |
| WebDAV 同步 | 变更 | 是 | 覆盖是 | 覆盖需确认 | ⏳ 命令名待冻结 |
| 自更新检查 | 只读 | 否（降级说明） | 否 | 否 | ⏳ 命令名待冻结 |

### 4.3 输出与退出码

| 项 | 要求 | 冻结 |
|---|---|---|
| `--json` 字段命名 | 与三维状态、实体字段对齐 | ⏳ |
| `--json` 版本化 | 提供契约版本，便于脚本稳定依赖 | ⏳ |
| 输出脱敏 | 输出层统一掩码，**禁止输出 S3 级数据** | ✅ |
| 退出码语义 | 成功 / 参数错误 / 实例离线 / 需确认标志 / 执行失败 等分类 | ⏳ 待冻结 |
| 幂等 | 重复执行相同命令不产生额外副作用 | ✅ 方向 / ⏳ 验证方式待冻结 |

### 4.4 IPC 请求与响应

| 字段 | 类型 | 说明 | 冻结 |
|---|---|---|---|
| `command` | string | 子命令 | ⏳ |
| `args` | map | 参数（**不得含明文凭据**） | ⏳ |
| `confirm` | bool | 确认标志 | ⏳ |
| `contract_version` | string | 调用方与实例协商的契约版本 | ⏳ |
| `ok` | bool | 响应状态 | ⏳ |
| `data` | object | 结果载荷（按命令不同） | ⏳ |
| `error_code` | string | 失败分类 | ⏳ |
| `message` | string | 可读说明（脱敏） | ⏳ |

- 端点字段与访问控制见 `领域模型.md` 的 `IpcEndpoint`。
- 关闭时移除端点并校验不可用。

## 5. 状态上报（后端 ↔ 界面）

| 字段 | 类型 | 说明 | 冻结 |
|---|---|---|---|
| `runtime` | enum | 运行状态取值（`数据与状态.md` §2.1） | ✅ 取值 / ⏳ 字段名 |
| `connection` | enum | 连接状态取值（§2.2） | ✅ 取值 / ⏳ 字段名 |
| `operation` | enum | 操作状态取值（§2.3） | ✅ 取值 / ⏳ 字段名 |
| `gate` | enum | 环境前置门禁状态（§2.4） | ✅ 取值 / ⏳ 字段名 |
| `facts` | object | `RuntimeFacts` 字段（见 `领域模型.md` §4） | ✅ |
| `actions` | array | 当前状态下允许的动作集合 | ✅ |
| `updated_at` | timestamp | 最近一次刷新时间 | ✅ |

- 三个维度**必须能同时上报**，界面不得把它们压成单一状态。
- 刷新策略与优先级（轮询 / 事件、冲突时的呈现）留 IMP 冻结。
- 官方命令输出到 UI 枚举的**字段映射**留 IMP 冻结。
