| W18-05 / WP92 | 官方 shim 适配器清空环境后只设置 HOME，缺少 Windows SystemRoot/USERPROFILE 等；附加 Codex 发现还只检查无扩展名文件。 | 统一补齐 Windows 用户和系统环境，识别受控候选内 `.exe/.cmd/.bat`，保留系统最小 PATH。只读假 CLI 修复前返回失败，修复后核对正确 HOME/USERPROFILE；未操作用户真实 shim。 |
| W18-06 / WP92 | 环境发现把普通 `.txt` 当作 Windows 可执行文件；相对现存文件也可能过关。生命周期领域验证未完整要求所有路径绝对。 | 发现复用受支持入口校验并要求绝对路径；生命周期 executable/cwd/OPENCODEX_HOME 均要求绝对路径。修复前普通文本 Node 得到 Ready，修复后 MissingNode；既有绝对路径/目录/凭据隔离回归保留。存在性发现仍不等于已成功运行或版本兼容证明。 |
| W18-07 / WP93 | 打开文件/目录按裸 `explorer`、外链按裸 `cmd /C start` 启动，依赖当前目录或进程 PATH；直接传内部路径给不同 Shell 消费者也缺少统一边界。 | 改用 Unicode `ShellExecuteW`，Shell 边界只安全简化同一身份的路径，不解析命令行、不搜索应用 cwd 中的 cmd/explorer，检查 Shell 返回值。原后端路径白名单和文档资源定位不变；用实际 Explorer 目录位置核对本轮测试路径。 |
| W18-08 / WP90 | 完整卸载的官方命令未绑定当前 OPENCODEX_HOME；npm 全局卸载未传入方案识别的 prefix，且继承管理器 cwd。 | 命令契约显式携带配置目录与 prefix，npm 使用 `--prefix`，cwd 绑定明确的用户 HOME；缺失目标拒绝执行。修复前假命令打印 HOME 缺失、prefix 缺失和管理器 cwd；修复后全部匹配选中对象。夹具只打印参数，没有执行用户安装的真实卸载。 |
| W18-09 / WP95 | 系统环境把 COMSPEC 拼成 `C:\WINDOWS\System32/cmd.exe`，本机 NVMD 输出命令语法错误（本轮四组对照原文为 `The syntax of the command is incorrect.`）。 | 改为原生反斜杠。原生 Rust 四组入口/COMSPEC 交叉对照证明仅 COMSPEC 变化决定该提示，入口混合分隔符不是该提示原因；四组 npm 都退出 0。**这证明一个环境兼容缺陷，不证明历史退出码 1 根因。** |

原始诊断命令、stdout/stderr、第三方 CLI 原文、URL、WebDAV 远端路径、JSON 字段路径和历史证据保留原文；不能对任意字符串做删前缀/换斜杠处理。恢复引导中应用自行插入 HTML 的路径额外经过 HTML 转义，避免合法 `&` 等字符改变展示结构。

## 验证与失败记录

最终验证结果及对应源码/EXE 身份以[本轮证据清单](../../../../.adg/evidence/0.2.18/windows-path-environment-audit-20261028/manifest.json)为准；逐项回执区分成功、失败前对照、测试前置条件修正与未执行环境。

- 前端最终回归：170 个测试文件，1034 项通过，10 项既有跳过；typecheck、构建通过。覆盖显示/复制与 raw 打开分离、合法空格和中文、盘符/UNC/长路径/设备/URL/POSIX 保留、备份根及目录选择。
- Windows 定向回归：17 项通过、4 项显式忽略。模型宿主环境泄漏、普通文件误识别、卸载目标遗漏及 shim Windows 环境缺失均保留修复前失败和修复后结果；不把假 CLI 称为真实用户卸载。
- 本机原生 COMSPEC 四组对照分别保留 stdout/stderr 原始字节；不因 npm 最终成功而忽略命令解释器的前置错误。
- 完整工作区首轮编译出现 OS1455（页面文件/提交量不足），两个集成测试未编译完成；不是测试通过，也没有调整系统页文件。后续采用 `--jobs 2` 限制**编译**并发，测试线程数、超时与断言保持。
- WebView 早期脚本失败保留：未聚焦文档拒绝剪贴板读取；只模拟焦点仍等待权限；全新 Profile 尚无偏好文件时备份按契约拒绝；随后误选始终存在的通知 dialog，未命中实际确认框。脚本修正后使用真实剪贴板 API、保存沙箱实际偏好、匹配当前 modal；没有拦截或模拟生产 IPC。
- 一轮路径检查曾过早读取到 Skills 源目录占位，只有一条路径即结束；已将验收改为逐项等于后端全部六个分区/十三个 Agent 路径。该轮不得用来声称全量客户端路径已验。
