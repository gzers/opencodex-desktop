# 方案草案

## 已冻结方向

- 桌面壳：Tauri v2 + Rust 后端 + Web 前端。
- P0：macOS 优先；发现 OpenCodex；选择/切换 `OPENCODEX_HOME`；统一数据根；直接托管官方启停子进程；状态观测、日志入口和官方 Web 面板。
- P1：全量配置导出/导入；敏感内容进入用户口令保护的加密容器；导入前校验、备份并确认。
- P2：WebDAV 全量同步；客户端加密；冲突提示；覆盖前备份；可恢复。

## 实现边界

- 只发现 npm 安装形态，不管理 npm。
- 不安装或管理 launchd service。
- 不接管 `codex-shim`。
- 不替代官方 `ocx update`，只做升级前备份与引导。
- 不重写 OpenCodex 核心，不绕过官方 API。
- 不直接修改 AiMaMi 等外部路由器托管的配置。

## 实现参考：扩展管理（2026-09-14）

- **参考实现基线**：`farion1231/cc-switch`。它是同类产品（Tauri + Rust）、面向同一批客户端（Claude Code、Codex、OpenCode、OpenClaw、Grok Build、Hermes Agent），MCP 与 Skills 均已产品化。
- **采纳的架构**：单一真相源（本项目统一扩展配置，含 per-app 启用矩阵）+ **逐客户端投影** + 每客户端适配器四件套（导入 / 全量同步 / 单条同步 / 移除）。
- **采纳的机制（12 项）**：原子写（临时文件 + `create_new` + 保留权限 + rename）、凭据文件 `0600`、TOML 用 `toml_edit` 保留注释与顺序且不触碰 `auth.json` 等非目标文件、客户端未安装时跳过且不落盘、导入逐项容错、Skills 源存储可切换、Skills 分发支持 symlink/复制（symlink 优先，回退复制）、卸载前备份并可恢复、SHA-256 内容哈希用于变更与冲突检测、路径重叠/别名/逃逸强制校验、写入状态锁串行化。完整清单见 `04-需求分析计划/安全评审输入.md` §15.6。
- **不采纳的部分 / 保持更严**：MCP 执行边界确认（写入前展示完整命令行并显式确认）、凭据只写环境变量引用、多写入者并发保护（文件锁 + 摘要比对 + 冲突待处理）。前两项是 DMD `AC-11` / §10 已确认的需求条款。
- **同步与迁移也参考同一基线**：WebDAV 采用其 manifest 协议（格式串 + 协议号 + 兼容版本 + 快照 ID + 逐件哈希；载荷先、manifest 后；逐件校验；同步互斥；大小与条目上限），配置迁移采用其「临时区校验后再生效 + 导入内容不得拥有任意执行能力」的加固思路。
- **有意更严的两处**：配置迁移使用**口令保护的加密容器**，WebDAV **上传前必须客户端加密**——cc-switch 两者均未加密，但这是 DMD `AC-06` / `AC-07` 已确认的需求，不跟随基线放宽。
- **偏离规则**：实现如需偏离该基线，须说明理由并记录；若发现上游行为与文档不一致，以上游实际行为为准并回改文档。

## 已确认：可选 CLI 控制面（2026-09-13 提出并确认）

- 背景：用户询问本项目是否需要支持 CLI，供 AI 控制、调整配置。
- 关键区分（结论取决于此）：
  - OpenCodex 自身配置（provider、路由、模型映射，即 `~/.codex/config.toml` 一类）的权威属于官方 CLI；本项目再加一个写入者，等于制造自身要检测的「外部接管」场景，与本包「不重写 OpenCodex 核心、不绕过官方 API、不覆盖外部托管配置」相冲突。
  - OpenCodeX-Desktop 自身状态与数据操作（数据根、备份、导出/导入、WebDAV、自更新通道）属于本项目自有域，可安全对外暴露。
- 2026-09-13 用户确认：采纳「管理器控制面 CLI」，形态参考 Obsidian 自带 CLI 开关——设置中默认关闭、手动启用；CLI 作为运行中实例的客户端，经本地 IPC 委托执行；只覆盖管理器自有域（发现/status、start/stop/restart、数据根、备份、导出/导入、WebDAV、自更新检查），不做第二个 OpenCodex 配置写入者。
- 已回写 DMD：新增 `AC-OPENCODEX-DESKTOP-10`，并在 §8 范围补充「CLI 控制面（可选）」、§10 安全边界补充本机 IPC 访问控制。
- 待 IMP 冻结：命令集与子命令、`--json` 机读契约、非交互与幂等语义、破坏性操作的确认标志、单写者/并发锁、GUI 与 CLI 的 IPC 协议、CLI 注册到 PATH 的落点。
- 备选路线：以 MCP server 作为 AI 适配层，复用同一 core（后置，不阻塞 P0）。
