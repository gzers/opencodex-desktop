## 1. 两种展示形态

独立页面用于承载评审与右侧原型工具板，默认展示居中选择弹窗。关闭后留在打样背景和结果摘要，可重新打开；取消或单选返回不会立即自动重开。右侧工具切换单选 / 多选时重新展示对应弹窗。页内展示仅是工具板中显式选择的对照形态。两种形态使用同一目录、渲染与选择规则，切换时清理旧实例，避免同名控件 ID 重复。

弹窗最大约 980 × 620 px，并随产品窗口收敛；页内展示约 510 px 高，窄内容区约 460 px。渠道与表格分别滚动，单选 / 多选已选区和底部动作固定在组件内；窄窗表格可在自身容器横向滚动，不撑开外层。独立页在短窗口内可纵向滚动到结果与动作。左栏与右侧主体沿用同一背景，渠道不再铺单独底色。

单选不展示复选框或单选框，也不展示全选；当前项用加深的整行底色、左侧竖线和“✓ 已选”标记表示；单选与多选都常驻底部已选区。标签改为更清楚的玻璃底、边框、勾选图标与 12 px 型号文字；启用推理能力时，等级作为次要后缀。模式由调用方决定，选择器标题不放“单选 / 多选”徽标。打样页右侧工具可以切换形式，不作为产品用户操作。

## 2. 浏览、搜索与表头排序

| 区域 | 当前规则 |
|---|---|
| 左栏渠道 | 第一项“全部”固定且默认选中；下方渠道与官方 / 原生组独立滚动。点击只切右侧范围，不批量选择模型 |
| 渠道搜索 | 按渠道名称 / ID 过滤左栏，“全部”始终保留。搜索不自动改变当前模型范围或已选值；当前渠道暂时不在筛选结果中时，模型范围保持；左侧选中项及表格的可访问名称表明范围 |
| 标题与搜索位置 | 左“渠道”、右“模型”固定标题，两侧搜索都在标题下方，同高同线；结果数留在模型标题右侧 |
| 模型搜索 | 只放右侧模型区，按名称 / ID / 别名查询当前渠道；“全部”时跨渠道查询。切渠道保持模型关键词，清空两侧搜索各自独立；输入框只有一个清除按钮，居中对齐并预留文字右边距，不叠加浏览器原生清除控件 |
| 模型表格 | 表头沿用弹窗的中性半透明材质，并保留轻分隔线、吸顶与排序；模型名称与完整原始 ID、别名（有时）、渠道、上下文、推理档位、状态；调用方提供明确推荐列表时增加推荐列。未知数据显示“未知” |
| 点击表头 | 每列按升序 → 降序 → 原目录顺序循环，箭头与 aria-sort 表示方向；移除排序下拉。只有本次浏览顺序变化 |
| 数值 / 档位 | 上下文按数值，默认推理档位按档位序列排序，未知值在升 / 降序下都留在末尾；同值保留原顺序 |
| 推荐 | 只展示明确推荐引用，不推测型号的质量、价格或速度；推荐列表索引参与排序，无推荐数据时不显示该列 |

同模型 ID 来自不同渠道时是不同记录，每行必须显示渠道；不能合并身份。单选 / 多选底部保持全部已选项，包括搜索或渠道范围以外的项。表头排序不改变模型配置顺序、已选列表优先级或推荐策略。

## 3. 单选、多选与返回

| 调用形式 | 操作与返回 |
|---|---|
| 单选 | 点模型只替换唯一待选项；启用设置能力时打开连续编辑浮层，改档与 Fast 都不关闭。点击浮层外 / 焦点移出只收小浮层；主“确定选择”才返回组合并关闭，取消保留原值。未额外选档时显示实际默认，底部无删除或清空 |
| 多选 | 表格增加复选框与全选；底部显示所有已选标签，启用推理时各项可独立设置档位；从未选行直接选档位会加入该模型。移除 / 清空 / 确认不变，取消恢复型号和档位 |
| 已选优先级 | 调用方要求有序列表时，底部提供上移 / 下移；新选项追加，移除保持其他项相对顺序。集合用途不显示排序动作 |

“全选当前结果”只操作右侧当前范围的可选结果，标明数量，保持查询外已选项。取消全选同样只移除当前结果，不清空其他范围。“全部”渠道只是导航，不是全选。

选择器只负责选具体模型，移除继承区及其工具开关。继承 / 自定义状态、有效模型、来源与恢复继承操作留在调用方的业务配置页；沿用上层时，调用方可以把当前有效模型传入组件用于高亮和底部核对。选择具体模型后由调用方形成本层覆盖，浏览或取消不改变继承语义。单选底部展示当前已选，多选展示临时选择列表，均不冒充上层来源。

模型缺失、渠道停用或无额度时按提供的事实显示原因，已选失效项仍能在底部查看；单选点可用型号替换待选项，多选可移除，未处理失效项时不能确定。生产可选性规则仍由业务调用方决定，组件不自动开启渠道或添加主模型白名单。

键盘可从模型搜索按向下键进入行，方向键 / Home / End 移动，单选 Enter 选入唯一待选项并保持主弹窗；多选 Space 勾选，两者均确认后返回。弹窗 Esc 取消、关闭归还焦点。已选结果的确切身份独立于名称、查询和排序。

## 4. 通用注释与工具板

操作说明“单选 / 多选均确认后返回；小浮层失焦只收起，保存由调用方负责”等收进通用折叠“原型 01 +”标记，使用已有 annotation-cards 组件；默认收起，页内标记和右侧“本页注释”目录都可展开。单选底部仅保留当前已选和取消；启用推理能力时可从标签修改档位，仍不能删除型号。多选保留数量、删除、取消和确认。原型标记移入弹窗标题层绝对定位，正文不设占位行；页内对照同样悬浮。显示、隐藏和展开标记不改变软件尺寸或模型区高度。说明只在折叠注释中阅读，不常驻为产品文案。

独立页右侧上下文是“公共渠道模型选择器 / 单选打样”或“多选打样”，弹窗开关不影响工具板可操作性。工具板提供完整目录、长名称、空目录、读取中、读取失败、已选引用缺失，以及推理选择开关、能力差异、推荐 / 优先级示例。结果摘要留在打样页和工具板，业务页面状态不受影响。

## 5. 数据边界与后续接入

组件消费已保存的渠道模型目录，包含原生身份及渠道稳定引用，返回 nativeModelId 或 channelId + modelId，可附该项 reasoningEffort；默认与不启用推理时不带该字段，继承意图由调用页独立保存。当前只消费模型模块的已保存 **mock**，正常目录 152 项（30 + 104 + 12 + 6），长名称额外 8 项，不因主选择器白名单或 100 项激活兼容预算截断。A6api 无额度、能力、上下文与推荐均为 fixture，不证明真实模型事实。

公共组件负责浏览、临时选择与返回。调用方负责用途、支持范围、可选性、继承来源、草稿和保存 / 采用；命名、搜索、子 Agent、制模助手、项目 / 对话模型分别验证真实执行路径。原生 hosted search 没有独立模型参数时，不能靠选择器假装支持。打开选择器不自动扫上游、查额度或调用模型；真实分页与刷新契约在生产接入时确定。

本轮未替换 model-config、conversation-config 或 sync-config 的业务模型字段，也未交付生产组件、目录服务、真实配置存储或历史同步。用户已明确将公共组件纳入模型配置包的 0.2.0 开发范围，组件由该包实现与接入；对话功能后续复用，本身继续版本待定。按当前已确认交互逐项实现、接入业务并回归。公共规则集中在本文件，两个协作包引用，不复制第二份规格或 HTML。

## 9. 可选推理滑杆与已选标签

2026-10-13 用户提出模型与推理可一次选定，可选择档位也可不选；随后提供 Codex 滑杆与型号后缀参考，要求悬停已选模型弹出同总体玻璃风格的浮层。推荐方案获“同意执行”；追加要求标签更清楚、显眼。本轮已在唯一总原型 #model-picker 制作，仍是公共设计探索，版本及业务接入时机未定。

### 交互与组件范围

| 入口 / 形式 | 当前行为 |
|---|---|
| 调用方不启用推理 | 原型工具“允许选择推理档位”关闭后，表格只展示原有元数据；已选标签没有等级后缀、浮层或档位入口；单选 / 多选均由主“确定选择”返回 |
| 单选模型行 | 悬停可预览；点击名称进入该模型的连续设置浮层，先选档再切 Fast，均保持；点击外部 / 焦点移出只收浮层，主“确定选择”返回并关闭；新型号沿用自身实际默认档位 |
| 单选底部已选 | 标签不可删；悬停 / 点击可调整档位与 Fast，连续修改不返回，编辑后点击外部 / 焦点移出只收浮层，主“确定选择”才采用 |
| 多选模型行 | 普通勾选加入型号，不额外指定时显示实际默认档位；从档位入口直接选“模型＋档位”会一次加入该模型；同渠道同型号只更新原项，不重复添加 |
| 多选底部已选 | 每个标签独立调整档位与 Fast，修改时浮层保持，点击外部 / 焦点移出后只收浮层，最后统一确认；移除与优先级不变 |
| 悬停与离开 | 首次悬停等待约 70 ms，已展开时跨行预览立即切换；点击和键盘聚焦直接展开。从标签移入浮层保持。离开约 220 ms 收起，键盘正在浮层中操作时保持，点击外部 / 切范围 / 滚动列表 / 关闭主弹窗时收起 |
| 鼠标滑杆 | 只在支持的真实档位上吸附，修改即时更新草稿与底部标签，松开也不关；下面档位文字直接更新当前档位 |
| 键盘 / 滚轮 | 方向键、Home / End、滚轮同样更新草稿且不关；Tab 离开浮层时只收起，单选 / 多选均等待主确认，Esc 撤回本次浮层修改，主选择器保持 |
| 恢复默认 | 清除显式等级并显示实际默认，浮层保持，Fast 状态不变；点击外部仅收起，主确认才返回 |

浮层是组件自有固定定位层，约 268 px 宽，在软件窗口与浏览器可见区域交集中摆放。优先在标签上方，空间不足改放下方；不挤压表格、底部标签或窗口尺寸，也不受表格 / 已选区滚动容器裁切。使用现有主题材质、模糊变量、圆角、闪电与恢复图标、离散滑杆和柔和强调色。原型注释仍位于标题层，零占位。

浮层承载推理档位与可选快速模式，不提供换渠道、改型号或真实模型调用。不额外指定时直接显示调用方提供的实际默认档位，例如“中”，滑杆也定位到该实际档位，不再增加“默认”选项。“无”是模型确实声明支持的 none 档位，仍保留。实际档位未知时显示“未知”；未提供支持集合时提示“未提供可选档位”，不根据型号名称编造滑杆。演示能力来自已保存模型 mock；新增“推理能力差异”场景以 fixture 验证不同集合，不代表真实型号支持情况。

### 标签与状态

- 底部标签采用 7 px 圆角、较清楚的边框和玻璃底色、勾选图标、与表格一致的 12 px 型号文字和紧凑留白；hover / focus 使用轻强调边框。等级在型号后面显示，例如“NewApi / gpt-5.4 极高”；沿用默认时显示实际值（如“中”），标签不带下拉箭头；悬停 / 点击功能保持。关闭推理功能时只保留型号。
- 多选有序列表保留编号、上移 / 下移与移除；按钮与型号分区，单选无这些动作。长渠道 / ID 可换行，已选区自身有界滚动，不撑开软件。
- 选择以 channelId + modelId（或 nativeModelId）为唯一身份，档位附在该身份上。切渠道 / 搜索 / 排序不丢选择；换型号不套用之前型号的档位。移除后再选从该模型实际默认档位开始。
- 多选修改等级只更新临时缓冲，主“确定选择”才返回全部；取消恢复原型号、各项档位与顺序。元数据变化导致已选显式档位不再支持时保留可见意图，允许恢复默认或重选支持档位，不静默转成另一个档位。
- 表头档位排序在能力启用时按当前生效档位排序，未覆盖项使用实际默认值，未知值末置。关闭能力时继续按目录默认档位排序。浏览排序仍不改变已选优先级。

返回仍是稳定型号引用，可附加可选字段：

~~~json
{
  "kind": "models",
  "models": [
    {"kind": "channel", "channelId": "newapi", "modelId": "gpt-5.4", "reasoningEffort": "xhigh"},
    {"kind": "channel", "channelId": "aimami", "modelId": "gpt-5.4-mini"}
  ]
}
~~~

第二项沿用默认，所以省略 reasoningEffort；界面仍展示其实际默认值，不能把 null / 默认当成 API 档位发送。关闭推理选择时组件只返回型号字段。原型结果摘要显示型号后缀供评审；生产保存、继承、能力查询和路由适配仍由调用方负责，未交付真实配置写入。

## 13. 模型模版 Agent 共用执行设置接入

2026-10-13 用户明确要求模型模版 Agent 配置使用本专题的弹窗组件选择模型和推理等级，并再次指出它属于 0.2.0 开发范围。本轮在唯一总原型 #models 接入，组件专题 #model-picker 继续使用原样式和交互。

本机模型模版 Agent 共用一份执行偏好，供自动填充 / 纠偏、单个更新、所选更新和全部更新读取；不属于某个模版 revision，也不覆盖 Codex 命名、搜索或子 Agent 的设置。任务开始冻结执行身份、显式推理及有效默认；之后更改共用设置只影响下一次任务。

组件新增 choose 调用接口，接收当前模型引用、是否启用推理、业务提供的动态目录与 onSelect / onCancel。业务调用不跳到打样页，也不修改专题的模拟选中结果、模式、场景或推理开关；关闭后恢复原场景状态。模型模版调用单选形态，主“确定选择”后返回设置缓冲，用户保存共用设置才更新偏好；取消选择恢复原缓冲，离开业务页面则关闭且不重新弹出旧设置。

## 14. 推理与快速模式连续编辑，失焦后收起

本节记录前一轮行为与当时验证；其中“单选失焦返回”及“不设确认按钮”已由第 15 节取代。连续编辑与 Fast 契约继续保留。

2026-10-13 用户指出点选推理就提前确认，来不及选择快速模式，要求“选择推理等级也不关，点击快速模式也不关，点其弹窗外失去焦点就可以了”。本轮修改唯一总原型 #model-picker，并同步已接入的模型模版 Agent 共用执行选择入口，继续归 0.2.0 / WP-07。

| 交互 | 当时规则 |
|---|---|
| 直接点击模型 | 调用方启用推理或 Fast 任一能力时，先打开该模型设置浮层，明确选择该型号但不提前回调；两种设置能力都关闭时保留普通单选点即返回 |
| 改推理 / 滑杆 / 恢复默认 | 仅更新当前选择缓冲和底部标签，浮层与主选择器都保持；默认仍显示实际值，不固化成覆盖，恢复默认不改 Fast |
| 快速模式 | 浮层左上闪电为 switch，点亮表示开启，再点关闭；仅明确支持时允许开启，未知 / 不支持列明原因。仅改 Fast 也不关闭、不提前返回 |
| 单选点击外部 / 焦点移出 | 已明确选择或编辑后，收起浮层并一次返回型号、可选 reasoningEffort 与可选 fast，再关闭主选择器；单纯悬停预览不返回 |
| 多选点击外部 / 焦点移出 | 仅收起当前浮层，型号 / 等级 / Fast 留在多选草稿，最终主“确定选择”才一起返回 |
| 取消 / Esc | 主选择器取消保留原值，不把取消点击误当外部采用；Esc 优先撤回当前浮层本次修改并收起，主选择器保持。业务页切换仍走取消 |
| 连续操作稳定性 | 改档 / Fast 刷新标签时不重建或关闭浮层，不移走滑杆焦点；开始编辑后鼠标移离不自动确认，防止跨到另一触发项时偷换正在编辑的型号 |

快速模式可由调用方 fast 开关启用，目录提供 fastCapability（supported / unsupported / unknown）及实际默认 Fast 状态。每项返回可选布尔 fast；明确关闭也保留 false，未设置且无原值时不额外生成覆盖。已开启但能力变化的项允许关闭，不允许继续以不可用 Fast 返回。模型模版 Agent 调用 fast:true，目录使用已保存有效规则；返回组合进入共用设置缓冲，点击“保存共用设置”才更新本机偏好，运行中的任务快照不变。

连续编辑沿用 268 px 紧凑玻璃浮层、16 px 主档位和 28 px 标签；已选标签开启快速模式时显示 Fast 后缀。没有重新加入默认滑点、删除单选或确认按钮。此前“改档 / 点档即关闭”的原型检查是历史行为，当时以本节为准，当前单选采用第 15 节最终确认。

## 17. 表格推理浮层响应优化

本轮于 2026-10-13 开始、2026-10-14 完成。用户反馈：“推理层级的弹窗响应慢，特别是在表格的时候。”目标仍为 OpenCodex 桌面管理器 Desktop，唯一入口 [总原型 #model-picker](原型/index.html?design=models#model-picker)，同时检查设置 → 模型配置 → 配置 / 调整 Agent 的共享组件使用。

源码发现初次悬停固定等待 180 ms；点击模型、调档和切 Fast 又会重建渠道和完整表格。当前目录示例 152 行，重复 DOM 重建还会移除原焦点锚点。已调整首次悬停等待为 70 ms，已展开浮层跨行预览直接切换，点击 / 键盘聚焦不等待。开始连续编辑后仍固定当前型号，直到失焦收起，避免移动鼠标时误换型号。

|---|---|
| 表格悬停与跨行预览 | 实际鼠标经过表格档位入口，浮层显示对应型号；跨行预览显示新型号。70 ms 为代码配置值，本轮没有测量端到端延迟或作性能百分比承诺 |

| Agent 共用执行设置 | 实屏核对无独立“使用 Fast”开关，组件确认返回高＋Fast 到缓冲，再保存更新共用 mock 偏好；补充第 16 节此前尚缺的该路径实屏验证 |
