## 5. 「视觉特效」档位定义（2026-09-30 定：三档 高 / 中 / 低）

一个旋钮，三档 **高 / 中 / 低**。全局属性 **`data-effects="high|mid|low"`**（写在 `<html>`，与 `data-theme` 同构）。

| 档 | 动态光场 | 玻璃（模糊 + 半透明） | 通知 | 定位 |
|---|---|---|---|---|
| **高**（默认） | 动 | 有 | 玻璃 | 完整观感 |
| **中** | **静止** | 有 | 玻璃 | 省电；等价系统「减少动态效果」 |
| **低** | 无 | 无（纯色实底） | 实底 | 退回**应用原本黑白实底风格** |

三档只动两个真实杠杆：**光场是否动画**（最吃 GPU）与 **是否玻璃**（`backdrop-filter` + 半透明填充）。
「中」冻结光场但保留柔光底与玻璃，观感几乎不变、只去掉运动——这也是 `prefers-reduced-motion` 的自动落点。

- **低** 的语义（＝应用原本黑白实底风格）：隐藏光场；所有玻璃表面 `backdrop-filter:none`、填充退回实底
  `--panel`、描边 `--border`、投影退回 `--shadow-sm`；强调按钮退回 `--accent` 实底 + `--accent-ink`；**通知同样退回实底**。
- 原型：`?effects=high|mid|low` + 顶栏「特效档：高 / 中 / 低」控件（glass.html 已落地）；后续在**设置 → 通用**加「视觉特效」行。
- 生产：新增 `effects` 偏好字段；按 `app/appearance/theme.ts` 同款写 `document.documentElement.dataset.effects`；
  `tokens.css` 增 `html[data-effects="mid|off"]` 块。
- `prefers-reduced-motion: reduce` 且用户未显式指定时，自动落 **mid**。
- 未采纳：更细的「高/中/低」四档——三档已覆盖真实杠杆，多一档只是重复。

## 9. 架构（唯一真源）

- **`05-原型/glass-tokens.css`** ＝ 玻璃**表面令牌**的唯一真源（light + dark：玻璃填充 / 模糊 / 双色滤镜 /

- **`05-原型/glass-effects.css`** ＝ **特效档**的唯一真源：低档只**翻转玻璃令牌**
  （`--glass-fill` / `--glass-rail` / `--glass-blur-notif` / `--glass-blur` / `--notif-tint-a·b`）＋关闭环境光；
  各页所有消费玻璃令牌的表面（外壳 / 内容页 / 通知 / Toast / 任务卡 / 浮层）**自动退实底**，无需逐页重写。
- 各页只需：① `<html data-effects>`；② 页尾 `<link rel="stylesheet" href="…/glass-tokens.css">` + `…/glass-effects.css`（放在本页 `<style>` 之后）。
- 逐页 `<link>` 相对路径：`原型/` → `../`，`候选/*/` → `../../`。
- `glass.html`（组件基准页）与 `通知与反馈专题`（独立演示台）令牌集不同，保持自带；其中 `通知专题` 已 `<link>` `glass-effects.css`。

## 11. 修订（v2，2026-09-30 用户反馈后）

用户指出第一版落地**差异很大**，根因是**范围没做对**——只把玻璃/特效零散贴在少数表面，没有当成「全局材质系统」。修正如下：

| 反馈 | 根因 | 修正 | 状态 |
|---|---|---|---|
| 低特效概览动态图标没了 | 低档直接隐藏了 `.motion-backdrop`（形象一起没了） | 低档**不隐藏形象**；光场由 iframe 自身关（`?effects=low`），形象经 `reduced()` 静态落到当前状态形状（`setState` 在 reduced 下 snap 并重绘 → 静态但随状态更新） | ✅ |
| 所有组件没按玻璃做（设置是全局的） | 玻璃只贴在通知/主按钮/底部卡；其余组件仍是实底 | 新增 **`glass-components.css` 玻璃组件层**：卡片 / 设置行 / 浮层 / 按钮 / 标签 / 胶囊 / 输入 / 选择器 / 开关 / 分段 / 表头 等统一套通知玻璃；消费玻璃令牌 → 低档自动退实底 | ✅ 第一版（待你逐屏验收） |
| 强调按钮跟专题页不一致、又做高亮了 | 强调按钮继承了 `.btn` 的顶部 `inset` 棱线 | 强调玻璃改为**扁平无棱线**（`box-shadow:0 8px 22px …`），与 `glass.html` 一致 | ✅ |

**修订后的组件层级（唯一真源）**
1. `glass-tokens.css` —— 玻璃表面令牌（light + dark）。
2. `glass-components.css` —— 组件层：常规组件 = 通知玻璃配方（消费令牌）。
3. `glass-effects.css` —— 特效档：低档翻转令牌 → 上面两层全部自动退实底。

> 组件层仍是第一版：**组件清单是否完整、每类的外观细节**需要你逐屏验收后再收敛（这是第一版投入不足的地方）。
