# 多用户、团队与多设备用量及服务端协作

状态：**候选方案已整理，待产品与技术评审；未实施、未部署，未指定发布版本**。本包独立于模型配置 v0.2.0 协作。正式入口为 [COL-LOCAL-20261005-01](COL-LOCAL-20261005-01.md)。

建议增加可选、自建的账户、团队与用量服务：Desktop 连接服务端并登录，登记设备和用量归属空间后同步精简事件；用户查看自己的多设备用量，团队管理者查看本团队及成员聚合，站点管理员查看全站汇总。模型请求继续走本地 OpenCodex，统计服务不可用时在本地排队补传。

需要修正一个前提：调研的 **OpenCodex 2.77.0 已有 Hub / client 和按接入密钥隔离的远端用量查询**。这可以复用，但尚不等于完整的用户登录、设备归属和跨独立安装实例统计。方案将“统计同步服务”与“集中代理 Hub”分开设计，后者是可选接入模式。
