# 0.2.24 保存来源显式重核合同

revision: 1；2026-11-11。归属 IMP-34 P24-02，代码 main 11bc469b496098a6827ca3db704d67fd789017b4。此文拥有接口/行为边界，进度仍以 IMP-34 为准。

## 入口及确认

保存或配置投影报告真实来源冲突时，渠道页显示「核对配置来源」。预览显示受影响渠道及冲突；取消不改配置或草稿。无冲突时可「确认重核」，仅更新草稿基准及观察，不写正式配置、不应用模版。前端保留渠道/型号/Key 待提交意图和行编辑，之后用户自行保存。详情保存与列表保存复用同一后端。

同一渠道模型编辑与外部连接字段变化可独立核对；有本地连接/Key 意图、服务器草稿变化或其它不能证明不重叠的变化时不走该例外。同一渠道双边修改、被删除来源、原生名称变化及复制来源变化必须保持冲突；不提供静默覆盖赢家。

## IPC

| 命令 | 输入 | 结果/写集 |
| --- | --- | --- |
| model_v2_file_reconcile_preview | request.expected 原 ReadBaseV2；localChannelIds 本地编辑渠道 ID；modelOnlyChannelIds 仅模型编辑、无连接/Key 编辑的子集 | sourceDigest、reviewDigest、changedChannels、conflicts；只读业务对象，可建立共享稳定锁，不恢复其它事务、不分配持久渠道身份 |
| model_v2_file_reconcile_apply | 同一 request、预览的 reviewDigest | FileSnapshotV2；只更新原草稿，正式 config.json 不写 |
| model_v2_file_save | 既有 SaveRequestV2 | 使用重核后基准正常保存；仍经过锁内源/根/模版库/策略/草稿检查与现有文件事务 |

重核 IPC 不接收 Key、模型值、来源路径或由页面传入的磁盘 DTO。reviewDigest 覆盖实际文件、当前根、草稿原字节、策略/库/映射和渠道身份注册表摘要及本地编辑范围，确认时在锁内重新计算。预览后任一对应对象变化拒绝旧确认。原基准私有渠道指纹只在后端保留，不经 FileSnapshotV2 输出。缺乏可核对的指纹不猜基准或自动迁移。

## 保留与拒绝

- 不调用 read_existing 或 match_read_to_draft_v2，不隐式变更模版、绑定或生效配置。
- 草稿中的明确修改保留；外部改动由新的实际观察承接。真正重叠时整个重核不推进，草稿与文件原件保留。
- 原复制来源引用不换 ID、不改摘要。新建复制记录携带源 provider 完整内容指纹；只有该 provider 全部内容不变，才允许跨无关全局/其它渠道变化后复用。源凭据/地址变化、未知来源继续拒绝。
- 前端确认核对自己的编辑上下文；请求期间产生的新输入不被回执覆盖。Key 仍只在本地缓冲或受控暂存库，不能因重核推断认证已成功。
- 单渠道保存仅保存其明确凭据动作，保留其它渠道的暂存 Key；刷新其它已管理渠道的实际观察，不自动接管未管理原生渠道。
- 历史恢复草稿不混入本重核，未完成事务只报告，不由预览擅自补偿；取消、同字节无变化及拒绝均不写配置。
