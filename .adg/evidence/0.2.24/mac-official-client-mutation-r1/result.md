# Mac 原样官方 2.99.0 客户端文件写入复现

首轮显式传入 --port 0 被 CLI 拒绝，首错和单独清理回执保留。后两轮从隔离配置读取 port:0，使用同一官方包、Node 和 Bun，合成客户端目录仅改变 Grok 备份是否预置。本轮限制外部联网和对官方运行包的写入。

| Grok 备份初始状态 | 官方客户端启动用时 | 官方 Stop 用时 | 停后备份 |
| --- | ---: | ---: | --- |
| 已存在 | 1,740.920 ms | 897.846 ms | 与原件一致 |
| 不存在 | 1,703.981 ms | 810.772 ms | 保留启动时创建的备份，字节与原 Grok 配置一致 |

两轮 Codex 和 Grok 的主配置在 Start、Stop 各更换一次 inode。Ready 与 PreStop 快照一致。Stop 后原字节恢复，合成扩展属性丢失。每轮 Stop 命令和启动器均正常退出，退出码为 0，四个监听端口关闭，测试进程和夹具已清理，各自三个专用协调器已清理。

这两轮证明官方包能产生与 IMP231 相同的主配置文件变化。IMP231 的单个替换文件写入归属仍未证实。整体 accepted:false。
