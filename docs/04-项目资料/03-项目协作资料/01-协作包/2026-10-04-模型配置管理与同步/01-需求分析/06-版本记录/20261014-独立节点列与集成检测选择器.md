# 独立节点列与集成检测选择器

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器。范围：模型配置管理与同步 0.2.0 候选原型。

用户要求渠道列表的节点独立成列、单行展示，节点选择器集成一键检测及逐节点检测和速度结果。本轮替代前序在名称下堆叠下拉 / 测速按钮 / 结果的列表布局。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models) → 渠道模型列表。

## 页面与交互

| 入口 / ID | 调整 |
|---|---|
| 渠道列表 mp-provider-table | 增加独立“服务节点”列，顺序为选择 / 渠道 / 服务节点 / 模型 / 启用 / 操作；节点不再堆在渠道名称下，表格窄窗水平滚动 |
| mpChannelNode-渠道ID | 单行触发器显示当前节点、耗时或检测状态、展开箭头，长名称省略；官方 / 原生显示官方管理 |
| mpNodePicker | 非模态下拉浮层，使用顶层 popover 与固定定位回退，限制在应用窗口边界内；单实例，无额外遮罩 |
| 选择器各行 | 节点名称、当前选中标记、检测结果和独立“检测”按钮。点击节点名称才切换草稿，检测不会选择该节点；选择后收起并聚焦列表触发器 |
| mpNodePickerAll | 顶部“一键检测”覆盖本渠道全部节点，运行中为“停止检测”，旁边显示进度；逐项等待 / 检测中 / 成功耗时 / 失败 / 超时 / 已停止分别呈现 |
| 异步结果 | 局部更新同一浮层单元及按钮，并同步列表单行耗时；不重建浮层或输入表单。收起不取消在途检测，重开可见会话结果 |
| 键盘 / 收起 | 打开聚焦当前节点，方向键 / Home / End 移动名称按钮焦点；Esc 关闭并回触发器。外部点击、焦点离开、滚动、resize、切页和正文重绘关闭悬空浮层 |
| 服务节点详情 | 沿用每行测速和顶部一键测速 / 停止，仍与集成选择器共享同一会话结果和保存边界 |

未确认渠道认证、保存锁、地址 / Key 改变后的结果失效、两项并行 / 停止 / 晚回拒绝保持原规则。选择节点仍先进入全渠道草稿，保存确认后生效；检测结果不自动选择最快节点，不写入策略、保存记录或同步包。原型仍为确定性 mock，不读取 / 发送真实 Key，不发网络请求。
