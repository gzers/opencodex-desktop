# 模版直接复制与渠道副本

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器，模型配置管理与同步 0.2.0 候选原型。

用户要求将模版详情中仅含复制一项的“更多”改为直接“复制模版”，复制应新建模版；渠道模型也增加复制。模版列表其他操作仅给建议，本轮不实施。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。

## 范围与行为

| 页面 / 入口 | 调整与边界 |
|---|---|
| 模型模版 → 行内编辑 → copy-template | 操作区直接显示“复制模版”，移除单项更多菜单；以当前表单内容（包括未保存修改）创建新 templateId 的独立缓冲，保留原模版和源缓冲 |
| 复制的新模版 | 复制名称 / 说明 / 匹配 / 规则 / 具体型号，不复制历史版本、默认指针、归档、确认可用及渠道采用关系。保存后仅首个时间版本，记录复制来源，不自动采用 |
| 新建缓冲保护 | 已有未保存新模版时先保存或放弃，再复制；按钮禁用和事件检查同时阻止覆盖 |
| 渠道列表 copy-provider | 自定义渠道行增加“复制”，原生来源不提供；填写新名称及新标识，预填唯一副本名，确认前校验重复 / 保留值及基准 |
| 渠道复制弹窗 | 复制节点 / 当前节点、清单 / 选择 / 顺序、默认规则、模版精确引用及人工覆盖；重建模型 key，副本与源独立。API Key 默认不复用，可明确勾选复用已配置 Key，原型只复制配置状态 |
| 新渠道副本 | 默认停用，只加入全渠道草稿并进入编辑页，保存差异列新增副本；取消不改草稿，丢弃草稿可移除副本。测速结果、连接验证不复制；明确复用同 Key 时无额度状态保留 |
| 保存 / 未确认编辑 | 源有未确认行 / 连接输入先处理；保存中拒绝复制，过期确认不创建副本。复制本身不写配置、不改变 Agent 执行渠道、不增加启用预算 |

渠道操作列适度扩宽，表格仍按前序规则在窄窗横向滚动，保持服务节点单行列。模版导航收起仍保留复制图标、tooltip 和可读标签。

真实凭据复用需在实施时明确 credential ref 的权限及删除归属，不把原型布尔状态当真实密钥复制证据。源与副本规则相同可能匹配相同模型，仍按既有精确版本 / 优先级冲突校验，不因复制自动采用。

稳定行为回写：[模版规则方案](../02-方案草案/模型模版与匹配规则方案.md)、[交互细化](../02-方案草案/模型页交互细化.md)、[主方案](../02-方案草案/模型配置管理方案.md)。

## 模版列表建议（未实施）

- 优先“使用位置”：按精确版本列出渠道 / 模型引用，帮助判断改动和清理的影响范围。
- 优先“匹配预览”：快速查看规则命中、排除和冲突，不改变配置。
- 行内“复制”：以所选保存版本新建独立模版，与本轮详情复制共用语义。
- 低频“归档 / 删除”：避免占满行内操作；删除须检查采用、默认、恢复记录及编辑依赖，被引用内容不能直接删除。整模版归档与现有版本归档应另行明确，不混用。

列表已有编辑、新建、全部 / 所选更新和外部任务操作；本轮不为建议新增 UI。
