## 开跑前假设

1. 在启动前保存Claude Agent目录原件，并固定本轮官方写入/覆盖/删除的操作写集；正常服务退出后，Desktop侧测试宿主可在原10秒总预算内仅补偿该写集，恢复原文件、删除本轮新增且未变的自有文件；遇外部编辑/不安全路径则拒绝补偿而非覆盖用户内容。
2. 官方claim/owner稳定锁可以释放数据库锁和原句柄，文件身份保持；文件仍在不等于仍被持有。验证新进程在同一文件身份上能够获得官方同类锁，且活持有者存在时竞争者被拒绝。不要删除它们或把0字节等同于无锁。
3. 用合法Grok模型表和真实目录原件时，官方确实改写后能恢复；主/伴随监听的全部退出能在同一个停止预算内证明。未发生改写不记“已还原”。

每轮先写本轮要证伪的具体假设和受影响检查，再开新目录；不要为未变的15项原语或已通过无依赖项反复跑整轮。真实补验仍需启动服务建立恢复前提，但不扩成core-sweep或全量。

## 原型先行：安全Agent写集

Mac已直接调用官方syncClaudeAgentDefs验证创建/覆盖/删除旧生成定义的实际写集，可恢复原集合/字节，带ocx-前缀但无生成标记的用户文件保持。用injectAgents=false代替恢复不可行：官方会删掉以前生成的定义；禁止采用此捷径。

Windows先给原型补以下要求，达到再跑一次新普通账户恢复链：

- 启动前记录真实Claude目录及原文件身份/字节摘要/权限和“原来不存在”，保存到当前隔离事务保护备份。包含旧已生成文件，不只是新建3文件；不归档真实秘密。
- 形成与本次操作绑定的后像清单，用官方生成标记加精确目录、前/后身份和内容共同确认写集，不能按文件名前缀批量删除。进程运行中持续变化的清单不可假定在最初ready时永远固定；明确采集/封口时点，无法证明归属的晚变化保持未知。
- 补偿前整体核对源/目标与后像，先处理本地并发：同名外部修改、链接/硬链接、不可读项不获得写权限，整批拒绝时不先改一半。用Windows句柄共享/路径保护和事务回退证明检查到写入的边界；Mac内存/文件算法只证明变更计算，不提供原生竞态证明。
- 原有生成文件被覆盖或删除，恢复受保护原件及适用权限；仅原来不存在、明确属本轮且当前等于后像的文件可删除。新出现的其它用户文件保留并报告完整原树差异，不能默默删去。
- 反例用小文件/小进程原型先验，不为每个反例完整启动官方服务。至少覆盖新增/覆盖/旧生成文件被删后的恢复，用户自有同前缀文件保持，外部编辑/符号链接/硬链接/不可读拒绝及失败不误报完整恢复。

## 定向实机：一次单用户恢复链

保持原先挂起创建→Job分配→Resume、原句柄TokenUser/FILETIME/HOME与只读官方包保护。不能改旧身份/Job断言，原30秒启动、5秒状态、10秒停止总预算不变；计时含官方正常停止、退出/Job空、Agent补偿及全部恢复读回，不在补偿前重置秒表。

1. **有效输入**：Grok使用以下合法形状（LF原字节也可作基线），并在官方配置中有可选的合成静态模型fixture/gpt-6.1-sol，liveModels:false，baseUrl使用fixture.invalid，合成Key不出私有目录。禁止真实模型调用、OAuth刷新或公网模型发现。原例顶层model="synthetic-grok"且没有[model.<alias>]表会被拒绝，保留原失败，不再用它充作可还原样本。

   ~~~toml
   # synthetic fixture
   model = "native"

   [model.native]
   model = "grok-fixture"
   name = "Synthetic native"
   api_backend = "xai"
   ~~~

2. **模型目录**：从已核对原版归档的src/codex/data/upstream-models.json取原生目录样例，记录其来源和摘要；作为私有Codex模型目录原件并明确config.toml的model_catalog_json。Mac真实syncCatalogModels已确认可写出fixture/gpt-6.1-sol，但没有验证停止恢复。Windows必须记录真正原件→运行期改写→停止后原字节/范围恢复，不能仅用未生成/未注入的目录给pass。
3. **Agent前提**：准备已有生成定义、用户自有定义和不存在的新路径，服务启动前作受保护备份；记录运行期实际发生的Agent写集，不自造“官方已还原”的回执。官方POST /api/stop原回执与Desktop测试宿主补偿结果分别记录。
4. **全部监听**：在运行期捕获原进程及受控Job成员的实际监听集合（原生IPv4/IPv6 TCP表），并绑定原进程代次/Job身份。不可仅猜主端口+100；原输出的Claude伴随端口只是线索。正常Stop后同一10秒内核对各原监听和Job原成员退出；不可读、成员集合不完整或晚到结果保持未知，不把tasklist成功当清理。
5. **稳定锁独立证明**：正常停止后由原生同身份的新小进程取得并释放官方claim/owner对应锁，前后文件ID不变，owner/DACL安全；先通过活持有者竞争拒绝反例。清理只退出自有测试进程，不能unlink稳定锁来解除竞争，也不能用普通open读文件代替实际锁获取。
6. **结果分列**：完整原树原判定、配置/凭据/目录/Agent实际恢复、稳定锁释放、安全权限和全部监听分别给pass/fail/首错。若发生外部并发或未知归属，安全拒绝是反例成功，正常恢复主路径仍必须真成功，不能混成整体通过。
7. **清理**：沿原精确SID/原LoadUserProfile token+hProfile/非Special且未Loaded门，逐项读回账户/Profile/目录/包体/进程/端口。原失败目录不覆盖，成功另目录；强制清理与正常停止分列，未清净不补零。
