## 最新输入及原因

用户原话：

> 所有下拉框应该按照组件规范去做。而且发现现有下拉框层级没有最高，应该放到最高层级不被其他卡片挡住。

原有 Select 菜单嵌套在卡片内部，局部层级固定为 24；完整窗口存在 isolation / overflow 和玻璃层叠，增大内部 z-index 不能解除祖先裁剪。模型及动态表单另用了原生 select，与原公共组件外观不同。本轮依据 [UI 规范](../../../../../../02-项目核心/UI规范.md) 收敛样式和交互。

## 本轮改动

- [公共 Select CSS](../../../../../01-项目支撑资料/01-产品原型/原型/select-component.css) 使用尺寸、文字、间距、圆角与状态令牌；材质仍由 glass-components / glass-effects 决定，低档保留实底语义。模型 CSS 只处理布局。
- [公共 Select JS](../../../../../01-项目支撑资料/01-产品原型/原型/select-component.js) 接管主原型原有 13 个 Select 与 31 处原生单选声明，覆盖渠道 / 模版 / 设置 / Agent / 导入导出、代理和拓展表单，包含运行时插入的表单。这里是源码声明数量，不是同时显示的控件数；历史候选不重新绘制。
- 展开挂到 body，支持时使用 manual Popover 进入 top layer。兼容宿主使用原型专属 z-select 令牌，高于现有 DOM 通知 / 系统弹层 / 提示；不把原型的兼容数值升级为生产层级令牌。关闭后菜单归还原属主。
- 菜单根据触发器位置、可用空间及局部缩放换算位置，支持水平约束、上下翻转、长选项换行 / 滚动；短选项按内容宽度展开。触发器长 ID 省略并保留全文 title。
- 保留原生控件的 ID、dataset、value、disabled、onchange 及 input / change；原生控件隐藏并退出 Tab。动态选项 / 禁用同步，Agent 渠道 → 模型 → 推理联动继续使用原契约。
- 旧 Skills / MCP 分页改为属主 selectchange 接值，菜单移出属主后不丢分页回调。保留原 select-value，原设置读取继续可用。
- 同时只开一个；方向键、Home / End、Enter / Space、文字查找、Escape / Tab、外部点击和滚动关闭统一。Escape 先收下拉，不直接取消所属弹窗；Tab 收起后继续导航。路由 / 弹窗切换或属主移除清理浮层。

## 实际验证与剩余边界

[Select 源码行为脚本](../05-原型/qa/select-component.source.mjs)：**15 PASS**。Node VM + 最小 DOM stub 检查原生契约、portal / popover 调用 / 还原、动态列表、禁用、键盘事件、分页语义、联动、属主清理及位置计算；不运行浏览器引擎，不验证真实 popover 支持、CSS、焦点、辅助技术或缩放视觉。

[既有模型状态脚本](../05-原型/qa/model-layout.source.mjs)：**12 PASS**；[资源脚本](../05-原型/qa/verify_assets.py)：**42 PASS / 0 FAIL**，相比上一轮新增公共 JS 和检查脚本的语法项。文档链接、格式结果以 [QA](../05-原型/原型QA.md) 为准，不把源码断言 / 资源检查合并为产品场景验收。

当前 file:// 原型此前已被浏览器工具拒绝，策略禁止替代浏览器或 HTTP 转送等绕行。本轮未尝试绕过，**新版视觉 / CSS / 真实焦点验收待完成**。需后续走查全部下拉、长模型 ID、动态联动、弹窗与通知叠层、上下边缘、亮暗 / 材质 / 两窗口和缩放。独立原生 WebView 需生产层合成方案与实测，DOM top layer 不能被记为跨原生表面的验证。

未改 apps、运行配置、密钥、实际 Agent / CLI、WebDAV 或 A6api 接口；没有安装依赖、发布或提交，也不冻结生产组件 schema。
