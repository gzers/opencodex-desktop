# 列表显式编辑入口与统一模版编辑页

日期：2026-10-14（Asia/Shanghai）。项目 / 产品：OpenCodex 桌面管理器，Desktop。归属：COL-LOCAL-20261004-01。状态：唯一总原型已修订，源级检查通过，实屏待验，生产未实施。

用户要求渠道模型和模型模版列表不通过整行或名称直接进入详情 / 编辑，必须点击行内操作；取消单独查看页，编辑表单本身承担查看。

## 唯一源与页面范围

唯一入口：[产品主原型 #models](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。直接修改 [model-config.js](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.js)与[配套样式](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.css)，没有新建第二个原型或生产页面。

| 页面 / 流程 | 当前规则 |
|---|---|
| 渠道模型外层列表 | 渠道名称改为普通文本，整行 / 名称没有点击导航；行内操作统一“编辑”，进入既有连续渠道编辑页。勾选、启停、排序与删除继续各自独立，不顺带进入页面 |
| 模型模版列表 | 名称与修改摘要改为普通文本；只有行内“编辑”进入该模版表单。勾选只改变选择范围，空白点击无导航 |
| 模版页面 | 删除已保存版本的独立只读摘要页及“编辑为新候选”步骤；新建、行内编辑、版本切换、人工保存、Agent 更新和外部候选都使用同一五区连续编辑表单 |
| 来源与版本 | 保存时间 / 短标识、来源、修改摘要、基于来源版本与采用情况放在编辑器的来源与版本分区，不再依赖另一查看页 |
| 未修改表单 | 进入时只建立缓冲，不创建新版本或更改策略。标题同时显示“未修改”和当前保存版本的采用状态；未修改缓冲不在列表伪装为未保存草稿 |
| 切换历史版本 | 无未保存变化时在同一表单加载选择的时间版本，保留原规则。修改后保存另存 revision，旧版不原地更改 |
| 未保存修改 | 修改发生时禁用版本切换和采用按钮，事件执行处再次检查；保存后恢复可用。比较仍可查看当前编辑差异，修改默认 / 归档 / 删除须符合既有依赖保护 |
| 保存与更新结果 | 人工与 Agent 保存后留在同一编辑器，重建已保存新版本的清洁缓冲。外部结果保存时清洁旧缓冲切到新候选，已有人工改动缓冲继续保留 |
| 返回 | 沿前序规则：未修改直接退出并清除清洁缓冲；有修改显示保存并返回 / 放弃修改 / 继续编辑。返回不能删除已保存版本；渠道返回继续保留全渠道草稿 |

官方 / 原生来源也复用同一渠道页面，受官方管理的字段仍按实际能力保持不可修改。此次删除的是独立模版查看页面和列表隐式导航，不据此解除官方管理权限，也不删除版本比较 / 更新详情等明确的只读差异弹窗。
