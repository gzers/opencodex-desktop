## 约束

- 只使用 mock 数据。
- 不调用真实 `ocx`。
- 不读取真实 OpenCodex 配置。
- 不触发真实启停、restore、备份或文件选择。
- 原型中的真实页面是官方 GUI 渲染后的源码级快照：保留真实 DOM、CSS、文案与层级，用于视觉对照；不请求运行态 API，不构成生产嵌入方案。
- **官方来源素材不随仓库分发**：`原型/官方页面快照/` 与 `文档/截图/官方/` 已被忽略，仅本地保留（原因见根 `.gitignore`）。克隆后如需查看「面板」路由，须本地自备同名快照；缺快照时该路由不可用。
- 不记录、展示或同步任何真实凭据。
- 稳定交互结论后续进入 IMP 输入；本包不替代 DMD。
- 视觉与颜色体系向 OpenCodex 官方面板对齐，避免嵌入面板后割裂；OpenCodex 品牌色只做轻量识别。
- 当前根入口为 [产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html)，使用 hash 路由串联页面；原型按 1180 × 760 macOS 应用窗口表达。官方面板视图采用方案 B：保留标题栏与 64px 图标栏，官方中文页面快照占满剩余内容区，仅保留最小悬浮操作。概览集中提供配置迁移、WebDAV 同步和版本升级的常用动作；通用偏好、备份策略、迁移参数、同步端点与升级策略统一放入「设置」路由。
- 概览当前原型采用**双形态**：环境就绪时为无框居中 Logo、主线状态和运行操作，环境明细进入运行详情弹窗；检查中或前置缺失时收起三卡与最近事件，展示纵向检查列表、当前处理指引和动作。卡片尺寸按正式页面重新整理，并非直接复制独立探索稿。`overview-dual.css` / `overview-dual.js` 由正式入口和 Logo 对照页共用。**2026-10-01 用户确认当前基本效果，已回写 DMD Revision 14、UI 规范 §25／§26；生产按 IMP-05 待实施与验收。**

- **收起图标统一在通知表面右上角**（2026-09-19）：通知中心面板、Toast 卡片、任务卡右上角各有一个「收起到铃铛」按钮，收起时向铃铛收拢并触发铃铛脉冲；只做视觉收起，不改动 `read` / `resolved` / `deleted`，也不取消后台任务，未读角标保留。`prefers-reduced-motion` 下直接收起不播放动画。
- **通知内的按钮统一「半透明 + 小一档」**（2026-09-19）：通知中心、Toast、任务卡里的按钮共用 `--notif-btn-*` 令牌（半透明底 + 描边 + 轻模糊），条目主体不参与；取消类动作（取消观察 / 取消同步）走 `--notif-cancel-*`，同样是半透明但换成红色调。尺寸统一收敛到 `--notif-ctl-h:24px`（11px 字号），与右上角收起按钮、条目删除键同族，不跟随页面主控制 34px。
- **通知浮层避让面板**：通知中心展开时，Toast / 任务卡顺次落在面板下方，不再互相压盖。
- 评审便利参数：`?notifPos=win-top|win-tr`、`?notifMaterial=clear|glass|solid`、`?notifTint=on|off`、`?theme=light|dark|system`、`?notif=N`。
- WebDAV 卡按**配置/连接状态**渲染：未配置时不置灰，只把动作区换成一颗「配置 WebDAV」直达设置；其余状态（未连接 / 同步中 / 已同步 / 连接失败 / 冲突）在原型注译区可切换预览。
- **两个版本对象分开**：概览「版本升级」卡与设置第一块 = OpenCodex 本体（`v2.50.0`，官方 `ocx update` 引导）；设置第二块 = 桌面管理器自身（`v0.1.0`，应用自更新）。套壳更新在外部**只走通知中心**，不新增概览卡片。
- 通知支持**点开详情弹窗**（正文 + 时间/级别 + 可执行动作「前往处理」）与**单条删除**；通知中心与「诊断中心 → 通知历史」共用同一份数据，任一处改动同步。
- **窗口分层：外壳一片 + 内容是一张圆角页面**（2026-09-19，全路由）：**窗口底层就是一整块底面**（`.window` 用 rail 玻璃），菜单与标题栏都是这块底面上的内容、各自不带底色（`background:transparent`）——两块玻璃各带 `backdrop-filter` 会因背后环境光不同而颜色对不齐；内容页才是浮在上面那层；共同的底上浮着一张圆角内容页（`.main` 左/顶描边 + 左上 12px 圆角 + `--panel` 底色）。**不再画分栏竖线**——竖线在面板路由 64px 窄栏下会落进内容压住按钮。
- **面板浮层控件也用同一套玻璃**（2026-09-19）：面板路由右下角的快捷操作球、它的弹出菜单，以及缩放读数、重载/浏览器、预览提示等同族浮层，统一改用 `--glass-fill` + `--glass-blur-notif`（原先接近实底、暗色下还有硬编码不透明覆盖）。
- **滚动条是覆盖式**（2026-09-19）：不常驻；滚动时淡入、停 0.9s 淡出，指针悬停时也可见（`.is-scrolling` 由捕获阶段的 scroll 监听统一打点）。
- **Skills 同步：系统目录选择器 + 检查并修正**（2026-09-19）：设置 → 扩展管理里，「选择自定义目录」调用**操作系统原生目录选择器**（macOS 访达 / Windows 资源管理器）——**不自造目录浏览器**；原型用一个独立的系统样式面板示意该系统对话框（`20-系统目录选择器-*.png`），含位置栏、文件夹列表、当前文件夹与「取消 / 选择」。**与 `FZ-23` 一致**：源目录**默认为** `<主目录>/.agents/skills`、**允许改为自定义目录**（只读 + 路径校验）——该口径已于 2026-09-19 定稿并回改 `FZ-23` 与 `领域模型.md` §10；**正式应用已于同日对齐并改用系统对话框**（`source_store` 配置 + `tauri-plugin-dialog`，`R-22` 已关闭），路径校验细节**已实现**（`source_dir.rs` 七种原因码）但参数仍待安全评审确认（`R-23`）；「测试同步」按钮删除，改为 `检查并修正`——它把当前源目录 + 同步方式 + 启用矩阵与客户端 live 状态逐条比对（只读），分出「正常 / 需修正 / 需清理 / 跳过」四态并给出修正动作，覆盖类型不符、指向旧源、断链、未启用却有残留四类不一致；确认后按条修正。因此**不改任何设置也能体检并修正**。`同步方式` 已定为**用户可选项**：选「软链接优先」时创建失败或安全校验不通过按 `FZ-24` 自动回退为复制，选「文件复制」则每个客户端存独立副本；体检结论**跟随所选方式**——同一份客户端状态，切到「文件复制」后结论会整体翻转（原本正常的软链接变为需修正）。

## 扩展管理 Skills：点击「名称 + 描述」查看完整信息（2026-09-23）

用户评审意见：拓展页的 Skill 标题描述单元格应可点击，查看完整信息，并需要设计弹窗界面。

### 选定的做法

- 可点击范围是整块「名称 + 描述」单元格（`.skill-info`），不是整行：行的其余区域仍归目标开关与行内操作，避免误触。
- 单元格按 `role="button"` + `tabindex="0"` 处理，`Enter` / `空格` 与点击等价；关闭后焦点归还单元格。
- 可点击提示由两件事表达，**都不加任何外框**（2026-09-23 用户两次明确要求去外框）：
  1. 指针变手型；
  2. **悬停 / 键盘聚焦时把单元格里的次要文字提亮到正文色**（描述、版本、更新时间由 `--muted` → `--text`，`--motion-fast` 过渡）。
  连浏览器默认的聚焦环也一并关掉（`:focus-visible{outline:none}`），焦点状态同样用「文字提亮」表达——若之后判定
  键盘用户的可辨识度不够，需要另定替代方案。
- 描述底部还有**颜色渐隐**，用来表达「文字没显示完」。
- 描述面板（2026-09-23 第二轮）：`描述` 不再是普通段落，而是一块**文档面板** —— 带外框、`--rail` 加深底色、**独立滚动**，
  内部按 **Markdown 渲染**（标题 / 有序与无序列表 / 引用 / 围栏代码 / 加粗 / 行内代码）。
  - 弹窗改成纵向 flex：描述块吸走剩余高度并内部滚动，**信息 / 同步目标 / 底部操作固定不动**，因此只有一层滚动条（不会出现内外两层）。
  - 渲染器 `renderSkillMarkdown()` 先整段转义再套 Markdown 标记：**描述里的 HTML 不会被当作标签执行**；链接只保留文字，不生成 `href`（原型不外链）。
  - 内容 = 列表里那段完整描述 + `SKILL_DETAIL_FACTS[name].md`（演示用的 SKILL.md 正文摘要），所以列表与详情读的是同一段文字，详情再多给正文结构。
  - 详情弹窗**不再显示**「当前为原型演示；真实实现尚未启用。」脚注（新增 `openModal` 的 `hideNote` 选项）。
    该选项后续也被**安装器弹窗**复用（2026-09-25）；普通确认弹窗仍保留脚注，见 `文档/design-qa.md`。
  - 渐隐是 `mask-image:linear-gradient(to bottom, …)` 遮罩，不是叠色块，因此亮暗主题都不用改色。
  - **只给真被截断的描述加渐隐**（`.is-clamped`，由 `markClampedDescriptions()` 按 `scrollHeight > clientHeight` 判定），
    短描述保持干净——避免把完整的一行读成残缺。判定在筛选、翻页、`resize` 与 `load` 时重算。
- 顺序按「先读描述」排：标题承载 Skill 名称（**右上角带「检查 / 更新」「卸载」图标动作**）；正文依次为「描述面板（Markdown）」→「元数据网格」→「6 个可点击的客户端同步格」。底部只有一个「关闭」。

  （与列表行内同一套图标与危险色）。`openModal` 新增 `headActions` 选项，其它弹窗不传即不显示（有断言保证）。

## 窗口拖拽区（2026-09-24）

用户问「为什么窗口不能拖拽」。macOS 用 `titleBarStyle: Overlay`，窗口移动靠 `.titlebar` 条带，**拖拽要三件套齐**：

| 软件 | `App.vue` 属性 + `base.css` `pointer-events:auto` + `capabilities/default.json` 补授权 + 条带铺满窗宽 |
