## 最新决定的优先级

用户已明确渠道名称及对应运行标识一起改，保存后重启生效，不需要旧标识兼容。替代UI规范旧§29.1中“providerId固定”的该项限制，不改变原始模型ID、请求目标及稳定对象身份。重启不是跳过配置引用与凭据校验的理由，也不把历史会话迁移重新作为条件。

通知采用取消自动聚焦的最新决定，替代旧§44默认聚焦立即重启；§32主动交互暂停规则保留。同步采用用户按保存时间判新的要求，替代IMP-28历史云端优先分支；旧实现、测试和证书不构成本版批准依据。共同规则回写[UI规范§54](../../02-项目核心/UI规范.md#54-0221开发前采用补充2026-11-04)。
