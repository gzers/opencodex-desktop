## 实现与边界

原登记组合执行五次完整来源／历史观察。本批将原先独立的计划准入放入已有 SQL 事务：同次完整来源认证及 expected Head 比对之后、SQL 写入之前，读取计划并核对来源、当前目录和目标归档缺席。候选写入后与 COMMIT 后完整认证保持；只有全部成功才构造登记凭据并复核当前独立索引事实，Active 直接接收，避免再立即重复一次完整登记观察。

凭据不构成移动许可，实际 retire 入口仍完整 require，后续当前来源／帧／目录／原生归属与原 deadline 不变。提交前拒绝沿原事务回滚；提交后读回失败保留 RootRetirementPrepared，不返回凭据、不补偿删除、不推进 RootAbsent。其它 write 调用不增加新产品准入语义。
