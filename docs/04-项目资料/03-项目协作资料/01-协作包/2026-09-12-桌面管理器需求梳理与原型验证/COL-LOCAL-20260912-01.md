## 构建管线对齐（2026-09-14）

报告此前是「HTML 即源」——正文、样式、目录都写在 `index.html` 里，改一处要在几万行 HTML 里找。现按参考项目的约定改为「Markdown 源 + 构建脚本」：

2. **`build.py` 负责生成**：`需求分析报告.md` → `index.html`，顺带写出 `assets/report-metadata.json`（报告编号 `RPT-LOCAL-20260914-01`、版本、源文件 sha256、生成时间、章节索引与 REQ / AC / WP 数量）。

4. **`index.html` 与 `assets/report-metadata.json` 是构建产物，可整体重建，不手改**；元数据放在 `assets/` 下，与参考项目一致。

> 两处有意保留的差异：参考项目把构建脚本放在仓库根的 `scripts/reports/<报告名>/`（Node，`build.mjs` + 拆分模块），本仓库是纯文档仓库、没有 Node 工具链，故把 `build.py` 放在报告目录内、用 Python-Markdown。产物的形态与约定一致。
