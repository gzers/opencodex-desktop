# 03-测试验收

## 状态

**未开始。** 本目录是预留槽位。

## 位置约定

与 `02-开发实施/` **同级**，测试资料不并入开发目录；也不替代运行时的测试回执。

## 预留结构

| 位置 | 内容 |
|---|---|
| `01-测试分析.md` | 为什么这样测、风险在哪、哪些必须人工或目标环境验证 |
| `02-测试方案.md` | 测试范围、角色、入口、数据准备、门禁与验收方法 |
| `03-测试报告/` | **唯一活跃报告源**；`测试记录/`（按批次可归因）、`来源归档/`（原稿，不参与构建）、`素材/` |
| `输出/` | 派生的测试报告 HTML 与素材 |

## 约定

1. **唯一活跃报告源**：同一时间只保留一份活跃报告，历史原稿放 `来源归档/` 并显式标注不参与构建。
2. **批次可归因**：自动化批次与人工轮次各自成目录，证据与记录同批次存放，追加不覆盖。
3. **证据分层**：本地隔离证据不替代目标环境、权限绑定与人工验收。
4. 验收标准取自 `01-需求分析/04-需求分析产物/场景与验收矩阵.md`（`AC-01` ~ `AC-13`）。
