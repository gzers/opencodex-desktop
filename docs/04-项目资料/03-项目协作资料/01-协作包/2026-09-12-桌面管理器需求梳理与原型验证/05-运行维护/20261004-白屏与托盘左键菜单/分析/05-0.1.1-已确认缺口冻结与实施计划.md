# 05-0.1.1 已确认缺口冻结与实施计划

维护 ID：MNT-OPENCODEX-DESKTOP-20261004-01。冻结日期：2026-10-04。受影响 **0.1.0**；拟修复 **0.1.1**。

本文件是 0.1.1 的**范围冻结**：只收已确认缺口（用户确认 A 级或源码确认 B 级），并把未证实假设、独立问题与需单独授权的方向明确列在范围之外。范围沿用 [01-问题与根因分析](01-问题与根因分析.md) 与 [03-版本备注与待决策](03-版本备注与待决策.md) 的编号，不新增平行编号。

## 1. 冻结范围（在 0.1.1 内实施）

| 编号 | 缺口（证据等级） | 0.1.1 要做的行为 | 边界 |
|---|---|---|---|
| F-01 | 托盘左键菜单始终关闭（B；右键可用为 A） | 托盘图标左键展开同一份状态菜单，右键保持可用 | 不新增托盘动作；不启动/停止服务，不重复执行菜单项 |
| F-03 | 窗口 show/focus/激活策略返回值被忽略、无入口记录（B） | 统一 Dock reopen / 托盘 / 原生菜单的重开路径；记录入口与结果（非敏感） | 不宣称已定位首次触发；不改写调用顺序结论 |
| F-06 | 没有独立原生主 UI 恢复入口（B） | macOS 应用菜单「视图」下新增「重载主界面」，直接重载主 WebView | 不依赖前端轮询；与官方面板刷新、服务启停区分；不把重载当作白屏根因已修复 |
| F-02 | 重开复用异常窗口、缺少「存活但不绘制」恢复路径（B；首次触发为 C） | 由 F-06 提供用户可达的恢复入口；重开路径统一但不强制每次重载 | 不把「隐藏复用」写成白屏根因 |
| F-04 | 运行中 WebGL 上下文丢失无处理（B；放大候选 C） | 监听 contextlost 停止绘制并回退 CSS；contextrestored 重建资源、清理监听、单一 rAF | 不泛称 GPU 性能不足；不改变既有创建失败回退 |
| F-05 | 启动早期异常覆盖空档（B；本次 D 匹配） | 更早记录 window.error 与 bootstrap 异常；提供不依赖完整 Vue 的最小提示 | 不把启动失败判为本次主因 |
| F-07 | 托盘命令经前端轮询、失败静默（B） | 处理结果与失败可见（非静默）；恢复类命令走原生路径 | 不把右键菜单失灵合并进白屏 |
| F-09 | 渲染/恢复事件与构建来源不可观测（A/B） | 记录非敏感生命周期/恢复事件；构建注入源码提交并在启动事件记录 | DOM 心跳与视觉恢复分开，不以心跳关闭事故 |
| F-13 | 关窗/完全退出/启动/重载文案边界不清（B） | 校正设置与退出入口的用户可见文案 | 不把文案当作已实现能力；不改动代理退出策略语义 |

## 2. 明确排除（不在 0.1.1）

| 编号 | 排除项 | 原因 |
|---|---|---|
| F-11 | 完全退出后的代理连续性、退出信号链 | 用户要求代理退出原因与信号链调查暂不处理；无现场信号/退出码证据 |
| F-12 | 重开后自动恢复运行（无条件 start） | 用户明确不无条件自动启动代理；需先定义运行意图与所有权语义 |
| F-08 | 原生面板并发/代次重构 | 静态竞态为 C 级候选，本次遮挡未证实；保留既有 syncBusy 守卫，不扩范围 |
| F-10 | 测试版自动更新通道端点 | 与白屏独立；无可用真实通道，不伪造端点 |

排除项不得在 0.1.1 回写为已修复；如需推进，另建独立记录与授权。

## 3. 未改变的口径

首次触发根因仍未锁定。0.1.1 提供的是**恢复能力与可观测性**，不是已证实的根因修复；任何结论都必须以真实复现或可证明的责任链为准。[处置与验证计划](02-处置与验证计划.md) 的执行事实在实施后按真实结果回写，未执行项保持待执行。
