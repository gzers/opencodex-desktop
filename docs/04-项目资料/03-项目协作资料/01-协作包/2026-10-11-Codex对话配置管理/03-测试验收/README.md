在 main 工作区执行（按实际安装位置修改原生 CLI 路径，不能用 OpenCodex shim 代替）：

```sh

  --codex '/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex'
```

按 [独立配置与订阅适配方案](../01-需求分析/02-方案草案/独立配置存储与事件订阅适配方案.md)另补以下针对性验证；这些尚未执行，不能沿用上文“8 项通过”的结论：

- 策略原子保存、修订冲突合并，false / 空列表 / 恢复继承以及外部非法文件保留。
- 先订阅再读取快照、事件遗漏后重连校准，保存 / 接收 / 实际采用状态一致。
- 开页按需分页、到期刷新与同对象在途合并，离线保存不丢已有绑定。
- 清缓存保留策略及去重状态；恢复生成新修订，不重放未决模型调用或沿用旧实例采用成功。
- 协作备份清单真实可恢复，活动根切换无旧写者和未收尾标题任务；如启用周期刷新，再验证前台停止与退避。
- 全局 / 项目 / thread 分层按需建文件，仅保存当前作用域；同名项目及不同数据源不会串目录。
- 对话归档只清它的覆盖和状态，取消归档继承上层；项目删除清理原目录，存活对话随真实归属迁移。
- 列表分页缺项、断线不触发误清理；重连重复清理幂等，清理后的迟到任务与旧编辑页不会重建文件。
- 项目删除后归属待确认的存活对话覆盖不被提前删除；快速归档 / 取消归档时，旧清理不删除后来新建的覆盖。
- 对话跨项目迁移中断后只有一份有效覆盖；bundle 恢复不重新激活已确认归档 / 删除对象，不补跑历史命名。
- 新建 / 升级后的 WebDAV 默认不包含全局、项目或 thread 对话配置；同步模型引用不会携带该模块，远端含协作条目时关闭模块仍跳过应用和删除。
- 手动导出 / 导入不改变 WebDAV 选择；按范围导出可重新映射导入，本机备份不受默认关闭影响；关闭协作同步不删除本机或远端已有副本。
