## 1. 左侧菜单图标

建议采用**三层叠片的线框图标**：顶部一片菱形，下方两条叠层轮廓，表达模型集合及分层配置。文档暂用 `layers` 标识这个图形语义，不假定项目已有该图标键或依赖某个图标库。

现有菜单分别为概览四格、面板分栏、拓展拼图、诊断文档、设置齿轮。叠片轮廓容易与这些图形区分，也能同时涵盖模型、族模板和渠道分组。图形不使用某一家模型品牌，保持全部渠道的共同入口。

| 项目 | 候选规则 |
|---|---|
| 图形 | 三层叠片，单色线框，不带内嵌小齿轮或品牌字母 |
| 规格 | 沿用侧栏共用尺寸、线宽、圆角端点、颜色及选中态；视框与现有图标同为 24 × 24 |
| 宽 / 窄栏 | 与其他菜单图标同列对齐；窄栏只藏文字，保留同一图标及可读名称 |
| 悬停 / 读屏 | 中文名称“模型”；图形本身作为装饰，不重复播报 |
| 状态 | 选中态沿用导航样式，不把发现失败、未应用或同步失败直接画进菜单图标；这些状态在页面内说明 |

实现基线 `main@9ca7a9458d951ba313e8ea46c51c99cc14f8cd44` 的 `apps/desktop/ui/src/components/AppSidebar.vue` 使用内联 SVG，`styles/base.css:141` 的侧栏图标为 18px；这是本轮只读观察。后续按 [UI 规范](../../../../../../02-项目核心/UI规范.md) 统一还原时跟随侧栏公共规格，不为新入口单独扩大图标，也不为此引入图标库。具体路径和像素走查留待图标候选确认后的原型阶段。

建议导航短名为 **“模型”**，页面全名为 **“模型配置”**。用户要求菜单两个字，短名与概览 / 面板 / 拓展 / 诊断 / 设置保持一致；“模型”覆盖白名单、推理、快速模式、顺序和族模板，“渠道”适合作为页内管理对象。

| 位置 | 候选文案 |
|---|---|
| 左侧导航 | 模型 |
| 菜单 tooltip / 可读名称 | 模型 |
| 页面顶栏标题 | 模型配置 |
| 页面简短说明 | 管理渠道模型、族模板与选择器顺序。 |

| 一级导航顺序 | 概览 → 面板 → 模型 → 拓展 → 诊断 → 设置 |

只在现有页面顶栏显示全名，不在内容区另造重复大标题。页面内的两个 Tab 继续采用现有自然宽度、透明底及激活下划线，遵守 UI 规范；不要求 Tab 名也缩成两个字。

## 3. 页面公共区域与上下文

### 3.1 全局 Select 组件约束

按 2026-10-04 用户补充，全部下拉复用 [UI 规范](../../../../../../02-项目核心/UI规范.md) 的 Select，不为模型页或 Agent 表单另造一套原生下拉外观。触发器、选项、选中 / 悬停 / 焦点 / 禁用 / 校验态统一使用控件尺寸、文字、圆角和材质令牌；业务样式只负责宽度、对齐和响应布局。

菜单在展开时脱离所属卡片，进入当前 DOM 交互的最高浮层，不能被卡片、滚动容器或弹窗裁剪。生产组件应共享 portal / top-layer 管理，避免每个页面加大 z-index；新弹窗或路由打开前收起原下拉。靠近窗口边缘时水平约束 / 上下翻转，长模型 ID 的触发器省略并有全文提示，菜单选项可换行 / 滚动。

同一时间只展开一个；方向键、Home / End、Enter / Space、文字查找、Escape / Tab 和外部点击遵循公共规则。Escape 先收下拉再交由下一次 Escape 关闭弹窗；Tab 收起后继续正常导航。动态渠道 / 模型 / 推理列表保留选值与联动，禁用项不接受选择。当前 [共用组件迭代](../06-版本记录/20261004-统一下拉组件与顶层浮层.md) 是静态 mock，浏览器真实焦点和视觉仍待验；独立原生 WebView 的跨层保证另列生产验收。

### 3.2 公共区域与保存

页面由现有顶栏、Tab 行、操作栏及当前 Tab 内容组成。首次从菜单进入“渠道模型”；同一会话内返回保留上次 Tab、当前渠道 / 模板、滚动位置和未保存草稿。直达某个模型或模板时优先展示指定对象，目标不存在则给出说明和选择入口。

| 公共区域 | 显示与动作 |
|---|---|
| 草稿 / 写入状态 | 分开显示未提交草稿与最近写入 / 客户端状态，允许“已保存待重启 · 另有草稿”；模板缺失、待绑定、部分失败和同步候选另行说明 |
| 草稿查看 | 列表顶部 / 详情左侧底部固定“查看草稿”，比较最近成功保存与当前草稿；按全局、渠道和模型列出完整差异，不受搜索或勾选范围限制 |
| 次级操作 | 导入、导出、应用记录、设置；导入导出明确选择模板 / 策略 / 组合包和作用范围 |
| 渠道主动作 | “保存”在一个流程里校验预算 / 依赖、确认差异、备份、持久化并写入官方配置、读回；成功显示待重启，失败保留草稿及真实结果 |
| 模版主动作 | “保存模版”只入库新候选 revision，不写运行配置、不要求重启；“采用此版本”形成渠道草稿后由渠道“保存”提交 |
| 预览 / 重启 | 预览为可选次级入口，保存仍展示差异确认；自动重启能力待核对，不可用时提供手动说明 / 重新检查；自动加载证据与用户目视确认分开 |
| 激活计数（渠道模型） | 全渠道共用“模型激活数 xx/100”，区分草稿计划、已写入待重启和当前客户端读取；超限保留草稿并提示收窄 |
| 同步状态 | 显示最近同步结果与待处理原因，入口定位到设置中的“同步”；下载成功、已写入待重启与客户端已生效分开显示 |

“查看草稿”打开只读弹窗：分组显示“配置项 / 已保存 / 当前草稿”，包含新增 / 删除渠道、连接摘要、启停、白名单、内部与渠道顺序、族引用、推理 / Fast 和恢复继承；长清单可展开全文。存在的渠道提供“管理 / 查看”返回详情，已删除对象只显示差异。没有改动时显示“暂无未保存改动”，此前待重启状态独立保留。底部“继续编辑”关闭返回；有可提交改动时“去保存”进入同一保存确认，超限或保存中仍可查看但不提供提交入口。查看本身不改变配置、撤销记录或重启状态。它是当前工作区的对比视图，持久暂存和历史恢复仍由对应流程负责。

模板内容改动保存时生成新 revision，公共保存动作不原地改写旧 revision，也不自动把策略引用升级。只有模板库变化、策略引用没有变化时，可以保存模板，不能把这次保存描述成运行模型已经更新。

切换 Tab、打开详情或进入配套设置时，共用同一草稿并保留上下文；不把一次切换变成应用动作。离开工作区或关闭窗口时若有未提交改动，提供本机暂存、放弃改动、继续编辑；暂存只为下次续编，不写运行态、不标记保存成功或触发同步。已写入待重启只显示状态，允许稍后重启。作用范围始终显式，搜索过滤不充当导出或应用范围。

## 4. Tab：渠道模型

### 4.1 标准布局

### 4.2 渠道列表

渠道表包含批量选择框、名称 / 协议与可用性提示、已选 / 全量数量、启用开关、管理、删除及排序动作。点击名称或“管理”进入该渠道详情，包含“渠道配置”、模型默认、白名单 / 顺序和单模型设置；勾选复选框才加入批量作用范围，二者独立。默认展示全部渠道及必要的官方 / 原生来源组，停用或发现失败条目仍可查看并保留策略。原生组在当前 mock 中只读，批量范围仅含可管理的自定义渠道。

渠道顺序就是选择器组顺序，拖动手柄或使用上移 / 下移 / 置顶可移动整组。渠道搜索隐藏同级排序项时，提示清除搜索后排序。移除重复“全部渠道”按钮，清除搜索后表头可选全部可管理渠道。批量作用区显示例如“已选择 3 个渠道”，不让用户猜测操作影响范围。

表头第一列以公共复选框替换“范围”文字，提供未选 / 半选 / 全选。它只选择当前搜索结果中的可管理自定义渠道；取消全选也只移除当前结果，搜索外已有选择保留。没有可管理结果时禁用，官方 / 原生始终不参与。清除搜索后表头可选择全域自定义渠道。选择本身不改策略或增加撤销记录；选中后显示总数，有隐藏目标时补“含搜索外 N 个”。

批量栏提供“启用、停用、删除”，以及现有“按族批量配置、套用模版”。启停对完整已选范围一次加入草稿，一次撤销恢复全部；只改启用字段，保留选择 / 顺序 / 配置。目标已全部处于所需状态时按钮禁用，重复动作不生成空撤销记录。保存中锁定范围复选框、清除选择和批量改动；仍可查看。

自定义渠道每行直接提供“删除”，只固定该行目标，不带入当前其他勾选对象；批量栏“删除”才处理完整已选范围。官方 / 原生只提供“查看”，不显示删除。两种删除共用以下确认、草稿与恢复流程。

删除使用公共危险按钮，确认列出全部目标名称与已选 / 发现数量，包含搜索外目标；涉及 Agent 执行渠道时提示保存后生成将不可用，保留执行偏好并要求重新选择。确认绑定当时的范围和配置，配置变化时重新确认。删除只移除草稿中的渠道及其模型策略，保留族模版库；清理已删目标的勾选范围，当前详情失效时返回列表。确认前取消不改草稿；确认后可撤销 / 重做 / 丢弃。页级保存明确列出移除差异，成功后提示待重启；应用记录可将删除前的配置转成恢复草稿，再保存。

影响范围恢复补回所删渠道和配置，按删除前的相邻位置插入并保留其他渠道的现有顺序与草稿；已有同 ID 的对象不静默覆盖，正式接入须显示身份 / 绑定冲突。完整回到提交前是独立选择。真实注册移除、凭据与绑定处置、发现晚回、跨机删除合并和安全恢复仍待技术契约；当前内存演示不证明运行渠道或凭据已删除 / 可恢复。

官方 / 原生来源组承载其实际目录发布和可支持的排序，不套用渠道凭据、上游刷新或 provider 级 Fast 控件。最新修订增加自定义渠道创建 / 连接编辑；不支持的连接类型保留官方管理出口，详情区明确区分“渠道配置”和“模型默认”。

#### 启用开关与状态分层

按用户最新反馈，自定义渠道的“启用”列直接提供公共 Toggle，旁边显示“启用 / 停用”。显示的是草稿计划，不用“已启用”暗示客户端已经切换；未保存状态由页面统一表达；详情位于左侧导航底部，行内不再重复标注。原生来源显示“官方管理”，不提供可点击的虚假开关。紧凑布局也保留开关入口与文字。

点击开关即加入同一工作区草稿，支持撤销 / 重做 / 丢弃；不立即写运行配置或重启。停用保留渠道连接、选择模式、白名单、渠道及内部模型顺序、模版引用、推理与 Fast 配置，仍可查看、发现和编辑，批量范围也可包含停用渠道；编辑不会自动启用。该渠道的基础项及独立 Fast 项从计划选择器移除，激活贡献为 0，但“已选 / 发现”继续显示保留的数量。再次启用按原选择模式和最新草稿配置恢复投影，不把“全部隐藏”变成全选；全渠道超过 100 项时保留完整草稿并阻止保存，不截断清单。

页级保存差异明确列“渠道名：启用 → 停用”或反向变化，不把启停误报成白名单删除 / 新增。保存过程中锁定开关；成功写入后显示待重启，重启 / 客户端核对后的结果仍由页级提交状态表达。开关不负责“立即生效”。

状态分为以下独立维度，不再塞进同一个互斥枚举：

| 维度 | 状态 / 文案 | 来源、位置与行为 |
|---|---|---|
| 配置开关 | 启用 / 停用 | 用户策略；列表启用列可编辑，仅决定是否纳入计划发布，不保证连接或模型能力可用 |
| 本机可用性 | 未验证、连接检查通过、无额度、认证失败、连接失败、上游不可用 | 名称下的次要提示；记录检查来源、时间和适用范围，手工记录明确标注；检查通过不代表所有模型、推理 / Fast 均通过 |
| 清单发现 | 未获取 / 空闲、获取中、获取完成、清单为空、获取失败 | 获取操作与最近结果；失败 / 空清单保留旧选择及顺序，不自动停用或关闭 discovery，成功也不自动启用 |
| 连接 / 绑定事实 | 动态发现 / 静态清单、已绑定 / 待绑定 | 数据来源及本机依赖，单独说明原因与配置出口；待绑定计划不能伪装为可写入成功 |
| 管理归属 | 自定义可管理 / 官方管理（只读） | 决定可操作入口；官方管理不是故障或停用状态 |
| 草稿 / 提交 / 客户端 | 未保存、保存中、已保存待重启、核对结果及失败 / 部分失败 | 沿用页级提交状态统一表达，行内不重复“未保存”，不挤占启用枚举 |

可用性未知或异常不会自动改变启用策略；用户仍可手动启停。A6api 的“无额度（手工）”来自本次用户说明，保留清单但不发探测；其他示例渠道为“未验证”。生产需按最新证据更新提示，不凭错误码武断判断额度，也不把拉取成功当作调用成功。原型没有真实可用性检查、检查时间记录或完整绑定解析器，上表为目标契约，不是已冻结的数据 schema。本机可用性记录不进入模型策略的便携导出 / WebDAV 同步。

制模 Agent 使用最近已保存的渠道启用状态；该执行渠道停用后保留 Agent 偏好并提示原因，不自动换渠道。未保存的重新启用不会提前放行生成；保存恢复后重新核对执行依赖。已知无额度 / 认证或连接失败 / 上游不可用在执行选择中另行禁选，不因策略开关仍打开就发生成请求。Agent 模型仍不要求进入 Codex 白名单。

#### 新增渠道的两步表单

渠道列表工具栏的“新增渠道”进入“连接配置 → 选择模型”。第一步的名称 / 标识、协议 / Base URL、认证 / 密钥按公共表单分组，协议和认证复用统一 Select 顶层菜单；稳定标识与显示名分开，密码不回显。下一步只校验输入，不创建渠道或触发请求；第二步用户点击“获取模型列表”才获取。

第二步列表显示完整清单与已选数量，搜索、仅已选及结果范围全选 / 取消共用现有语义。新项不选；手动 ID 折叠在次要区，精确输入去重，不按名称补能力。获取中可取消等待，加入草稿禁用；认证失败、网络错误、空列表、无清单接口各有原因和重试 / 返回修改 / 手动添加出口，既有选择保留。至少一项明确选择后“加入草稿”，新渠道追加末尾，进入详情继续调整模板 / 顺序；仍由页级保存统一提交。

改变连接目标需重新获取和选择，关闭 / 返回取消不改保存态；同连接返回保留清单与选择。连接编辑不改稳定 ID，已有 all 模式的有效选择转换为明确白名单时显示完整集合；零项不误表达为 all。100 项预算在保存时统一检查，不截短发现。凭据和虚构连接摘要不进入便携策略；预览接口和真实受管写入缺口见 [新增渠道契约](模型配置管理方案.md#25-新增渠道与保存前获取模型最新候选)。

### 4.3 当前渠道模型表格

模型区顶部显示当前渠道摘要，发现清单获取入口移至左侧快捷区；贴顶标题保留名称 / 状态和切换。刷新只获取清单，不发生成请求、不重置启停、不重排已有项；失败保留旧清单。原始 ID、别名 / 显示名称搜索、族筛选与“仅启用”只改变视图。模型工具提供全部展开 / 收起和快捷排序，批量工具仅在存在勾选时出现。

当前渠道详情的模型表格分为四列：

| 列 | 默认内容与操作 |
|---|---|
| 批量选择 / 排序 | 复选框只选操作对象；表头选择当前结果并保留筛选外选择；完整列表提供拖动与上移 / 下移 |
| 模型标识 / 别名与配置 | 原始 ID、可直接修改的别名输入；原始 ID 可换行，摘要分协议 / 上下文、推理 / Fast 两组多行；各单元格垂直居中，长 ID 可查看全文 |
| 启停 | 独立开关与启用 / 停用文字；修改进入草稿，与复选框无关 |
| 编辑与排序 | 展开编辑 / 收起编辑、编辑明细；排序操作在过滤时禁用并提示先清除过滤 |

“展开编辑”在本行下方展示两列字段：协议、上下文大小预设 / 自定义正整数 tokens、推理等级下拉多选、默认推理等级、是否支持快速模式及协议端点。每个规则独立继承 / 自定义；摘要和来源帮助判断当前生效值。推理自定义列表至少保留一项，默认 / 强制档必须在最终列表中；若需要不显示档位，到编辑明细高级区明确设置。上下文声明不扩容，Fast 能力与实际 Fast 策略分开。收起保留缓冲，“还原本行”撤回未确认改动，“加入草稿”校验后统一保存。

别名失焦后合法值进入草稿，失败还原到已接受值并解释原因；不改写上游 ID、匹配与顺序。独立启停 / 别名不丢失尚待确认的规则。页面显示未确认行数并提供定位入口；未确认行须先加入草稿或还原，才能全局保存或执行涉及它的批量操作。

批量工具栏仅在至少勾选一个模型时出现；不再放操作范围下拉、重复“选择全部模型”及“0 项”。表头选择当前结果并保留筛选外选择，清除过滤后的表头用于当前渠道全量操作。已选总数包含筛选外选择并明确提示；确认面板显示渠道、数量和完整 ID。提供批量启用、停用、编辑和恢复字段继承；批量编辑逐字段“不修改 / 继承 / 自定义”，另含启停保留 / 启用 / 停用及别名保留 / 清空 / 规则生成。任一目标冲突或基准变化整批拒绝；成功一次进入草稿、可整批撤销，无变化不添加撤销。恢复继承仅清字段覆盖与指定端点，保留别名、启停、精确模版引用和顺序。已有族配置 / 套模版路径继续保留，应用模板默认保留单模型例外。

模型管理排序以当前渠道完整模型序列为依据，停用保留位置，选择器仅投影启用项。快捷下拉包含名称 A → Z / Z → A、别名 A → Z、协议分组、上下文大 → 小 / 小 → 大、启用优先；别名为空使用 ID，未知上下文始终排末，同值保留相对位置。任一搜索、族或仅启用过滤开启时禁用排序并提供清除入口。重排保留勾选、展开与行缓冲，进入草稿可撤销。全部展开作用当前显示项；全部收起作用当前渠道，保留缓冲。官方 / 原生只读，不参与模型批量修改。当前为内存原型，生产白名单的 all / whitelist / none 编译契约仍见主方案。

### 4.4 配置详情与顺序预览

“编辑明细”使用统一弹窗，显示原始 ID / 模版与最终协议来源，并可编辑别名、显示名称、启停、指定端点，以及上下文窗口、输入模态、可选档位 / 默认档、快速模式和完整高级规则。协议逐项继承 / 自定义；推理参数映射、强制档、不传参数与明确“不显示推理档位”放在高级区。字段与模型模版共用 §4.6 的编辑器规范，每项独立继承。若本行已展开编辑，明细从该待确认缓冲开始；确认前校验名称 / 规则及基准，成功进入同一草稿，失败保留弹窗和输入。取消只撤回此次弹窗改动，保留此前行缓冲和工作区改动。渠道默认、渠道内族覆盖、单模型例外共用字段表达，各层支持什么由 adapter 决定。

完整选择器由公共“预览选择器”打开弹窗；打开时按最终顺序展示所有来源组及基础模型，Fast 派生项紧跟父项。按当前草稿即时重建，不受当前渠道或搜索筛选限制；关闭预览返回原列表 / 详情上下文。预览显示草稿 / 已生效来源，暂不可用条目单独标注保留位置的原因，不冒充实际可选项。

本机当前客户端默认只取前 100 项而未继续分页；渠道列表公共状态栏 / 渠道详情左侧底部持续显示“模型激活数 xx/100”。编辑时注明草稿计划数，另列上次已写入数；保存成功注明待重启，客户端核对后才显示已生效。分子是全渠道与官方 / 原生等真实读页条目，包含实际发布的 alias / hidden / Fast 派生行；Fast 只有元数据时不加一，不直接用勾选基础模型数或上游总行数计算。具体口径见 [激活预算](模型配置管理方案.md#24-模型激活数与-100-项兼容模式)。

计数超限时显示例如“108/100，超出 8 项”，提示按渠道 / 族收窄，当前兼容模式阻止保存写入，继续允许编辑、发现和暂存，不静默隐藏第 101 项以后或关闭 discovery。计数无法完整核对时显示待核对原因，不假装精确数字；已有超限运行配置打开页面只诊断，不自动改。阈值按客户端版本能力调整，非永久 schema 限制。草稿完整顺序、catalog 已读回和客户端实际可选 / 过滤差额分别报告，未完成重启核对不显示全量已可选；证据见 [本地分页核对](本地调研依据.md#codex-模型选择器分页核对2026-10-04)。

### 4.5 紧凑布局

窄窗口继续使用同一列表 → 详情路径，当前渠道切换保留在贴顶标题，内部锚点导航可收起为图标。侧栏受可用高度约束且可滚动到底部状态 / 保存；正文连接和展开字段转单列，身份和摘要允许多行，精确身份、勾选、启停及配置入口保留。排序操作保留中文可读名称。按钮允许整组换行，不把短按钮文字拆行。

页面沿用主内容滚动，配置 / 预览弹窗仅正文按需滚动，标题和操作固定。模版编辑内的生成与纠偏共用非模态悬浮面板，不设遮罩、不锁主页面，主内容与对话独立滚动；紧凑时保持可收起入口。最小 900 × 600、基准 1180 × 760、缩放及两主题 / 三档材质继续按 UI 规范验收。本轮仅完成源码与静态资料检查；旧布局的浏览器证据不证明新版实际显示，具体待验项目见 QA。

### 4.6 渠道、模型与模版的统一字段编辑器

设置按照“协议与基本能力 → 推理 → 快速模式 → 高级”排列。模型模版的候选编辑区与渠道 / 族 / 模型详情共用字段名称、控件和校验；对象身份与作用范围在开头说明。每行显示“本层设置、继承来源、当前解析结果”；无法确定时显示未知和原因，不用空白横线同时表示继承、关闭与未知。

| 字段 | 控件候选 | 继承与校验 |
|---|---|---|
| 模型协议与端点 | 协议继承 / 自定义；Responses / Chat / Anthropic / Google / Ollama；专用 adapter 显示待接入原因；单模型端点自动匹配 / 指定 | 模版输出可覆盖渠道默认，族 / 单模型人工值更优先；显示最终协议与来源，端点不反改协议；缺失 / 歧义 / 冲突 / 未绑定阻止受影响保存 |
| 上下文窗口 | 继承 / 自定义；常用 tokens 预设 + 正整数输入 | 标注单位 tokens、声明值与最终值；官方已有元数据时配置可能只收窄窗口，填写更大数值不会扩容；不因选择某族而统一所有代际的窗口 |
| 输入模态 | 继承 / 自定义；text / image / audio 多选及中文解释 | 当前官方管理接口只接收这三项；未知保持继承；声明不赋予实际输入能力，按协议约束显示可用项，不因底层类型含 video 就提供可应用的视频选项 |
| 可选推理档位 | 默认继承；自定义时多选档位 | 显示来自模版通用 / 具体型号、渠道 / 官方的列表，档位按强度固定顺序；版本及协议不支持的标签不可选；隐藏档位入口放高级区，不能把取消全部勾选悄悄保存为关闭推理 |
| 默认推理档位 | 独立的继承 / 自定义；从最终可选列表中单选 | 不要求先自定义可选列表；例如继承 low / medium / high 后仍可单独将默认设为 medium；具体目标的最终列表为空 / 不支持时阻止采用；无具体目标、列表未知时可保留合法标签并提示待目标校验 |
| 快速模式 | 复用已有能力声明与 Fast 控件 | 能力、渠道开关和全局策略分开，继承及来源可见；模板只放可复用能力规则，不新增第二个全局开关 |
| 高级推理设置 | 强制档、标签映射、不传参数、适配器支持的权威声明 | 分项显示作用及来源，默认保留已有值；不由普通档位多选自动启用强制请求或权威声明 |

截图中的“覆盖推理强度”表示**为当前模型自定义可选推理档位**，不是必须启用，也不是要求所有请求使用某一档。建议正文改用“可选推理档位：继承 / 自定义”，并附说明“仅定义可选范围；默认档位单独设置”。默认档位是没有另选档位时的默认选择，强制档位才会按适配器规则接管请求；三个设置保持独立。

新建策略 / 模版时各字段默认继承；迁入既有设置时如实保留原有声明，不为了呈现默认 UI 而清除。进入自定义时以当前解析值填充草稿，只切换字段或暂存草稿不写运行配置；从自定义切回继承清除本层字段，继续使用前序有效规则，不能清除父模板或其他层。推理未覆盖不代表没有推理，列表中的“无”档位也不代表继承或通用的不传参数。

输入模态自定义不可保存空选：当前 model-settings 的 [] 与 null 都删除声明，UI 应明确引导恢复继承。推理列表 [] 则表示不显示档位，和 null 的恢复继承不同；“不显示推理档位”是明确高级动作，并提示不等于禁止模型思考。缩窄列表使原默认档无效时，显示原值与拟恢复 / 更改结果，先在草稿修正并纳入应用差异，不静默保存越界默认值。

模型模版没有单一目标时只显示规则、适用范围与来源，不虚构一个所有模型共有的最终值；选择渠道 / 型号后可预览逐模型结果，批量范围内值不同显示“多种值”并可展开。上下文窗口、输入模态等族内有差异的字段优先继承，证据只覆盖部分型号时缩窄模板范围或形成精确例外。

官方没有某层的直接写入口时，Desktop 编译器按最终逐模型结果映射到官方字段；不支持的目标保留原值并说明阻止应用的原因，不能显示批量已成功。模板不承载某个渠道的白名单、选择器顺序或凭据；这些仍由渠道模型策略管理。

## 5. Tab：模型模版

首屏采用全宽模版表，搜索、多选、行内“编辑”；右侧紧凑“新建模版 / 外部 Agent 配置”。模版即自建模型族，不先选择 GPT 等固定族。已有预置与自建同结构，不证明所有代际的能力。新建直接打开编辑缓冲；取消无空条目，返回列表保留未保存编辑。行内“编辑”直接进入候选字段表单，已有缓冲继续编辑；模版名称与已引用版本仍可只读预览。编辑不改库，保存才新增候选版本，主指针和已采用引用保持。

## 6. 配套设置

建议需要一个**现有“设置”里的轻量“模型配置”分区**，与拓展已有配套设置的组织方式一致；模型页保留“设置”入口定位到这里。模型页内部仍只有渠道模型、模型模版两个 Tab，WebDAV 端点继续在已有“同步”分区维护。

| 位置 | 放什么 | 与模型页的关系 |
|---|---|---|
| 设置 → 模型配置：自动生成 Agent | 执行渠道、执行模型、可选推理 / Fast；复用已保存连接，不重复填写密钥；未配置 / 不可用状态明确 | 本机偏好独立“保存设置”，不写模型双文件、不要求 Codex 重启；生成和会话有同一快捷入口，保存后返回原任务；外部 CLI 使用自身设置 |
| 设置 → 模型配置：全局快速模式 | 已有 fastMode 策略及 fastRows 兼容行控制，提供继承现有值及适配范围说明 | 复用同一状态与策略字段，不新增第二个 Fast 总开关；渠道 / 单模型控制仍在模型页详情 |
| 设置 → 模型配置：文件与应用状态 | 两个模型配置文件的实际位置、模板依赖 / schema 状态、上次写入与重启 / 客户端读回状态、兼容预算依据；只读展示及打开入口 | 独立导入导出仍从模型页选择范围；显示本机应用记录出口；策略历史恢复经新草稿 / 预览，不直接整份覆盖官方配置 |
| 设置 → 同步：模型配置范围 | 两项产物“族模板”“渠道模型策略”的同步选择、依赖提示和各自产物结果 | 共用现有端点、认证、runner 和同步入口；不同步 bindings / 缓存 / 运行配置 |

全局 Fast 控件修改的是模型策略，继续采用同一草稿及“保存 → 差异确认 → 写入 → 提示重启”；设置分区明确显示草稿和已保存待重启状态，不沿用普通外观偏好的即时写运行态语义。模型页可显示全局摘要并链接过来，但不另建一个同义开关。查看文件和状态不改配置。Agent 执行偏好拟扩展现有 preferences.json 的本机 modelTemplateAgent 命名空间；因为原 preferences 已参与同步及全配置导出，必须先实现该分区排除、导入时保留本机值和失效引用校验。这项过滤尚未实现，不能声称已经隔离；详见 [执行配置方案](Agent制模与版本恢复方案.md#211-内置-agent-执行配置新增候选)。

同步范围拟允许仅模板或含策略的组合选择。策略依赖的模板 revision 必须齐备；选择策略却未选择模板时明确提示依赖，沿用主方案的依赖校验，不悄悄增加同步范围或绕过缺失模板。范围配置只决定将来同步包含什么，勾选本身不触发同步或应用；新产物不因版本升级自动纳入既有全局同步授权。冲突处理继续使用已有可执行机制，未实现的静默策略不能展示成可用选项。

## 9. 多协议渠道与模版输出（本轮补充）

渠道行“管理”进入四区连续详情，内部左侧锚点为模型列表、渠道配置、协议端点、模型默认。渠道配置直接编辑名称 / 默认协议 / Base URL / 认证 / 密钥替换意图，按渠道保留缓冲；确认后复用模型选择步骤再加入草稿，取消不丢输入，未确认连接阻止全页保存。只改名称保留清单，连接身份改变使旧清单失效；旧确认绑定连接和策略摘要，保存中 / 原生只读受保护。协议端点直接列默认及附加端点，新增 / 编辑仍用紧凑 D-13；模型设置可独立指定端点，模版只定义协议。左侧快捷区集中获取清单、预览、更多和设置，底部集中已写入 / 未保存 / 待确认状态、激活数、查看草稿、保存和草稿工具。mock 不保存密钥输入，只存配置布尔和替换意图，生产凭据及真实编译尚未接入。
