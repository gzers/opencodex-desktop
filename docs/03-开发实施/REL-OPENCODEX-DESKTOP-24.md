# 0.2.21 发布后问题修复发布

2026-11-04，Asia/Shanghai。范围DMD-OPENCODEX-UI-021、顺序IMP-OPENCODEX-DESKTOP-29、状态与证据归0.2.21-bugs.md。用户已授权治理、开发、测试、发布连续推进；当前仅记录计划，不是发布通过证明。

支持macOS Apple Silicon与Windows x64，沿用既有正式构建和签名/通道机制。新版本必须固定最终源码commit/tree、CI与原包身份；安装、原生、实际相邻升级和公开资产均引用该同一包体。0.2.20→0.2.21相邻OTA需分别完成Mac和Windows MSI/NSIS验证，Windows另验默认/自定义四安装格。

发布前必须完成本版七项修复及共同验收，包含真实隔离文件保存读回、取消/失败副作用、隔离客户端重启后的渠道显示/有效路由和公共模态消费者。浏览器原型或mock IPC不能替代原生；没有平台证据不标通过。不得改日常配置、日常安装或日常秘密，不执行日常真实WebDAV同步。

构建先生成草稿候选；冻结八资产ID/字节/摘要、三份更新签名及平台清单，按既有公钥完整验签。同原包通过安装/原生后，使用既有beta通道执行真实相邻升级，再通过发布器晋升stable；晋升时不移动tag、不重打包、不换密钥，最后匿名读回tag/Latest及资产身份。

2026-11-04只读准备：GitHub Actions可用，既有Windows临时runner路径可复用，无持续自托管Windows/SSH环境。已有验收脚本暂仅接纳0.2.20，正在增加0.2.21及实际升级路径，保留未知版本/错误方向拒绝与严格字节身份门禁。当前stable/beta均仍为0.2.20，尚未触发0.2.21构建或发布。

回退来源保留公开v0.2.20原包/签名及操作前保护备份；不承诺自动降级、不移动已公开版本。最终具体源码、制品、检查、失败纠正、限制与通道读回将在本文件及正式RCP/CERT取得真实证据后回写。
