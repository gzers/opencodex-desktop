# 树形比较与只读详情

日期：2026-10-08，Asia/Shanghai。产品版本 0.2.0 暂定，当前未提交、待用户评审；沿用唯一[主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#sync?tab=file)。本轮按产物归属修改 docs 分支的原型与说明。

## 用户输入与设计

用户要求导入比较采用与主页面相同的分类树，简要显示新增、更新、删除；每项通过第二层只读弹窗查看详情。凭据覆盖移到树的右侧操作区，支持顶层统一规则和单项例外。普通对象不再重复选择保存候选等处理方式；WebDAV 采用相同设计，按钮名改为“同步配置”。

文件导入与 WebDAV 共用默认折叠的分类树，表头 / 分类 / 对象选择支持半选；变化数量汇总到分类。普通对象勾选即可应用，所需精确模版版本自动补齐。明确删除记录默认不选；包内没有、范围未选和明确删除区分处理。

右侧包含查看详情与凭据规则。统一、分类、单项规则联动；渠道 Key 与 MCP 扩展凭据默认不覆盖，可迁移账户登录状态、WebDAV 连接密码默认随对象采用，并允许仅账户信息或仅配置。缺失凭据没有覆盖入口，同名异端点必须处理身份映射，两端冲突必须选择方向；未勾选冲突不拦截其他对象。

## 只读详情布局

| 类别 | 展示字段 |
|---|---|
| 渠道与模型 | 连接身份、地址、协议、Key 状态；模型清单增删、别名、上下文、启停、推理、Fast、顺序、模版引用 |
| 模型模版 | 版本、主版本、匹配范围、协议端点、能力、版本或后缀覆盖及来源 |
| 账户 | 身份、提供方、授权范围、登录材料可迁移性、有效性与采用规则 |
| Skills | SKILL.md 摘要、资源文件增删、启停、内容校验、明确删除 |
| MCP | 传输、地址、命令 / 参数、环境变量、授权状态、启停与本机绑定保留 |
| 桌面偏好 | 主题、语言、密度、选择器；排除本机路径、窗口坐标、缓存与草稿 |
| WebDAV 配置 | 地址、目录、用户名、密码状态、待启用状态；保留本机范围，不迁移同步加密口令 |

字段按本机 / 配置包或远端两列比较，敏感值隐藏。第二层只读，不重建父弹窗；关闭和 Escape 返回时保留勾选、规则、方向、口令、内区滚动值并恢复触发位置。两层都有独立长内容滚动；布局和真实焦点行为仍待浏览器验证。
