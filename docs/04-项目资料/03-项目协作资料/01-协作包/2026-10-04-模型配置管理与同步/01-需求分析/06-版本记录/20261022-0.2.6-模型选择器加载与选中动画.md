# 0.2.6：公共模型选择器的加载态与选中反馈

2026-10-22，用户在组件样式专题指出公共模型选择器“怎么做加载动画，还有选中去不报错的动画怎么做”，随后补充实际场景：“agent 配置的模型渠道获取有延迟不能秒开……模型没获取到前，会报没有当前模型的错误”。本文登记判定、原型方案与实施边界。原型侧已实施（组件样式专题），实现侧待确认后跟进。

## 决策

1. 先做**组件样式专题**（原型 `#components?section=model-picker`）里的公共形态；
2. 用户确认后再铺到原型软件的业务弹窗；
3. 本轮不改实现代码，只在原型体现。

## 三个问题

| 问题 | 表现 | 根因 |
| --- | --- | --- |
| 慢 | 打开选择器要等一次目录往返，全程无进度感 | 原型只有一句纯文本加载提示，无骨架；实现 `loading` 只渲染一行 `<p>` |
| 误报 | 目录未回来时已保存型号找不到，先报“没有当前模型 / 执行型号已缺失”，目录回来后自动消失 | `ModelPicker.problem()` 把“目录未就绪”与“型号真缺失”折叠成同一结果；`available()` 又把 `loading` 并进可用性判定 |
| 选中无反馈 | 点选只变背景色，推理 / Fast 改完无过渡 | 原型与实现都缺过渡定义 |

实现侧的关键遗漏：`ModelPicker` 有 `loading` prop，但 `AgentExecutionField` 从未传入，所以加载期间选择器完全不知道目录还没到。

## 原型方案

**加载态**

- 保留左右分栏骨架：左侧 3–4 条渠道占位、右侧 6–8 条表体占位，复用 `.mpk-col-*` 列宽，加载完成不跳版。
- 占位行静态底 + 低幅扫光；低画质档位关闭扫光，与 `effects.css` 既有约定一致。
- 顶部 `role="status"` 状态条：spinner + 「正在读取模型目录」+ 「已有选择保持」。
- 已选区照常显示，但加载期不判定为问题，不出现红字。
- 表格 `aria-busy="true"`，骨架行 `aria-hidden="true"`。

**选中反馈**

- 行选中：背景 + 左侧 3px 强调条，120–160ms 过渡。
- 「已选」徽标：`opacity` 0→1、`scale(.92)`→1，140ms。
- 已选芯片：新增时 120ms 淡入 + 6px 落位；移除不播动画。
- 推理 / Fast：档位文字 100ms 透明度过渡；滑杆拖动不加过渡。
- `prefers-reduced-motion` 与 `data-effects` 双闸，任一触发降级为直接切换。

**误报消除**

- 加载中只有「目录读取中」，不出现“缺失 / 不支持”；确认按钮禁用并说明原因。
- 加载完成且型号确实不在目录，才显示「型号已缺失，请重新选择」，与加载中文案分属不同状态。

## 实现边界（原型确认后）

`ModelPicker` 拆出 `loading`（目录未就绪）与 `unavailable`（型号确实不可用）两个概念；`problem()` 分出 `pending-catalog` / `missing`；`AgentExecutionField` 把目录请求的进行中状态传下去，并先用 store 快照渲染、真实目录到达后无跳变替换。公共样式落在全局 token 层，`ChannelsView` / `AgentPanel` / `BatchAgentDialog` 共用。

## 再次打开时的已选保持

用户追问：“我没有看到有选中模型，再次点开加载的时候怎么办？”

判定为原型 demo 数据缺口：组件样式专题此前只在有确认结果时传入 `models`，于是「读取中 / 读取失败」场景打开时已选区是空的，看不到“已有选择保持”的实际样子。现改为在无结果且处于该两个场景时传入一条既有选择（NewApi / gpt-5.4）。业务侧对应的是已保存的执行设置，本来就通过 `current` 传入。

新增断言覆盖：已选区出现计数、芯片显示渠道与型号、不出现缺失警告、待选与传入一致、确认按钮禁用。

## 原型侧实施（2026-10-22）

- 加载态：`skeletonHTML()` 输出状态条 + 8 行骨架表 + 6 条渠道占位；列宽沿用 `.mpk-col-*`，加载完成不跳版；`aria-busy` 与 `aria-hidden` 分别落在表与骨架行上。
- 动画闸门：扫光在中 / 低画质档关闭，`prefers-reduced-motion` 同样关闭；选中反馈（行背景 140ms、强调条、「已选」徽标 140ms、档位文字 100ms）在同样条件下直接给终态。
- 误报：加载期已选芯片不输出「目录缺失 / 档位不支持」，确认按钮保持禁用。
- 验证：`model-picker.test.cjs` 17 项通过（新增读取中骨架与已选保持断言）；原型 31 文件 257 项全通过。
