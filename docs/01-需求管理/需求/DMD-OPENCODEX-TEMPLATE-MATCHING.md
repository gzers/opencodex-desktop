# 0.2.23 模型模版通用规则与条件覆盖

2026-11-06。用户已确认处理思路与覆盖范围，授权提前准备配置，并明确纳入0.2.23；**本次为配置资料和文档，不启动生产开发、日常配置变更或发布**。整版顺序/收口归[IMP-31 P23-11](../../03-开发实施/IMP-OPENCODEX-DESKTOP-31.md)，细目归[IMP-33](../../03-开发实施/IMP-OPENCODEX-DESKTOP-33.md)。

## 范围与数据

以[专题确认](../../04-项目资料/01-项目支撑资料/06-问题记录/专题-模型模版通用匹配-待分析.md)为设计范围，候选数据唯一源为[配置JSON](../../04-项目资料/01-项目支撑资料/06-问题记录/模型模版通用匹配配置/model-templates.0.2.23.candidate.json)。使用族级包含/排除、局部数字版本和名称片段组合条件；名称可以在版本前或后，不限字面后缀。符号只在明确数字槽位等价，频道前缀仅显式限定渠道的匹配视图处理，真实ID不变。

已知能力参数只从固定种子保留，不凭名字推断未知型号。配置库保存新不可变版本和明确采用关系，当前候选不自动覆盖旧版本或用户自建模版；不开发旧格式自动转换。正式文件/发布Schema及消费者兼容声明在开工前冻结，未知/不支持格式明确拒绝，不能静默忽略新字段。

用户补充取消渠道层协议属性：新增/编辑/复制连接均移除默认协议，渠道仅承载连接与认证；协议按模版通用→条件覆盖→单模型自定义解析，不保留渠道级/渠道族级协议覆盖，不反向参与模版匹配。模型列表发现适配与请求协议解耦；原版provider.adapter若必需，只是最终模型协议生成的运行事实。未解析协议提示待配置，使用前补齐，不靠隐藏默认兜底。详见[补充记录](../../04-项目资料/01-项目支撑资料/06-问题记录/专题-模型模版通用匹配-待分析.md)。

## 读取现有渠道后自动匹配（0.2.23最新确认）

用户明确“应该按照模版做匹配”，替代前轮“只读取/只建议、另确认采用”的入口行为。读取成功后即按已保存模版匹配模型并更新草稿，不增加独立采用确认；正式配置仍由正常保存流程写入。新增/保存模版自身不自动触发后台重配，历史版本不原地改写。

- 适用集合为有默认保存版本的模版，加上当前明确的渠道/全局保存版本引用；显式引用优先保持其版本，无指定时取该模版明确默认保存版本，不取未保存编辑、任意最新候选或无默认版本。
- 模型逐项按渠道范围、包含/排除、名称/版本条件及优先级选择，生成可见的精确保存版本引用及“读取自动匹配”来源。读取后的模型参数按该引用解析；不将模版值复制成不可追溯的单模型手工值。
- 已明确的单模型手工协议/参数及人工指定模版保留；读取文件自带的普通有效参数不能一律标成手工覆盖，避免模版匹配虽发生却永远不生效。生产Schema须区分来源值、显式人工覆盖和自动引用，来源无法确定时明确显示，而非伪称是用户锁定。
- 未匹配、缺默认版本或最高同级冲突保留原模型配置，并显示原因/数量；不禁用、不清空、不中断无关成功项，也不为剩余19项强行扩族。已有自动引用在本次无法重判时保留原值并提示，不默选另一项。
- 成功读取不得改变模型ID、已选/启停、顺序、渠道节点或凭据。匹配结果会形成未保存草稿，正常保存预览展示真实差异，取消保存不写基线；重复读取无变化不生成重复修改。
- 失败、认证错误、无接口、空结果及读取期间基准发生变化均不应用自动匹配，不覆盖晚到的新编辑；默认模版变化只在下一次明确读取时重新评估，不后台强改运行配置。

实现细节与来源合同归IMP-33 MATCH-01～04；本节不标软件验收完成。
