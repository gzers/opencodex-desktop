## 建议走查顺序

1. 渠道表：先“新增渠道” → 填演示连接 → 获取模型 → 搜索勾选 → 加入草稿；再搜索 / 拖动渠道 → 管理 NewApi 模型 → 内部排序。保持 discovery，按需“预览选择器”；现有自定义渠道在详情打开“渠道配置”或“协议端点”。
2. 全部渠道：渠道表“全部渠道”或范围勾选 → 按族批量配置；工具选中后出现，原生只读。模型白名单和渠道配置范围分别表达。
3. 单模型：打开“配置”，逐字段继承 / 自定义；只改默认推理档，不必覆盖可选档位列表。
4. 保存：差异确认 → 进度 → 已保存待 Codex 重启 → 手动重启后的重新检查；用窗口外测试器演示失败、部分写入、超时、漂移和超额。
5. 模型模版：“新建模版”自由填写企业编码族 → 精确 / 前缀 / 通配包含与排除 → 在连续表单中用可收起锚点导航定位，手动滚动观察高亮；返回图标、可编辑名称、状态和版本合为标题，Tab 滚过后贴顶；名称直接编辑标题、基本信息只留说明。导航下独立按钮区依次提供“Agent 自动填充 / 匹配预览 / 与主版本比较 / 更多操作 / 设置”，收起保留图标和可读标签；设置全部 / 白名单 / 黑名单（空白名单无命中、空黑名单全部）和优先级 → 设置族通用协议 / 能力 / 推理 / Fast → 可选“具体型号”按原始 ID 后缀添加任意子项、预览最长后缀继承 → “预览匹配”看未选 / 停用与排除原因 → 比较 → 保存候选。已有模版点行内“编辑”直接修改候选，返回后再点继续原缓冲；名称入口保留版本预览、复制、比较、设主 / 归档及依赖删除。
6. 编辑内自动填充：从左侧导航下首个“Agent 自动填充”文字按钮打开非模态对话，顶部重复条与右下启动器已移除，收起后焦点尝试返回左侧按钮；浮动模式保持页面操作 / 滚动。顶部实际执行模型入口及图标放大 / 还原、收起，中部角色聊天，底部紧凑资料 / 上下文锁 / 导出及输入发送。放大铺满应用窗口，再还原到悬浮尺寸，输入 / caret、聊天与正文位置保留；收起再开沿用尺寸偏好，刷新重置。在新建 / 编辑中填提示词 → 未配置则设置执行模型并返回 → 生成建议 / 比较 / 接受 → 连续对话微调、人工改动与通用 / 子项上下文锁定 → 锚点跳转 / 同对象重绘保持位置与缓冲、切模版隔离目标 → 停止 / 晚回 → 保存候选。设置 → 模型配置也可修改执行偏好。
7. 外部 Agent 配置：独立按钮 → 当前 / 已选 / 全部 / 仅新建 → 填要求 → 查看任务和文件 → 复制提示词 → 粘贴演示单个 / 多个新增修订 → 整批校验 → 逐项比较 → 全批保存候选。
8. 后续采用：版本详情“采用此版本”直接勾选目标渠道并保留例外 → 前往渠道模型 → 查看草稿 → 保存待重启。设主不切渠道，未采用模板不参与匹配；同最高优先级重叠可在草稿 / 保存解释冲突。
9. 设置 / 导入导出 / WebDAV / 应用记录：检查共用草稿、两项同步范围、导出依赖、候选接受和恢复到草稿。

A6api 104 项 / 32 项选择仅为清单 fixture，不做额度或推理测试。所有模型能力是原型样例，不作为真实支持证明。
