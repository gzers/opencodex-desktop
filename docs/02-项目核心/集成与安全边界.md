# 集成与安全边界

## 外部集成清单

| 集成对象 | 方向 | 权威归属 |
|---|---|---|
| 官方 `ocx` CLI | 调用（启停、状态、诊断、升级引导） | 官方 |
| 官方 Web 面板 | 承载视图（源码级快照） | 官方 |
| 各客户端配置（MCP / Skills） | 受控读写 | 共享节点 |
| WebDAV 远端 | 加密同步 | 用户指定，视为不可信 |
| 应用自身更新通道 | 下载与安装 | 本产品自有 |
| 本机 IPC 端点 | 供可选 CLI 委托 | 本产品自有 |

## 扩展配置落点

### MCP 服务器节点

| 客户端 | 配置落点 | 格式 | MCP 键与形状 |
|---|---|---|---|
| Codex | `$CODEX_HOME/config.toml`（默认 `~/.codex/config.toml`） | TOML | `[mcp_servers]` 表；`command` + `args` |
| Claude Code | 用户级 `~/.claude.json`；项目级 `<project>/.mcp.json` | JSON | `mcpServers` 映射；另有 `disabledMcpServers` / `enabledMcpServers` |
| Gemini CLI | 用户级 `~/.gemini/settings.json`；工作区 `<project>/.gemini/settings.json` | JSON | 顶层 `mcpServers`（定义）+ `mcp`（全局规则） |
| Grok CLI | 用户级 `~/.grok/user-settings.json`；项目级 `<project>/.grok/settings.json` | JSON | `mcp.servers`，为**数组** |
| OpenCode | 全局 `~/.config/opencode/opencode.json[c]`（XDG；`OPENCODE_CONFIG_DIR` 可覆盖）；项目同名文件 | JSON / JSONC | `mcp.servers`；服务器为**标签联合**（`local` / `remote`），`command` 为数组，环境变量键为 `environment` |
| Hermes Agent | `<HERMES_HOME>/config.yaml`（默认 `~/.hermes/config.yaml`） | YAML | `mcp_servers` 映射；官方读取时把 `type` 归一化为 `transport` |

> 键名、容器类型、命令形态、环境变量键名与文件格式**逐客户端不同**，因此必须按客户端分别实现适配器，不得假定统一 schema。

## 单一真相源与投影

```text
管理器统一扩展配置（含每个能力项的启用矩阵）
        │  逐客户端投影
        ▼
各客户端 live 配置文件
```

- 管理器维护统一事实；客户端配置是**投影**。
- 每个能力项记录它在哪些客户端启用，启停以投影方式同步到对应文件。
- 导入方向相反：从客户端 live 配置读回并合并进统一结构，**不覆盖**其他客户端的启用状态。

## 写入边界

| | 范围 |
|---|---|
| **允许写入** | Skills 目录同步；各客户端的 MCP 服务器节点 |
| **禁止写入** | provider、路由、模型映射，以及 OpenCodex 核心运行配置 |

被禁止的内容一律走官方 CLI；本产品不提供写入通道。

## 写入规则

| 规则 | 要求 |
|---|---|
| 目标校验 | 目标必须是**普通文件**；符号链接、FIFO、设备文件或越出预期根目录的路径一律拒绝写入 |
| 前置备份 | 任何写入前生成可恢复备份；备份失败即阻断 |
| 原子替换 | 同目录临时文件写入后原子替换；替换后保留原文件权限 |
| 节点级写回 | 只改目标节点，保留未知字段与注释；解析失败即拒绝，不做"尽力而为"的部分写回 |
| 非目标文件 | 不改写同目录的凭据、认证等非目标文件 |
| 并发互斥 | 写入持有**跨进程文件锁**，并在写入前比对目标内容摘要 |
| 冲突处理 | 检测到外部改写或客户端间不一致时进入待处理，**不静默覆盖** |
| 可恢复删除 | 卸载 Skills、删除 MCP 等删除类操作进入回收区，可恢复 |
| 串行化 | 扩展配置写入由单一状态锁串行化，避免并发动作互相覆盖 |

## 敏感值与凭据

### 数据分级

| 级别 | 数据 |
|---|---|
| S0 公开 | 应用版本、官方项目信息 |
| S1 内部 | 安装路径、版本、运行状态、端口、进程标识、数据根路径 |
| S2 敏感 | 日志正文、备份内容、同步索引摘要、Skills 文件内容、MCP 配置结构 |
| S3 凭据 | API key、token、Authorization、WebDAV 账号口令、加密口令、MCP 环境变量值 |

### 处理规则

- S3 **不得**进入仓库、Markdown、日志、命令行参数或未加密文件。
- **敏感值范围包含** `env`、`args`、`headers`：三者一律按潜在敏感值处理，默认掩码。
- 掩码在**取值之前**完成，不得"先明文取回再在界面掩码"；编辑场景按字段短暂显示。
- 涉及凭据的配置文件按凭据文件处理，Unix 权限 `0600`。
- MCP 的 `command` / `args` / `env` 具备执行本地程序的能力：必须展示执行边界并经用户**显式确认**，不得静默执行任意本地程序。

## 信任模型

| 对象 | 信任假设 | 结论 |
|---|---|---|
| WebDAV 远端 | **不可信** | 上传前客户端加密；完整性校验（哈希）只用于检测传输损坏与回放，**真实性由认证加密覆盖**，不得把哈希当作对恶意远端的防护 |
| WebDAV 连接 | 需要证书校验 | 证书校验失败**默认拒绝**，且**不提供**"忽略证书"选项 |
| 外部客户端配置 | 可能被第三方改写 | 写入前比对内容摘要，冲突进入待处理 |
| 官方 CLI | 权威写入者 | 不与其争夺 provider / 路由 / 模型映射的写入权 |

## 明确不做

- 不重写 OpenCodex 核心，不绕过官方 API。
- 不接管 npm 包管理器，不替代官方 `ocx update` 事务。
- 不接管 `codex-shim`，不安装或管理 launchd。
- 不写入 provider、路由、模型映射等核心运行配置。
- 不自动覆盖外部 provider 托管配置，只检测、解释并引导官方 `restore`。
- 不明文迁移或同步凭据。
