## 原型改动

| 区域 | 本轮结果 |
|---|---|
| 渠道模型首屏 | 全宽渠道表，搜索和全部渠道范围；批量工具只在有选择时出现；原生组只读；渠道重排仍改变整个选择器组顺序 |
| 渠道详情 | 返回 / 切换渠道、获取模型列表、搜索 / 族 / 仅已选、选择模式、搜索结果勾选及模型表；推理、Fast、顺序和配置保留 |
| 完整顺序 | “预览选择器”弹窗展示草稿 / 已保存；按渠道及内部模型展开，Fast 紧跟父项，不占首屏长列表 |
| 模型模版 | 首屏模板表；版本详情先只读规则摘要，“编辑为新候选”后出现字段；来源和版本低频操作按需查看 |
| 内置 Agent | 设置 → 模型配置 → 配置 Agent；生成 / 会话中同一快捷入口，独立保存后返回原输入；未配置不能生成或纠偏 |
| Agent 执行参数 | 复用已保存连接和模型目录、推理 / Fast；执行模型与目标模板分开，不必占选择器白名单；A6api 无额度禁选且不探测 |
| 对话纠偏 | 独立生成会话弹窗，消息按模板隔离；结果先比较 / 接受到候选，不自动主用或改渠道引用 |
| 外部 Agent | 自行配置模型 / 检索，导出任务包足以说明当前目标和约束；不携带内部执行偏好，导入仍为候选 |
| 配套设置 | 自动生成 Agent、共用全局 Fast、折叠文件 / 状态；窗口外 mock 测试器折叠，减少常驻信息 |

具体源码在 [产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html)、[model-config.js](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.js) 和 [model-config.css](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.css)。交互与规则同步到 [DESIGN](../05-原型/DESIGN.md)、[原型交互方案](../02-方案草案/原型交互方案.md)、[模型页交互细化](../02-方案草案/模型页交互细化.md) 及 [Agent 方案](../02-方案草案/Agent制模与版本恢复方案.md#211-内置-agent-执行配置新增候选)。

## 持久化候选与实现依赖

模板库及渠道 / 模型策略继续分两个文件。内置执行偏好拟复用 `manager-state/preferences.json` 的本机 `modelTemplateAgent` 分区，保存连接引用、模型 ID、推理 / Fast，不重复保存密钥，不建第三份规则文件。保存 Agent 偏好不触发 Codex 重启；保存渠道策略仍需写入 / 读回并提示重启。

现有 preferences 已参与 WebDAV 和全配置导出，因此“不带出该分区”必须由生产同步 / 导出过滤及导入保留本机字段实现，不是已有能力。失效连接、可用性、runner / 检索、结构化结果、取消和超时另在 WP-06 落实。模版双文件同步与 Agent 执行设置的边界不得混写。当前原型只保存内存状态。
