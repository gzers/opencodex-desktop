# 数据与状态

> 字段级配套：分区里的条目实体见 `领域模型.md`；加密容器的头字段见 `契约字段.md`；凭据分级见 `集成与安全边界.md`。

## 1. 数据根

用户可选择一个自定义数据根，管理器按用途划分产物。`OPENCODEX_HOME` 可以选择放在数据根内，也可以由用户指定为独立路径。

### 1.1 分区

| 分区键 | 用途 | 内容 | 可丢弃 | 需备份 |
|---|---|---|---|---|
| `manager state` | 桌面壳设置、数据根元信息、UI 偏好 | 设置项、数据根元信息 | 否 | 是 |
| `opencodex home` | 可选承载 `OPENCODEX_HOME` | OpenCodex 自身数据 | 否 | 是 |
| `backups` | 升级、导入、同步覆盖等动作前的备份 | 备份对象 | 否 | 否（本身即备份） |
| `logs` | 桌面壳操作日志与旋转后的本地日志 | 日志文件 | 否 | 否 |
| `exports` | 加密配置导出容器 | 加密容器 | 否 | 否 |
| `cache` | 可丢弃缓存 | 探测结果、缩略图等 | 是 | 否 |
| `sync state` | WebDAV 冲突记录、远端索引摘要、同步历史摘要 | 索引摘要与冲突记录 | 否 | 否 |

- ⏳ **目录名待冻结**：上表的「分区键」是逻辑名，物理目录名在 IMP 冻结。
- 分区键是稳定标识，实现与文档引用分区时用分区键，不用物理路径。

### 1.2 路径解析

| 优先级 | 来源 | 说明 |
|---|---|---|
| 1 | 用户在设置中显式指定的数据根 | 唯一权威来源；切换走 §1.3 |
| 2 | 默认位置（`~/` 下的应用数据目录） | 首次启动时建立 |
| — | `OPENCODEX_HOME` | **独立解析**：可在数据根内，也可为独立路径；界面不得与数据根混用 |

### 1.3 切换语义

```text
选择目录 → 检查（可写、空间、已有数据） → 引用 或 迁移
→ 运行前备份 → 停止代理 → 执行迁移 → 校验 → 更新配置 → 恢复代理
→ 成功 / 回滚
```

- **引用优先**：默认引用已有位置，不搬动数据。
- **迁移可选**：仅在显式选择时移动；迁移前强制备份，失败自动回滚并保留原数据目录。

检查项字段（检查阶段即阻断，不进入下一步）：

| 检查项 | 判定 | 失败行为 |
|---|---|---|
| 可写 | 目标目录当前用户可创建与写入 | 阻断并说明原因 |
| 空间 | 迁移所需空间可得 | 阻断并说明原因 |
| 已有数据 | 是否已是有效数据根 | 是则默认走「引用」 |
| 结构版本 | 已有数据的结构版本可比对 | 异常即阻断 |

失败、取消、回滚分支：

| 分支 | 触发 | 结果 |
|---|---|---|
| 失败 | 目录不可写 / 空间不足 / 迁移中断 / 校验失败 | 回滚到原数据目录，备份可定位可恢复 |
| 取消 | 确认阶段取消 | 保持原数据目录，不写入任何变更 |

## 2. 状态模型

状态按三个**互相独立、可同时成立**的维度建模，避免"代理在跑但同时正在同步"这类情况被压成单一状态机。

三维之外另有一组**环境前置门禁状态**，属发现阶段的门禁，不是第四个维度。

### 2.1 运行状态（`runtime`）

代理进程观测。

| 取值 | 含义 | 可用动作 |
|---|---|---|
| `not_found` | 未发现安装 | 刷新状态 |
| `loading` | 正在探测安装与状态 | 无（只显示状态说明） |
| `stopped` | 已发现但未运行 | 启动 OpenCodex、刷新状态 |
| `starting` | 正在启动 | 刷新状态 |
| `pending` | 端口可达但未通过就绪检查 | 刷新状态 |
| `running` | 运行且就绪 | 打开面板、停止、重启、查看日志 |
| `stopping` | 正在停止 | 无（只显示状态说明） |
| `starting_failed` | 启动失败 | 重试启动、查看日志 |
| `at_risk` | 官方状态报告 startup at-risk | 查看建议、刷新状态 |
| `external_takeover` | 外部 provider 接管配置 | 查看建议、刷新状态 |
| `unreachable` | 进程或端口不可达 | 刷新状态、查看日志 |

> 界面文案：`starting_failed` 下启动按钮文案为「重试启动」；十个状态各有自己的状态说明句，用来替代灰按钮传达原因。

### 2.2 连接状态（`connection`）

外部依赖（当前为 WebDAV）的连接与同步状态。

| 取值 | 含义 | 标签 | 动作区 |
|---|---|---|---|
| `unconfigured` | 未配置端点 | 未配置 | 配置 WebDAV（单颗整行） |
| `disconnected` | 已配置未连接 | 未连接 | 立即同步 / 测试连接 |
| `connecting` | 正在连接 | — | 取消 / 测试连接 |
| `syncing` | 正在同步 | 同步中 | 取消同步 / 测试连接 |
| `synced` | 已同步 | 已同步 | 立即同步 / 测试连接 |
| `conflict` | 冲突待处理 | 冲突待处理 | 处理冲突 / 立即同步 |
| `failed` | 连接或同步失败 | 连接失败 | 重试连接 / 立即同步 |

- 「未配置」**不整卡置灰**：主体说明未配置，动作区只留一颗「配置 WebDAV」直达设置，右上角更多菜单恒可用。
- 冲突态下「连接状态」显示已同步、「冲突策略」显示待处理。

### 2.3 操作状态（`operation`）

单次动作的执行阶段。

| 取值 | 含义 | 备注 |
|---|---|---|
| `idle` | 空闲 | 默认值 |
| `validating` | 校验中 | 含前置校验与内容比对 |
| `backing_up` | 备份中 | 失败即阻断，不进入下一步 |
| `applying` | 应用中 | 写入或迁移的实际执行 |
| `rolling_back` | 回滚中 | 失败路径 |
| `cancelled` | 已取消 | 无副作用 |
| `succeeded` | 成功 | — |
| `failed` | 失败 | 需带失败原因 |

### 2.4 环境前置门禁状态

按 `node` → `npm` → `ocx` 顺序**短路检查**，前一项未通过时不继续。

| 取值 | 含义 |
|---|---|
| `checking` | 检查中 |
| `missing_node` | 缺 Node.js，阻塞后续检查 |
| `missing_npm` | 缺 npm，阻塞后续检查 |
| `missing_ocx` | 缺 `ocx`，阻塞后续检查 |

全部通过后隐藏门禁，进入常规运行状态机。缺失态展示当前缺失项、状态与**最短可复制命令**；应用只做检测与引导，不代装。

### 2.5 并存与优先级

- 三个维度**必须能同时表达**，例如「`running` + `syncing` + `backing_up`」。
- 运行状态、连接状态、操作状态各自独立存储与渲染，互不覆盖。
- ⏳ **字段命名与映射待冻结**：三维在代码与 `--json` 输出里的字段名在 IMP 冻结。

### 2.6 渲染规则

- 动作**按状态渲染**，不渲染无解释的禁用按钮；用状态说明文字替代灰按钮传达原因。
- 阶段编号（P0 / P1 / P2）**不出现在应用界面**；界面只用功能名与状态（「规划中 / 可用」）。
- 敏感值永远掩码。

## 3. 持久化与备份

| 对象 | 落点（分区键） | 约束 |
|---|---|---|
| 应用设置与偏好 | `manager state` | 不含真实凭据明文 |
| 操作与运行日志 | `logs` | 只读、脱敏、可轮转 |
| 升级 / 导入 / 覆盖前备份 | `backups` | 必须可定位、可校验、可恢复 |
| 加密导出容器 | `exports` | 口令保护；按凭据文件处理，Unix 权限 `0600` |
| 同步索引与冲突记录 | `sync state` | 记录远端清单摘要与冲突，用于变更检测 |
| 可丢弃缓存 | `cache` | 可随时清空 |

备份的最小信息字段见 `契约字段.md` 的备份清单。

### 3.1 备份规则

| 规则 | 要求 | 来源 |
|---|---|---|
| 备份先行 | 任何可能覆盖数据的写入前必须生成备份 | `ARC-04` |
| 失败即阻断 | 备份失败时阻断后续破坏性动作 | `AC-06` `AC-08` `AC-11` |
| 可定位可校验可恢复 | 备份必须能被找到、校验、还原 | `REQ-16` |
| 删除可恢复 | 删除类操作进回收区，保留恢复窗口 | `REQ-27` |
| 保留策略 | 保留份数与天数 | ⏳ 待冻结 |

## 4. 加密导出容器

导出容器是**跨边界数据**，其头字段、白名单与拒绝策略见 `契约字段.md`。

本文件只记其数据侧约束：

| 字段 | 约束 | 状态 |
|---|---|---|
| 内容范围 | 全量配置，**包含敏感内容** | ✅ 已定 |
| 保护方式 | 用户口令保护；推荐 Argon2id 派生 + AES-256-GCM 认证加密 | ✅ 方向已定 / ⏳ 参数待冻结 |
| 完整性 | 认证加密自带完整性校验；解密或校验失败即拒绝，**不部分导入** | ✅ 已定 |
| 版本策略 | 容器头含格式版本与派生参数；不兼容即拒绝并说明支持范围 | ✅ 已定 |
| 结构约束 | 只接受白名单字段与合法路径；拒绝未知字段与越界路径 | ✅ 已定 |
| 文件权限 | 按凭据文件处理，Unix `0600`；不写入符号链接目标 | ✅ 已定 |
| 口令输入方式 | 只经内存 / 标准输入；**不得进入命令行参数、日志或配置文件** | ✅ 已定 |
