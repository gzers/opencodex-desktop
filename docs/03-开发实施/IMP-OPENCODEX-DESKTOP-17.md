## 实施选择

- PERF-01/02：Vue + SVG + WebGL 保持现有质量、DPR 与前台帧率；概览路由与原生应用激活、隐藏、最小化共同门控。暂停时保存相位，恢复不补跑。缓存目标色、几何与相同属性/uniform，复用追踪缓冲。着色器预计算仅在等效与收益证据充分时采用。
- PERF-03：高频轻量检查复用可信官方进程身份及健康端点，不能把 healthz 存活当作完整就绪；缓存完整官方报告，配置周期重校验，身份/运行变化和手工刷新重新诊断。共享采集锁避免并发诊断。
- 所有新增检查周期、超时、退避、面板 TTL 与日志字节上限来自 tauri/config/runtime.defaults.json；构建期校验、嵌入，无设置 UI 或热更新承诺。
- PERF-04：托盘请求事件驱动，低频带退避兜底、在途去重；原生菜单只更新变化值。
- PERF-05：隐藏面板闲置后回收 WebView，保留页面位置。输入修改采用保守保护：无法证明已保存时保留页面。官方代理服务、连接及偏好不受回收影响。
- PERF-06：诊断命令输出有上限，超时终止并等待回收该子进程。
- PERF-07：日志尾读增加总字节上限、避免重复扫描/不完整记录泄露；关键结果保持同步落盘，普通日志合并同步策略按验证结果决定。
