## 4. 依赖图

```text
IMP 确认 + 首批 TASK 授权
  → WP-01 工程底座
      ├→ WP-21A 测试基线最小集
      ├→ WP-22A 本地构建与 CI 最小集
      ├→ WP-18A 单实例锁与命令边界基础
      └→ WP-17A 锁 / 临时文件 / 原子替换原语
            → WP-03 备份与数据根
            → WP-17B 写入事务与回滚编排

WP-03 + WP-04 接口
  → WP-02 发现 → WP-04 启停 → WP-05 状态
      ├→ WP-06 日志 / Doctor / 通知
      ├→ WP-07 面板接口与失败回退
      ├→ WP-08 风险与 restore
      └→ WP-09 官方升级引导
      ├→ WP-10 托盘 / 菜单（状态稳定后）
      └→ WP-11 关于（界面就位后并行）

WP-17B + WP-20A 安全设计
  → WP-13 公共加密 / 凭据 / 导出
      → WP-14 导入 / 白名单 / 回滚
      → WP-15 Skills
      → WP-16 MCP
  → WP-18B CLI 业务命令逐项接入
  → WP-12 自更新（依赖 WP-04 / WP-22B）
  → WP-19 WebDAV（依赖 WP-13 / WP-14 / WP-17B / WP-20A）
```

依赖检查结论：没有 WP-03 与 WP-17 的互相等待循环；WP-17A 先做锁与原子写原语，WP-17B 再依赖 WP-03 备份服务。

## 5. 首批候选范围

首批不覆盖全部 22 个 WP，只建立底座：

| 候选范围 | 内容 | 直接前置 |
|---|---|---|
| WP-01 骨架 | Tauri + Rust + TypeScript / Vite / Pinia、IPC 边界、公共错误与类型 | IMP 与首批确认 |
| WP-21A 测试基线 | 测试命令、临时目录、fake runner、fixture 目录设计 | WP-01 |
| WP-22A 构建基线 | 本机构建命令、平台目标占位、CI 清单 | WP-01 |
| WP-17A 写入原语 | 文件锁、临时文件、摘要、原子替换；不做业务写入 | WP-01 |
| WP-18A 实例约束 | `app.lock`、启动/退出行为；不开放 CLI 命令 | WP-01 |

WP-03 / WP-17B 可随后创建；不与 WP-17A 形成循环。

## 6. 写入范围约定

- 项目核心、IMP、协作包对象、报告构建物和 `.adg` 索引由集成线维护。
- 贡献者 TASK 只写工程目录、测试、fixture 和回执证据。
- 首批 TASK 不触碰真实用户家目录、真实钥匙串、真实 WebDAV、系统 PATH 和发布私钥。
