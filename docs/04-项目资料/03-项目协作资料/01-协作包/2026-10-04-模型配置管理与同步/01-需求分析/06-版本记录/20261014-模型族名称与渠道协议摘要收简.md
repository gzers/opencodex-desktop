# 模型族名称与渠道协议摘要收简

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex桌面管理器，模型配置管理与同步0.2.0候选原型。

用户要求模版和渠道的列表/详情身份展示不直接附Chat/Responses等协议，协议由具体模型规则定义。前序回复和执行偏回摘要任务，没有落实协议展示；本轮核对源码后补上该漏项，撤回误加的“变更：”摘要前缀。没有浏览器证据支持缓存归因，因此不以缓存解释本次漏项。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。

## 页面与变化

| 页面 / 入口 | 本轮变化 |
|---|---|
| 模型模版列表及mpTemplateHeader | 内置示例名称从GPT·Responses、Claude·Anthropic、Gemini·Google改为GPT、Claude、Gemini，来源标记继续保留；规则字段与稳定ID不变 |
| 渠道列表mp-provider-name | 去掉渠道默认协议，摘要保留节点数和连接/发现状态 |
| 渠道详情mpChannelHeader | 状态与数量保留，去掉协议摘要，不用一个默认协议概括全渠道 |
| 新增/编辑渠道的选择模型步骤 | 只显示渠道名称，不拼接协议后缀 |
| 模版/模型/渠道配置 | 族通用、具体型号、单模型协议字段和渠道默认协议配置仍可编辑，具体模型行与明细显示其实际解析协议/来源；解析及覆盖逻辑未改 |

用户自定义名称不做后缀截断，协议相同与否不决定模版或渠道身份。版本摘要继续按实际差异显示，不额外增加未请求的前缀。模型字段、版本/基线保护、采用关系及已保存运行配置均沿现有规则。
