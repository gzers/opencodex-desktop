建议先跑通两个用户各两台设备、两个团队交叉成员的纵向切片，再补所有图表；不要先堆页面，最后才决定事件身份。每个实现变更保留字段映射与对应验收 ID，引用本包版本 / 后续已确认需求。

首期之外：预算提醒 / 周期报告 / 配置模版同步另拆工作包；团队成员 / 角色属于首期；Hub 接入、团队项目、SSO 自动入组、服务身份、上游凭据托管和远程执行另定边界。

既有项目核心对云端数据的边界需在方案确认后更新，再冻结 IMP。当前实现未动，不需要为这份设计伪造已完成任务或要求高风险操作许可。
