    桌面壳只隐藏窗口，不自动停止官方 OpenCodex 子进程。
    启停结果通知
    通知启动、停止、重启和失败结果；不展示敏感配置。
    同步冲突提醒
    检测到本地与远端冲突时暂停覆盖，并要求显式确认。

    画质

    背景光与视觉效果的渲染方式；按设备能力自动降级。

    视觉特效
    高＝会动的光场＋玻璃（默认）；中＝光场静止＋玻璃（省电，等价系统「减少动态效果」）；低＝无光场＋无玻璃，退回原本黑白实底风格。关掉特效后通知同样为实底。
    背景光渲染
    WEBGL＝网格渐变＋颗粒着色器（默认，画质最高、过渡最平滑）；CSS＝纯 CSS 极光，不依赖 GPU，低端机与禁用硬件加速时更稳。当前环境不支持 WEBGL，已自动回退纯 CSS 极光。

    官方共享配置

    与官方 OpenCodex 使用同一配置源；模型、路由与 provider 仍由官方面板或官方 CLI 管理。

      日志与通知清理

      自动清理只作用于管理器本地记录；不会清理官方 OpenCodex 服务日志。

      日志自动清理
      本地日志超过上限或保留期后自动截断；原始错误先保留摘要。
      通知自动清理
      已读通知超过保留期后自动清理；未读和 danger 通知不自动删除。
      启动时清理
      应用启动时按策略执行一次轻量清理，不阻塞主窗口。
      清理前备份摘要
      danger 日志和重要通知会先生成脱敏摘要，再进入自动清理。

      外观 · 总开关
      内容页表面（打样）

      只作用于内容页这一层：窗口底面、菜单、标题栏保持不透明。页面是盖在「软件自己的底 + 环境光」上的磨砂玻璃，参照物在软件内部，跟桌面无关；卡片、按钮、表格仍是实底，正文与长表照旧可读。

      特效档（总开关 · 打样）

      全局总开关：高=会动的光场＋玻璃（默认）；中=光场静止＋玻璃（省电）；低=无光场＋无玻璃，退回应用原本黑白实底风格。低档对通知同样生效。本页环境光为静态，暂无动画，故「高 / 中」此处观感相同。

      背景光渲染（画质 · 打样）

      默认 WEBGL：概览背景光用网格渐变＋颗粒着色器，过渡最平滑、色带最少；CSS 为纯 CSS 极光兜底，不依赖 GPU。环境不支持 WEBGL 时自动回退 CSS。与「背景光渲染」设置项同一开关。
