# Logo 本体形变：聚合结构开合

2026-09-28，视觉候选，尚未定稿。入口：[交互演示](./index.html)。

## 1. 本次方向

用户要求根据品牌 SVG 做真正的形变，用形态表达状态。用户随后明确否定“压扁”的效果，认为难看，需要更好的方案。

据此淘汰纵向压扁、下沉、外轮廓凹陷的候选，改为**保持品牌外形，用内部聚合结构的开合表达状态**。外层云形维持比例，三个圆节点保持圆润，三段弧形连接沿各自曲线伸展或回收。动态来自 SVG 镂空路径的几何变化。

这是对专题 §8 旧候选“本体呼吸＋外圈指示”的进一步探索。聚合开合方向已获用户认可，新增渐变与背景效果仍待视觉评审，不修改已确认需求基线、现行主原型或生产实现。

## 2. 为什么选择内部结构

原 Logo 的三节点聚合图形天然具备“分离、建立关系、连接完整、局部断开”的含义。用这组关系组织动作，可以让形变与品牌结构一致。

统一外轮廓还能保持概览中的视觉重心与占位。未运行不会显得坍塌，异常不会变成破损的云朵。状态下方保留文字：单靠图形不足以区分全部业务语义，尤其在 72px 尺寸。

此轮只采用一种结构语言，不给每个业务结果发明独立图腾。v04 为各状态设置协调渐变；过期状态使用低饱和雾灰。原始品牌渐变可通过对照按钮查看。

| 演示情形 | 内部结构 | 结束条件与主线 |
|---|---|---|

| 正在启动 | 节点靠拢，三段弧线错峰伸展，始终留有间隙 | 只在新观测核验运行后完整归位 |
| 运行中 | 精确恢复原始品牌路径 | 稳定静止 |
| 正在停止 | 连接从两端回收，节点小幅外移 | 核验前主线仍保留运行中 |
| 启动失败 | 接合未完成，一段连接退回、节点略偏离 | 单次过渡后停住；失败属于操作 |

取消、部分完成、待重启等结果继续由支线文本承载，本轮不强行为它们增加主 Logo 形态。

## 4. 几何与动画实现

- `logo-geometry.js` 从品牌素材 `docs/04-项目资料/04-品牌与图标素材/04-品牌组件/Logo/logo.svg` 提取原始云形和聚合镂空路径。
- 云形始终使用原始 `d`。镂空按三个圆节点和三段弧形连接分别处理；多子路径分开采样，避免错误跨接。
- 圆节点只移动位置，保持圆形。连接在极坐标中收缩角度跨度，并适度调整径向厚度，实际更新遮罩内的 `path d`。
- 稳定运行恢复原始镂空 `d` 和原坐标变换；不是用采样结果近似品牌定稿。
- 状态切换约 950ms，从当前几何参数插值到下一组参数。快速切换使用当前值作为起点，不跳回固定首帧。
- 启动和确认期间使用错相、小范围往复形变；其他状态的几何过渡后停止更新；v04 运行态可保留独立的柔和流光，关闭相关开关后停止逐帧更新。
- 页面隐藏时停止动画帧；暂停按钮冻结当前帧；系统或页面“减少动态”直接显示目标静态结构。
- 无外部依赖，`index.html` 可本地打开。演示有九种状态、启停场景、深浅主题、原图对照、强度控制和 72px 概览尺寸对照。

这是 CPU 参与的路径更新，不能沿用“CSS transform 即 GPU 合成”的性能结论。生产接入建议在构建时固化采样点，并仅动画一个可见概览实例；真机帧耗与 WebView 兼容性仍需验证。

## 5. 与真实状态机制的边界

本页的 `STATES` 是演示情形列表，不是新增业务状态机。实际组件应消费专题中已有的主线、操作、问题和新鲜度投影。

建议投影优先顺序：未知/过期先限制真实性表达；有效事实下使用主线作为底态；相关启停操作暂时展示开合；持续问题作为局部断开。普通后台同步和备份不应使全局 Logo 进入启动形变。

定时场景仅用于预览。真实接入必须由观测决定归位，不能在动画播放完毕后自行宣布启动成功。可在视觉层合并短时重复更新，不能因此吞掉操作结果或延迟关键错误文本。

## 6. 验证范围

在本机 Chromium 无头浏览器中检查九态渲染、路径有限数值、稳定态停帧、进行态变化、暂停、减少动态，以及运行态原路径还原；检查 900px 与 390px 视口页面不横向溢出。深浅主题截图用于人工查看。

验证仅涉及独立候选；不代表真实状态采集、刷新时延、原生 WebView、托盘或生产制品已通过验收。是否美观、内部开合幅度是否合适，仍需用户评审。


## 7. v04：状态渐变与背景光效（2026-09-28）

用户认可聚合开合，并建议丰富渐变颜色与配套背景。本版保留已认可的几何结构，增加同步色彩插值与局部光场：

| 状态 | 渐变 | 背景 |
|---|---|---|
| 待接入 / 未运行 | 雾蓝 / 柔紫 | 静态低强度光晕 |
| 启动中 | 鸢紫 → 电光蓝 | 三层蓝紫光团缓慢交融 |
| 运行中 | 薄荷青 → 靛蓝 | 青蓝流光，几何本身保持稳定 |
| 停止中 | 暮蓝 | 回到静态柔光 |
| 启动失败 | 珊瑚 → 莓紫 | 稳定暖色光晕，无闪烁 |
| 运行中待处理 | 琥珀 → 薰衣草 | 局部暖色光晕，无重复警示运动 |
| 正在确认 | 冰蓝 → 浅紫 | 轻微流动，与节点探寻配合 |
| 事实过期 | 雾灰 | 灰色静态残光 |

状态切换时，从当前实际颜色向新配色插值，约 950ms；快速切换不先跳回旧色。SVG 渐变方向和中间色标可低频往复变化，不做整圈旋转。背景采用三层局部渐变光团及底部漫反射，限制在 Logo 区域，不覆盖操作与详情；72px 概览对照同步展示简化的两层光晕。

提供“背景光效”和“流动渐变”独立开关。统一暂停、减少动态和页面隐藏机制同时覆盖形变、颜色与背景。稳定运行仅更新色标和光团位置，缓存几何避免反复重建路径。原图对照恢复原始几何和品牌渐变，并隐藏氛围背景。

本版明确允许运行态的装饰性流光，因此替代前版“全部稳定态不循环”的视觉约束；状态与新鲜度语义保持不变。色彩是辅助提示，仍保留形态和文字。以上配色与光效仅为候选，未进入生产品牌规范。


## 8. v05：全状态持续循环（2026-09-28，替代前版定格策略）

用户明确要求动画可循环，背景光效也持续运动。v05 保留聚合开合、渐变与配套光场，改为九态均循环：启动 2.8s、运行 4s、停止中 4.5s、待处理 5s、未运行 5.5s、失败 6s、待接入 6.5s、确认 3.8s、过期 8s。

节点沿局部方向往复，弧形连接错峰伸缩，外轮廓保持原始比例。运行态仅轻微开合，失败与待处理的断口始终保留；过期采用雾灰低幅度循环，并明确显示过期文字。动画表示当前状态的视觉节奏，不代表有新的观测或业务进度。

背景三层光团按对应节奏持续游移、伸展并柔和改变亮度；72px 对照同步运行且按比例缩小位移。暂停统一冻结几何、渐变和背景；减少动态显示静态目标，隐藏页面暂停，原图对照仍为静态原始素材。此节替代 v03/v04 的稳定态、异常和过期定格策略；此前记录保留为迭代历史。


## 9. v06：旋转、聚合与状态语义（2026-09-28）

用户提出以类似“写轮眼”的层次感加强动画，包含整体旋转、内部三球线条整体旋转，要求动效与状态相符。本版借鉴内外层相对运动的视觉语言，继续使用项目原始 Logo，不引入其他图案。

### 动效分层

1. **整体层**：SVG 整体旋转，镂空与云形一同运动。仅启动阶段持续整圈转动；其他状态减速回正，保留品牌方向和稳定感。
2. **内核层**：遮罩内三球与三段连接置于同一个 SVG 组中，围绕 `(12,12)` 旋转，叠加现有路径形变。不是把三个球分别当加载点绕圈。
3. **背景层**：三束渐变能量光带、三个柔光团及漫反射。光带表现相对运动，光团表现能量聚散；全部限定于 Logo 区域。
4. **文字层**：主线、支线和新鲜度始终不旋转，保留明确业务结论。

### 状态—动作映射

| 状态 | 整体 | 内核 | 背景 | 语义 |
|---|---|---|---|---|
| 待接入 | 固定 | 离散结构缓慢探寻 | 雾蓝散光 | 关系尚未建立 |
| 未运行 | 固定 | 小角度休眠摆动 | 低能量柔紫光 | 可启动但未运转 |
| 正在启动 | 顺时针约 24°/s | 反向约 150°/s，周期调速并接合 | 蓝紫三束光聚散 | 建立运行关系、蓄能 |
| 运行中 | 回正固定 | 三球和线条成组匀速 60°/s，约 6s/圈 | 青蓝稳定流转 | 已确认、稳定运转 |
| 正在停止 | 减速回正 | 继承当前速度后衰减，连接回收，再小幅摆动 | 暮蓝收束 | 退出运转，等待停止核验 |
| 启动失败 | 固定 | 断口保留，有限角度受阻回摆 | 珊瑚局部柔光 | 未能建立完整连接 |
| 运行中待处理 | 固定 | 保持单向运转但周期减速，断口始终可见 | 琥珀局部起伏 | 仍运行，但存在问题 |
| 正在确认 | 固定 | 半开结构大角度双向扫描 | 冰蓝往返光场 | 寻找可用观测，尚无结论 |
| 过期 | 固定、去饱和 | 虚接结构极低幅漂移 | 雾灰残光 | 旧事实，不表达正常运转 |

对比依据：单向匀速适合正常运行；加速和内外反向适合启动；减速适合停止；有限角回摆适合受阻；双向扫描适合未知；过期不使用完整整圈运转。所有效果仍循环，但运动模式有区别，不把所有状态都变成高速旋转。

### 连续性与限制

旋转采用角速度积分，切态从当前角度和速度过渡，不把角度重设为零。整体回正取最近的正向角度。停止的速度衰减仅为呈现，不自动推进主线；启动循环不保证启动成功。失败回摆不触发真实重试。

表中的有限角度与周期是目标节奏，速度平滑会产生相位延迟；实际不承诺严格数学振幅。减少动态与原始素材对照取消旋转；暂停和页面隐藏同时冻结整体、内核和背景。72px 对照复用同一角度，背景位移按尺寸缩小。

本版仍为候选，不作为真实运行速度、服务吞吐、故障数量或进度的量化图表。性能与原生 WebView 制品验证仍待生产接入阶段完成。


## 10. v07：居中结构 A/B/C 与悬浮位移（2026-09-28）

用户认可将 A 完整内核、B 分离三球、C 柔性连接分配给不同状态，并要求增加跳跃、下沉与漂浮感。本版按以下映射替代前版全状态连接线伸缩方案。

| 状态 | 结构 | 整体位移 | 循环与结束边界 |
|---|---|---|---|
| 待接入 | B 分离三球 | 轻缓上下漂浮 | 低能量持续等待 |
| 未运行 | B 分离三球 | 低位小幅起伏 | 正常待命，不整圈运转 |
| 启动中 | B → C | 轻跃蓄能，约 3.2 秒循环 | 柔性连接显现度保持 46%–78%，核验后才进入 A |
| 运行中 | A 完整内核 | 稳定悬浮 | 内核形状固定，约 6 秒一圈 |
| 停止中 | A → C → B | 缓慢下沉至低位 | 减速与退去连接为入态过渡，其后低位浮动，等待核验 |
| 启动失败 | C → B | 一次短促回落后低位浮动 | 不循环假装重新启动 |
| 运行中待处理 | C 柔性连接 | 平缓横向起伏 | 始终完整连接，连续曲线小幅弯曲，仍表达运行 |
| 正在确认 | B 分离三球 | 缓慢横向漂移 | 内核双向探寻，背景扫描 |
| 状态过期 | 保留上一帧结构与方向 | 雾灰低幅漂移 | 不再改变内部结构与转向，文字明确旧事实 |

### 居中与连接重做

旧素材内的节点布局、弧线圆心与固定 `(12,12)` 旋转中心并不完全统一。候选现在从原云形的 SVG 包围盒求中心，三球以 120° 等角分布，节点布局、连接弧线与旋转均共用该中心。节点质心始终与云形包围盒中心一致，避免旋转导致内核绕偏置中心摆动。光学居中仍需视觉评审；数学对齐不等于所有人对不规则云形的视觉重心判断完全一致。

A 使用固定圆润曲线与三球，不再按时间改变几何。B 完全不显示连接。C 使用三条相接的三次贝塞尔曲线，端部延伸到节点中心并被圆节点覆盖，圆头圆角、恒定线宽，通过控制点轻微弯曲表达柔性。建立/解除连接通过完整曲线整体显现/淡去完成，不把短弧压成线段碎片。

这对候选内核做了对称化设计，**不是原始品牌镂空的逐点还原**。原云形仍使用原始路径；“对照原始 Logo”单独保留原始镂空路径与原始配色，方便评审新旧差异。

### 高度与阴影

位移在 SVG 坐标中定义，换算成显示尺寸的百分比，72px 预览同步按比例缩小。运行约 3px 轻浮、启动轻跃最大约 13px（232px 展示尺寸）；云形不做 squash/stretch，不改变宽高比例。实际位移幅度仍待视觉评审。

底部投影与高度耦合：升高时扩散、变淡，下沉时收拢、变浓。状态转换从当前位移插值，避免切换时瞬移。暂停、原图对照、减少动态和页面隐藏机制覆盖新增位移与投影。

仅改独立候选与本专题说明，未接入真实状态，也未修改现行主原型或生产代码。


## 11. v08：任意切态连续过渡（2026-09-28）

用户要求任意点击状态都平滑过渡，背景也必须连续。本版替代先前每次切态重新计时插值、背景直接读取目标状态参数的方式。

- 形状、浮动位置、三色渐变、饱和度、透明度、光团位置/大小/亮度以及光束大小/亮度，均以当前值和当前速度进行临界阻尼追踪。切态只改变目标，不归零、不排队等待上一动画结束。
- 整体与内核旋转保留当前角度和角速度，逐步趋近新速度；过期态也平滑减速，不立即锁死转速。
- 所有周期动作使用积分得到的连续相位，周期变化只调整相位速度，避免 `时间 / 新周期` 造成背景瞬间换位置。
- 柔性曲线改用弯曲的正弦/余弦分量追踪，避免插值累计角度造成连接线快速扭转。
- 背景光束使用独立连续角度与速度，从单向流转切到双向扫描时不直接切换角度公式。
- 状态文字即时更新，视觉随后收敛；暂停时切态保留画面并记录新目标，继续后平滑过渡。系统减少动态仍直接呈现静态目标；原图对照与显式重播是独立展示控制，不属于自动切态承诺。
- 新增“随机切换状态”按钮。九态按钮支持在过渡中继续点击，最后一次选择生效。

验证：本机 Chromium 对全部 72 种有向跨状态切换、100 次快速切换做连续性检查（固定 16ms 仿真步长），状态选择当下的几何、颜色、位移、背景、角度及速度均未重置；同时检查运行态固定曲线收敛、过期减速、暂停切态保留、减少动态，以及 900px/390px 无横向溢出。固定步长检查不等同于真机帧率性能验收。

此次仍仅改候选与说明，不改真实状态采集和生产实现。
