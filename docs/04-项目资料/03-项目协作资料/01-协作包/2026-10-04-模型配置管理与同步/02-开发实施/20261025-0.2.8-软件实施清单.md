## 1. 阻断与高优先级

### MO-1 导出被渠道 name 回显字段阻断

| 段 | 内容 |
| --- | --- |
| 现象 | 导出报「实际渠道含当前适配器未知字段，请升级适配后再导出」，渠道无法导出 |
| 根因 | 官方 provider-validation 的字段白名单不含回显字段 name，导出侧把它当未知字段拦下 |
| 修法 | provider_fields.rs 新增 ECHO 分类：校验放行，写入载荷仍按 PUBLIC 过滤，name 不进入配置 |
| 断言 | 单测覆盖「放行 + 不外泄」两侧；真实导出已可生成备份包 |

### MO-2 顶部操作行不换行、控件等高

| 段 | 内容 |
| --- | --- |
| 原型 | model-config.css:583 定义 --mp-policy-control-height:34px，:593 让保存/还原按钮取同一高度；整组 flex-wrap:nowrap |
| 软件改前 | ModelsRoute.vue 允许 flex-wrap，状态框与按钮高度各自为政，窄窗被挤成两行 |
