# 模版列表单版本列与所选版本操作

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器，模型配置管理与同步 0.2.0 候选原型。

用户同意前序模版列表操作建议，并要求将“版本与使用情况”改为可选版本下拉，与“以后默认版本”合并为一列。此次把前序仅建议的列表操作接入唯一活动原型；维护动作按精确保存版本提供，不另建查看页。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models) → 模型模版列表。

## 页面与行为

| 入口 / ID | 调整与边界 |
|---|---|
| mp-template-table | 收简为模版 / 版本 / 操作三列，去除重复默认与版本使用情况列；窄窗横向滚动，保留完整选择与动作 |
| mpTemplateListVersion-模版ID | 完整时间与短标识下拉，标记以后默认 / 归档，不显示版本数量，仅有未保存编辑时保留提醒。初始显示默认版，无默认则最新保存版；选择只改行操作上下文 |
| open-template-editor | 按行所选保存版进入同一编辑器，改动保存另存新版本。清洁旧缓冲按所选重新加载；未保存源缓冲锁定列表版本并继续原编辑，防止覆盖 |
| copy-list-template | 按所选已保存内容新建独立模版，明确区别于详情复制当前未保存表单；源版本与采用关系保持 |
| template-list-menu / 使用位置 | 按精确版本列已保存配置的全局族 / 渠道族 / 单模型引用，草稿引用变化分开显示，可展开解析到的模型。匹配命中不冒充采用 |
| template-list-menu / 匹配预览 | 明示所选版本，复用只读匹配弹窗，不切走列表，不改变库或策略 |
| 更多 / 设为以后默认 | 先独立确认，选择下拉本身不改默认；已有渠道引用仍采用原精确版本 |
| 更多 / 归档与删除所选版本 | 默认版不能归档，已采用归档版保持引用。删除检查默认、采用、草稿、恢复、编辑及待审更新依赖；确认后再核对库与依赖。只删一个版本，最后一版无依赖时明确提示整个模版将移除 |
| ann-mp-07 | 原型标签解释单版本列、选择与写入、当前表单 / 保存版复制和维护依赖边界 |

列表行内保持编辑 / 复制 / 更多，不让名称或空白点击导航。版本数量不展示，使用情况通过使用位置查看。行选择为会话 UI 状态，不持久化或同步；保存新版本会定位新保存版，不自动切默认。列表选择不改变全量更新的既有冻结 / 差异 / 新版保存与引用保持规则。

规则回写：[交互细化](../02-方案草案/模型页交互细化.md#模版列表单一版本列2026-10-14)、[模版规则方案](../02-方案草案/模型模版与匹配规则方案.md)、[主方案](../02-方案草案/模型配置管理方案.md)及[实施范围](../../02-开发实施/README.md)。前序仅建议状态由本轮接入替代，历史记录保留当时范围。
