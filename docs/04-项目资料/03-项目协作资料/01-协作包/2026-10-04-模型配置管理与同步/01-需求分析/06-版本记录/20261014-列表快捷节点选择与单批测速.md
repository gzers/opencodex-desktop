# 列表快捷节点选择与单批测速

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器。归属：模型配置管理与同步 0.2.0 候选原型。

用户本轮要求渠道列表增加快捷节点选择、测速和一键测速入口，详情服务节点提供单节点与一键测速。此次追加按需测速，替代前序“暂不提供测速”的范围；不增加定时测速、自动切换或请求故障转移。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。

## 页面、入口与行为

| 入口 / ID | 调整 |
|---|---|
| 渠道列表，mpChannelNode-渠道ID | 名称下增加快捷节点下拉，选择只改该渠道草稿，不进入详情；保存后才生效，节点选择重绘后恢复控件焦点 |
| 列表 node-speed-current / node-speed-all | “测速”测草稿当前节点，“一键测速”测该行渠道全部节点；显示当前节点耗时及进度，官方 / 原生无节点操作 |
| 详情 mpChannelSection-nodes | 每行增加“测速”和结果，分区标题旁增加一键测速；运行时一键入口变为停止测速 |
| mpNodeSpeedSummary-渠道ID / mpNodeSpeed-渠道ID-节点ID | 等待、进行中、成功（ms）、失败、超时、停止分开显示；最多两项模拟任务并行，停止保留已完成结果，未完成的取消项不计作完成 |
| 右侧工具板 mpNodeSpeedDemo | 增加正常 / 部分失败 / 超时的独立模拟结果选项，只影响测速观察，不重置渠道草稿或自动开始测量 |
| 原型标签 06 | 说明接口响应耗时与模型生成速度、能力和额度的区别，以及模拟 / 保存 / 自动切换边界 |

测速结果只存本次会话的独立观察，不进渠道策略、保存记录、导出或同步。测速完成不切换节点，不改清单、认证、连接验证或无额度状态。结果绑定渠道身份、节点 URL、默认协议及共用认证版本；修改地址或 Key、删除后重建同 ID 渠道使旧结果失效，晚回不能覆盖新测量对象。取消和新一轮测量使旧回调失效。

异步测速只更新结果单元、进度及测速按钮，不重建编辑表单或抢占弹窗。未确认渠道认证先处理；保存中不新开测速，但已有测试仍只产生观察。列表 / 详情共用同一结果，测速不影响保存确认的策略基准。

本轮是确定性内存 mock，不发网络请求、不读取或发送真实 Key。正式实现应核验适配器的轻量只读探测接口及超时 / 认证边界，不发模型生成请求测速；不因探测响应就标记模型能力或额度可靠。
