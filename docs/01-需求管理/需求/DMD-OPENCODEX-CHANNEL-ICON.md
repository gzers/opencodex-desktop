# 渠道图标上传与附件管理

来源：2026-11-01 用户在概览改版对话中提出：“节点用图标更好，客户端节点用图标，渠道默认用中转名称，那么渠道模型中允许渠道传图片做图标，但是要求统一格式处理（大小等），然后有专门的存储位置，而且附件要有个管理位置，方便选已有图标，在线图标，上传图标，同步渠道要带上图标存储，默认可以传图标。这个你先记录，先做概览效果。”

当前只登记需求，未设计也未实施。已落地的部分只在概览原型：客户端节点改用内置图标，渠道节点仍显示中转名称缩写，节点函数预留了图片入口（见[概览反应堆与环形重构](../../04-项目资料/01-项目支撑资料/01-产品原型/全景概览第二轮专题说明.md#概览反应堆与环形重构2026-11-01)）。

待确认：图标尺寸与格式（如 128×128 PNG / WebP、圆形裁切）、单个文件体积上限、“在线图标”的来源与离线缓存、附件存储位置（应用数据目录或同步目录）、WebDAV 与文件同步是否都带图标、删除被引用图标时的处理。
