# 数据与状态

## 数据根

用户可选择一个自定义数据根，管理器按用途划分产物。`OPENCODEX_HOME` 可以选择放在数据根内，也可以由用户指定为独立路径。

| 分区 | 用途 |
|---|---|
| manager state | 桌面壳设置、数据根元信息、UI 偏好 |
| opencodex home | 可选承载 `OPENCODEX_HOME` |
| backups | 升级、导入、同步覆盖等动作前的备份 |
| logs | 桌面壳操作日志与旋转后的本地日志 |
| exports | 加密配置导出容器 |
| cache | 可丢弃缓存 |
| sync state | WebDAV 冲突记录、远端索引摘要、同步历史摘要 |

### 切换语义

```text
选择目录 → 检查（可写、空间、已有数据） → 引用 或 迁移
→ 运行前备份 → 停止代理 → 执行迁移 → 校验 → 更新配置 → 恢复代理
→ 成功 / 回滚
```

- **引用优先**：默认引用已有位置，不搬动数据。
- **迁移可选**：仅在显式选择时移动；迁移前强制备份，失败自动回滚并保留原数据目录。

## 状态模型

状态按三个**互相独立、可同时成立**的维度建模，避免"代理在跑但同时正在同步"这类情况被压成单一状态机。

### 运行状态（代理进程）

| 取值 | 含义 |
|---|---|
| `not_found` | 未发现安装 |
| `loading` | 正在探测安装与状态 |
| `stopped` | 已发现但未运行 |
| `starting` | 正在启动 |
| `pending` | 端口可达但未通过就绪检查 |
| `running` | 运行且就绪 |
| `stopping` | 正在停止 |
| `starting_failed` | 启动失败 |
| `at_risk` | 官方状态报告 startup at-risk |
| `external_takeover` | 外部 provider 接管配置 |
| `unreachable` | 进程或端口不可达 |

另有环境前置门禁状态：`checking`、`missing_node`、`missing_npm`、`missing_ocx`，按 `node` → `npm` → `ocx` 顺序短路检查。

### 连接状态（外部依赖）

| 取值 | 含义 |
|---|---|
| `unconfigured` | 未配置端点 |
| `disconnected` | 已配置未连接 |
| `connecting` | 正在连接 |
| `syncing` | 正在同步 |
| `synced` | 已同步 |
| `conflict` | 冲突待处理 |
| `failed` | 连接或同步失败 |

### 操作状态（单次动作）

| 取值 | 含义 |
|---|---|
| `idle` | 空闲 |
| `validating` | 校验中 |
| `backing_up` | 备份中 |
| `applying` | 应用中 |
| `rolling_back` | 回滚中 |
| `cancelled` | 已取消 |
| `succeeded` | 成功 |
| `failed` | 失败 |

### 渲染规则

- 动作**按状态渲染**，不渲染无解释的禁用按钮；用状态说明文字替代灰按钮传达原因。
- WebDAV 卡按连接状态渲染动作：未配置时动作区只留「配置 WebDAV」；未连接 / 同步中 / 已同步 / 连接失败 / 冲突各有对应动作组合。
- 阶段编号（P0 / P1 / P2）**不出现在应用界面**；界面只用功能名与状态（「规划中 / 可用」）。

## 持久化与备份

| 对象 | 落点 | 约束 |
|---|---|---|
| 应用设置与偏好 | `manager state` | 不含真实凭据明文 |
| 操作与运行日志 | `logs` | 只读、脱敏、可轮转 |
| 升级 / 导入 / 覆盖前备份 | `backups` | 必须可定位、可校验、可恢复 |
| 加密导出容器 | `exports` | 口令保护；按凭据文件处理，Unix 权限 `0600` |
| 同步索引与冲突记录 | `sync state` | 记录远端清单摘要与冲突，用于变更检测 |
| 可丢弃缓存 | `cache` | 可随时清空 |

## 加密导出容器

| 项 | 取值 |
|---|---|
| 内容范围 | 全量配置，包含敏感内容 |
| 保护方式 | 用户口令保护；推荐 Argon2id 派生 + AES-256-GCM 认证加密 |
| 完整性 | 认证加密自带完整性校验；解密或校验失败即拒绝，不部分导入 |
| 版本策略 | 容器头含格式版本与派生参数；不兼容即拒绝并说明支持范围 |
| 结构约束 | 只接受白名单字段与合法路径；拒绝未知字段与越界路径 |
