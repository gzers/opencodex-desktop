# 配置同步验收矩阵

日期：2026-10-08。以下是新增生产验收条件，**全部待实施 / 验证**。原型可点击或模拟通过仅记入本包原型 QA，不改变此表状态；原 AC-M 模型验收编号与历史计数保持。

| 编号 | 必须成立的行为 |
|---|---|
| AC-S01 | 独立同步菜单、文件 / WebDAV 两 Tab；旧设置与模型 / 模版入口归一并保留范围 |
| AC-S02 | 类别 → 对象浅层树表支持搜索、全选、半选、隐藏勾选提示和对象字段来源 |
| AC-S03 | Desktop 模版 / 策略和非 Desktop 创建的 OpenCodex 渠道模型完整纳入；独立 Codex 客户端配置不越界 |
| AC-S04 | 同渠道策略 / 运行字段去重；稳定身份与外部漂移比较不依赖显示名称 |
| AC-S05 | 精确模版 revision / digest 补齐；不带秘密的选择不被依赖闭包绕过 |
| AC-S06 | 全部 / 分享（不含凭据）/ 自定义 / 换设备预设准确；新敏感类型不自动扩大已有范围 |
| AC-S07 | 勾选账户默认含可迁移登录状态，详情可选仅账户信息，取消账户即排除登录状态；渠道 Key / 扩展凭据独立且支持对象子集，分享预设关闭全部凭据 |
| AC-S08 | 过滤已知授权头、认证环境变量、URL 秘密；未知自定义内容不伪称已脱敏 |
| AC-S09 | 无 Key 导入保留同身份本机秘密；新对象待配置；掩码 / 空值不作删除 |
| AC-S10 | 异端点 / 异认证身份重新映射；禁止把原 Key 静默复用到新端点 |
| AC-S11 | 含秘密强制应用层认证加密；独立解密材料不随远端数据 / 包上传，错误口令零写入 |
| AC-S12 | 新设备无预登录情况下自动恢复并检查每种已支持账户，身份正确、无需额外勾选登录态或手动核对即可用 |
| AC-S13 | 访问令牌过期后能刷新且原设备继续使用；刷新旋转 / 并发版本冲突准确处理 |
| AC-S14 | 设备绑定、不支持、撤销、过期刷新失败自动标明需重新登录，不计入免登录成功，失效远端登录状态不能采用 |
| AC-S15 | Skill 实际内容 / 资源与完整 MCP 定义可恢复；名称 / Keychain 引用不冒充本体 |
| AC-S16 | 文件导入只能选包内子集，账户默认采用包内可迁移登录状态，可改仅账户信息；渠道 Key 采用独立，不携带对象不删除本机值 |
| AC-S17 | 模板只入候选不切主用，模型既有草稿保留；三方差异确认后按预算保存 |
| AC-S18 | WebDAV 范围归本设备且约束上传 / 接收，取消勾选不删除远端或其他设备 |
| AC-S19 | 子集上传保留所有范围外对象，新客户端隔离域不被旧客户端清理 / 覆盖 |
| AC-S20 | 首次采用 / 覆盖 / 凭据替换先待审，定时同步不自动扩大授权 |
| AC-S21 | 上传只含已提交配置和精确依赖；失败 staging、草稿、机器验证状态不上传 |
| AC-S22 | 活动 WebDAV 连接与本机 scope 不自覆盖；文件导入连接为未启用项 |
| AC-S23 | 关闭凭据不宣称清除旧加密快照；历史清理范围与结果单独核对 |
| AC-S24 | 旧容器如实显示偏好 / 扩展开关等原内容，新格式拒绝旧客户端误读；未知版本零写入 |
| AC-S25 | 大小 / 深度 / 数量限制、路径穿越、链接逃逸、损坏包与重复 ID 写前拒绝 |
| AC-S26 | 备份失败零写入；中途失败 / 超时 / 崩溃先核对，可恢复项与已完成项分开 |
| AC-S27 | planId / digest 去重，重复导入 / 重试不重复建账户、渠道或应用 |
| AC-S28 | 分开报告已传输、待审、已写入、待读回 / 重启、登录态恢复与账户可用 |
| AC-S29 | 双设备并发、远端锁 / ETag 漂移、缺依赖与令牌旧版本回放均无静默覆盖 |
| AC-S30 | 光暗主题、宽窄桌面、键盘 / 焦点、错误和空状态可用；界面与日志不泄露秘密；连接按钮无“演示”，两个同步 Tab 无页底原型说明 |
| AC-S31 | 文件同步默认勾选 WebDAV 配置并携带密码；仅配置可排除，取消 / 重选恢复默认；分享预设不含密码，含密码导出须加密；WebDAV Tab 不自同步连接配置 |
| AC-S32 | 导入密码随配置默认采用且可排除；无密码包不能选出密码；同身份仅配置保留本机密码，新连接待补密码；导入连接待启用，当前连接与本机 scope 不变；取消 / 失败不报告密码已导入 |

真实账户与加密验收按最小必要权限和虚构测试凭据执行，不使用用户日常账户做未经授权的全局同步实验。验收材料记录设备 / OS / provider / 客户端版本和测试边界，敏感值不进入协作包。
