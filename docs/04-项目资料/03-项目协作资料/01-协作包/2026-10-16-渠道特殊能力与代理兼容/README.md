# 渠道特殊能力与代理兼容

状态：**独立协作包，渠道配置驱动、互斥模式与重启应用方向已获用户同意；不修改 OpenCodex，优先评估出站增强层，具体链路与多渠道统一策略待验证，版本与开发时机未定**。正式入口为 [COL-LOCAL-20261016-01](COL-LOCAL-20261016-01.md)。

用户要求支持 Krill 压缩、支持 Ultrafast，并继续保留当前通过 OpenCodex 代理接入多渠道的方案；随后补充支持新版上下文管理（history/notes）。本包围绕这四项目标整理渠道说明、官方配置依据、本机源码观察、候选接入方案与待验证事项。

用户已同意在渠道管理中配置“上下文策略单选 + 独立速度档”，保存后提示待重启，重启 Codex 时应用有效配置；运行时按固定渠道规则执行，不猜测或自动探索机制。Krill 的互斥依据仍来自渠道说明，实际线路、原生压缩、history/notes 和档位组合尚待验证；默认值、同一实例的多渠道统一策略及异常处理细节未定。

2026-10-18 补充 Superba 固定提交的配置实现参考，仅用于佐证字段组织、适用条件和生效表达；不采用其 router，也不把其说明文字当作官方普遍规则。压缩协议、后台执行、history/notes 与速度档的组合仍需遵守已有验证边界。
