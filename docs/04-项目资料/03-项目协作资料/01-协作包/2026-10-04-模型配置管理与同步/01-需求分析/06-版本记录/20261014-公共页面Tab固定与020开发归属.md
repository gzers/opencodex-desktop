# 公共页面 Tab 固定与 0.2.0 开发归属

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器。

用户明确要求除概览、面板之外的其他页面也采用“Tab 滚动到顶部后固定”，并特别记录归入 **0.2.0 版本开发调整**。本轮将模型页规则抽为公共页面组件并推广，不把该要求局限在模型页，也不以原型通过代替生产交付。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html)。

## 接入范围

| 页面 / 路由 | 主 Tab 入口 | 本轮处理 |
|---|---|---|
| 模型 #models | mpTabsBar：渠道模型 / 模型模版 | 注册公共规则，保留详情标题与 Tab 双层高度和锚点避让 |
| 扩展 #extensions | ext-tabs：Skills / MCP | 滚至主内容顶边后固定，内容继续滚动 |
| 诊断 #logs | diag-tabs：环境诊断 / 日志历史 / 通知历史 | 主 Tab 到顶固定，页内日志分类不注册 |
| 设置 #settings | settingsTabs：通用等分区 | 主 Tab 到顶固定，换行和切页后重新测量 |
| 同步 #sync | sx-tabs：文件同步 / WebDAV | 保留内部对象表 / 凭据栏滚动和原有 Tab 常驻，不强改为整页滚动 |
| 对话探索 #conversations | cv-note-anchor：全局设置 / 项目与对话 | 原型主 Tab 复用规则，树形侧栏避让 Tab 高度；对话功能及该页 Tab 适配 / 验收均随对话包，版本未定，不属于 0.2.0 |

概览、面板排除；页面没有主 Tab 时不增加。弹窗、原型工具板、页内分类 / 筛选分段及面板内嵌官方界面不默认接管。未来主 Tab 页面沿此公共规则接入。

## 公共行为与开发归属

新增 sticky-tabs.css / sticky-tabs.js，页面通过 data-page-tabs 明确注册。组件按主内容容器内距和实际 Tab 高度计算顶部位置、背景延展及锚点偏移；控件与正文保持对齐，沿公共玻璃令牌，低特效 / 不支持背景模糊回退实色。动态生成、换 Tab、窗口变化和隐藏页重新显示时重新测量，清理旧 DOM 观察。不改变页面选择、草稿、保存或滚动容器。

模型详情标题仍固定在主 Tab 下，其他固定导航消费公共高度；已有内部滚动工作区保留原滚动职责。弹窗和下拉仍高于固定栏，键盘焦点、实际阈值和滚动表现需逐页实屏验收。

**0.2.0 归属已确认**：WP-03 承接公共页面组件及模型 / 扩展 / 同步 / 诊断 / 设置接入，WP-05 承接各页验收。用户进一步明确：对话原型可以补绘，但对话功能及该页 Tab 适配 / 验收都不属于 0.2.0，随对话包后续版本实施。公共组件的 0.2.0 交付不能扩大为对话页面开发。本记录不将其他候选功能的版本改写为 0.2.0。

权威规则回写[UI 规范 §28](../../../../../../02-项目核心/UI规范.md#28-页面主-tab-到顶固定2026-10-14-确认020-开发调整)；明确开发范围见[0.2.0 公共页面 Tab 固定](../../02-开发实施/README.md#020-公共页面-tab-固定已纳入开发调整)。前序模型页固定记录保留当时范围，当前全局规则以 UI 规范为准。
