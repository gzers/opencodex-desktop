# 概览背景光延伸到下方卡片（玻璃卡透光）

2026-10-02。用户在原型上批注：背景光效果应该要超过底部，这样下面卡片都能透光；改好后代码也要调整。承接 [IMP-10](IMP-OPENCODEX-DESKTOP-10.md) 的光场范围对齐。

## 1. 现象与根因

- 光场容器只盖到状态区：标准就绪 `400`、标准准备 `260`、紧凑就绪 `330`、紧凑准备 `224`（`top:-75/-35/-66/-27`）。
- 概览布局（1180×760）：状态区 `124–424`、三卡 `438–602`、事件卡 `616–700`。
  容器底边在标准就绪是窗口 `49+400=449`，只擦到三卡顶部 11px；**事件卡整块在容器之外**——
  `.motion-ambient{overflow:hidden}` 会直接把它裁掉，一点光都收不到。
- 下方卡片本身已经是玻璃面（`--glass-fill` + `backdrop-filter: saturate(1.5) blur(8px)`，实测
  `rgba(34,36,42,.56)`），所以只要光场铺到它们后面就能「透光」，不需要改卡片材质。

## 2. 修复

- 容器纵向延伸到路线区底部：`660`（标准就绪）／`520`（标准准备）／`640`（紧凑就绪）／`480`（紧凑准备）；
  原型 `.motion-backdrop` 与软件 `.motion-mark` 用**同一组值**。
- 纵向渐隐改成一段长渐变：`transparent 0% → #000 6% → #000 55% → transparent 100%`——上端留住 Logo 附近的光，
  往下缓慢衰减到卡片之后。原型 `.hero-embed .ambient` 与软件 `.motion-ambient` 同步。
- 顺带把光场的 `filter: blur()` 全部去掉（原型 hero 的 `.hero-embed` 逐层模糊一并去掉）：这几个光团是低频
  径向／锥形渐变，模糊不产生可见差别（与「容器一层 20px 模糊」的成像差 ≤0.5/255），却要在软件光栅化下
  每帧多花约 5ms。能量束的径向遮罩保留（那才是防硬边的一层）。

## 3. 实测（暗色主题，1180×760，内容列）

| 区域 | 原型 Δ（开光−关光） | 软件 Δ |
| --- | --- | --- |
| 状态区底部 y≈400 | 19.6 | 19.7 |
| 三卡 y≈440 / 480 / 520 | 7.2 / 5.4 / 4.1 | 7.8 / 5.7 / 4.2 |
| 事件卡 y≈600 / 640 / 680 | 2.1 / 0.8 / 0.1 | 2.0 / 0.5 / 0.0 |

改动前事件卡各行为 0（被裁掉）；现在两边的逐行光强差 ≤0.5/255。
