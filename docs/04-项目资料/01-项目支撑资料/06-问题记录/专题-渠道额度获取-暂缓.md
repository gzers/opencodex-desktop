## 前轮候选规则（已从当前原型撤下）

1. **列表**保持“渠道 / 额度 / 模型 / 启用 / 操作”。原“服务节点”列取消，操作列新增两字按钮“检测”；点击仍打开原节点测试窗口，保留单节点检测、一键检测/停止与选择动作，关闭/Escape回到该按钮。检测不查询额度、不自动切节点，也不保存配置。服务节点底层配置仍在详情，未删除模型路由所需节点。
2. **额度**展示最近查询的值、数据范围和状态，行内刷新只查询本渠道。区分未查询、查询中、有限金额/配额、真实0、Key未设上限、接口暂不支持、查询失败。单位明确显示；没有来源单位/换算依据不擅自标为USD、CNY或Token。当前Key未设上限不代表账户余额无限。
3. **详情“额度获取”**提供可选独立查询地址、独立查询凭据、认证方式与数据范围；自定义返回格式折叠放置剩余额度字段、单位与换算系数。独立项留空时沿用渠道API Key和默认节点（即渠道当前采用的服务节点）；默认以已验证适配器识别标准接口。支持“恢复默认”。查询配置不改变模型协议、地址、选择与请求路由。
4. 查询结果为会话观察，不使渠道变成未保存，也不进入模型策略/同步快照；额度获取配置本身属于当前渠道编辑，详情保存仍只保存该渠道，全列表保存预览须列出变化。独立凭据只显示掩码，公共状态/差异不带明文；复制渠道不隐式复制独立查询凭据。生产安全存储与传输合同尚未实施。
5. 默认不因页面重绘持续轮询或生成模型请求；本轮原型以行内刷新演示查询。失败不伪造0，原配置相同的上次结果应保留并标过期；节点/认证/查询配置改变后旧结果失效，晚回不得覆盖新配置。后续若增加自动刷新，应单独明确频率、缓存与流量，不把本次模拟当作后台查询已开发。
6. 本原型只用确定性mock。示例金额、0值和“不限额”仅用于状态演示，不来自本机真实账户；独立查询凭据也只进入私有mock内存。原型本身不读真实Key、不连真实API、不保存日常设置。

## 当前渠道首轮技术验证

## 接口依据与实施边界

- [NewAPI路由](https://github.com/QuantumNous/new-api/blob/main/router/api-router.go)的`/api/usage/token/`使用只读Token认证；[GetTokenUsage](https://github.com/QuantumNous/new-api/blob/main/controller/token.go)返回Key级total_available/total_used/unlimited_quota。新实现只有令牌允许查询时才提供user_quota，不能默认模型Key都能读取账户余额。
- [OneAPI账单实现](https://github.com/songquanpeng/one-api/blob/main/controller/billing.go)给出兼容subscription/usage结构，usage按金额乘100输出。该源码是适配参考，不能据此断言AgentRouter或其它闭源部署恰好使用同一换算；本轮不直接把不同单位相减。来源按2026-11-04读取，第三方main为可变来源。
- 生产需由后端承担Key读取、同源/独立地址授权、认证注入、超时/限流、字段解析、缓存与取消。独立地址跨域使用凭据的授权、额外Header/用户ID等供应商要求须明确，不能静默将模型Key发送到任意查询站点，也不执行供应商脚本。
- 请求仅返回格式正确、范围明确的余额或限额才算成功。HTML200、401/403、无字段、网络失败、单位未知分别处理；真实0与不限额优先级明确。token_usage的内部配额单位不直接当Token数；按站点公开元数据/已验证规则换算。
- 这轮没有为18项未打通渠道添加猜测配置，也没有改写当前Key、节点、模型或账户。下一轮在可确认的服务商接口/凭据条件下补专用适配，再决定软件开发与版本。
