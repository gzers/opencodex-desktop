## 4. 扩展管理安全条款（已生效）

（2026-09-14 OQ-01 决定纳入后生效，已随 AC-11 回写 DMD §10）

- Skills / MCP 属于**扩展配置域**（管理），不属于 OpenCodex 核心运行配置（不管理）。
- 允许修改外部客户端配置；具体允许的客户端清单留 IMP 冻结。
- 写入前**强制备份**，采用临时区 + **原子替换**，失败回滚。
- 删除类操作**必须可恢复**，恢复窗口留 IMP 冻结。
- 环境变量**默认掩码**。
- MCP `command / args / env` **不得静默执行任意本地程序**，必须展示执行边界并经用户显式确认。
- 多客户端配置不一致时**检测冲突并提示**，不静默覆盖。
- 外部应用改写配置后同样**检测冲突并提示**。

## 7. 建议结论（分析级草案，2026-09-14）

> 以下为分析得出的**结论**，用于把契约类开放问题从「未决」推进到「已确认」。

| ID | 建议结论 | 影响落点 |
|---|---|---|
| OQ-02 | 采用**引用优先、迁移可选**：默认把数据目录「引用」为已有 `OPENCODEX_HOME` 所在位置，不搬动已有数据；仅在用户显式选择「迁移」时执行移动。迁移前强制备份；不可写、空间不足、已有数据结构异常在**检查阶段**即阻断；迁移中断或校验失败**自动回滚**并保留原数据目录；备份不可定位时不得开始迁移。 | `state-and-flows.md §4.1`、AC-02 |
| OQ-03 | restore 结果链固定为：查看风险 → 影响摘要 → 生成备份 → 用户确认 → 官方 restore 引导 → 执行中 → 成功 / 失败 / 取消 → 刷新状态。备份失败即阻断；失败**不自动重试**，只给建议；取消不留副作用；执行结果不改变「restore 属官方路径」的定性。 | `state-and-flows.md §4.2`、AC-05 |
