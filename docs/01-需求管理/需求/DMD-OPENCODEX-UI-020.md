# 0.2.20 原型一致性与同步流程修复

范围与逐项比较、偏差和证据来源：[S20-01～20、SY-01～26和全应用/弹窗台账](../../04-项目资料/01-项目支撑资料/06-问题记录/0.2.20-bugs.md)。基线为已发布v0.2.19/cb4c9c9b7，采用冻结原型cfbd90c4b与已确认MCP增量1da4cabca；不包含工作区并行原型、未来对话策略/全景/客户端扩展包功能。全部已采用入口、37处组件引用、26处动态调用及另列自定义宿主均有检查状态及证据，发现属于已采用基线的问题必须处理；原型专用/后续能力须写明排除依据。

## 验收绑定

AC-020-01～20分别一对一承接S20-01～20的验收列（按本次采用提交固定摘要，TASK记录）。不可仅以功能测试、安装/OTA或标题存在证明原型一致。先保留旧版失败，再以行为/真实配置文件/双引擎/原生证据验收。旧偏差需处理或取得明确产品决定，不把记录视为批准。

用户授权范围包括必要的文件/凭据/隔离网络夹具、Windows一次性Actions runner、代码提交推送/PR合并、正式原包构建与签名核验、公开stable及相邻实际OTA。不改日常配置、不读取/发布日常秘密值、不运行日常真实配置同步。发布私钥只在现有Actions secrets中使用。

已确认规则：移除逐次人工复核、预设/清空及额外明文确认；默认不加密；范围/凭据按文件与WebDAV分别记忆；概览原位共享弹窗；普通导入/下载确认后更新已保存内容且保护未保存输入；备份为实际所选资源。详见IMP-28采用决策与依赖。其他未决规则不靠旧实现默认批准。


2026-11-04采用补记：用户明确软件与原型在正常100%下的标准字体偏大，采用共同字体增量，正文/导航13px、普通控件12px、副标题15px、弹窗标题18px、页标题22px；小字10/11/12px及缩放语义保持。具体配方归UI规范§2.4/§3.1，作为cfbd90c4b+1da4cabca的明确追加，不采用其它并行未来模块。完整依赖加载、原型低档无光场与实际通过/失败边界见原0.2.20-bugs及integration-20261104；原验收范围与正式包/双平台/OTA/stable责任保持，不能凭字体局部通过关闭。
