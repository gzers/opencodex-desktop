# 配置同步

2026-10-08：用户同意补入 v0.2.0 协作包，并授权原型补绘。范围与独立菜单方向已确认；布局、容器契约、账户适配和生产实现待评审或验证。

文档保持在本包的需求、评审、原型和验收阶段下，用“配置同步”子目录区分专题；不另外复制协作包或完整桌面原型。人工长期材料保留在 docs，实施任务与机器回执后续进入 .adg。

本专题更新模型主方案第 10–12 节的导入导出 / WebDAV 范围。前序“不传连接或凭据、只同步双模型文件”的局部设计不再是本轮总范围；模型双文件本身仍不存秘密，凭据由独立受保护部分承载。历史调研、旧截图和旧验收记录保留原意，不改写为新功能已完成。

团队发布订阅仍由下一版本的独立协作包承接。本专题支持个人文件分享与设备同步，不增加公共发布、订阅源或团队管理。

2026-10-08 用户进一步确认文件同步默认勾选 WebDAV 配置并携带密码；对象可选仅配置，分享预设排除密码。按钮文案与双 Tab 页底说明同步精简，见 [增量记录](../../06-版本记录/20261008-WebDAV配置与密码联动.md)。

## 后续公共能力扩展边界（2026-10-13）

本专题是原包的公共同步流程基线。后续版本可以登记新增配置类型、schema、默认范围和域适配器，继续复用同一页面与服务；新增模块的需求、交付版本和验证归其功能包，不回填为本包 0.2.0 已承诺或已完成内容。

对话配置 / 历史与本地重装恢复由独立 [Codex 对话配置管理](../../../../2026-10-11-Codex对话配置管理/README.md) 承接，版本未定；两个同步范围均默认排除，对话历史首批用于本地恢复。具体接入和兼容建议见 [公共配置能力的分模块接入](../../../../2026-10-11-Codex对话配置管理/01-需求分析/02-方案草案/独立配置存储与事件订阅适配方案.md#83-公共配置能力的分模块接入)。本专题原有严格容器兼容、按范围合并和部分上传保留远端原则继续适用；新模块支持尚未实现。
