# Agent 配置页收敛与快速状态

日期：2026-10-14（Asia/Shanghai）。项目 / 产品：OpenCodex 桌面管理器，Desktop。归属：COL-LOCAL-20261004-01。状态：唯一总原型已修订，源码检查通过，实屏待验，生产未实施。

用户在设置页提出五项批注：弹窗保存 / 取消 / 运行任务说明收进原型标签；分析页面全局快速模式是否多余；Agent 摘要显示快速状态；“调整 Agent”改为“Agent 配置”；设置 Tab 改为“Agent 配置”。前序分析区分了单次执行快速模式与全局请求 / 旧目录兼容策略，用户随后授权“开始调整”。截图和页面文字只用作定位证据。

## 唯一入口与修订

主原型：[index.html](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#settings?section=models)。内部 settings-models 标识与已有模型页跳转保留；只更改用户看到的名称，不迁移配置或另建设置页。

| 页面 / 流程 | 实际变化 |
|---|---|
| 设置 → Agent 配置 | Tab 与页内标题改名；只保留“模型模版助手 · 本机共用”、模型组合摘要及 Agent 配置按钮。未配置和已配置时按钮名称一致 |
| 页面快速模式 | 移除原 Fast 请求策略、独立 Fast 项和“前往模型页保存”区块；没有删除底层模型策略或改动现用配置 |
| Agent 共用配置弹窗 | 执行模型仍通过公共选择器设置型号 / 推理 / Fast；移除正文的“选择后先返回这里……”说明，复用弹窗的唯一原型标记保存该说明 |
| Agent 模型摘要 | 已明确支持时显示“快速已开启 / 快速已关闭”；不支持显示具体原因，未知显示“快速能力待核对”。保留已选开启但能力变化的提示，避免把旧配置意图显示为真实已执行状态 |
| 内部实现说明 | 文件职责、持久化 / 同步过滤及任务冻结说明放进隐藏原型标签，取消常驻“配置文件与状态”详情块 |
| 模型 → 配置工具 → 高级模型配置 | 全局 Fast 请求策略及独立目录兼容项迁到这里；修改加入同一渠道草稿，返回模型页后保存 / 重启核对。不会更改 Agent 执行设置 |

单次执行 Fast 是公共选择器返回组合的一部分；全局 fastMode、渠道 fastEnabled 及目录 fastRows 仍属于不同的运行 / 兼容职责。此次移除是 Agent 设置页收敛，不以 UI 迁移宣称上游协议、旧客户端兼容或运行写入已改变。

弹窗公共 openModal 增加可选 prototypeAnnotation 标题 / 正文，由 logEsc 转义后放在同一个 annotation-source hidden 内。其他弹窗继续使用默认说明，未重复创建原型标记。长型号摘要可换行，Agent 配置按钮保持单行。
