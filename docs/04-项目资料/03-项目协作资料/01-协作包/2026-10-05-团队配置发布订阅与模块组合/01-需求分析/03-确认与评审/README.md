# 评审与待决策项

状态：需求方向已记录，候选细化待评审。这里只登记决定与实施前验证点，不要求在当前文档整理阶段逐项作答。

## 1. 用户已明确

独立协作包、下一版本方向；个人 / 团队发布与订阅；渠道 / 模型 / 模版整套、Skills、MCP 三类内容；双侧范围选择；模块独立换订阅；可选保留本地配置；考虑服务端依赖。具体版本号尚未指定。

## 2. 建议默认值与开放选择

| 编号 | 待决定项 | 建议默认 | 影响 |
|---|---|---|---|
| D-01 | 服务端依赖与启用方式 | 共用账户基础，订阅独立于用量上传 | 可以同站部署，不要求先完成全部统计功能 |
| D-02 | 首期来源与可见范围 | 单服务实例内多个源；个人私有 / 指定用户 / 团队 | 跨站聚合、匿名订阅与公共市场后置 |
| D-03 | 团队订阅的含义 | 提供成员可选推荐，成员自行采用 | 不引入隐式远程设备管理；强制策略另立项 |
| D-04 | 自动更新策略 | 自动检查 / 下载候选，手动应用 | 后续可讨论按模块授权自动采用，命令 / 权限变化仍需处理 |
| D-05 | 模型体系混用 | 一个策略主源 + 本地内容；额外模版先入候选库 | 确保依赖闭包；任意多策略融合后置 |
| D-06 | 本地保留 | 本地条目与本地覆盖分别默认保留 | 关闭保留表示不参与组合 / 清除所选覆盖，删除另行处理 |
| D-07 | 团队连接信息 | 可选非敏感连接建议，本机重新绑定和认证 | 与 v0.2.0 双文件隔离；上游密钥不随包发布 |
| D-08 | 源范围新增项 | 默认固定所选 ID，新增先提示 | 显式选持续全部时也先进入候选 |
| D-09 | 历史保留与撤回 | 保留被有效 release 引用的依赖，撤回阻止新采用 | 离线明文不能远程追回；具体期限 / 配额待部署决策 |
| D-10 | 页面入口与组合方案 | 统一订阅工作区，当前组合突出显示 | 一级菜单名称、位置与多组合便利切换待导航评审 |
| D-11 | 发布标签与轨道 | 不可变 release，stable / preview 指针；精确内容锁定 | 标签命名规则与回退提示待 UI 细化 |
| D-12 | 正式交付版本 / 范围 | 以 P1 三模块闭环作为目标，版本号另定 | 任何拆分交付必须如实列出未支持模块 |
