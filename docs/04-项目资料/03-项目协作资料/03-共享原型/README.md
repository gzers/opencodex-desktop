# 共享桌面原型

状态：**已启用，当前为 0.2.0 可交互设计草稿，待用户评审**。主原型只有一份；生产功能、技术契约和发布尚未完成。

打开 [完整桌面原型](原型/index.html)，选择左侧“模型”；直接打开模型页可在入口末尾加 `#models`。两个 Tab 为“渠道模型”“模型模版”，均以列表 → 连续详情组织。新增渠道分连接与获取 / 勾选模型两步，加入草稿后保存；已有渠道在管理详情直接展示模型列表、渠道配置、协议端点和模型默认，左侧锚点及快捷操作，下方集中保存状态 / 激活数 / 查看草稿 / 保存。渠道与模版详情标题滚到顶部后固定。模型行可独立启停 / 别名、展开常用字段并进入明细；复选后显示批量栏，表头可选当前结果，清除过滤后可全量编辑。请勿在原型输入真实 Key。配套设置位于“设置 → 模型配置 / WebDAV 同步”，内置 Agent 在模版左侧首个“Agent 自动填充”按钮中选择执行模型 / 持续对话。窗口外测试器用于模拟状态，不属于产品菜单；旧入口保留 query/hash 跳转。

## 来源与维护

来源为 COL-LOCAL-20260912-01 的完整桌面原型及八份共用样式 / 脚本。2026-10-04 用户授权迁移及 0.2.0 补绘，本轮维护归 COL-LOCAL-20261004-01；需求提出人 Ezio 负责设计决策，协作 Agent 负责整理、补绘和留证据。后续维护在相应 COL 登记增量、QA 与版本引用，不复制整套原型。

这是用户确认的项目专属资料落点，见 [组织决策](../01-协作包/2026-10-04-模型配置管理与同步-v0.2.0/01-需求分析/03-确认与评审/原型组织与版本管理决策.md)；共享区是关联 COL 的派生资产，不升级为 CDOC，也不承担 DMD / 项目核心事实源职责。共用主原型及资源保留在这里；原始输入、历史候选、截图和各轮决策保留在所属包。来源包处置说明已补充迁出关系。

## 注释便签（2026-10-09）

主原型的所有“原型提示 / 设计说明 / 实现边界”文字统一由共享区根的 `proto-notes.js / proto-notes.css` 通用组件渲染为注释便签：锚点右上角小标记（fixed 定位，不占正文空间、不改软件布局），点击展开半透明浮层，再点 / 外点 / Esc 收起。各页面只在 `registerNotes()`（或 `ProtoNotes.register`）声明注释内容与锚点，禁止重复实现标记与浮层。右侧栏“本页注释”汇总面板列出当前页面全部注释，支持搜索、点击定位并自动展开；通知专题与 Windows 专题模式下面板保持可见。组件跟随浅 / 深主题，特效低档退为实底，并尊重 `prefers-reduced-motion`。
