# 交互列表与表格样式方案

制作开始：2026-10-30；检查收口：2026-10-31，Asia/Shanghai。产品：OpenCodex 桌面管理器 / Desktop。状态：公共样式打样，版本未定，尚未接入扩展业务或生产组件。

## 入口与责任

使用已有唯一总原型：[组件与样式 → 交互列表与表格](原型/index.html#components?section=interactive-collections)。用户已授权先制作组件样式；本轮只扩展非功能专题，COL-LOCAL-20261014-01 负责后续双视图分发业务。原型文件与运行依赖直接维护在已有原型目录，没有新增另一活动原型文件夹。

## 交互规则

- 结构始终为左对象列表、右关系表格。按扩展 / 按客户端只切换内容；Skills / MCP 类型切换不改变结构。
- 点击左侧行的空白或说明区域激活当前对象。点击名称查看详情；勾选用于批量选择，行内操作只处理当前动作。详情和菜单均不改变当前行或关系选择。
- 当前行用底色，不使用左侧强调条。焦点描边与复选框独立于当前行，支持已勾选但不是当前项、已聚焦但未激活等组合。
- 左栏勾选选择批量对象；右表复选框快速启用 / 停用，与行内启停按钮共用同一启用草稿；半选显示全部启用。全选只作用于当前结果的可用项，禁用项解释原因。
- 两视图共用同一份关系草稿；各自搜索、当前对象和批量选择保留。搜索隐藏当前对象时显示定位出口，不自动换对象。
- 详情、操作菜单和预览复用既有公共浮层；关闭返回触发入口，预览取消保留草稿。撤销修改与应用是明确的独立动作。
- 两栏独立滚动，工具与底部操作常驻；窄宽继续保持左右结构，名称可截断但详情可看完整值。

## 公共实现与示例

交互集合渲染器 interactive-collection.js 提供 list / table 两种结构及 onActivate、onSelect、onSelectMany、onDetail、onAction、onRetry 回调，不读取业务配置。样式为 interactive-collection.css；双视图 fixture 为 interactive-collection-demo.js，持有示例资源、客户端、分发关系和草稿。组件目录登记 data.interactive-list、data.action-table、pattern.collection-workbench，均无生产版本。
