# 选择器预览与模型预算合并

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器，模型配置管理与同步 0.2.0 候选原型。

用户要求顶部模型激活数与选择器预览入口合并，按钮改为“预览选择器”，打开预览弹窗，删除下方重复入口。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models) → 渠道模型。

## 页面与流程

- mpBudget 改为 selector-preview 动作，按钮可见文字只有“预览选择器”；Tab 右侧顺序为预览选择器 / 状态 / 保存。激活数仍在 tooltip / 可读名称及弹窗内，超限样式与保存门禁保留。
- 渠道列表正文删除重复“预览选择器”按钮，详情侧栏入口也统一到同一预览；移除独立预算弹窗和旧 order-preview 动作。
- 弹窗标题为预览选择器，包含 mpPreviewSource 来源选择、mpPreviewBudget 数量 / 基础模型 / Fast / 系统占用、按渠道数量折叠区与完整编号顺序。停用示例不发布目录项，保留已选数量摘要。
- 草稿计划和已保存配置的顺序与数量共用同一 projection；切换来源重新生成对应投影并恢复来源控件焦点，不采用、写入、丢弃或改变保存 / 重启状态。已保存不冒充客户端已加载；待重启和超限提示保持。
- 原型标签说明目录预算与实际运行的边界：100 为兼容演示阈值，真实上限、分页和目录读回继续待实施。预览仍为内存 mock。

规则回写：[交互细化](../02-方案草案/模型页交互细化.md)、[主方案](../02-方案草案/模型配置管理方案.md)、[0.2.0 实施范围](../../02-开发实施/README.md)。详情与列表不再维护两套预算 / 预览入口。
