# 凭据与账户免登录迁移

## 账户选择与其他凭据

| 选项 | 结果 |
|---|---|
| 分享配置 · 不含凭据 | 不导出 / 上传渠道 Key、账户登录态、扩展授权材料或 WebDAV 连接密码；账户只带身份与显示信息，WebDAV 只带普通配置 |
| 渠道 Key | 所选渠道的必要认证材料单独勾选，不改变账户同步选项 |
| 勾选账户 | 默认包含该账户可迁移的登录状态与刷新材料；接收端自动恢复和检查 |
| 仅同步账户信息，不含登录状态 | 在账户详情的收起选项中选择；不携带登录材料，接收端保留已有同身份登录状态，新设备需登录 |
| 选择扩展凭据 | 指定 MCP 等扩展所需的环境变量 / 授权头；单独计数 |
| 勾选 WebDAV 配置 | 文件同步默认包含配置和连接密码；详情可选“仅同步配置，不含密码” |

“不带 Key”必须覆盖可识别的 API Key、Authorization / 自定义认证头、认证型环境变量和 URL 中的凭据，不能只删除名为 api_key 的一个字段。普通自定义字段 / Skill 文本可能含未知秘密，采用字段白名单、适配器和检查结果；未知内容提示待检查，不能声称任意文本已彻底脱敏。

凭据不在 model-policy.json 或 model-family-templates.json 内存成明文。传输的受保护部分通过对象身份引用连接普通配置与秘密；文件清单、日志、错误、截图不展示秘密本体。依赖包和历史版本也须执行同一过滤。

## 导入语义

导入预览中勾选账户默认采用包内可迁移登录状态；每个账户的收起“同步选项”允许选择仅账户信息。包没有登录材料时不能勾选出材料。确认应用后自动恢复并核对身份、令牌有效性及必要刷新，不另设“核对登录”步骤；检查失败显示“需重新登录”，并分别报告普通配置与账户结果。WebDAV 同样按账户范围自动检查；不同版本的登录状态仍须选择采用方向，失效远端状态不能采用。

WebDAV 配置导入默认采用包内密码，可在收起的同步选项中排除；没有密码的包不提供密码采用选项。连接保留为未启用项，当前连接与本机同步范围不受影响。仅配置导入保留同身份本机密码，新连接待补密码。

未携带秘密：匹配同一身份且认证端点一致时保留本机值；新对象标记“待配置凭据”。不能拿空字符串、null、掩码或占位符覆盖已有有效值。

端点、认证方式或账户身份发生变化：先重新映射，再明确是否采用传入凭据。不能把旧端点 Key 自动发到新端点。同名不等于同一账户 / 渠道。删除凭据是另外的明确操作，不由导入缺字段或取消勾选推导。

## 应用层加密

文件包或 WebDAV 只要含秘密，就必须先在应用层加密，且校验认证标签后才能解包。TLS、Base64 和 SHA-256 均不能替代此要求。普通不带秘密的配置可选择加密。

传输解密材料独立于 WebDAV 连接密码，不随包、清单或同一个远端目录上传；保存在本机安全存储或由用户在另一设备输入。密钥派生参数、认证加密算法、版本、轮换、口令错误和资源消耗上限需在实施契约冻结与测试；本原型仅演示交互，不实现加密。

只复制 Keychain 引用、绝对路径或系统保护后的机器密文，不能实现跨设备恢复。适配器需要取得允许导出的材料，再在接收方写入其安全存储；不读取或转移无关系统凭据。

## 免登录验收

目标是用户在另一设备导入或接收后，无需再次交互登录即可使用支持的账户。需携带什么由各账户类型适配器确定，可能包括访问 / 刷新令牌、账户与组织身份、授权范围、有效期和刷新版本；不得假设所有 provider 使用同一种 OAuth 文件。

| 类型 / 状态 | 必须呈现的结果 |
|---|---|
| 可移植且有效 | 恢复后核对授权身份与最低权限探测，分别显示已导入、已恢复、可用 |
| 访问令牌过期、刷新有效 | 安全刷新后可用，不能只测刚复制时的短暂有效 |
| 刷新材料失效 / 已撤销 | 登录态不可用，提示重新登录；普通配置导入结果独立 |
| 设备绑定 / 平台不可移植 | 显示“需重新登录”，注明设备绑定 / 未支持的原因；仍可导入非秘密信息 |
| 同账户两设备同时刷新 | 按授权身份和刷新世代冲突处理，不能用文件修改时间取胜 |

每种支持类型必须有“新设备无预登录”“访问令牌过期后的刷新”“原设备继续可用”的真实证据。若服务端旋转刷新令牌导致一端失效，产品不能承诺两端长期免登录；应制定串行刷新 / 明确接管等可行方案并让用户知情。证据不足的类型保持未支持，而非把下载成功计为通过。

原型中的 ChatGPT 可用性结果是明确标注的 fixture；不是 ChatGPT 或任何真实 OAuth 类型已经完成适配的证据。
