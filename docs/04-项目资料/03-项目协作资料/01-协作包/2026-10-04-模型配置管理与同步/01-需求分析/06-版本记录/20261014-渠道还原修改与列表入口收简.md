# 渠道还原修改与列表入口收简

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器，0.2.0 模型配置原型。

用户否定“保存与恢复”改名为保存记录的建议，认为已有配置导入导出，不必在渠道列表另放该入口；接受“还原修改”。本轮直接调整[唯一活动原型 #models](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。

## 页面、动作与状态

| 页面 / 入口 | 本轮变化与边界 |
|---|---|
| 渠道列表 mp-list-toolbar | 删除保存与恢复按钮及独立历史弹窗；不改名为保存记录。移除单项更多菜单及入口。搜索、新增渠道、选中后的清除选择及批量操作保留 |
| Tab 右侧 mpPolicyStatus | 按预览选择器 → 状态 → 还原修改 → 保存排列；还原使用次级样式，与保存及状态框等高。浮动原型标签继续零占位 |
| mpPolicyReset / 全渠道草稿 | 无修改或保存中禁用；有草稿或仅有未确认行 / 连接输入时可用。先展示全部渠道范围与差异，取消保留输入；确认基准改变时拒绝旧确认 |
| 还原修改确认 | 退回最近成功保存的配置，清理全部渠道未保存草稿和未确认输入；没有后续成功保存时使用初始读取基线。保存成功后新配置成为后续还原基准，不退回更早版本 |
| 已保存但待重启 | 保留独立待重启状态。最近成功保存可能尚未加载，不能称为客户端当前使用配置。还原不改变已保存 Agent 执行偏好、模版版本或待审候选 |
| 导入导出与恢复数据 | 导入导出继续使用同步页。保留自动保存记录、快照及模版采用恢复路径，删除列表按钮不删除历史数据，也不把文件迁移视为自动历史恢复 |
| 原型标签 08 / 05 | 更新顶部顺序、还原基准与全渠道范围，详情注释引导返回列表顶部还原，不再指向更多菜单 |

当前规格同步至[UI 规范 §30](../../../../../../02-项目核心/UI规范.md#30-agent-执行选择与-fast-配置入口2026-10-14-确认020)、模型配置管理方案、模型页交互细化、原型交互方案、Agent 版本恢复方案、公共选择器方案与[0.2.0 开发范围](../../02-开发实施/README.md)。历史讨论和旧版本记录保留当时语境，以本轮已确认入口为准。
