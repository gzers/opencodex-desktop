数据与安全边界

这个产品大半的复杂度都在这里：它要改别人机器上的配置文件，还要搬运凭据。原则是能不动就不动，非要动就先备份、可回滚、留证据。

Data root

数据根分区

用户可以选一个自定义数据根，管理器按用途划分产物。OPENCODEX_HOME 可以放在数据根里，也可以由你指定成独立路径。

分区放什么约束
manager state桌面壳设置、数据根元信息、界面偏好不含真实凭据明文
opencodex home可选承载 OPENCODEX_HOME引用或迁移，尊重既有数据
backups升级、导入、同步覆盖前的备份必须可定位、可校验、可恢复
logs桌面壳操作日志与旋转后的日志只读、脱敏、可轮转
exports加密配置导出容器口令保护，按凭据文件处理，权限 0600
cache可丢弃缓存可随时清空
sync stateWebDAV 冲突记录、远端索引摘要、同步历史摘要用于变更检测，不作权威

Classification

数据分级

级别数据
S0 公开应用版本、官方项目信息
S1 内部安装路径、版本、运行状态、端口、进程标识、数据根路径
S2 敏感日志正文、备份内容、同步索引摘要、Skills 文件内容、MCP 配置结构
S3 凭据API key、token、Authorization、WebDAV 账号口令、加密口令、MCP 环境变量值

处理规则

  • S3 不得进入仓库、Markdown、日志、命令行参数或未加密文件。
  • 敏感值范围包含 env、args、headers，三者一律按潜在敏感值处理，默认掩码。
  • 掩码在取值之前完成，不是「先明文取回来，再在界面上打码」；编辑场景按字段短暂显示。
  • 涉及凭据的配置文件按凭据文件处理，Unix 权限 0600。
  • MCP 的 command / args / env 具备执行本地程序的能力，必须展示执行边界并经用户显式确认，不得静默执行任意本地程序。
Placements

扩展配置落在哪

六家客户端的 MCP 节点位置、容器结构和文件格式都不一样，所以必须一家一个适配器，不能假设有统一 schema。这是实施阶段最容易低估的一块工作量。

SSOT

单一真相源 + 投影

管理器统一扩展配置含每个能力项的启用矩阵
→
逐客户端投影
→
各客户端 live 配置文件
  • 管理器维护统一事实；客户端配置是投影，不是权威。
  • 每个能力项记录它在哪些客户端启用，启停以投影方式同步到对应文件。
  • 导入方向相反：从客户端 live 配置读回并合并进统一结构，不覆盖其他客户端的启用状态。
Write boundary

写入边界与写入规则

允许写入

  • Skills 目录同步
  • 各客户端的 MCP 服务器节点

禁止写入

  • provider、路由、模型映射
  • OpenCodex 核心运行配置
  • 这些一律走官方 CLI，本产品不提供写入通道
规则要求
目标校验目标必须是普通文件；符号链接、FIFO、设备文件或越出预期根目录的路径一律拒绝写入
前置备份任何写入前生成可恢复备份；备份失败即阻断
原子替换同目录临时文件写入后原子替换；替换后保留原文件权限
节点级写回只改目标节点，保留未知字段与注释；解析失败即拒绝，不做部分写回
非目标文件不改写同目录的凭据、认证等非目标文件
并发互斥写入持有跨进程文件锁，并在写入前比对目标内容摘要
冲突处理检测到外部改写或客户端间不一致时进入待处理，不静默覆盖
可恢复删除卸载 Skills、删除 MCP 等删除类操作进入回收区，可恢复
串行化扩展配置写入由单一状态锁串行化，避免并发动作互相覆盖
Trust

信任模型

对象信任假设结论
WebDAV 远端不可信上传前客户端加密；哈希只用于发现传输损坏与回放，真实性由认证加密覆盖，不能拿哈希当防恶意远端的措施
WebDAV 连接需要证书校验证书校验失败默认拒绝，且不提供「忽略证书」选项
外部客户端配置可能被第三方改写写入前比对内容摘要，冲突进入待处理
官方 CLI权威写入者不与其争夺 provider / 路由 / 模型映射的写入权

加密导出容器

项取值
内容范围全量配置，包含敏感内容
保护方式用户口令保护；推荐 Argon2id 派生 + AES-256-GCM 认证加密
完整性认证加密自带完整性校验；解密或校验失败即拒绝，不部分导入
版本策略容器头含格式版本与派生参数；不兼容即拒绝并说明支持范围
结构约束只接受白名单字段与合法路径；拒绝未知字段与越界路径
几条「明确不做」也写在这里：不重写 OpenCodex 核心、不绕过官方 API；不管 npm；不替代官方 ocx update；不接管 codex-shim、不装 launchd；不写核心运行配置；不自动覆盖外部 provider 配置；不明文迁移或同步凭据。
