### 3.2 渠道查看、批量范围与发现

点击渠道名称或“管理”进入包含渠道配置与模型设置的详情，原生入口为“查看”；复选框只选批量目标。自定义行内另有“删除”，只作用该行；即使已勾选其他渠道，也不扩大目标。批量删除另按完整已选范围确认。批量动作栏显示“已选择 3 个渠道 / 58 个匹配模型”，列明停用、未知协议、待绑定和保留例外项。“全部渠道”是显式选范围动作，不是可以承载排序的虚假渠道。搜索只影响查看，跨页 / 跨搜索已有选择保留并显示总数；批量操作前展开完整目标列表，不能只用当前可见行推断范围。

表头复选框全选 / 取消当前搜索结果中的自定义渠道，保留搜索外选择；部分选中为半选，没有可管理结果则禁用。工具栏“全部渠道”选择全域自定义渠道，官方 / 原生不参与；选择本身不改草稿。批量栏显示完整已选数及搜索外目标数，提供启用 / 停用 / 删除及现有族配置 / 套用模版。批量启停作为一次草稿动作，可一次撤销，重复同状态不产生空记录。

自定义渠道在列表直接启用 / 停用，开关只改草稿，页级保存后提示重启；“未保存”只由页顶统一表达，行内不重复。停用保留白名单、选择模式、顺序、推理 / Fast 和模版引用，仍可编辑，但基础及 Fast 项不计入激活数；再次启用恢复原计划，超过预算则阻止保存。编辑和发现不会自动启用渠道。保存中锁定范围和批量改动。

批量删除先用公共确认弹窗列出全部目标及模型数量，包括搜索外选择；涉及 Agent 执行渠道时提示保存后失效，保留偏好供重新选择。确认只移除草稿渠道及其模型策略，保留族模版库；可撤销 / 重做 / 丢弃，配置改变后重新确认。页级保存展示移除差异、成功后待重启；应用记录能补回已删渠道原配置与相邻位置为新草稿，保留其他渠道草稿，同 ID 冲突不静默覆盖。真实移除 / 凭据 / 绑定 / 同步合并及安全恢复契约待实现，细节见 [渠道列表](模型页交互细化.md#42-渠道列表)。

配置开关只有启用 / 停用；可用性、发现进度、静态来源 / 待绑定、官方归属及页级提交状态分别表达，完整定义见 [启用开关与状态分层](模型页交互细化.md#启用开关与状态分层)。无额度提示不等于停用，拉取成功不等于请求能力通过。官方 / 原生组显示“官方管理”和实际占用 / 排序能力，不提供虚假的开关、provider 白名单、刷新或凭据控件。新增自定义渠道和“渠道配置”使用 D-11；暂不支持的连接类型保留官方管理出口，原生无连接表单。

“刷新模型”只请求清单，显示获取中，可取消等待；晚返回按请求身份判断，仅更新对应缓存，不能覆盖后来的选择 / 排序。失败显示真实原因和重试，保留旧清单与更新时间。成功空清单明确显示“上游返回 0 项”，不清掉已有暂缺选择。A6api 默认用已有 104 项清单 / fixture，不调用额度或生成实测。

#### 新增渠道与保存前清单预览

P-01 列表工具栏提供“新增渠道”；D-11 第一步填写名称、稳定标识、默认接口协议、Base URL 和认证，第二步主动获取模型、搜索勾选并加入草稿。获取成功默认不勾选，能力待核对；手动 ID 为可选退路。失败 / 空 / 401 / 无接口分开呈现，保留已有选择并提供重试、返回修改和手动添加。

获取中禁用加入、支持取消等待；关闭或目标变更使晚回失效。同连接返回保留搜索 / 选择。新渠道追加末尾，加入只改草稿；全渠道预算、白名单、顺序和连接统一页级保存，成功后提示重启。无已选项时不允许加入启用渠道，不写空白名单。整个发现列表不按 100 截断，API Key 不进入导出 / 同步。正式预览服务与受管注册事务待实现；mock 不连接上游。详见 [完整契约](模型配置管理方案.md#25-新增渠道与保存前获取模型最新候选)。

### 3.3 白名单与搜索勾选

| 操作 | 草稿反馈 / 边界 |
|---|---|
| 选择“全部模型” | 说明后续新发现也进入目录；先预览本次可见性变化及可能超限，不写运行态 |
| 选择“指定模型” | 展示精确白名单；有现有 all 时按当前完整清单形成明确选择，提示未来新增默认不选 |
| all 状态取消一项 | 先提示将转指定模型，以当前清单选择其余项；清单未完整时阻止这一快捷转换，不用截断缓存构造白名单 |
| 搜索结果全选 / 取消 | 显示“本次影响 x 项”，只处理该结果集；保留不在结果中的原选择 |
| 全部取消 / 清空白名单 | 询问是否转“全部隐藏”；取消保留原模式，不能将空 selectedModels 当作隐藏全部 |
| “全部隐藏” | 说明仍保留渠道与 discovery，未来模型也隐藏；适配器未证实未来约束时展示阻止原因 |
| 暂缺已选 ID | “已选但暂不可用”，保留精确身份与位置；删除要由用户明确操作 |

模型复选框是可见性选择，行名打开详情；批量配置目标另有“配置所选范围”选择，不把白名单是否勾选当作配置对象是否入选。按族操作默认对明确范围中的已选模型，用户可显式扩到该族全部已发现模型；预览包含未归族 / 不支持及未发布对象，不默认为它们补能力。

### 3.4 所见即所得排序

渠道手柄移动整组；模型手柄只调当前渠道内顺序，另有上移、下移、置顶及键盘出口。搜索 / 族过滤隐藏排序项时提供“清除过滤后排序”；完整“仅已选”视图可直接排序。跨渠道拖动模型不支持，提示去调整渠道顺序。

取消选择只隐藏，顺序存根保留；重选回原位，新项追加组末尾。未选项和暂缺项允许保留在 modelOrder，编译时只投影实际发布项，不要求顺序数组是当前白名单子集。Fast 只有真实独立发布时在预览生成跟随项，不可单独拖动或重复勾选；仅作为元数据时显示父项能力，不造新行 / 新计数。

“草稿预览”是完整全域展开，“已写入”展示最近运行读回；上游发现数、基础勾选数、真实目录读页数分别说明。未发布占位不编号成可选行，hidden 若实际占页则计数并说明。首次迁入跨渠道交错顺序时展示原序列与成组差异，未保存前原运行值保留。

## 4. 共用字段编辑与版本采用

D-01 顶部显示对象及范围：“NewApi / GPT 族 / Responses”“NewApi / 精确模型 ID”或“模板某版本”。每字段独立“继承 / 自定义”，当前解析值和来源可展开；高级入口包含“恢复官方值”，语义为跳过 Desktop 同字段模板 / 覆盖，不能混称普通继承。批量值不一致显示“多种值”，未操作字段保持各对象原值。

上下文为 tokens 正整数、预设和输入，分别显示声明 / 有效值；输入模态 text / image / audio 非空，未知保留继承。推理可选列表与默认档位独立：列表继承时仍可设置默认，默认须在最终列表；“无”是档位而非继承或不传参数。“不显示推理档位”、强制档、映射、不传参数和权威声明在高级区分开解释。Fast 能力三态、渠道控制和已有全局状态分别显示，不让开启按钮凭空赋予能力。模板没有具体目标时只显示规则 / 来源，选择目标后才预览逐模型结果。

弹窗主“确定”将本次字段变更放入工作区草稿，底部注明“保存后才写入”；“取消”仅丢掉本次弹窗缓冲；“恢复继承”先在缓冲里移除本层字段。父模板 / 其他层不被清空。字段非法就地说明，确定不可用且有可读原因。弹窗没有“应用”按钮，避免与页级保存混淆。

D-02 必须选择模板精确版本及作用域：所选渠道的某族、所选精确模型，或全部渠道的全局族默认。更具体引用替换模板来源；能力字段保持既有层次，协议按渠道默认 → 一份模版通用输出 → 命中的具体型号输出 → 族覆盖 → 单模型覆盖独立解析；预览列出哪些字段被已有覆盖遮住，默认保留例外，清除例外是另一个明确动作。采用 A 的 v3 不能让 B 的 v1 改变。

“采用到草稿”完成后给出目标数量、跳过项的明确原因和“前往渠道模型保存”。所有不支持 / 缺依赖目标须先解决或明确移出本次范围，不能静默部分采用。可选“设为以后默认”默认不勾，若勾选，另列其只修改模板主指针；完成后显示“主版本已更新；渠道草稿尚未保存”。丢弃渠道草稿不回退这个独立主指针动作；版本页可明确恢复指针。

## 5. 保存、计数和并存状态

### 5.1 状态与计数的呈现

| 情境 | 页内表达与动作 |
|---|---|

#### 查看草稿

D-12 固定在顶部状态栏，不藏入“更多”，无改动或保存中也可打开。比较最近成功保存和当前工作区全域草稿，按全局设置与渠道分组；各组以“配置项 / 已保存 / 当前草稿”列白名单、顺序、连接摘要、端点增删 / 指定端点、启停、引用、渠道默认 / 族覆盖 / 单模型例外、最终协议及来源、推理 / Fast 和恢复继承。组内可折叠，超过四项的清单可展开全文；已删除对象仍可核对且没有失效管理入口。

无差异为“暂无未保存改动”，待重启单独说明；“继续编辑”返回当前工作区。存在合法可提交差异时“去保存”打开 D-03，仍须确认；超限或保存中不提供该按钮，查看仍可用。读取对比不改变草稿、撤销记录或保存 / 重启状态。它与完整选择器预览职责独立；本机暂存尚需持久化服务，当前 mock 只比较内存对象。

### 5.2 保存确认与进行态

D-03 显示“本次提交 x 个渠道、x 个模型、x 个全局字段”，并列模板 / 精确依赖、白名单增删、字段来源变化、Fast、排序和预算。默认提交全部草稿改动；可明确把受阻改动留待稍后，重新生成完整计划与全域预算，并显示剩余未提交数量。共享字段的实际影响范围不能被省略。确认中“查看逐项差异”展开与 D-12 相同的已保存 / 当前草稿对比，不另生成第二份差异口径。

“确认保存”绑定冻结计划及基准；相关模板 / 草稿 / 发现 / 绑定 / 运行字段变化时提示重新预览，旧确认不能继续。第一次写入前备份失败就退出，草稿保留。双击只允许一个计划；进行中锁相关编辑，浏览 / 收起进度可用。D-04 行内展示校验、备份、写入、运行目录读回、Desktop 成功快照发布；成功后仍留客户端待重启阶段。

写入前“取消”无运行改动；开始后按钮为“停止后续步骤”，说明可能已有写入，停止后核对并安全补偿。关闭面板只收起，查看状态可再打开。超时先“核对实际结果”，不马上重发；补偿不能覆盖等待期间的外部修改。runtime 已写而 Desktop 发布中断，以 journal 恢复核对，不把半次保存上传或自动抹掉实际值。

### 5.3 重启与继续编辑

保存后明确对象是 Codex 客户端，沿用会话处理提示；不自动关应用，也不把重启 Desktop / OpenCodex 代理当作完成。自动重启若未适配，显示“手动重启 Codex → 我已重启，重新检查”；用户选稍后继续保留待重启。第二次保存后目标更新为最新成功计划，旧计划的晚核对结果不能把新计划标成已生效。

只有对应目标的客户端加载 / 可达性证据通过才报自动生效；无法获取时显示“运行目录已核对，客户端待验证”。允许用户目视核对并标“用户已确认”，仍保留证据来源。无新增运行差异不会清除旧待重启标记。

模版即用户自建的模型族，预置仅为起点，不需族下拉。包含 / 排除、精确 / 前缀 / 通配、大小写、渠道全部 / 白名单 / 黑名单和优先级随 revision 保存；输出协议独立。全部忽略保留的勾选，白名单空选不匹配，黑名单空选允许全部；新渠道依同一机制判断，模式切换保留列表。可自由增删具体型号，按上游原始 ID 的字面后缀选取最长一条，未命中仅用通用配置。自动解析须先命中顶层规则，型号不扩大自动范围；精确人工引用保留手工例外。D-14 可从编辑或详情打开，列命中与排除原因、零命中、未选和停用；不改变白名单或启用。运行只解析已采用集合，按同 ID 渠道引用替代全局再取优先级；同最高优先级冲突保留草稿并阻止保存。人工精确引用可越过匹配，仍验证能力。详见 [匹配契约](模型模版与匹配规则方案.md)。

新建只创建缓冲，取消不生成空候选；返回列表保留缓冲，已有详情默认只读。编辑为新候选时建立基准，编辑中版本切换 / 操作须先保存或取消，不能默默换基准。比较包含名称 / 说明、匹配、配置、来源。保存只入候选；主指针、采用和渠道保存分开报告。归档 / 删除保护主指针、策略 / 草稿、传入和恢复依赖；精确引用仍解析旧版。 返回图标、可编辑名称、候选状态及版本操作合并为一行标题；Tab 滚过后标题贴住主内容区顶部，左侧导航和锚点定位随实际标题高度调整。名称在标题编辑，基本信息不重复名称；左侧导航下独立按钮区依次提供“Agent 自动填充 / 匹配预览 / 与主版本比较 / 更多操作 / 设置”，收起保留图标、tooltip 和可读标签。编辑页设置归入左侧、移除顶部重复更多。页底取消 / 保存候选保持。

### 6.1 编辑内自动填充与对话纠偏

### 6.2 独立外部 Agent 批量配置

## 7. 导入、同步与恢复

D-07 先显示来源、产物、明确 scope、依赖齐备 / 缺失、待绑定，再显示与当前成功策略 / 草稿的差异。相同基准的无关字段可合并，重叠字段必须保留本机或采用候选；基准不可得时做手动比较。采取“先暂存当前草稿，再查看候选”或“继续当前编辑”不会丢候选；取消不改原值。采用到草稿可撤销，模板主指针候选另选接受，不因策略采用而自动切主版本。

导出范围默认是已提交策略或所选模板，另选渠道 / 族及是否附精确依赖。局部范围不默认携带全局 Fast / 全局来源顺序 / 范围外字段；共享字段另勾并列影响。显式导出草稿标为未提交候选。模板 revision 可入候选库，策略下载先本机 incoming；写入成功待重启的策略可同步，partial / 本机暂存 / 绑定 / 详细对话 / 验证记录不作为当前策略上传。下载完成、已采用草稿、已写入待重启、客户端核对分开报告。

D-08 应用记录展示成功 / 部分失败、影响范围、时间、前后差异、客户端证据来源。“恢复上次”默认撤回上次成功记录影响字段，也可明确选择完整策略回某基线；partial 记录只核对 / 补偿。主指针恢复另勾，默认保留当前。已有草稿先处理冲突，再生成恢复草稿；旧规则可恢复入库，无关新候选保留。最后仍经保存、预算、漂移检查和重启核对，形成新记录以便再向前恢复。

## 10. 协议字段与渠道端点交互

D-01 与模版编辑使用同一“模型协议：继承 / 自定义”控件，显示协议来源。单模型另选“端点：自动匹配 / 指定”，与协议独立；只配置地址不能暗改模型协议。候选模版正文带输出协议，参考协议标签不参与匹配，人工字段 / 精确引用默认保留。

D-13 从渠道详情按需进入；默认端点使用已有连接，附加端点可增删编辑。删除前列影响范围，确认进入草稿后保留模型引用说明错误，撤销可恢复。缺少 / 多个端点、协议冲突或本机连接不完整时可继续编辑，保存说明具体模型与处理入口，不悄悄回退默认协议。

D-12 和保存差异列最终协议 / 来源、指定端点及端点变化；保存确认另列候选运行计划。逻辑渠道仍只有一行，完整选择器按逻辑渠道 / 内部模型顺序展开。当前 mock 用静态默认清单、连接完整性布尔和演示分组 ID；尚未实现附加端点 discovery、真实凭据身份分组、稳定绑定或实际请求。生产约束以 [专项方案](模型协议与端点方案.md) 为准。
