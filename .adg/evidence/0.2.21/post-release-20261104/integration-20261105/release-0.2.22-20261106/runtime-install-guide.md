### 维护运行包的安装与更新

1. 下载本页 opencodex-2.97.0-post021.ownerquery.2.tgz，在“安装 OpenCodex → 导入离线包”中核对完整版本并确认安装。
2. 安装后重启 OpenCodex 服务，使服务使用新运行包；再按需重启 Codex 客户端。
3. 管理器升级不自动替换已安装运行包。联网安装及“官方面板”更新继续使用 npm 上游；当前官方 2.97.0 会显示为比本维护修订更新，执行会换回未含本次补丁的上游包。在上游吸收修复前，请保留维护归档并继续用离线来源管理。

这是本项目维护的独立修订，不是上游正式发行。运行包、签名、SHA256及维护清单随本版本提供。
