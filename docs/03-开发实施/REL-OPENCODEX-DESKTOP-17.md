# 0.2.14 文件读写、连接测速与原型通知统一发布

2026-10-27，Asia/Shanghai。用户授权文档、开发、测试、真实测速与发布，范围沿 [IMP-23](IMP-OPENCODEX-DESKTOP-23.md) 和 [WP-75～WP-81](../04-项目资料/01-项目支撑资料/06-问题记录/0.2.13-bugs.md)。

## 交付

当前 config.json 是渠道事实源；内存编辑经已有保存预览确认后备份并原子写回，旧管理器草稿和计划不作为普通保存资格。已有 Key 在编辑器掩码加载、眼睛查看，Key 单独修改也可离线保存。清空输入保留原值，明确清空按钮才删除。只更新修改过的字段并保留其它渠道与未知配置。

测速和获取模型共用协议路径补齐及有限同源回退。保存后结果只出现在现有通知宿主，立即重启走官方独立接口；稍后即结束。通知入口、材质、字号和按钮沿 0.2.0 主原型，删除底部保存卡、额外收起入口和自创清理卡。

## 边界与回退

立即重启会结束活跃 Codex 对话，本轮没有在当前宿主强行执行；17 项官方接口受控测试证明调用与返回分类，不宣称设备重启已验。真实测速限于上述两个渠道，不能覆盖所有供应商、代理网络和凭据组合。Windows 与 macOS 的 CI/安装器结果不等于所有真机交互均已覆盖。

OS 代码签名 / Apple 公证仍未配置；自更新签名按既有发布公钥验证。保留精确写前备份及真实文件冲突保护。回退版本前先备份当前配置，不删除用户原文件或将历史计划重新作为当前数据；若需回退 stable，按既有发布流程显式晋升上一版本并验证更新通道。
