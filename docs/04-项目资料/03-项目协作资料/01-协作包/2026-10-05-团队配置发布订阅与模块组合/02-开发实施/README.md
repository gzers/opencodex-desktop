# 开发实施

状态：**未开始**。以下为后续 IMP 的工作包建议，不是已分派 TASK。实现产物进入 main 或 codex/* 特性分支，本包仅保存方案与证据引用。

| 工作包 | 交付内容 | 主要依赖 / 验证 |
|---|---|---|
| WP-01 格式与解析契约 | 来源身份、发布 / 模块版本、范围清单、依赖、内容摘要、兼容规则和样本 | G-01、G-03、G-04；先对齐 v0.2.0 生产契约 |
| WP-02 团队内容域 | 接入共用用户 / 团队 / 角色，新增源 ACL、不可变发布、轨道并发、订阅与内容下载授权 | 共用账户与团队基础；G-02、G-04 |
| WP-03 发布客户端 | 模块范围、依赖 / 许可 / 私密内容预览、提交与轨道结果 | WP-01、WP-02；部分提交、并发与幂等 |
| WP-04 订阅与组合解析 | 发现 / 地址添加、范围、固定 / 跟随、独立选源、候选与本地覆盖 | WP-01、WP-02；身份映射与冲突解释 |
| WP-05 模型体系适配 | 精确模版依赖、渠道绑定、源到本地映射、原保存链路、全局顺序与预算 | v0.2.0 模型适配；G-03、G-05 |
| WP-06 Skills 适配 | 完整包暂存 / 安装、目录所有权、版本与本地副本、依赖 / 执行提示 | 实际宿主能力；G-01、G-05 |
| WP-07 MCP 适配 | 描述与固定制品、本机变量 / 认证、安装 / 启动 / 授权 / 连通状态 | 实际 MCP 宿主与平台；G-01、G-05 |
| WP-08 共存、恢复与交付 | WebDAV 容器 / 过滤、旧客户端、账户切换、应用日志 / 读回、撤回与端到端 | WP-04～WP-07；G-06、G-07 |

先做 P0 垂直样例，再推进 P1。最小演示应包含两个团队、发布者与接收者、同一接收者两台设备，至少一份含三模块的组合，以及一个可单独换入的 Skills / MCP 来源。采用虚构模型端点和无需真实付费请求的测试目标；实际验证方式由实施契约限定。

不先搭公共市场、跨站同步或远程执行服务。若验证发现某宿主无法安全读回 / 恢复，调整该适配器的支持范围并回写待决策项，不绕过门槛把失败隐藏成成功。
