## 菜单原因：有 blur 声明，但采样被祖先限制

使用日常 0.1.8 EXE 的独立 sandbox 实例，在相同主题、档位、菜单尺寸和填充色下采集：菜单 `rgba(34,36,42,.56)`，`backdrop-filter: saturate(1.5) blur(8px)`；`.setting-row` 和 `.card` 祖先同样有 backdrop-filter，构成菜单的 backdrop root。菜单延伸到设置行之外时，下一行文字不在可采样范围内，因而清晰穿透。GPU 能创建 WebGL，实际 renderer 为 Intel UHD 770 / ANGLE D3D11，未见硬件不支持证据。

临时将同一个菜单移至 `.app-window`，保留位置、填充和 blur，下一行文字即变为模糊；只去除祖先 backdrop-filter 也有相同效果。三张原图与 `baseline/menu-controls.png` 保存上述对照。不能由“模糊计算样式存在”直接推定真正玻璃，也不能以原生 Mica 解释这次页面菜单问题。

修复将设置页 14 个下拉统一迁移到 `UiSelectMenu`，通过 Teleport 放在无滤镜主壳；保持原玻璃配方，按应用 CSS zoom 折算定位并限制视口，支持滚动重定位、方向键、Home/End、Tab、Escape、外部点击和焦点恢复。旧的“打开菜单时抬高原卡片”规则一并移除。

复验使用同菜单、同填充、同几何的黑白条纹：分别截图真实 blur 和仅关闭 blur 的像素，计算安静区域横向相邻像素差。高／中档须低于无 blur 的 35%，并要求无 blur 对照有足够条纹信号；低档须无 blur 且实底。测试条纹在独立实例中临时插入，结束后删除，真实菜单另存原图。

## 画质、静态光场、软边与恢复

- 唯一画质输入为用户 high／mid／low；移除管理器 JS、CSS、注入面板快捷浮层中的系统减少动态覆盖，无新动态开关。高档前台连续动画；中档保留玻璃与静态 WebGL/CSS 光场；低档实底、静态 Logo、无光场。系统条件用独立页面媒体模拟，不修改 Windows 的客户端动画设置。
- WebGL 的“可绘制光场”和“允许连续动画”分开；中档静态首帧、尺寸／主题／状态变化及前台恢复允许按需重绘，后台仍停止调度。能力失败的 CSS 回退和现有 DPR 1.6 上限保留。
- CSS 光团去除椭圆圆角硬裁剪，closest-side 渐变在 94% 处透明，容器追加横纵相交软遮罩；WebGL 保留 Gaussian 光团并补横向渐隐。未恢复逐层 filter blur，避免违反原性能约束。截图检查软边不等于全原型逐像素相等。
- 原生最小化恢复测试另发现旧前台信号失效：User32 确认窗口 visible、非 minimized、foreground HWND 匹配，但 Tauri 焦点和 `app_foreground` 仍 false，SVG/WebGL 持续暂停。只补用户三档不能解决此问题。Windows 改用实际前台根 HWND 与显隐／最小化查询，通过固定数量的 WinEvent hooks 更新同一个 `AppActivity`，不增加轮询。macOS 接线保持原路径。

## 环境与证据口径

系统 Windows Server 2025 x64 / 10.0.26100；PowerShell 7.6.5；WebView2 154.0.4258.62；Intel UHD Graphics 770 驱动 32.0.101.5972，ANGLE Direct3D11。设备报告刷新率 60Hz。保留 Parsec / Microsoft Remote Display Adapter 的存在，不把此环境当作不同物理显示器覆盖。

双权限以实际 token 验证，分别独立输出。100%／150%／200% 使用候选 sandbox 专用 `OPENCODEX_WINDOWS_SMOKE_SCALE=1|1.5|2`，通过显式 WebView2 浏览器参数生效并核对实际 DPR。**这是设备渲染比例模拟；没有更改桌面全局 DPI，不能声称完成 Windows 10/11、物理多显示器或显示器迁移验收。**

另采集 User32 的原生 DPI：采集进程 `GetDpiForSystem=96`，当时普通候选窗口 `GetDpiForWindow=192`。该值与 WebView 强制 DPR 分开保存于 `environment.json`，未把不同 DPI awareness 的系统查询值当作物理显示器缩放验收。

保留 Vue 挂载、Tauri 关于／发现／偏好／数据根命令、首屏截图与构建来源断言。画质以实际 SVG 内容改变、drawArrays 次数与 readPixels 非零光场像素核验；后台用真正的原生最小化／隐藏，恢复后检查高档推进与中档静态重绘。九态仅改变装饰组件输入，不伪造业务运行状态，也不安装／启动官方代理。

高档 WebGL/CSS 各稳定可见采样 30 秒，60Hz 的 B=16.667ms；沿用 p95≤2B、绘制脚本 p95≤B/2，>6B 长帧保留并分析。记录全部间隔、回调耗时与 LongTask。测试窗口的前台重获次数另记，未把后台样本当作高档性能通过。
