### UI-024: Tab栏粘滞背景淡入效果缺失

**优先级**: 中  
**状态**: 待修复  
**发现时间**: 2026-10-21

**问题描述**:
- 设置页面 (#settings) 和扩展页面 (#extensions) 等所有带 tab 栏的页面，tab 区域背景色始终不透明
- 应该实现：未滚动时完全透明玻璃效果，滚动到顶部固定时淡入不透明背景
- 原型本身也存在这个问题，需要同步修复原型和代码

**影响范围**:
- 设置分区 tab 栏
- 扩展分区 tab 栏
- 所有使用 sticky tab 布局的页面

**修复方案**:
1. 使用 Intersection Observer API 监测 tab 栏是否到达顶部
2. 添加 CSS transition，建议 200-300ms 淡入效果
3. 原型同步修复

### UI-023: 读取渠道后误报"未保存修改"

**优先级**: 中  
**状态**: 已分析  
**发现时间**: 2026-10-21

**问题描述**:
- 在渠道模型配置页面点击"读取现有渠道"后，立即显示"● 未保存修改"指示器
- 实际用户未进行任何修改，仅执行了读取操作

**根本原因**:
`sourceReadId` 使用时间戳生成，导致每次读取都生成新的ID，触发脏状态检测。

**修复方案**:
使用内容哈希而非时间戳作为 `sourceReadId`，确保相同内容生成相同ID。
