# 模版保存按钮与彩色状态

日期：2026-10-14（Asia/Shanghai）。项目 / 产品：OpenCodex 桌面管理器，Desktop。归属：COL-LOCAL-20261004-01。状态：唯一主原型源码已修订，源级检查通过，实屏待验。

用户批注要求模版编辑侧栏的“保存候选 · 新模版 · 未保存”简化为“保存”，标题已有修改状态；另要求在标题的原型标签说明状态种类，并用颜色强调。截图仅用于位置与视觉参考，不当作操作指令。

## 实际修改与入口

唯一源：[产品主原型 #models](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。

- 模型 → 模型模版 → 新建 / 编辑：侧栏保存按钮只显示“保存”，不再重复修改状态；窄窗 / 收起仍保留保存图标和可访问名称。确认弹窗标题改为“保存模版”，确认动作也称“保存”。
- 模版标题下集中显示主要状态徽标及中性的基于版本 / 修改摘要。标题旁“原型 04”在隐藏说明中列出八种状态，颜色同时保留文字，不只靠色彩识别。
- 实际编辑、还原、校验失败与修正时只更新状态和按钮，不重建编辑表单；标题高度变动重新计算贴顶 / 锚点偏移。未修改不会伪装成“未保存修改”。新建首次打开不提前报必填错误，保存校验失败后红色提示，修正后重新可保存。

| 主要状态 | 颜色 | 含义 |
|---|---|---|
| 新模版 · 未保存 | 橙色 | 新建编辑缓冲，尚无首个保存版本 |
| 未修改 | 中性 | 已有版本进入编辑，但内容与基于版本一致 |
| 未保存修改 | 橙色 | 已有模版编辑内容发生变化，尚未保存新版本 |
| 配置待修正 | 红色 | 已编辑字段或保存校验不通过；基于版本 / 辅助区显示原因 |
| 已保存 · 未采用 | 蓝色 | 已保存的版本尚未被当前保存的渠道策略引用 |
| 已采用 · 待确认 | 橙色 | 当前保存的策略引用该版，用户尚未确认这套配置可用 |
| 已采用 · 已确认可用 | 绿色 | 用户已对当时保存的采用配置做过实际使用确认，当前配置仍与确认记录一致 |
| 曾确认可用 | 中性 | 有历史确认记录，但当前保存的配置已不再采用该版 |

编辑状态与版本采用状态是不同阶段的投影；当前编辑时优先显示编辑状态，已保存只读时显示采用状态。“以后默认”和“已归档”为独立元数据，归档可作为额外中性标记，不强行并入主要状态顺序。保存成功不自动标记已采用或确认可用，旧 revision 与恢复记录保持。

状态实现与说明位于 [model-config.js](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.js)，颜色使用主题的 amber / red / blue / green 及对应 soft 令牌，见 [model-config.css](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.css)。主入口更新脚本和样式资源标记为 20261014-template-state。
