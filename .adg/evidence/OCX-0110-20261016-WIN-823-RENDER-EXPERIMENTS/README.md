# 823资源失败后的隔离渲染实验

四次隔离Edge154/Intel ANGLE D3D11实验分别覆盖4种几何、深浅主题及3个动画时刻，各24组。只研究可证伪的渲染路径，没有启动桌面产品、重做正式600秒测量或修改系统缩放。

顶部不可见行的裁切：原始着色器保留区RGBA完全相同，但直接CSS高度方案合成最大差5/255；整数盒加底边缩放方案仍在分数DPR合成出现5/255差异。相同源码A/A及同一画面的重复截图全部零差，不能把差异归因于随机截图噪声。两版裁切原型均撤回。

预乘透明方案：显式按原RGBA8量化再预乘，仍有1–2级原始字节差及最大2/255合成差。该方案同样撤回，没有把理论中间纹理开销当作实际GPU内存节省。

44份PNG引用按摘要去重为13个原件；独立验证器重新计算全部合成差和A/A控制。原失败源码留在忽略的运行目录，只归档与823的最小差异、摘要及诊断方法。整数盒原型的浏览器方法未另外逐字节保存，此范围在provenance中明确，不能冒充完整方法封存。
