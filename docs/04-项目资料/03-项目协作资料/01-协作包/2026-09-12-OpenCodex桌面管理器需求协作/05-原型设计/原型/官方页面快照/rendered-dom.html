更新 OpenCodex

检查所选渠道的 npm 版本，然后选择安装后是否重启代理。

子代理

控制所有模型的多代理界面。 v1：经典单线程代理。所有模型使用 v1 协作界面。 base：上游默认 — sol/terra 使用 v2，luna 使用 v1，其他模型跟随 Codex 功能开关。 v2：支持 spawn_agent 的多线程代理。所有模型使用 v2 协作界面。 在 v2 下，Keep ChatGPT on v1 会让 Sol/Terra 停留在 v1 界面，因此它们仍可调用 Grok 或 Claude。ChatGPT 会加密 v2 子任务；路由模型无法读取它们。路由父任务保持在 v2。 更改仅应用到新会话。
v1 / v2 是什么？

V2 超高强度推理限制

限制 V2 超高强度模式的推理强度。设置后，来自超高强度模式的请求会限制到所选级别。子代理限制只作用于派生的子代理。限制只会降低强度，不会提高。如果模型不支持所选级别，会降到最接近的支持级别。

Shadow Call 拦截

Codex App 会为会话标题、提交信息和 skill 编排生成后台辅助请求。辅助模型随客户端版本变化，因此 OpenCodex 会拦截此集合中的每个模型：gpt-5.6-luna。开启后可把这些请求重定向到你选择的模型。
