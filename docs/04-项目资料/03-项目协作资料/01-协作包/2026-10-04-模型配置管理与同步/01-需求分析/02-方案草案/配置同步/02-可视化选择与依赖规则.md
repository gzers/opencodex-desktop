# 可视化选择与依赖规则

## 页面与入口

一级“同步”菜单位于“拓展”之后、“诊断”之前；不归设置。两个主视图是“文件同步”（明确显示导入 / 导出）和“WebDAV 同步”。设置保留通用偏好、安装、备份、模型执行配置等原有职责。

模型页和模版页的导入导出统一跳转“同步 → 文件同步”，带入所选渠道或模版；详情没有勾选时带入当前对象，列表没有勾选时带入该类对象。用户能在统一页面继续调整范围。外部 Agent 任务 / 返回结果仍是制模协议，不当作通用配置同步文件。

概览的文件同步、WebDAV 快捷操作也进入相同流程。旧 settings?section=migration 与 settings?section=sync 路由分别重定向两个 Tab，不保留两套设置表单。

| 视图 / 浮层 | 主要内容 |
|---|---|
| 主视图 1：文件同步 | 范围树表、搜索、预设、凭据选择、导入 / 导出配置 |
| 主视图 2：WebDAV 同步 | 连接摘要、本机范围、凭据选择、保存范围 / 同步配置、结果 |
| 浮层 1：配置对象详情 | 来源、字段、模型明细、身份、精确版本依赖和凭据状态 |
| 浮层 2：导出确认 | 配置与凭据数量、加密口令、按需查看内容清单、结果；不重复展示主列表中的对象列表 |
| 浮层 3：导入预览 | 读取 / 解密、选择子集、身份映射、差异处理、应用结果 |
| 浮层 4：WebDAV 连接 | 地址、目录、账号与本机连接凭据、测试状态 |
| 浮层 5：同步差异 | 上传 / 下载、冲突 / 登录态版本、采用或跳过、分项结果 |
| 浮层 6：比较对象只读详情 | 第二层弹窗，按类别逐字段比较本机与来源，关闭返回原比较树 |

合计 2 个主视图 + 6 类浮层；读取、校验失败、确认与完成是浮层内状态，不另加侧栏页面。

导入首先选择配置文件，加密包才显示解密口令；未选文件或校验失败不能进入比较。产品弹窗只呈现选择文件、解密、比较与应用。原型样例包及测试口令属于窗口外工具：上部公共导航 / 外观 / 窗口设置，下部当前页面与当前 Tab 的 Mock，两部分共用一个滚动区域。切换样例不改变已选文件，重新选择文件后才采用新样例。

## 结构和选择

主列表采用“类别 → 配置对象”两层，文件同步和 WebDAV 的分组初始全部收起，可折叠、搜索、全选和部分选中。Skills、MCP 分为独立类别。类别复选框与展开按钮独立，折叠不改变范围或凭据。渠道下模型 / 字段 / 来源文件在详情按需展开，不默认铺开文件目录树。

两个 Tab 均取消已选范围摘要区域。清空选择位于搜索框旁；WebDAV 的保存本机范围位于顶部操作区，有范围修改时可用，保存后才能同步配置。同步页占满应用内容区，外部主内容区不滚动；配置对象表独立滚动，表头固定在表内顶边。凭据选项保持右侧，窄窗使用紧凑宽度，内容过长时在凭据区内滚动；长结果也限制在自身区域内。勾选或展开后保留内区滚动位置，两个 Tab 分别记忆展开状态和滚动位置。

四种预设：“全部配置”“分享配置 · 不含凭据”“换设备 · 含可转移凭据”“自定义范围”。全部配置中的已选账户默认包含可迁移登录状态；文件同步默认勾选 WebDAV 配置并携带密码，WebDAV Tab 不包含该类别。分享配置将账户设为仅账户信息、WebDAV 设为仅配置，关闭渠道 Key 与扩展凭据。换设备额外包含所选渠道 Key 与扩展凭据，仍需查看清单并加密确认；设备绑定账户显示“需重新登录”。自定义范围保留当前选择。

搜索时自动展开匹配类别，也允许手动收起；清除搜索后恢复普通展开状态。选择搜索结果只改变可见对象的勾选，隐藏选择保留并提示。取消分类勾选不会改其运行启用状态。取消 WebDAV 对象只停止本设备参与，既不删除远端，也不清除其他设备配置。

导入清单只展示包中实际存在的对象；不能勾选包没有携带的秘密或资源。文件出口和 WebDAV 各自记住范围，切换 Tab 不相互覆盖；WebDAV 持久范围明确属于当前设备。

## 依赖闭包

所选策略依赖精确模版 ID / revision / digest；自动补入所需版本，展示“依赖补齐”及原因。自动补入不等于整库全选，不连带模板其他版本，也不自动切换接收方主版本。

缺依赖、同 ID / revision 异内容或未解析协议端点要在预览阶段阻止对应应用。若允许单独导出依赖描述，包必须明确“不完整、接收方需补齐”；不能将其显示为可直接应用的完整包。

局部渠道 / 模型包不暗带全局 Fast、全渠道排序或其他族白名单；另选全局字段时预览全域影响。未选择项保留。依赖解析只补必要配置，不能越过“不带凭据”的选择。

勾选账户默认包含该账户可迁移的登录状态与刷新材料，列表显示“含登录状态”；右侧不再设置重复的账户登录状态开关。账户详情的“同步选项”默认收起，提供“仅同步账户信息，不含登录状态”。取消账户同步也取消其登录状态，重新勾选按默认处理；全选保留已选账户的明确排除选项。渠道 Key 与扩展凭据保留右侧独立开关和对象子集。分享预设关闭全部受保护部分，依赖补齐不能绕过排除选项。缺失、明确删除和掩码展示使用不同语义，不能把星号写回 Key。

文件同步的 WebDAV 配置详情提供默认收起的“同步选项”，可勾选“仅同步配置，不含密码”。取消对象会清理该选项，重选恢复默认带密码；分类 / 表头全选保留已选对象的明确排除。顶部凭据数量与导出加密要求包含连接密码。两个 Tab 删除页底原型演示说明；连接弹窗按钮使用“测试连接”“保存连接”。

## 导入与同步比较

文件导入与 WebDAV 共用“类别 → 对象”比较树，分类默认收起，分别统计新增、更新、删除。表头 / 分类 / 单项支持联动与半选；普通对象勾选即采用变化，不再增加保存候选或合并新增的选择。明确删除记录默认不选，包内缺失或范围未选不产生删除；精确版本依赖自动补齐。

每行右侧为查看详情与凭据规则。表头统一规则、分类规则、单项例外使用复选框并支持半选；未携带凭据不允许覆盖。渠道 Key 与 MCP 扩展凭据默认不覆盖，可迁移账户登录状态和 WebDAV 密码默认随已选对象采用，可改为仅账户信息或仅配置。同名异端点必须新建或重新绑定后再处理 Key；两端冲突需选择同步方向，未勾选冲突不拦截其他对象。

查看详情打开第二层只读弹窗，以本机和来源两列展示字段与差异。七类布局分别覆盖渠道与模型的连接 / 能力 / 顺序、模版版本与匹配、账户身份与登录有效性、Skill 内容与资源增删、MCP 定义与环境凭据、桌面偏好及本机字段排除、WebDAV 连接与导入状态。敏感值隐藏，关闭后保留父层勾选、规则、方向、口令和滚动位置。具体字段见[原型说明](../../05-原型/配置同步/README.md)。

WebDAV 使用“同步配置”按钮进入比较，再确认所选变化；点击按钮不直接应用。
