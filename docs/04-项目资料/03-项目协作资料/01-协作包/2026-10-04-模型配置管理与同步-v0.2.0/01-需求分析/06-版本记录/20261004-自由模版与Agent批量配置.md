## 本轮结果

模版本身定义用户创建的模型族，以自由名称和稳定 templateId 表示，不要求先选固定族。GPT / Claude / Gemini / Qwen / DeepSeek / Grok 是可复制起始例子。版本保存包含 / 排除规则、精确 / 前缀 / 通配匹配、大小写、多渠道范围及优先级；协议与匹配分开，五个通用协议及专用 registry 项都有说明。

编辑字段包括身份 / 说明、匹配、协议、上下文 / 输入模态、可选 / 默认推理、Fast 能力、高级请求策略及来源。匹配预览可查看命中、排除 / 范围 / 未命中原因和未选 / 停用 / 人工覆盖状态，不改变模型选择。只采用精确版本；未采用或仅设主不影响渠道，同最高优先级冲突阻止受影响保存。

自动填充在新建 / 编辑内完成：提示词 → 建议差异 → 接受 → 连续对话或手改 → 三方比较 / 锁定 → 保存候选；停止使晚回失效。独立“外部 Agent 配置”支持当前 / 勾选 / 全部 / 仅新建，提供文件职责、自包含提示词复制和多个新增 / 修订结果。整批先校验，逐项比较，再复核基准后全批保存候选，任一坏项不部分写入。

后续原型补齐“预览匹配 → 保存候选 → 只读版本 / 比较 / 设主 / 归档 / 依赖删除 → 直接多选渠道采用并保留例外 → 前往渠道模型 → 查看草稿 → 保存待重启”。这些动作有独立出口，不自动切主版本或写运行态。编辑缓冲导航保留，编辑中版本操作阻止默默换基准。
