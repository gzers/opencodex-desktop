# COL-LOCAL-20261005-02 团队配置发布订阅与模块组合

## 目的与状态

用户提出从个人 WebDAV / 导入导出扩展到团队共同维护、发布和订阅配置体系，要求作为下一版本方向建立独立协作包。本轮交付需求分析、候选架构、发布 / 接收流程和验收草案，供后续产品与技术评审。

授权范围为思考与建立协作材料。具体版本、实施和服务部署未指定；推荐默认值不记为用户已确认决策。产品中的“发布”是待设计功能，本轮没有向外部系统上传或发布任何配置。

## 参与人与角色

| 角色 | 责任 |
|---|---|
| Ezio / 需求提出人 | 提出团队共享、按模块订阅与本地保留目标；后续评审 |
| AI 协作 Agent | 对齐前序协作包、整理方案与约束、检查文档一致性 |
| 后续产品、客户端、服务端、测试评审者 | 冻结产品边界、验证适配与权限、建立实施契约；当前未分派 |

## 回写、关联与保留

稳定结论经确认后回写 DMD-OPENCODEX-DESKTOP-MANAGER 和项目核心的产品定义、能力地图、领域模型、数据与状态、系统架构、集成与安全边界，再建立 IMP。本包不是第二份事实源，不创建已执行 TASK、回执或验收证书。

两个前序包只补本包的关联入口。v0.2.0 仍承担个人模型管理；服务端包的用量采集不自动扩大为配置上传。未来共享原型继续维护单份主原型，本轮提供文字流程与结构图，未增加第二份应用原型。

原始输入和评审材料随包保留；替代方案注明被替代关系，关闭时保留权威回写与实施引用。机器检查结果放在 `.adg/evidence/TEAM-SUBSCRIPTIONS-20261005/`，不保存真实配置、密钥、会话或用户数据。所有本轮新增与编辑均属于 docs 分支的文档 / 治理产物。
