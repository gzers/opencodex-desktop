控制说明What each control does

顶栏是评审用控制器：全部只切换本页的观察条件，不写配置、不影响其他原型页。生产里只有「主题」与「特效档」会作为真实设置暴露，其余仅用于评审玻璃配方。

主题
亮 / 暗两套令牌，用来验证同一块玻璃在两种底色下的填充、描边与文字对比度。
特效档
全局开关。高＝动态光场＋玻璃（默认）；中＝光场静止＋玻璃（省电，等价系统「减少动态效果」）；低＝无光场＋无玻璃，退回应用原本黑白实底。
背衬
玻璃后面的衬托物。光效＝纯色底＋概览页那套动态光场；素底＝纯色；彩底＝高饱和渐变，用来压测极端底色。
滤镜
玻璃上的双色滤镜。冷色＝通知默认之外的冷色调；无色＝中性（当前基准）。
强调色
主按钮与强调标签的取色：品牌＝品牌紫蓝；中性＝黑白（当前基准）。
强调质感
强调件的玻璃配方：磨砂／清透／烟熏。只改强调件，不影响普通卡片。
强调浓度
强调玻璃的填充浓度。越低越透明；低于约 55% 时白字可能达不到 AA 对比度，读数会转黄提醒。
材质
整体表面档：轻磨砂（默认）／纯透明（无模糊）／实底（退回不透明面板）。

特效档Effects · 高 / 中 / 低

一个旋钮三档，只动两个杠杆：光场动不动 与 是不是玻璃。第三档「低」＝关掉特效，退回应用原本的黑白实底风格。用顶栏「高 / 中 / 低」实时切换。

高 · 默认

会动的光场 + 玻璃。

  • 光场：三团光公转 + 自旋 + 涨缩（动）
  • 表面：磨砂玻璃（半透明 + 模糊 + 1px 描边 + 投影）
  • 通知：玻璃
  • 定位：完整观感

中

光场静止 + 玻璃。

  • 光场：仍在、仍是柔光底，但不再动
  • 表面：与「高」完全一致（仍是玻璃）
  • 通知：玻璃
  • 定位：省电 / 系统「减少动态效果」；观感几乎不变，只是不晃

低 · 关特效

无光场 + 无玻璃。

  • 光场：完全没有，背景就是纯色底
  • 表面：全部实底（卡片白 / 按钮黑底白字；无模糊、无半透明、无双色滤镜）
  • 通知：实底
  • 定位：退回应用原本黑白实底风格；开销最低

两句话记牢：高 → 中 只去掉「动」，其它一模一样；中 → 低 去掉「光场」和「玻璃」两样，回到实底。
