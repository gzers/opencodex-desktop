| 项目 | 结论与状态 |
|---|---|
| 补入版本与资料组织 | 用户同意纳入当前 v0.2.0 协作包，按配置同步专题分文件夹 |
| 模型范围 | 用户澄清仅 OpenCodex；包含本次模型模版 / 策略及已有原生渠道 / 模型 |
| 账户范围 | 用户要求真实登录状态，另一设备导入 / 同步后免登录；可移植性逐类验证 |
| 选择范围 | 文件导入导出与 WebDAV 共用可视化范围，支持全部或子集 |
| 不带 Key | 用户明确要求；渠道 Key 另选；账户登录态随账户默认包含，账户详情可选仅账户信息 |
| 导航 | 用户明确独立“同步”一级菜单、两个 Tab，不放设置；原模型 / 模版入口统一 |
| 原型授权 | 用户同意补绘；允许更新共享主原型和本协作包，无真实配置写入授权 |
| 具体名称与布局 | “文件同步 / WebDAV 同步”、浅层树表、2 主视图 + 5 浮层为本轮可评审设计 |
| 账户交互确认 | 用户确认勾选账户默认包含可迁移登录状态，移除重复开关；详情保留仅账户信息，导入 / WebDAV 自动恢复并检查，设备绑定与失效提示需重新登录 |
| WebDAV 配置确认 | 用户要求顶层名称为“WebDAV 配置”、文件同步默认勾选且携带密码；详情可选仅配置，分享预设排除密码，导入后连接待启用 |
| 文案精简确认 | 用户要求连接按钮去掉“演示”，删除文件同步与 WebDAV 同步页底原型说明；按钮使用“测试连接”“保存连接” |
| 实施状态 | 未实施生产同步、加密或账户适配；不能用静态原型结果替代功能验收 |
