## 用户提供的渠道说明摘录

以下来自用户粘贴的 Krill 说明，属于渠道宣称。未提供该说明的独立页面 URL；本包没有将其标为已独立核实的渠道原站材料，也没有完整复制安装教程。

- 宣称已适配 Codex `0.163-alpha.11` 以上的后台上下文压缩，相关请求在渠道请求日志中单独标为“后台压缩”。
- 开启配置为 `[features]` 下的 `async_compaction = true`。
- 基础配置使用内置 `openai` provider，并设置以下地址：

```toml
model = "gpt-6.1-sol"
model_provider = "openai"
openai_base_url = "https://api.krill-code.net/backend-api/codex"
chatgpt_base_url = "https://api.krill-code.net/backend-api/"
web_search = "live"
suppress_unstable_features_warning = true

[features]
fast_mode = true
context_management = true

[features.token_budget]
enabled = true
use_history_notes_extension = true

[analytics]
enabled = false
```

- 宣称 `auth.json` 的 `personal_access_token` 与 `OPENAI_API_KEY` 应填同一个渠道 API Key，不添加 `auth_mode` 等字段；另要求 `CODEX_AUTHAPI_BASE_URL` 指向 `https://api.krill-code.net`。本包仅保留字段和非秘密地址，不保存实际凭据。
- 宣称 CLI 可以通过 `/fast`、`/ultrafast` 切换；桌面端可以从模型面板的闪电入口选择档位。默认 Fast 使用 `service_tier = "priority"`，默认 Ultrafast 使用 `service_tier = "ultrafast"`。
- 宣称模型列表自动同步；给出 `0.159.0` 的 Ultrafast 和 `0.160` 的账号校验版本门槛；加速档按渠道更高倍率计费。

这些地址是渠道直连示例，不是本项目已确认的接入配置。用户后续明确要求继续通过代理使用多渠道。
