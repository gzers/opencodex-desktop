# Mac 打包应用正常启停预算

使用 IMP223 至 IMP225 已绑定的 ARM64 Release 应用和原样官方 OpenCodex 2.99.0。隔离环境完成供应后，从单次点击「启动 OpenCodex」前到界面显示「运行中」及「启动已完成」，观测上界为 **6,963.669 ms**，预算 30,000 ms。Ready rev4、启动回执、运行记录及本地监听对应同一 PID 67448 和端口 56524。

单次正常 Stop 为 **5,536 ms**，预算 10,000 ms。界面显示「停止已完成」，同一票据进入 root_absent rev9，完成摘要与归还读回一致。独立进程和端口查询确认退出。随后退出隔离管理器，独立检查测试目录及三份自有协调文件均已清理。非回环请求被拒，测试使用合成配置。

原始探针的通用标题沿用取消测试名称。本次实际入口为 stop-progress，仅覆盖正常启停。探针生成和模拟 PID 预检各有一次本机失误，均发生在本次实际服务启动前。原始结果留在本机，仓库回执只保留核验字段及摘要。此次 Mac 定向验证通过，整版 `accepted:false`。
