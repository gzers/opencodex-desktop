## 数据与兼容边界

- 快照是已保存内容而非传输时间。无远端用本机；有共同同步基线时按内容变化判断；双侧变化不能以设备时钟强行胜出，使用远端已提交版本序列作确定性基准并在预览说明，保存后收敛；相同内容不传输。模版历史追加，当前采用引用随所选对象，不删除整对象。算法决策和反例写入回执，尚未实现前不可报完成。
- 旧all_*仅在加载旧范围时按当前可用目录物化为具体IDs；新对象不由历史隐藏all值自动加入，node_repl默认排除。
- “更新前备份”控制可供用户恢复的本次范围快照；事务临时回滚材料是内部补偿，不能伪称用户备份。未选范围与本机身份/活动连接保留；凭据不按同名跨对象绑定。
- 普通保存快照直接更新已保存文件；明确source=draft的候选包兼容独立保留，不作为普通流程。旧已完成计划只读恢复，重试必须绑定同一源摘要和原操作。
