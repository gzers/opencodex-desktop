# 前端测试恢复与界面回退修正

日期：2026-11-22。代码：main 6dd13ccd6。

## 问题

范围收缩时清理前端测试采取了一刀切：232 个 UI 测试文件被删除，其中只有一部分真正依赖已移除的模型编辑与客户端恢复模块。其余属于设置、通知、诊断、扩展、版本与主题等领域，删除后让这些领域失去回归覆盖。

同一轮改动里还有三处连带回退：

- 设置页「用户目录与程序安装」的路径区依赖只读查询 model_paths_v2_snapshot，命令被删后该区域永远显示「尚未读取」。
- 端口设置保存成功后不再通知设置页刷新路径，路径状态停留在保存前。
- 模型相关通知动作在通知中心没有按钮文案，也没有跳转去向。

## 修正

测试：从基线 cfb3c8aa7 恢复全部 232 个文件，按真实运行结果分类，最终只移除确实引用已删模块的用例。恢复后为 142 个文件、892 项检查。

界面：

- 恢复 model_paths_v2_snapshot 只读投影并重新注册，不包含任何写路径。
- 端口设置恢复 saved 事件，设置页据此刷新路径。
- 模型通知动作文案改为「在 OpenCodex 中管理」，确认后进入模型页的官方入口。
- 组件登记表移除指向已删组件的引用，概览卡断言改为「打开同步」与不含「检测版本」。
