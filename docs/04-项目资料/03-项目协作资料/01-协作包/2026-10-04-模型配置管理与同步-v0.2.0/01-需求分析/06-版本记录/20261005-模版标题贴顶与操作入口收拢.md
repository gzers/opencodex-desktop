## 当前可走查行为

进入[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html)的“模型 → 模型模版 → 新建 / 编辑”：

- 返回图标、名称、候选摘要与版本操作合为标题；名称在标题直接编辑，基本信息只保留说明。只读标题点击后进入新候选，再修改名称；保存 / 取消 / 返回继续沿用原缓冲与版本语义。
- Tab 滚过后标题固定于主内容区顶边。读取主内容上内边距并补偿固定位置，消除固定后仍保留的 20 px 初始上留白；导航与锚点使用实测标题高度及内容区边框，标题换行 / 窗口变化后重新计算。真实 sticky 效果仍待浏览器验收。
- 左侧导航下独立按钮区依次为 Agent 自动填充 / 匹配预览 / 与主版本比较 / 更多操作 / 设置，收起保留图标、tooltip 和可读标签。设置打开原模型配置页，缺主版本比较仍解释原因；页底取消 / 保存候选保持。
- 编辑页顶部不重复设置 / 更多，也不显示 Agent 条或右下启动器；列表 / 渠道原工具入口保持。左侧首个 Agent 文字按钮打开非模态助手，收起后焦点尝试返回该按钮。
- 助手的实际执行模型、聊天 / 建议、紧凑资料 / 输入发送和放大 / 还原 / 收起保持；浮动模式正文可操作。尺寸切换及异步重绘继续保留输入 / caret、聊天 / 正文位置与按模版隔离的目标。

名称修改只改候选缓冲；保存只新增候选，不自动更改主版本、渠道引用或运行配置。右侧五区连续展示，导航只滚动定位；位置 / 缓冲保留、范围与最长后缀继承保持。

## 实现与验证

[共享 model-config.js](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.js)合并标题与名称绑定，收拢入口，计算标题 / 导航 / 锚点偏移；[共享 model-config.css](../../../../../01-项目支撑资料/01-产品原型/原型/model-config.css)提供 sticky 标题、窄窗换行、可用高度内的导航以及面板默认尺寸约束。[模版工作流检查](../05-原型/qa/template-workflow.source.mjs)新增六项：

1. 唯一左侧首位 Agent 入口、收起 / 重开输入保留、展开语义及焦点调用。
2. 设置移至左侧且目标正确，列表 / 渠道原入口可用。
3. 唯一标题名称输入、只改缓冲、返回继续和取消不入库。
4. 只读标题进入并选中候选名称、空名拒绝，保存不改变主版本 / 引用。
5. 标题实际高度、窗口高度、导航可用高度和锚点 / 高亮同步，减弱动效保持。
6. 主内容上内边距 / 边框在只读与编辑详情均参与贴顶及导航 / 锚点计算，resize 后保持缓冲。
