# 用户更新的 Windows 本机验收条件

2026-11-05，用户明确：“下一步是是什么，考虑本机硬件限制问题，你不能严格卡修复通过问题。”随后要求“那么继续”。本线据此采用硬件条件下的功能交付：本机共享UHD770/RDP绝对p95≤33.33ms与over6B=0不再作为本次Windows贡献回交的硬阻断；原指标保留参考，已采failed原件与数值不改写为passed，不宣称60fps或已做生产性能优化。

例外只适用于该环境的绝对性能门。高/中真实玻璃、低档/无法模糊可读实底、字号布局、焦点/退出、前后台停绘恢复、准确构建身份和真实重启结论继续按功能要求验证。正式重启的进程探针超时是功能故障，不在硬件帧率例外内；不会把未重启写成通过。其它用户程序、日常15119配置、同步业务、发行合并边界保持。

旧TASK及旧RCP按其冻结原预算保持历史failed，不再拿旧failed作为当前本机硬件条件下交付的硬阻断。新TASK明确关联这份用户决定承接后续收口，最终DMD/IMP/问题清单和发布由本机集成者按用户新条件统一回写，不在贡献分支改共享事实。
