# P0 原型设计包

## 定位

本包用于验证 `DMD-OPENCODEX-DESKTOP-MANAGER` revision 2 的 P0 交互方向。原型只表达界面结构、状态流转和文案边界，不进入实施代码。

## 约束

- 只使用 mock 数据。
- 不调用真实 `ocx`。
- 不读取真实 OpenCodex 配置。
- 不触发真实启停、restore、备份或文件选择。
- 原型中的真实页面是官方 GUI 渲染后的源码级快照：保留真实 DOM、CSS、文案与层级，用于视觉对照；不请求运行态 API，不构成生产嵌入方案。
- 不记录、展示或同步任何真实凭据。
- 稳定交互结论后续进入 IMP 输入；本包不替代 DMD。
- 视觉与颜色体系向 OpenCodex 官方面板对齐，避免嵌入面板后割裂；OpenCodex 品牌色只做轻量识别。
- 根入口为 `原型/index.html`，使用 hash 路由串联页面；原型按 1180 × 760 macOS 应用窗口表达。官方面板视图采用方案 B：保留标题栏与 64px 图标栏，官方中文页面快照占满剩余内容区，仅保留最小悬浮操作。概览集中提供配置迁移、WebDAV 同步和版本升级的常用动作；通用偏好、备份策略、迁移参数、同步端点与升级策略统一放入「设置」路由。
- 概览已定稿为 **B+ 合并版**：一行运行摘要 + 页内折叠的「运行详情」+ 压缩快捷动作卡；进程按钮按状态渲染。方案对比过程与实测见 `文档/design-qa.md`，对比期截图归档在 `文档/截图/归档-20260913/概览方案/`。
- 概览「模块区」（**版本升级 / 配置迁移 / WebDAV 同步**，按此从左到右排列）已**定稿为唯一配置**：顶部一行三格（整行不换行），每格两行状态 + 右上角「更多」省略号进入对应设置分区；动作区以**页脚分隔线**沉底，两颗真实动作按钮**等宽双列**铺满。原型说明区不再提供布局/按钮方案切换。
- 亮暗色只有**一份取值** `ocx-theme`（`light` / `dark` / `system`）：外壳与内嵌官方面板都由它派生，面板不保存自己的主题。切主题时通过 `postMessage` 实时同步到面板 iframe，无需重载。
- **应用界面里不出现阶段编号**（P0 / P1 / P2）：设置分区标签、模块卡标签、设置面板标题都只用功能名与状态（「规划中 / 可用」）；阶段信息只保留在原型注译区与文档里。
- WebDAV 卡按**配置/连接状态**渲染：未配置时不置灰，只把动作区换成一颗「配置 WebDAV」直达设置；其余状态（未连接 / 同步中 / 已同步 / 连接失败 / 冲突）在原型注译区可切换预览。
- **两个版本对象分开**：概览「版本升级」卡与设置第一块 = OpenCodex 本体（`v2.50.0`，官方 `ocx update` 引导）；设置第二块 = 桌面管理器自身（`v0.1.0`，应用自更新）。套壳更新在外部**只走通知中心**，不新增概览卡片。
- 通知支持**点开详情弹窗**（正文 + 时间/级别 + 可执行动作「前往处理」）与**单条删除**；通知中心与「诊断中心 → 通知历史」共用同一份数据，任一处改动同步。
- 应用窗口按 **1180 × 760**（标准 macOS 应用窗口，同类 Tauri 桌面端默认区间）表达，最小 900 × 600。
- 视觉基准优先使用官方 GUI 构建产物中的设计 token 与源码级快照；截图仅作为视觉 QA 证据，不用作样式来源。
- 页面背景套用**官方面板的环境光渐变**：`.window::before` 用三层柔光 radial-gradient（取自官方 `body:before`）叠在 `--bg` 之上、内容之下；亮暗各一套（`--glow-1/2/3`）。挂在非滚动的 `.window` 上，内容滚动时背景不动。

## 目录结构

包内只分两类，资源跟着引用它的页面走，不设全局 assets：

```text
05-原型设计/
├── README.md                      本包索引
├── 原型/                           一类：所有 HTML 及其运行资源（整袋搬，内部相对路径不变）
│   ├── index.html                 可交互原型入口
│   ├── 官方面板布局对比.html        官方面板布局方案对比（历史决策记录）
│   └── 官方页面快照/               官方源码级快照 + 官方 CSS（被 index.html 加载）
└── 文档/                           二类：说明、调研、基准、QA 记录与截图证据
    ├── state-and-flows.md
    ├── design-qa.md
    ├── design-tokens.md
    ├── 同类产品调研-2026-09-12.md
    └── 截图/
        ├── 官方/                   官方快照的 light / dark 渲染截图
        ├── 现行/                   原型当前 QA 证据
        ├── 对比-20260913/           最近一轮方案对比（模块区 / 按钮摆放 / WebDAV 状态）
        └── 归档-20260913/概览方案/   已退役的概览方案对比
```

约定：
- 要打开演示的页面放 `原型/`；说明、调研与证据放 `文档/`。
- 新增素材一律跟着引用它的页面走（同目录或其下的 `assets/`）。
- 第三方 / 官方素材进 `原型/` 时**保持其内部相对结构不变**，这样搬目录不需要改素材内部引用。

## 产物

| 产物 | 用途 |
|---|---|
| `原型/index.html` | 可交互 P0 原型根入口；hash 路由串连概览、官方面板、安装与数据根、日志和设置 |
| `原型/官方页面快照/` | 官方 GUI 渲染后的源码级快照与官方 CSS（被 index.html 加载） |
| `原型/官方面板布局对比.html` | 官方面板布局方案对比（历史决策记录，已选定方案 B） |
| `文档/state-and-flows.md` | 状态机、场景与交互说明 |
| `文档/design-qa.md` | 设计 QA 与待确认项 |
| `文档/design-tokens.md` | 从官方 GUI 构建产物提取的 P0 对照 token |
| `文档/同类产品调研-2026-09-12.md` | 同类桌面管理器调研：窗口基准、状态驱动按钮、卡片密度分级等可借鉴做法 |
| `文档/截图/` | 原型 QA 证据（`现行/`、`对比-20260913/`、`归档-20260913/`）与官方对照截图（`官方/`） |

## 覆盖范围

- OpenCodex 发现与安装状态。
- 统一数据根与 `OPENCODEX_HOME`。
- 启动、停止、重启。
- 健康、at-risk、外部 provider 接管、不可达、启动失败。
- 最近错误摘要。
- 日志查看与全幅官方面板视图。
- 运行环境诊断：官方 `ocx doctor` 的只读摘要，位于「诊断中心」，不从概览动作行触发。
- macOS 原生菜单结构示意。
- 管理器产物分区展示。

## 非目标

- 不完成 P1 配置迁移的最终交互。
- 不完成 P2 WebDAV 的最终交互。
- 设置页仅表达参数与边界，不保存真实偏好或凭据。
- 不冻结 Rust 接口、状态字段名或真实目录名。
