# 能力地图

## 范围原则

- **原型中出现的全部功能都在实现范围内**，不做功能取舍。
- `P0` / `P1` / `P2` 与「可选」只表示**实现与交付顺序及前置依赖**，不表示"可以不做"。
- 顺序依据：**P0** 运行管理主线 → **P1** 需要安全评审的能力（配置迁移、扩展管理、CLI 控制面）→ **P2** WebDAV 同步。安全评审未完成不阻塞立项，但阻塞对应能力的实现。

## 能力域明细

### 1. 安装发现

- 依次检查 `node` → `npm` → `ocx`，前一项未通过时不继续；缺失时给出当前状态与最短可复制命令。
- 展示安装路径、版本与可执行校验结果。
- **不执行** npm 安装、卸载或依赖管理；用户安装后由本人手动触发重新检查。

### 2. 数据目录

- 用户可选择或切换 `OPENCODEX_HOME`；管理器自身产物保存在可自定义的数据根中按结构划分。
- 切换采用**引用优先、迁移可选**：默认引用已有位置、不搬动数据；仅在显式选择「迁移」时执行移动。
- 迁移前强制备份；目标不可写、空间不足或数据结构异常在**检查阶段**即阻断；迁移中断或校验失败自动回滚并保留原数据目录。

### 3. 运行托管

- 直接托管官方启停子进程；不安装或管理 launchd，不接管 `codex-shim`。
- 展示健康状态、端口、进程标识与最近错误摘要。
- 动作按状态渲染，不做无解释的禁用按钮；用状态说明文字传达原因。

### 4. 观测

- 日志只读、脱敏；提供打开日志文件或目录的能力；代理离线时明确说明实时日志不可用。
- 运行环境诊断展示官方 `ocx doctor` 的**只读**摘要，不提供写入型修复参数。
- 官方 Web 面板以源码级快照视图承载，保留标题栏与图标栏，只承载官方 GUI，不重绘内部、不注入控件。
- 通知中心与通知历史共用同一份数据；支持详情弹窗与单条删除。

### 5. 风险识别

- 识别外部 provider 接管与 startup at-risk，解释影响，不直接改写外部配置。
- `restore` 一律走官方路径，需用户显式确认，并展示前置备份、执行中、结果与恢复建议。

### 6. 配置迁移

- 导出为全量内容（含敏感内容），必须进入**口令保护的加密容器**。
- 导入前完成格式、版本与完整性校验；自动备份当前配置；展示掩码摘要；显式确认后写入；失败不部分写入并回滚。

### 7. WebDAV 同步

- 同步全量内容，上传前**客户端加密**。
- 采用冷同步；覆盖前生成可恢复备份；冲突先入待处理，不静默覆盖。
- 与官方 `ocx connect` remote hub 是并列能力：不自建 hub、不替代官方 hub，只同步用户指定的端点。

### 8. 官方升级

- 升级前必须生成备份；备份失败则阻断升级引导。
- 可检测版本偏差并引导官方 `ocx update`；展示成功、失败、备份位置与恢复建议。

### 9. 应用自更新

- 桌面管理器可检查并更新自身，区分 `stable` / `beta` 通道；签名校验通过后才安装；重启应用生效。
- 重启**不得停止**由桌面壳托管的 OpenCodex 代理；重启后重新接管并恢复状态展示。
- 失败保留可回滚的上一版本；检查结果以非阻塞通知呈现。
- 与官方 `ocx update` 是两条独立通道，界面与文案必须让用户分清当前更新的是哪一个对象。

### 10. CLI 控制面

- 默认关闭；启用后注册 `ocxd` 入口，并明确提示开放的能力范围。
- 是**运行中实例的客户端**，经本机 IPC 委托执行，不产生第二写入者；实例未运行时只读命令降级说明、变更类命令报错。
- 能力限定在管理器自有域：发现与只读状态、启停、数据根、备份、加密导出/导入、WebDAV 同步、自更新检查。
- 变更层命令需实例在线与显式确认；破坏性操作需确认标志；提供 `--json` 机读输出。

### 11. 扩展管理

- Skills：发现、导入、更新、卸载、恢复；仓库与路径管理。
- MCP：导入、新增、编辑、删除；JSON 配置、向导与校验。
- 多客户端分发：同一份定义投影到多个客户端。
- 写入范围、并发与冲突规则见 `集成与安全边界.md`。

### 12. 托盘与菜单

- 托盘菜单动作限定在管理器自有域，并用图标与颜色表达运行状态；系统托盘默认仅显示图标。
- macOS 原生菜单提供进程、视图与日志入口；应用退出后不残留。

### 13. 关于与归属

- 「关于」区域区分官方项目 / 本应用 / 许可、归属与免责声明三部分。
- 提供官方许可与第三方声明的查阅入口，并说明两套许可彼此独立。
