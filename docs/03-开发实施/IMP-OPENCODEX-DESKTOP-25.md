## 实施合同

1. 文件服务明确当前渠道范围，沿原写锁/备份/原子路径，以真实文件与已存布局合并本渠道。全局请求保持兼容，当前请求不写其它渠道、全局排序/采用或未提交布局；预算按实际候选核验。导入授权仍只在显式文件保存时投影。
2. store 提供按渠道脏判定、候选与保存接收，避免全量 acceptTransfer 清空其它草稿。更新实际文件摘要同时保留其他 Key、型号、模版缓冲与导入意图，保护晚回和保存期间后续输入。
3. 详情不再打开完整保存预览，成功返回列表，失败原地保留。列表保留完整预览与统一剩余修改保存；全局还原不撤销已完成局部保存。历史恢复仍显式独立。
4. 移除连接局部确认/还原及重复状态，保留模型获取和节点检测。Key 意图在读取失败/重开/保存其它渠道时保留，显示与请求授权仍分开。
5. 两处无修改保存禁用并有处理器守卫；状态范围与规范化差异一致。沿既有原型通知及材质，实际对照共享依赖、亮暗/特效/窄窗，不把本机原型漏载 CSS 当软件同根故障。
