## 产生与消费

新建 .runtime-image.json 增加必需 treeSha256。固定离线供应在版本目录组装后生成，联网/离线安装候选在原官方包和本地依赖核验后生成。current的imageSha256仍绑定该镜像清单，清单中的treeSha256则绑定该版本目录完整内容。该摘要证明已准入镜像的本地漂移情况，不是上游签名，也不允许仅凭一个自行生成的清单接管任意目录。

program_image::content_digest(version_root) 返回完整目录摘要；program_image::verify(SelectedProgram) 与已绑定的镜像treeSha256及清单imageSha256比较。安装动作先核对当前完整镜像，激活和显式恢复也分别核对原/候选镜像。它们是动作边界，普通program_selection::read_image继续核对关键程序，verify_current继续做小型新鲜度检查，不把整树扫描放入高频运行状态或端口查询。

新字段无默认/自动补写：旧开发镜像缺少它时保持不可确认；不扫旧版目录、不计算新摘要后接管旧安装，不开发迁移分支。程序/用户数据根及固定资源摘要保持原合同。

## 文件树规则

- 相对路径排序后编码，包含普通文件内容摘要、大小及Unix可执行标记，包含空目录。Windows无Unix执行位时固定false，不伪造权限证明。
- 仅排除根 .runtime-image.json 避免自引用；它另以imageSha256及普通单链接文件检查绑定。同名嵌套文件是普通内容，不能被排除。
- 有界读取：100000条目、深度64、单文件512MiB、总原字节2GiB。用流式摘要，稀疏超大文件在读取正文之前拒绝；目录遍历期间和文件读取期间检查可观察变化，异常即拒绝。
- 不跟随未知软链接、重解析点或多硬链接文件，不静默跳过不可读条目。新增普通文件或空目录、内容/执行位变化、清单漂移均拒绝，原目录保持。
- 固定Node资源内npm/npx是清单已核验的文件别名。版本供应在落位前按descriptor的最终普通文件目标实体化，核对原链接文本、输出大小/模式/摘要，再替换本次新建链接。归档/descriptor不变，未知链接不因此获例外；包含额外npm副本和别名实体化后的合计体积也不能越过2GiB。
