## 采集行为

`windows-idle-family.ps1`保留真实进程句柄，按PID和创建代际识别成员；退出成员CPU继续计入，退出后不计活跃RSS。父进程的存活区间限定后代关系，避免数字PID被复用后把新无关进程当成旧成员。只对已知父族行要求创建时间，不读取无关系统行中不可用的创建字段。

读取或代际校验失败立即使观察失效，保存阶段、PID/父PID、预期/实际创建时间、异常类型与HRESULT及基础异常类型/码；不保存完整命令、原始异常消息或无关进程详情。证据写入失败同样拒绝继续。此规则保留原零读取失败准入，不通过忽略短命进程、推测其CPU很少或放宽精度来换取通过。

`windows-idle-observe.ps1`是只读附着入口，核对显式source/EXE摘要、实际普通令牌和进程代际、sky准备态、至少60真实秒稳定期、窗口归属与2360×1520客户区。每次读数前后核对前台/可见/最小化，实例数必须为1；失败立即停止采样，保留实例等待绑定的正常关闭，不激活窗口、不强杀、不自行重试。完整跨度仍为首末已完成计数≥600秒，CPU单位与进程族RSS相加口径保持。

所有结束路径及时写terminal与相同终态progress；名义完成标志不能覆盖读取失败或不足600秒。入口不启动产品、改根/偏好、操作计时器或宣布性能预算通过。该模块仍不保证捕获1秒快照之间所有短命进程，RSS仍未去重共享页，这些限制没有删除。
