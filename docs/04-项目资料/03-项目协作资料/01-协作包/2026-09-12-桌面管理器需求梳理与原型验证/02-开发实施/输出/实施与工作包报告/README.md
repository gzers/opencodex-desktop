# 实施与工作包报告

## 定位

面向开发实施评审的**单页 HTML 报告**：一个长页，左侧固定目录负责章节跳转，滚动时自动高亮当前位置。

- 派生产物，**不作为事实源**；有冲突时以 DMD `revision 3`、`docs/02-项目核心` 与 `IMP-OPENCODEX-DESKTOP-01` 为准。
- 不构成开工授权；`IMP-OPENCODEX-DESKTOP-01` 仍待用户确认。

## 生成方式

```bash
cd 02-开发实施/输出/实施与工作包报告
python3 build.py
```

- 正文改 `实施与工作包报告.md`，不要手改 `index.html`。
- `index.html` 与 `assets/report-metadata.json` 都是构建产物。
- 样式复用需求分析报告的参考方案：`shared-style.css` + `side-nav.css` / `side-nav.js`。
- 报告编号：`RPT-LOCAL-20260914-02`。
