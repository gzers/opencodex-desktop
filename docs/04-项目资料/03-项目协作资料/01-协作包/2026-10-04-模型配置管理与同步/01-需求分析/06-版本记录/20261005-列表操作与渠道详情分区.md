- 增加全部展开当前显示项 / 收起当前渠道及七种快捷排序：名称升降、别名升序、协议分组、上下文大 / 小、启用优先。任一搜索 / 族 / 仅启用过滤开启时禁排序；未知上下文排末、同值稳定，保留勾选 / 展开 / 缓冲，顺序进入草稿可撤销，Fast 仍跟父项。
- 渠道标题把返回图标、名称 / 状态和切换器合成一行；滚至顶部后固定并补偿内容区上内边距。导航和锚点按标题实际高度避让。

- 左侧下方放获取清单、预览选择器、更多、设置，再集中全渠道已写入 / 未保存 / 待确认状态、激活数、查看草稿、保存和撤销 / 重做 / 丢弃 / 待重启核对，正文不重复放保存条或预览。
- 模型单元格垂直居中，身份可换行；摘要分协议 / 上下文、推理 / Fast 两组多行。连接与展开字段在窄内容下转单列。

## 连接编辑与保存保护

已有自定义渠道的连接表单直接展示，按渠道缓存名称、协议、地址、认证、密钥配置布尔和替换意图。返回列表、切换渠道、重绘和取消模型确认保留缓冲；字段输入即时更新还原入口与待确认提示。未确认连接或模型行阻止页面保存，侧栏可定位处理。

“确认连接与模型”先校验再复用既有模型选择向导，冻结连接和策略基准，确认才进入草稿；过期确认拒绝。只改名称保留清单 / 选择；地址、协议、认证或密钥替换意图改变使旧清单失效，重新获取或手动添加 ID。已有未确认模型行须先处理再调整连接，原生只读与保存中受保护。

内存 mock 不存密钥输入，仅存是否配置及替换意图；便携资料仍剔除本机连接。没有实际渠道注册、API / Agent / CLI / WebDAV 请求、命令安装或运行配置写入。正式凭据暂存、绑定、稳定身份 / 编译及真实目录核对继续由 G-09 / G-10 / G-11 承接，AC-M01～M94 仍待生产验收。
