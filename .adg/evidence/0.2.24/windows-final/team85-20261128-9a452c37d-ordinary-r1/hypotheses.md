# TEAM85 测试前待证伪判断

候选源码 `9a452c37d3005119042d81ee1ae8f62c4920c4d0`，Windows 制品 `15224497695`，治理 `fa336d097`。各夹具使用独立新根和真实普通账户桌面。

1. 下载 ZIP、MSI、NSIS 的本地 SHA-256 均与治理回执一致。任一不符即不启动制品。
2. 完整包首开，无需用户确认或外部下载，从随包资源展开并校验，界面在就绪前显示本地准备阶段、可见步骤和「无需联网」。断开桌面网络按合同跳过。
3. 缺包保留清单，暂缓及重开后确认前 GET 为零。确认后请求、响应和终态可关联同一 attemptId，且 downloadConfirmed 为 true。公开地址不可用时原样记录。
4. 从环境就绪后的首次 Status 计时，5 秒内收敛或显示「运行状态未知」并禁用 Start，提供重试和诊断。Doctor 保留实际结果，失败时核对首错与旧结果。
5. PID-only 无保留 Owner 时拒绝启动并返回 windows024_owner_unknown。独立端口写锁夹具在原 Start 期限内拒绝。比较端口设置、记录、进程和监听。
6. 仅在可信确认空闲后执行普通桌面 Start → Status → Stop，分别核对 30／5／10 秒及正常终态。缺席或仅 Unreachable 不构成空闲。
7. 先归档，再核对本轮自有进程、监听、夹具的清理。保留历史。强制清理不计正常 Stop 或 Closed。accepted:false。
