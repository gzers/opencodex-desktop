# 测试验收

状态：**以下全部是待执行的生产验收条件**。即使文档链接、格式与示例检查通过，也不代表任何功能条件通过。技术门见 [评审](../01-需求分析/03-确认与评审/README.md)。

| 编号 | 场景 | 应验结果 | 对应需求 |
|---|---|---|---|
| AC-S01 | 发布一个三模块整套环境 | 清单明确 models / skills / mcp 精确版本，接收可整套或分模块选择 | R-01～03 |
| AC-S02 | 只发布所选渠道 / 模型 | 附带精确模版依赖，保留渠道范围语义，不带未选内容和隐含全局变更 | R-02、04 |
| AC-S03 | 只发布 / 订阅模版库 | 只入候选，不改主指针、渠道采用或运行态 | R-02、04 |
| AC-S04 | 发布选定 Skills | SKILL.md、引用文件和资源齐备，外部依赖明确，缺失拒绝完整提交 | R-03 |
| AC-S05 | 发布 MCP 描述 | 秘密值与本机路径不进入包，固定制品 / 远端连接和本机变量可识别 | R-03、04 |
| AC-S06 | 包含密钥或私有依赖 | 阻止秘密字段；读取权不自动变再分发权，缺授权不扩大受众 | R-01、05 |
| AC-S07 | 暂存上传失败 / 重试 | 半包不可见，幂等返回同一提交结果，不伪造版本成功 | R-01、06 |
| AC-S08 | 两维护者同时更新 stable | 两份 release 可保留，轨道 CAS 冲突可处理，不覆盖未见变化 | R-06 |
| AC-S09 | 私有源访问与已知摘要下载 | 无权限者目录、清单、依赖与内容均隔离；不能凭摘要绕过 | R-05 |
| AC-S10 | 团队管理员订阅 | 必须团队有源读取权；成员只收到推荐，设备不自动应用 | R-05 |
| AC-S11 | 成员退组 / 源授权撤销 | 后续获取被拒，缓存 / 短效 URL 边界明确；不宣称追回离线明文 | R-05 |
| AC-S12 | 只订阅若干条目，源新增项目 | 固定选择不扩大；持续全部选择也只新增候选，不自动启动 | R-04 |
| AC-S13 | 三模块分别选不同源和版本 | 每模块独立显示、更新和固定；当前精确组合可复现 | R-06 |
| AC-S14 | 采用整套后单独换 Skills | 模型 / MCP 的选择不被改动，组合标自定义；后续整套更新不强行换回 | R-06 |
| AC-S15 | 模块换源破坏硬依赖 | 展示具体缺口，保留原运行态；明确调整组合才继续 | R-02、06 |
| AC-S16 | 多源同名渠道 / templateId | 通过完整来源身份隔离；映射后全部引用正确，不能按名称合并 | R-02、06 |
| AC-S17 | 固定版本与跟随轨道并存 | 下载中轨道变化不污染已冻结集合；回指历史有明确回退提示 | R-06 |
| AC-S18 | 新格式、损坏摘要或不兼容平台 | 候选被拒或标不可用，当前配置保持；不丢字段后继续 | R-03、06 |
| AC-S19 | 保留本地条目开启 / 关闭 | 开启共存；关闭仅不参与该组合，个人内容不被删除 | R-07 |
| AC-S20 | 保留本地覆盖开启 / 关闭 | 与本地条目开关独立；清除覆盖范围可预览与恢复，绑定不被清空 | R-07 |
| AC-S21 | 源与本地同时改同一字段 | 展示 B0 / B1 / L 和字段来源，默认保留本地，确认后再应用 | R-06、07 |
| AC-S22 | false / inherit / 空列表 / 缺省 | 业务含义分别保留；空模型白名单不扩大成全部 | R-02、07 |
| AC-S23 | 上游删除有本地改动的对象 | 明确复制为本地或移除，不丢修改、不遗留悬挂引用 | R-07 |
| AC-S24 | 同名 Skill / MCP 占同一运行目标 | 明确唯一所有者，保留未受管本地内容；不自动拼接脚本 | R-03、07 |
| AC-S25 | 模型体系与本地渠道合并 | 两级顺序可预览，全局预算 / 能力统一检查，写入后读回 | R-02、07 |
| AC-S26 | 本机无渠道凭据 / MCP 认证 | 订阅成功但采用待绑定；不给虚假生效，不能转用订阅令牌 | R-02、03 |
| AC-S27 | MCP 域名、命令或权限变更 | 展示新增执行 / 认证影响并处理授权，旧令牌不静默转交 | R-03、06 |
| AC-S28 | 只下载 Skill / MCP 更新 | 没有执行脚本、安装 / 启动进程或写运行配置的隐式副作用 | R-03、06 |
| AC-S29 | 模型成功、MCP 失败 | 真实部分结果、受管补偿与恢复入口可见，组合不显示全部成功 | R-02、03 |
| AC-S30 | 应用中断、超时、外部改配置 | 依据日志读回，重试幂等；保留外部修改，不盲目重写 | R-06、07 |
| AC-S31 | 同账户两设备，只有 A 已应用 | 服务端订阅相同但生效版本独立；B 仍需本机绑定和采用 | R-05、06 |
| AC-S32 | WebDAV 与订阅同时更新 | 订阅缓存 / 私有包 / 凭据不回流；本地事实与派生投影分清，新旧容器行为可验证 | R-01、07 |
| AC-S33 | 账号 A 切 B / 新服务实例 | 队列、缓存、候选与认证隔离；B 不复用 A 的私有包或权限 | R-05 |
| AC-S34 | 离线、404、权限拒绝、版本撤回 | 各自状态明确；不把失联当清空；已知撤回版本阻止新采用 | R-05、06 |
| AC-S35 | 暂停、停用、取消、回退 | 四种语义分明；保留为本地和移除可选；依赖与覆盖不丢失 | R-06、07 |
| AC-S36 | 下一版本范围审阅 | v0.2.0 与用量首期未新增隐含交付；功能关闭时本地模式可用 | R-08 |
| AC-S37 | 订阅团队 A 内容后产生个人调用 | 用量来源、空间和待传历史不随内容来源改变；ContentSource 与采集 Source 身份隔离 | R-05、08 |
| AC-S38 | 退组后重新加入 / 团队解散 | 新成员期重新授权，旧发布令牌和暂存不能恢复；内容不自动转为个人源 | R-05 |

建议按格式 / 解析单测、服务端授权与内容集成测试、真实宿主适配测试、端到端交互分别取证。不得用静态页面断言替代运行读回，也不得用模拟发布证明实际权限隔离。
