# 项目支撑资料

## 状态

**已启用。** [产品原型](01-产品原型/README.md)保存唯一一份持续维护的完整桌面原型及必要共用资源；当前为待评审设计草稿。各轮增量、候选、截图与 QA 保留在所属协作包。

## 用途

保存产品交互原型和 `EVD-*` 项目支撑证据：用于判断和追溯的长期材料、非敏感环境访问边界，以及迁移审计。

## 进入条件

只收纳**有长期支撑价值**的材料，并为每份材料登记：

| 项 | 说明 |
|---|---|
| 支撑对象 | 这份材料支撑哪个需求、核心事实或实施结论 |
| 用途与结论 | 它用来判断什么、得出什么结论 |
| 来源与适用范围 | 来源出处，以及结论能覆盖到哪 |
| 回写目标 | 稳定结论回写到哪个权威对象 |
| 保留要求 | 保留理由与保留期 |

## 边界

- 不直接替代需求、架构、实施或验收的权威事实。
- 例行日志、临时脚本输出与机器事件留在运行时层（`.adg/`），不放这里。
- 不保存凭据与敏感实值；只登记键名、路径与访问边界。
