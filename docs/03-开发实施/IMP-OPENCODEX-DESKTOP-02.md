## 目标与执行原则

以“用户操作产生正确的实际结果，失败时数据和状态仍正确”为验收核心。暂停新增无关功能，优先完成已有能力。不能以截图相似、输入值变化、模拟返回成功、测试数量或构建成功代替功能验收。

本计划确定的产品方向：管理器界面缩放实际生效；新配置导入导出不要求额外口令；WebDAV 保留服务端认证凭据，取消新流程的额外内容加密口令。旧加密内容必须有经过验证的读取或迁移路径。

具体实现选择由执行者基于代码与复现结果决定。不得用固定密码、硬编码密钥或只有本机可用的自动密钥冒充跨设备免口令方案。

## 执行结果（2026-09-20，A–D 完成、E 部分完成）

### 用户可见行为

- **界面缩放真的生效**：单一 `interfaceScale` 驱动主壳 CSS `zoom` 与内嵌面板原生 `set_zoom`；
  滑块即时预览、去抖落盘、失败回退；启动即恢复。已在真实 Release 制品上按 50/100/125/150/200% 验收。
- **导入导出与同步不再索取额外内容口令**：新容器/新载荷为明文 + SHA-256 完整性校验，
  只保留 WebDAV 服务端认证；旧加密容器与旧远端按版本号识别后仍需「原口令」读取。
- **CLI 的同步与生命周期不再是空壳**：`ocxd sync run` 与 GUI 共用同一段真实执行；
  `start/stop/restart` 与 GUI 一致、退出码可信、失败不谎报成功。
- **数据根切换可用**：切换引用（含含空格/中文路径）、重启生效、可切回自身，且不再破坏结构元数据。
- **GUI 反馈与菜单可信**：设置页缩放读数与实际比例一致；顶部应用菜单的进程项按运行态启用/置灰；
  重启/启动超时后仍会按真实收敛改判为已完成。
- **旧版加密容器两条导入路径都可用**：GUI 原口令对话框与 CLI `--password-stdin` 均经真实容器验证，
  错误口令不修改现有配置。
- **壳层与窗口行为可信**：对话框打开时通知层不再盖住对话框；关闭窗口只隐藏桌面壳（托盘与代理存活，
  菜单或 Dock 图标都能找回窗口）；点击 Dock 图标不再无反应。

### 关键实现取舍

- WebDAV 远端布局展平为 `latest.txt` / `<snapshot_id>.ocxd` / `<sha256>.ocxd`，继续只使用
  冻结的 `PROPFIND/GET/PUT` 三个边界（不新增 MKCOL），避免依赖中间集合。
- 子进程回收改用独立线程 `waitpid`，不再依赖本环境下永不就绪的 `tokio::process::Child::wait()`；
  SIGTERM 后固定 5s 窗口收口，绝不无限阻塞（仍不使用 SIGKILL）。
- 状态映射中 `proxy.running=false` 一律回退到「未运行」；只有字段缺失/类型未知才保留上一次状态。

### 兼容策略

- 容器 `container_format_version=2` 明文 + 完整性摘要；`1` 旧格式仅兼容读取，缺口令返回错误码 13。
- 同步 manifest/payload `version=2`；`1` 旧格式仅兼容读取且仍需原口令。
- 旧配置里的 `encryption=forced`、偏好里的 `client_encryption` 作为历史字段读取后忽略，不再写出。

### 支持范围与遗留限制

- 仅验证 macOS arm64；未做签名/公证/公开发布，未在真实用户数据上执行迁移、恢复或全局同步。
- 桌面 GUI 交互已在解锁窗口内完成真机验证（2026-09-20），**无遗留未验证的 GUI 交互项**：
  缩放矩阵（50/100/150/200% 真实像素比 0.52/1/1.50/1.98，切页与重启保持）、刻度点击、
  旧版 v1 容器的原口令分支（GUI 与 CLI 各一条真实路径，错误口令不改配置）、启停与重启反馈收敛、
  原生应用菜单可用态与「打开主界面」激活、托盘状态项状态绑定与托盘菜单内容/门控/「停止·启动·退出」
  三个菜单项的真实激活、窗口关闭只隐藏桌面壳（Dock 图标与菜单均可恢复）、日志页与真实日志清理副作用、
  通知历史、扩展管理、版本升级页与应用更新检查结论、全新隔离 HOME 下的首次启动。
  详见 `.adg/work/IMP-OPENCODEX-DESKTOP-02.checkpoint.md` 与阶段文档 04/05。
