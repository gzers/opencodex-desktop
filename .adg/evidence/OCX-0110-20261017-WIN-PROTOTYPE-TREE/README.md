## 原件与方法边界

- `result.json`和`check-prototype.initial.mjs`保留最初24组的结果与方法。该轮只改变浏览器视口，原型默认窗口未改，**不作为实际窄窗证明**。
- `remaining-before/`保留首次48组结果；方法曾把折叠隐藏行和隐藏占位算作控件，导致导入/模型比较的假阳性。隐藏元素没有显示几何，修正为只测有实际布局矩形的节点，保留原1px口径。
- `remaining-before-visible/`在产品样式修复前用修正方法完成48组；只有12组备份树失败，每组7个可见动作按钮均偏低8px。未因工具错误改导入或模型业务。
- `remaining-after/`使用同一可见节点方法，48组通过；`remaining-extras/`补4组独立状态。所有阶段浏览器子进程均正常exit0、loopback服务关闭，来源文件在各阶段内字节保持，外部请求0。浏览器自动化脚本的失败退出码与其正常关闭的浏览器退出码分开。
- 未启动、安装或控制Windows产品，未动系统DPI、Windows配置/指针或真实数据，未执行FZ50、重跑CI或发布。

生产Windows异步刷新叶焦点、原生主题/档位/密度等确实未覆盖组合继续待验；原型浏览器结果不能抵扣这些原生缺项。原型其它未覆盖业务状态不扩大为本轮已验收。

`verify-evidence.py`只复核本档摘要、已保存结果、可见控件口径及当前原型源文件，不重开浏览器。
