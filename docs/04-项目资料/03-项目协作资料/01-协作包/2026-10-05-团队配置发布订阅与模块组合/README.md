# 团队配置发布订阅与模块组合

状态：**下一版本方向的独立候选协作包，具体版本号未定；需求与方案待评审，未实现、未部署、未发布内容**。日期：2026-10-05（Asia/Shanghai）。正式入口为 [COL-LOCAL-20261005-02](COL-LOCAL-20261005-02.md)。

把个人配置管理扩展为团队可复用的工作环境：发布者选择渠道 / 模型 / 模版、Skills、MCP 的内容范围，发布不可变版本；服务端管理发布源、访问权限和个人 / 团队订阅；接收者可以整套采用，也可以为各模块分别选择订阅源与版本，并选择保留本地条目和本地覆盖。

**建议的产品单位是“订阅源 + 模块版本 + 本地组合方案”。** 整套发布负责提供经过检查的推荐组合，各模块仍能独立换源。自动检查 / 下载更新先进入候选区，应用到本机另有差异预览、绑定和验证过程。

| 模块 | 一个示例组合 | 本地选择 |
|---|---|---|
| 模型体系 | 团队 A 的渠道、模型策略及其精确模版依赖，跟随稳定轨道 | 保留个人渠道和单模型覆盖 |
| Skills | 团队 B 的编码技能集合，选择其中几项 | 保留自己编写的技能 |
| MCP | 团队 C 的工具连接集合，固定某个版本 | 使用本机凭据，保留本地 MCP |

上表是候选交互示例，不代表现有客户端支持。模型体系内的策略与所引用模版必须形成完整依赖集合；高级用户可单独订阅模版库，但换模版来源仍须明确改策略引用并校验。
