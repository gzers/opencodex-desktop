# 渠道配置优先与默认端点说明

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器，模型配置管理与同步 0.2.0 候选原型。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models) → 渠道模型 → 行内“编辑”。

## 调整

- 用户要求将渠道配置、协议端点和模型默认放在模型列表之前。导航与连续表单统一为：01 渠道配置、02 协议端点、03 模型默认、04 模型列表。对应 ID 仍为 mpChannelSection-connection / endpoints / defaults / models。
- 初始分区、切换渠道及重置演示场景的首分区改为渠道配置；同渠道重绘继续沿用原滚动锚点和草稿。
- 默认端点沿用已有规则：primary 自动使用渠道配置的默认协议与连接，无需重复新增。协议明确选择，不能仅凭 Base URL 推断；连接编辑确认进入草稿后默认端点随之更新。额外协议 / 地址 / 凭据需求才新增附加端点，单一匹配自动路由，多个同协议端点要求指定。此次没有改变路由行为。
- 稳定说明回写[模型页交互细化](../02-方案草案/模型页交互细化.md)和[模型协议与端点方案](../02-方案草案/模型协议与端点方案.md)。资源标记更新为 20261014-channel-order。
