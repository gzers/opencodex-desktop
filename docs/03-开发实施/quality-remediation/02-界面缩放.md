# B：界面缩放

入口：[实施计划](../IMP-OPENCODEX-DESKTOP-02.md)。开始前读取 A 的缩放复现证据。

## 产品行为

“界面缩放”作用于管理器主界面的文字、控件、侧栏、设置、弹窗与通知。内嵌面板的缩放关系应明确：先检查面板是否已有独立控制与偏好，再选择独立控制或随全局变化，并更新标签说明。不得重复叠加缩放。

保留当前 50%—200% 范围及已约定的输入归一化行为，除非复现证明需要调整并记录理由。原生窗口装饰不要求跟随网页内容同比缩放。

## 实现调查

- 核查 `SettingsRoute.vue`、`scale.ts`、`App.vue`、全局 controller、偏好存储、`PanelRoute.vue` 和原生 `commands/panel.rs`。
- 追踪启动加载与应用时机，缩放应由全局生命周期应用，不能依赖打开设置页。
- 根据真实 WebView 与布局表现选择实现方案，核查原生子视图的坐标、尺寸和命中区域。
- 处理快速连续修改时的请求乱序、旧值覆盖、写盘频率和重复提示。
- 明确即时预览、持久化和失败回退行为，失败后显示值、实际比例与持久化值一致。

## 必测场景

| 场景 | 预期 |
|---|---|
| 50%、100%、125%、150%、200% | 文字与控件实际尺寸变化，读数正确 |
| 滑块、刻度、数字输入 | 结果一致；非法值与越界值按规则处理 |
| 页面切换与重新打开设置 | 比例持续生效 |
| 退出后重新启动 | 自动恢复比例，无需再次打开设置 |
| 快速拖动与保存失败 | 最后选择不被旧请求覆盖；失败明确回退或保留未保存提示 |
| 小窗口、高比例、滚动 | 关键操作可达，不被永久裁切 |
| 弹窗、通知、面板子视图 | 布局和点击位置正确，不双重缩放 |

自动回归覆盖应用链路和保存竞争等实质性行为。实际渲染在原生桌面应用验证，记录固定窗口条件、前后图像或尺寸证据；jsdom 中的数值断言不能承担该验收。

## 通过条件

复现问题得到修复，原生应用渲染、交互与重启验证通过，相关检查通过。将实现取舍和用户可见行为写回本节或相关长期文档，详细回执保存在 `.adg/`。

## 本轮实现与验证（2026-09-20，B 阶段回写）

实现取舍：

- **单一比例，外壳与面板同源**。`interfaceScale` 是唯一比例；外壳用根元素 `--ui-zoom` + `.app-window` 的 CSS `zoom`，内嵌官方面板继续用原生子 WebView 的 `set_zoom`。两者同为「比例/100」，按缩放后的留白计算面板边界，实测无双重叠加（同一文本行 OCR 高度比 ≈2，非 ≈4）。
- **CSS `zoom` 而非 native page zoom**。在 WKWebView 引擎上实测：`zoom` 受支持，`getBoundingClientRect()` 返回按 zoom 放大后的坐标（因此原生面板边界无需额外换算），但视口单位不折算，故 `.app-window` 的 `100vh`、最小尺寸与 `.notif-layer`/`.modal`/`.select-menu` 的 `vw/vh` 显式除以 `--ui-zoom`。
- **启动即应用**。缩放在偏好加载/保存/还原后由 store 统一应用，不依赖打开设置页；`--panel-zoom` 这一无人消费的历史变量已删除（连同 dev 探针字段改名 `uiZoom`）。
- **面板 hub 不再自成一套比例**。hub 的 `−`/`+` 现在改的是同一个 `interfaceScale`（即时预览 + 落盘回读），不会与设置页读数分叉。
- **媒体查询不再承担自适应**。元素 `zoom` 不改变视口宽度，`@media` 无法反映实际可用宽度；关于页自适应改为 `flex-wrap` + `auto-fit` 网格，设置页沿用 `@container`。
- **原生窗口装饰不缩放**：标题栏保持物理高度，避免红黄绿按钮错位。

用户可见行为：

- 设置页「界面缩放」50%–200% 立即改变主界面文字、控件、侧栏、设置、弹窗与通知的实际尺寸，并同步内嵌官方面板。
- 切页面、退出重启后比例保持；拖动滑块以最后一次选择为准，保存失败回退到已保存值。
- 高比例 + 小窗口时控件仍可达（可滚动），卡片会变窄、换行增多。

验证证据（真实 Release 制品，窗口固定 1180×760）见 `.adg/work/IMP-OPENCODEX-DESKTOP-02.checkpoint.md` 与 `.adg/work/evidence/imp02-scale/`：侧栏宽度实测 121.5/244/305/366.5/489 逻辑 px（50/100/125/150/200%），旧制品在 98% 与 200% 下均为 244（复现缺陷）。
