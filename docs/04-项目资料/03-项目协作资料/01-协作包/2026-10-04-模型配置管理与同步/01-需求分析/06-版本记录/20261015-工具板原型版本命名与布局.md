# 工具板原型版本命名与布局

日期：2026-10-15。项目：opencodex-desktop。产品：OpenCodex桌面管理器。

用户要求将工具板“设计范围”改为“原型版本”，选项按版本号及协作包名称显示，未定版本明确写待定版本；下拉与下面输入等宽，分区导航放到它下面。

[唯一活动总原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)右侧工具板现按“标题与说明 → 原型版本 → 导航/外观/工具/本页演示 → 下方工具内容”排列。三个既有范围的ID不变：

| ID | 新显示名称 | 来源/版本边界 |
|---|---|---|
| models | 0.2.0 · 模型配置管理与同步 | 对应模型包，0.2.0仍暂定，未宣称发布 |
| conversations | 待定版本 · Codex 对话配置管理 | 对话包标题，版本/生产开发时机未定 |
| extensions | 待定版本 · 多 Agent 平台扩展管理 | 扩展包标题，版本/开发时机未定 |

去掉选择器自己的额外左右padding，移入已有工具板头部的同一内边界；原生select、公共Select增强外层和触发器分别约束100%宽度，保留长名称省略/菜单全文的共用行为。没有新增原型版本或把延期业务归入0.2.0。

本轮2项相关检查通过，JS/CSS语法、文档链接和diff格式检查通过。检查覆盖真实脚本的内存DOM加载、选项与真实协作包标题一致、可读名称、选择器/分区导航顺序、三范围切换及design查询保持，以及导航移位后仍能展开全局折叠组。CSS检查核对去除双重缩进及增强层宽度；资源/语法/链接/diff另行核对并留.adg证据。没有修改原型场景或生产代码，不为本轮低影响改动重复运行全部原型回归。

当前浏览器file访问限制未重试/绕行，无本轮实际像素/字体/窄窗实屏验收；DOM结构和CSS配方检查不能替代真实可视宽度结论。版本选择规则回写UI规范§34，未修改apps/共享根文件、运行设置或全局Skill，未提交/发布。
