## 范围

- 仅配置全局命名模型，触发与标题管理沿用 Codex；
- Web Search 使用的模型、推理档位和回退策略；
- 子 Agent 的模型、角色 / 执行类型、提示词、effort、并发和深度等配置；
- 全局、Codex 项目和单个对话 thread 的配置作用域及继承；
- 读取 Codex 项目 / 对话列表并建立稳定绑定；
- 配置保存后立即生效、下一次请求生效、刷新 / 重启和暂不支持的边界。
- 独立配置、本机来源绑定与运行状态的存储，以及按 0.1.10 底座适配事件、备份和按需刷新。
- 按项目分目录、对话覆盖按需建文件，配置随项目删除和对话归档 / 删除自动清理。
- 手动导出 / 导入与备份独立选择；WebDAV 默认不包含本包全局、项目和对话配置。
- 项目 / 对话内容导出及与策略的联合包、恢复时的对象映射；WebDAV 不自动包含历史。
