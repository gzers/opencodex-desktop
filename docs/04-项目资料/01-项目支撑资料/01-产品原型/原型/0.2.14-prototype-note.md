| 成功：notifHost / taskHost | 一次“已写入 / 立即重启 Codex / 稍后”，没有页面底部保存卡。默认聚焦立即重启；其他弹窗打开时不抢走其焦点。沿用共享 glass-tokens 的原玻璃、字号、尺寸和间距；通知按钮实测 11px、24px 高，未修改共享配方。 |

| 铃铛：notificationBtn、data-collapse=task | 收起仅入现有铃铛；终态 8 秒收起、最多三张的既有约束保留。点铃铛只开列表；点对应当前通知才恢复一张任务。已结束历史不恢复操作，没有额外展开入口。 |
| 重启：data-task-act=model-restart → openModal | 使用原有共享确认弹窗及位置参数合同；取消保留当前提示，确认仅演出重启并结束提示，不调用真实重启接口或 CLI。 |
| 清理：notificationPurge → openModal | 使用既有确认弹窗，面板内不新增确认卡；取消保留通知，确认软删除通知并清除对应卡和计时器。其他既有清理入口同步清除宿主。 |
| 失败与旧状态消费 | 备份失败、原子写入失败/超时均保留原文件与草稿，可直接重试；没有保存后核对入口。旧 success / confirmed / pending / verified 只消费为完成历史；旧 timeout / uncertain 按失败消费，不建立恢复准入。 |
| 节点测速与获取清单：服务节点、data-mp=refresh / channel-fetch | 共用 mock 路径处理：根地址、版本路径、完整清单地址、自定义前缀，以及 HTML/路径不存在的有限同源回退。认证、DNS、TLS、超时与无效清单不重试路径、不伪造成功耗时；不改保存基址。解释只在原型注释，产品界面不新增技术段落。 |

补充修正保留原布局：共享弹窗移入/归还焦点使用 preventScroll；外壳使用 clip 裁剪以免成为隐藏滚动区；mpContent 补 min-width:0，使窄窗横向滚动只发生在原有渠道表格内部，标题和主内容不被横向推走。未重排表格或增加组件风格。
