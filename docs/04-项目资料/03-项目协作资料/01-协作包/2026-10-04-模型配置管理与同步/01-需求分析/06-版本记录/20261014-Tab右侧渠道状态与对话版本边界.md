# Tab 右侧渠道状态与对话版本边界

日期：2026-10-14。项目：opencodex-desktop。产品：OpenCodex 桌面管理器。

用户要求渠道列表状态区移到 Tab 右侧，按模型激活数 / 状态 / 保存排列，有修改时保存强调，状态框与按钮等高，原型标签举出状态与样式。另明确对话不属于 0.2.0，该页 Tab 虽补绘也不归此版本。

唯一入口：[产品主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models) → 渠道模型列表。

## 本轮调整

- mpPolicyStatus 进入 mpTabsBar 右侧，不在列表正文占重复状态行；核心顺序为 mpBudget → 状态框 → mpPolicySave。沿 Tab 的到顶固定规则，窄窗可分行但保留顺序与可达性。详情仍在侧栏保存，不改模版列表的操作归属。
- 激活数、状态框和保存按钮共用 34px 高度令牌；状态有描边、底色、圆点 / 进行环及主题颜色。未修改时保存弱化禁用，有修改且可提交时主色与细外描边强调。待确认编辑、超限、保存中仍禁用，禁用状态不会伪装可提交。
- 原型标签 ann-mp-08 实际展示九种状态样例：未修改（灰）、未保存修改（橙）、有待确认编辑（橙）、超出预算（红）、正在保存（蓝 + 环）、已保存待重启（橙）、保存失败（红）、保存已取消（灰）、结果待核对（橙），对应保存可用性说明。
- 上次保存待重启可与新修改同时显示在同一状态框，仍与连接检查、额度及客户端实际加载分开。进行环遵循减少动效设置。待处理行 / 连接、候选和重启核对入口继续保留，冻结差异确认与保存流程未改变。

## 对话版本澄清

**对话功能以及对话页面 Tab 的开发接入 / 验收均不属于 0.2.0，随独立对话包后续版本实施，版本仍未定。** 当前共享原型可预先补绘对话 Tab，但不能把该页面产出计入 0.2.0。0.2.0 的公共组件与既有模型 / 扩展 / 同步 / 诊断 / 设置接入不因此扩大范围。

该边界已写入 [UI 规范 §28](../../../../../../02-项目核心/UI规范.md#28-页面主-tab-到顶固定2026-10-14-确认020-开发调整)、[0.2.0 开发范围](../../02-开发实施/README.md#020-公共页面-tab-固定已纳入开发调整)、[前序公共 Tab 记录](20261014-公共页面Tab固定与020开发归属.md)与[对话包原型说明](../../../2026-10-11-Codex对话配置管理/01-需求分析/05-原型/README.md)。列表状态布局回写[模型页交互细化](../02-方案草案/模型页交互细化.md)，归 0.2.0 WP-03 / WP-05。
