## 缺口与修复

630的缓存只检查对象/通道/版本、正文长度与URL，没有拒绝ready却无正文、unavailable却有正文、未知说明来源和非法发布时间；坏缓存可被当命中返回。另HttpSource在读缓存前初始化代理/证书，非法手动代理会在有效缓存读取前失败，违背离线缓存优先。

新增同字节四项回归在旧生产实现实际12通过/4失败，日志cache-red.log保留。修复后16/16通过：ready必须有非空正文及认可来源；github_release必须带核验网页，updater只属于管理器；unavailable不含正文/来源，发布时间须合法RFC3339。字段矛盾缓存按坏缓存重查，仍遵守来源/版本/通道和响应限制。有效正文或真实缺失缓存不受影响。

HTTP客户端改为惰性OnceCell：仅真正缓存未命中且将发出请求时，在阻塞线程池完成代理/证书初始化；同一事务的面板两次HTTP复用该客户端。有效离线缓存无客户端初始化或HTTP请求，网络配置错误不会阻断它。无效代理在实际请求时仍如实失败，不静默降为其他代理。初始化在原30s总截止之内，连接15s/响应256KiB/正文64KiB、TLS/禁重定向不变。
