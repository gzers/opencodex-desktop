## 交互设计与补绘

同一份[模型主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html)中，“渠道模型 → 管理”按三个层次组织编辑：

- 列表直接编辑别名，启停使用独立开关；原始 ID 和最终协议 / 上下文 / 推理 / Fast 摘要保留。复选框只选批量目标，表头仅操作筛选结果，筛选外选择保留且提示数量。
- “展开编辑”提供协议、上下文预设 / 自定义、推理等级多选 / 默认档、Fast 能力和指定端点。每项支持继承 / 自定义，修改暂存本行，“加入草稿”确认或“还原本行”撤回。
- “编辑明细”保留完整规则、输入模态、高级推理设置、别名 / 显示名称和启停；从待确认行缓冲继续。明确不显示推理档位在高级区设置，列表 / 批量空选则提示至少保留一项或恢复继承。

上下文提供 32K / 64K / 128K / 200K / 256K / 1M 预设及正整数 tokens 自定义。Fast 选择表示能力未知 / 支持 / 不支持，实际快速模式策略沿用已有层级；协议选择与端点适配按既有方案解析，缺少对应端点可保留草稿，页级保存提示补齐。

批量栏可选择“勾选模型”“筛选结果”“当前渠道全部模型”。启用、停用、批量编辑、恢复字段继承均完整列出目标并冻结范围；按字段不修改 / 继承 / 自定义，别名可保留 / 清空 / 按规则生成。任一名称或规则无效、基准过期或目标存在未确认行编辑均阻止整批提交。有效整批只产生一次撤销记录，无变化不加记录；恢复规则继承保留别名、启停、精确模版引用和顺序。

列表别名 / 独立启停直接进入页级草稿；展开字段确认后进入同一草稿。未确认行编辑阻止页级保存，草稿入口显示数量并提供处理出口；撤销 / 重做 / 丢弃、差异预览和 mock 导入导出覆盖命名与启停。原始 ID 仍用于请求、匹配和排序。搜索 / 族筛选 / 仅启用下禁用重排，官方 / 原生只读，保存中锁定。
