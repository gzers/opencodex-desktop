## 交接行为

仅在新鲜默认根不可写、用户显式选根、验证及持久登记成功后，启动Windows内置PowerShell后台等待程序。系统目录由原生API取得，脚本嵌入EXE，不写临时脚本；使用NoProfile、NonInteractive、Hidden和CREATE_NO_WINDOW，不修改执行策略。普通成功启动从现有准入分支继续，按源码审阅不会启动等待程序。

等待程序先校验旧进程映像和创建代际，取得并保留真实句柄，再确认准备完成；收到独立提交才等待该句柄退出，之后才启动同一EXE并保持参数及程序目录。路径与参数以UTF-16十六进制管道数据传递，不拼入可执行PowerShell源码。准备最多15秒、旧进程退出最多30秒；没有提交、代际不符、目标无效或等待超时均不启动替代应用。未提交的自有等待程序由准备句柄收尾，不终止产品或按任意PID清理。

旧恢复进程在交接提交成功后释放所持根锁及选择租约，再请求正常退出。准备失败明确提示目录已经保存、退出后重新打开，保留登记和数据。该机制保留保存后自动重开的行为；完整普通/管理员原生交接、首屏、令牌及根回读尚未执行。
