# 0.2.2 首批 UI 修复（选择器、表宽、对齐、口令说明）

2026-10-22，用户确认 0.2.2 目标模式：先修原型（WP-13/WP-24），再建全局样式口径（WP-10 根因），然后回归代码。本文登记首批代码结果与验证边界。

## 分支与工作树

- 分支 <code>feature/0.2.2-ui-bugs</code>，工作树 <code>ocx-022-model-selector</code>。
- 基线为 <code>feature/0.2.1-ui-alignment</code> 的 3 个本地提交；未推送。
- 清理：该工作树上原有一笔把 <code>ModelPicker.vue</code> 从完整实现重写为 390 行不匹配实现的提交（引用不存在的 <code>channels[].name</code>、<code>policy.models</code>），已从历史移除，工作区改为在真实实现上做增量。

## 原型

<code>sticky-tabs.js</code> 的吸顶判定漏掉 sticky top 偏移：吸附线只取滚动容器顶边，导致“接近但未到顶”提前淡入。<code>syncStuck</code> 改为“容器可视顶边 + <code>--page-tabs-top</code>”，容差收到半个像素只吸收亚像素舍入。原 4 项测试从此前的失败恢复全绿。
