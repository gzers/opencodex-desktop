# 场景与验收矩阵

## 1. 定位与验收口径

- 每条 AC 至少配套：一个正常路径、一个失败或不可达路径、一个取消或用户拒绝路径、一个恢复或回滚路径。
- 验收不得只验证“按钮是否可点击”，必须验证**状态、数据落点、备份可恢复性和敏感信息不泄露**。
- 本阶段不连接真实 CLI、文件系统、WebDAV 或凭据；所有验证使用 mock 数据。
- 未冻结项（状态 `open`）对应的 AC 仍可写验收场景，但在对应 OQ 关闭前**不得判定为通过**。

## 2. 场景清单

| 场景 | 角色 | 前置条件 | 用户动作 | 系统响应 | 可见状态 | 失败处理 | 可恢复性 |
|---|---|---|---|---|---|---|---|
| S-01 首次启动发现 | 首次使用者 | 无管理器数据目录 | 打开应用 | 依次检查 `node` → `npm` → `ocx`，短路失败即停 | `checking` / `missing_*` / 发现结果 | 缺失项展示当前状态与最短可复制命令 | 用户安装后手动重新检查 |
| S-02 正常运行 | 日常使用者 | 已发现安装 | 启动 / 停止 / 重启 | 托管官方子进程 | `stopped → starting → pending → running` | 启动失败进入 `starting_failed` 并提供重试 | 重试启动、查看日志 |
| S-03 异常运行 | 日常使用者 | 已安装 | 刷新状态 | 读取官方状态命令 | `at_risk` / `external_takeover` / `unreachable` | 展示风险摘要与建议动作，不自动改配置 | 用户确认后走官方 restore |
| S-04 日常观测 | 排障使用者 | 已安装 | 查看日志 / 打开面板 / 运行 Doctor | 只读读取 | 日志页、面板页、诊断中心 | 代理离线时说明实时日志不可用 | 本地历史日志与日志目录仍可用 |
| S-05 数据目录切换 | 进阶使用者 | 已有数据目录 | 选择新数据目录 | 检查目录 → 检测已有数据 → 选择引用或迁移 | 操作状态 `validating → backing_up → applying → succeeded/failed` | 迁移失败回滚并保留原数据目录 | 见 AC-02 恢复路径 |
| S-06 配置迁移 | 进阶使用者 | 有可导出配置 | 导出 / 导入 | 加密导出；导入按校验→备份→确认→写入 | 操作状态链 + 掩码摘要 | 校验失败中断，不部分写入 | 导入前备份可恢复 |
| S-07 WebDAV 同步 | 进阶使用者 | 已配置端点 | 立即同步 / 处理冲突 | 客户端加密 → 上传 → 冲突判定 | 连接状态 `connecting → syncing → synced/conflict/failed` | 冲突或网络中断不静默丢失历史 | 覆盖前备份可恢复 |
| S-08 双版本升级 | 日常使用者 | 已安装 | 检查更新 / 升级前备份 | 区分 OpenCodex 与套壳两条通道 | 各自独立状态链 | 失败展示原因与恢复建议 | 保留可回滚上一版本 |
| S-09 通知处理 | 日常使用者 | 有通知 | 打开通知详情 / 删除 | 通知中心与诊断中心共用数据源 | 两处同步 | 操作可撤销语义明确 | 通知数据可重新拉取 |
| S-10 CLI 控制面 | 高级 / AI 使用者 | 已在设置中启用 | 执行 `ocxd` 命令 | 经本机 IPC 委托运行中实例 | 命令输出 / `--json` | 实例未运行时只读降级、变更类报错 | 破坏性操作需确认标志 |

## 3. AC 验收矩阵

### AC-01 安装发现

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 应用启动，系统存在 npm 安装形态 | 展示路径、版本、运行状态；不触发 npm 管理操作 |
| 失败 | 未安装 / PATH 不可见 | 展示未发现说明，只提供只读指引，不引导 npm 安装 |
| 取消 | 用户不处理前置缺失 | 门禁保持阻塞，不进入常规状态机 |
| 恢复 | 用户安装后手动重新检查 | 前置通过、进入常规运行状态机 |

### AC-02 数据目录

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 选择或切换 `OPENCODEX_HOME` | 数据根就位，产物按分区落位 |
| 失败 | 目标路径不可写 / 空间不足 | 明确失败原因，不产生半成品目录 |
| 取消 | 迁移确认时取消 | 保持原数据目录，不写入任何变更 |
| 恢复 | 迁移中断 / 失败 | 回滚到原数据目录，备份可定位可恢复 |

> 2026-09-14 已确认（OQ-02）：引用优先、迁移可选；迁移前强制备份；检查阶段阻断不可写/空间不足；失败自动回滚并保留原数据目录。

### AC-03 启停

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 点击启动 | `stopped → starting → pending → running`，展示端口、PID、健康结果 |
| 失败 | 启动失败 | `starting_failed`，展示最近错误摘要与重试入口 |
| 取消 | 停止 / 重启前取消确认 | 进程状态不变，无副作用 |
| 恢复 | 失败后重试启动 | 重新进入 `starting`，成功后回到 `running` |

### AC-04 观测

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 打开面板 / 查看日志 | 面板加载官方 GUI；日志只读、敏感字段掩码 |
| 失败 | 面板加载失败 / 代理离线 | 面板区展示重试与浏览器打开；实时日志标注不可用 |
| 取消 | 关闭预览 | 不改变任何运行态 |
| 恢复 | 重载面板 | 恢复展示，无残留空白内容区 |

### AC-05 外部接管

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 状态为 `at_risk` / `external_takeover` | 展示风险摘要，说明属 OpenCodex CLI 边界 |
| 失败 | restore 执行失败 | 展示失败原因，不重复自动尝试 |
| 取消 | 用户拒绝 restore | 保持现状，仅保留说明 |
| 恢复 | 用户确认后走官方 restore | 展示前置备份、执行中、结果，随后刷新状态 |

> 2026-09-14 已确认（OQ-03）：结果链固定为「查看风险 → 影响摘要 → 生成备份 → 确认 → 官方引导 → 执行中 → 成功/失败/取消 → 刷新状态」；失败不自动重试。

### AC-06 配置迁移

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 导出 → 导入 | 加密容器生成；导入前校验、备份、确认后写入 |
| 失败 | 口令错误 / 容器损坏 / 版本不兼容 / 写入失败 | 明确失败原因并中断，不部分写入 |
| 取消 | 确认阶段取消 | 不写入，保留原配置 |
| 恢复 | 导入失败自动回滚；回滚失败可见 | 备份可定位、可校验、可恢复 |

### AC-07 WebDAV

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 立即同步 | 客户端加密后上传；`connecting → syncing → synced` |
| 失败 | 认证失败 / 网络中断 / 远端不可达 | 进入 `failed`，不静默丢失历史 |
| 取消 | 同步中取消 | 停止本次同步，已上传部分有记录 |
| 恢复 | 冲突处理后重试 | 覆盖前生成备份，冲突侧可恢复 |

> 2026-09-14 已确认（OQ-04）：按文件比对远端索引与本地摘要；单端点单次同步；冲突先入 `conflict`，覆盖前备份。

### AC-08 升级

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 检查更新 → 升级前备份 → 官方更新引导 | 备份成功后才引导 `ocx update` |
| 失败 | 备份失败 | 阻断升级引导并说明原因 |
| 取消 | 用户暂不升级 | 保持当前版本，无副作用 |
| 恢复 | 官方更新失败 | 展示备份位置与恢复建议 |

### AC-09 应用自身更新

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 检查更新 → 下载 → 校验 → 安装 → 重启 | 重启后重新接管代理并恢复状态展示 |
| 失败 | 签名校验失败 / 安装失败 | 保留可回滚上一版本，展示原因与建议 |
| 取消 | 用户暂不重启 | 保留已下载版本，不改变当前运行 |
| 恢复 | 回滚到上一版本 | 应用与代理状态均可正常恢复 |

> 2026-09-14 已确认（OQ-05）：采用完整状态链；签名校验失败即终止并保留上一版本；重启不停止 OpenCodex 代理。

### AC-10 CLI 控制面

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 启用后执行只读命令 / 启停命令 | 经运行中实例委托执行，返回结果或 `--json` |
| 失败 | 实例未运行 | 只读命令明确降级；变更类命令报错且不直接写状态 |
| 取消 | 破坏性操作缺少确认标志 | 拒绝执行并说明需要确认标志 |
| 恢复 | 关闭 CLI 开关 | 不留可被调用的监听端点 |

### AC-11 扩展管理（Skills / MCP）

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 浏览 / 导入 Skills；新增或导入 MCP；选择多客户端落点 | 写入前生成备份、原子替换成功；仅写入扩展配置；环境变量掩码 |
| 失败 | 写入失败 / 备份失败 / 校验失败 / 目标客户端不可写 / 配置冲突 | 明确失败原因；备份失败即阻断；冲突进入待处理而非静默覆盖 |
| 取消 | 卸载 Skills、删除 MCP 前取消；MCP 执行边界确认时拒绝 | 不写入、不删除、不执行；无副作用 |
| 恢复 | 回滚到写入前备份；从删除恢复；冲突处理后重写 | 删除类操作可恢复；回滚可定位、可校验 |

> 2026-09-14 已确认（OQ-01）：扩展管理**正式纳入需求（P1）**，对应 DMD revision 3 的 AC-11、§8 与 §10。
> 边界口径：只写扩展配置（Skills 目录同步、MCP 配置节点），不写 provider / 路由 / 模型映射与 OpenCodex 核心运行配置；实施前必须完成安全评审。

### AC-12 托盘与原生菜单

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 从托盘或原生菜单触发动作 | 动作限定在管理器自有域；托盘用图标与颜色表达运行状态 |
| 失败 | 目标动作不可用（如未发现安装） | 动作按状态渲染或给出原因说明，不做无解释的禁用 |
| 取消 | 菜单打开后未选择 | 无副作用，状态不变 |
| 恢复 | 应用退出后重新启动 | 退出后不残留托盘与菜单项；重启后状态重新接管并正确呈现 |

### AC-13 关于与归属

| 路径 | 输入 / 动作 | 预期可观察结果 |
|---|---|---|
| 正常 | 打开「关于」区域 | 区分官方项目 / 本应用 / 许可、归属与免责声明三部分；提供官方许可与第三方声明入口 |
| 失败 | 外链不可用 | 给出可读说明，不静默失败 |
| 取消 | 不点击外链 | 区域内容完整可读，无副作用 |
| 恢复 | 关闭并重新打开 | 内容一致，归属口径不变 |

## 4. 异常场景矩阵

| 异常 | 触发 | 期望行为 | 关联需求 |
|---|---|---|---|
| 前置缺失 | 无 `node` / `npm` / `ocx` | 短路检查、展示缺失项与最短命令、不代装 | REQ-01 |
| 启动失败 | 子进程非零退出 | 进入 `starting_failed`，保留退出码与最近错误 | REQ-05/REQ-06 |
| 待就绪超时 | 端口可达但未 ready | 停在 `pending`，提供刷新与日志入口 | REQ-06 |
| 代理不可达 | 进程或端口不可达 | `unreachable`，可刷新、可看本地日志 | REQ-06/REQ-07 |
| 外部接管 | 外部路由器改写 Codex 配置 | 检测并解释影响，不自动覆盖 | REQ-09 |
| 口令错误 | 导入时口令不匹配 | 中断且不写入 | REQ-14 |
| 容器损坏 | 导出文件被截断 | 完整性校验失败，中断 | REQ-14 |
| 版本不兼容 | 容器版本高于当前支持 | 明确拒绝并说明支持范围 | REQ-14 |
| 备份失败 | 备份目录不可写 | 阻断后续破坏性动作 | REQ-14/REQ-15/REQ-16 |
| 网络中断 | WebDAV 上传中掉线 | 进入 `failed`，保留本地与远端索引摘要 | REQ-15 |
| 远端被篡改 | 远端内容非预期变化 | 标记冲突，覆盖前备份 | REQ-15 |
| 并发动作 | 同一资源上多个动作 | 串行化或拒绝，避免状态互相覆盖 | REQ-25 |
| 扩展写入失败 | 目标客户端不可写、原子替换失败 | 回滚到写入前备份，明确失败原因 | REQ-27 |
| 扩展配置冲突 | 外部应用改写、或多客户端之间不一致 | 标记冲突并提示，不静默覆盖 | REQ-27 |
| MCP 参数越界 | `command` / `args` 指向非预期本地程序 | 展示执行边界，需用户显式确认后才可执行 | REQ-27 |
| 敏感泄漏 | 日志/导出/UI 出现明文凭据 | 视为验收失败 | §安全边界 |

## 5. 测试数据与可重复构造

| 数据 | 构造方式 | 约束 |
|---|---|---|
| 安装发现快照 | mock 状态注入，覆盖 `not_found` 到 `unreachable` | 不调用真实 `ocx` |

| 操作状态矩阵 | mock `validating / backing_up / applying / rolling_back / cancelled / succeeded / failed` | 校验与运行状态可同时表达 |
| 导出容器 | 仅用 mock 结构与口令 | 容器内不得出现真实凭据 |
| WebDAV 冲突 | mock 远端索引与本地差异 | 不连接真实端点 |
| 通知数据 | mock 通知集，覆盖级别与可执行动作 | 通知中心与诊断中心共用同一份数据 |
