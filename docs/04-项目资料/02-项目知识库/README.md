# 项目知识库

## 状态

**暂未启用。** 本目录是预留槽位，当前没有任何知识材料。

## 用途

保存 `KNOW-*` 项目知识：已经稳定、可复用、可被后续需求或实施引用的材料。

## 进入条件

满足下列任一条，才考虑从普通知识升级为 `KNOW-*` 对象：

- 是**稳定参考**，会反复被引用；
- 有**多个来源或附件**需要一起解释；
- 需要**采纳追溯**（谁在什么时候采纳了它）；
- 需要**长期迁移**（换平台、换仓库后仍要保留）。

一般知识用带中文标题的 Markdown 记录来源与适用范围即可，不必升级为 `KNOW-*`。

## 边界

- 内部结构按项目实际情况组织，不套用统一模板。
- 不复制协作包里的过程材料；知识库只保存已沉淀、可复用的结论。
