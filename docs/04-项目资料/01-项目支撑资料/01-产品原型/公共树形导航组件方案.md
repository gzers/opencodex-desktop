# 公共树形导航组件方案

日期：2026-10-27，Asia/Shanghai。项目 / 产品 / 端：opencodex-desktop / OpenCodex 桌面管理器 / Desktop。状态：用户已确认组件效果，并授权接回项目与对话原型；原型已采用，版本与生产实施待定。用户要求“这个组件重新设计下，在全局组件先做好，这个算是树形结构组件”。

唯一原型：[组件与样式 → 树形导航](原型/index.html#components?section=tree-navigation)，登记 ID 为 navigation.tree。现有 data.tree / PrototypeTreeTable 继续负责树表、勾选和配置比较；本组件只负责层级对象的导航与明确选择。项目→对话→子 Agent 的公共样例与业务页复用同一组件；本轮用户确认后已替换对话页旧树，样例数据仍与业务配置隔离。

## 交互与状态

| 项目 | 方案 |
|---|---|
| 展开与选择 | 箭头只展开，整行选择对象；只有分组而不可配置的行仅展开。父项目可以被选中。展开、筛选、刷新不自动选首项或写配置 |
| 视觉 | 图标区分项目、对话、子 Agent；18px缩进，叶节点保留箭头槽位。标准最小行高42px，紧凑34px；选中只用底色，不加左侧强调条，键盘焦点保留独立描边；状态使用短标签，数量保持中性色；完整名称可通过标题与当前对象详情查看 |
| 搜索 | 按名称 / 描述查询，命中子项时保留完整祖先路径，分组命中可展示其下符合筛选的对象。筛选展开状态与日常展开分开，清空恢复原有展开；搜索中也能手动折叠 |
| 隐藏选择 | 折叠 / 筛选后保留所选ID，底部显示当前隐藏选择，可定位并恢复路径；无结果也不改变右侧当前对象 |
| 键盘 | 树作为一个Tab停靠点。↑↓及Home/End只移动焦点；→展开或进入子级，←收起或返回父级，Enter/空格明确选择。Tab自然离开，焦点描边与选中底色分别表达 |
| 状态 | 空、读取中、失败、重试、长名称 / 长列表、多级与禁用均有样例；加载与刷新保留选择。失败仅重试fixture，不发起网络读取 |
| 操作栏 | 搜索及单一清除入口常驻；全部 / 专属 / 归档为业务适配器筛选示例，通用组件不固化业务字段。刷新与展开 / 收起放紧凑工具，不把使用说明塞进业务树中 |

## 复用边界

PrototypeTreeNavigation 消费稳定 id、parent、label、kind、可选 description/status/disabled/selectable，输出明确选择事件；层级校验复用既有树表契约。页面适配器持有业务数据、筛选、配置草稿与保存，组件只处理导航状态。搜索、筛选、展开与键盘移动不触发选择回调；目录暂时缺少已选对象时保留引用并明确显示，不静默换对象。

样例右侧工具可切目录场景、行密度、224 / 280 / 340px宽度和辅助描述；沿已有亮暗、画质、缩放及原型注释。该专题本身属于非功能文档，使用建议和键盘说明可直接展示；后续业务页面只消费组件与必要结果。

## 实际检查与交接

本轮直接修改唯一总原型并新增公共树形导航，登记与样例同源生成“组件与样式 → 树形导航”。既有树表、配置比较与对话业务没有因本轮被替换。

| 检查范围 | 方法与结果 |
|---|---|
| 层级 / 搜索 / 筛选 | 浏览器核对命中子 Agent 保留三层祖先、搜索无结果保留当前对象；折叠和专属筛选只改变可见范围，底部当前选择可定位 |
| 焦点 / 键盘 / 禁用 | ↑↓不选择，Enter激活，Tab离开；禁用对象不能激活。实际键盘焦点下Home/End只移动树内滚动，不滚外层页面。树有单一Tab停靠点及aria层级 / 选中 / 展开信息 |
| 状态和尺寸 | 读取中 / 失败重试 / 空目录仍保留选择；长列表在224px侧栏无横向溢出；深色、标准42px和紧凑34px实际检查；五层子任务正确显示 |
| 旧组件与业务隔离 | 原tree-table测试保持通过；component-topic接线检查覆盖目录、跨页面环境、旧选择器及业务内存不变。新导航不继承虚假的生产版本或采用状态 |

**19 项浏览器检查通过；26 项相关 Node 检查通过**，其中新增导航8项，其余覆盖树表、组件专题与注释零占位。JS语法和资料引用检查通过。浏览器截图与行为证据：[默认公共导航](../../../../.adg/evidence/COL-LOCAL-20261011-01/tree-navigation-20261027/screenshots/01-public-tree-navigation.png)、[224px深色长列表](../../../../.adg/evidence/COL-LOCAL-20261011-01/tree-navigation-20261027/screenshots/02-dark-224-long.png)、[浏览器检查](../../../../.adg/evidence/COL-LOCAL-20261011-01/tree-navigation-20261027/browser-checks.json)、[相关测试日志](../../../../.adg/evidence/COL-LOCAL-20261011-01/tree-navigation-20261027/node-tests.txt)。改动前快照与源摘要同目录保留。

初版检查时，原生读屏播报、生产大数据性能、真实异步目录读取及对话业务迁移仍未验证；后续用户确认与业务原型采用见下节，生产版本仍未分配。


2026-10-27 视觉批注修订：按用户“左侧强调条不要了”移除公共树形导航选中行的左侧内阴影，只用选中底色；键盘焦点仍有独立描边。浏览器选中文档网站后回读 box-shadow 为 none、aria-selected 为 true，截图见[无左侧强调条](../../../../.adg/evidence/COL-LOCAL-20261011-01/tree-navigation-20261027/screenshots/03-selection-no-left-bar.png)。本轮只改样式及缓存标记，选择、键盘和展开逻辑未变。


## 用户确认及项目与对话原型采用（2026-10-27）

用户回复“效果满意了，可以回去改原型”，确认公共导航效果并授权接回对话业务页。总原型 [对话 → 项目与对话](原型/index.html?design=conversations#conversations)已采用同一 PrototypeTreeNavigation 和共享导航外框样式，仍无选中行左侧强调条；公共组件专题保留独立 fixture。

| 页面 / 流程 / 状态 | 本轮调整与验证 |
|---|---|
| 项目 / 对话 / 子 Agent | 以project:与thread:稳定ID映射层级。默认展开本机项目与父对话，子Agent直接为第三层；点击返回原编辑器，未分配项目仅是分组。未改变配置继承来源 |
| 搜索、全部 / 专属 / 归档 | 使用同一公共查询与筛选逻辑；保留祖先路径，不自动选择或保存。专属同时包含已保存覆盖与未保存草稿；隐藏当前对象仍可定位 |
| 导航与配置重绘 | 复用原树根DOM，保存查询、展开、焦点与树内滚动。切换全局 / 项目Tab、字段编辑、保存或刷新不重建导航实例。程序同步选择不派发激活，明确再次激活当前项可重进窄窗详情 |
| 草稿、保存与生命周期 | 原单对象保存、失败保留、归档清理 / 取消归档不复活覆盖继续有效。重命名更新树内显示名但ID和草稿保持；恢复新增项目 / 对话 / 子Agent按映射加入导航并定位新对象 |
| 配置导入兼容修正 | 回归发现目标有与保存态相同的干净缓冲时，旧缓冲会遮住新导入值。导入成功仅清理这个已经确认不脏的目标缓冲；真正有未保存修改的目标仍按原逻辑拒绝，不丢输入 |
| 宽窄与样式 | 默认280px导航与详情并排；900px窄窗进入详情可返回列表，再激活同一项正常进入；亮 / 暗、树内无横向溢出、无左侧条实际检查 |

**45 项相关Node检查通过，19 项浏览器增量检查通过**。范围包括新增业务接线12项、公共树、旧树表、组件专题、版本切换、注释零占位与公共Tab。相关检查不等于全部产品功能或生产验收；前序其它渠道保存回归的未解决项仍由原维护线处理。
