## 交付内容

| 范围 | 已实现行为 | 验证与取舍 |
|---|---|---|
| 动画门控 | 仅在前台、可见、未最小化的概览续帧；切页、应用退出激活、隐藏或最小化时停止；返回后相位连续 | 原生事件与旧查询返回的竞态有回归；9 个状态、4 个时点的 SVG 输出与优化前黄金数据一致。切应用的原生 false 信号有自动化覆盖，未补成独立受控 GUI 采样 |
| 图形优化 | 缓存目标配色、复用计算缓冲；跳过完全相同的 SVG 属性和 WebGL uniform；尺寸变化才重设画布；销毁释放 GL 资源 | 保留原 shader、DPR、前台帧率与视觉公式。静态无续帧、资源释放和恢复计时有测试；短测未证明前台 CPU 降幅 |
| 状态采集 | 稳定运行时使用本地 `/healthz` 和 `/readyz`；完整 CLI 报告缓存 60 秒，手工刷新与来源变化重新诊断 | 验证 service、PID、端口、status、version 与 uptime 连续性；不接受仅端口存活。停止或无可信 PID 时仍逐次完整 CLI 检查，以发现外部启动；连接元数据最多缓存 60 秒 |
| 配置 | 周期、超时、退避、面板 TTL 和字节限额集中在 `tauri/config/runtime.defaults.json` | 构建期校验并嵌入；没有设置界面，也不支持编辑已安装文件后立即生效。字段必填、非零、上限与关联关系均有校验 |
| 托盘 | 先订阅事件再读取启动队列；事件即时处理，合并突发请求，在途去重，低频退避兜底 | 兜底默认 30 秒、最大退避 120 秒；原生菜单仅变化时写入，所有 setter 成功后才记缓存 |
| 面板回收 | 隐藏满 5 分钟后仅回收未编辑的子 WebView，重开恢复路径、hash 和滚动位置 | generation、隐藏状态与截止时间共同防止过期回收；任意 input/change 后保守保留页面，contenteditable 获焦也保护。该保护可能使编辑过的面板一直驻留 |
| 诊断与日志 | 命令输出上限 256 KiB，超时 kill 并 wait；日志只尾读最多 1 MiB，丢弃截断首行后脱敏 | Unix 独立诊断进程组回收测试通过；Windows 仅回收直接子进程，未实测后代进程。关键结果同步落盘策略保持现状 |

候选方案中的 shader 每帧预计算、SVG/WebGL 共用一个调度器、普通日志批量 fsync **未交付**，不记为已完成的优化。暂停隐藏面板不是向官方网页加入完整的可见性调度；本轮主要交付闲置回收。

## 同效果短时 CPU 对照

同一台 macOS 设备，暗色、高档、mesh 效果。两版 App 使用隔离 bundle ID、数据根、合成 CLI 与 HTTP 面板夹具，不承担真实 Bun 业务负载。统计核实过的桌面主进程及 WebKit 辅助进程；排除 `top` 首帧。100% 代表一个 CPU 核，不能当作整机使用率。

| 场景 | 有效样本数 | 桌面进程组平均 CPU |
|---|---:|---:|
| 0.1.6 前台概览高档 | 14 | 34.329% |
| 0.1.7 前台概览高档 | 14 | 36.057% |
| 0.1.6 隐藏 | 11 | 0.200% |
| 0.1.7 设置页 | 11 | 0.373% |
| 0.1.7 隐藏 | 9 | 0.022% |
| 0.1.7 最小化 | 11 | 0.018% |

可以确认本轮闲置场景接近空闲，不能据此宣称相比 0.1.6 节能 90%：旧版隐藏页面已被操作系统暂停，本机还有其他负载。前台 34.329% → 36.057% 是短时观测，既没有证明优化收益，也不足以判定性能回归。保留完整效果后，前台仍要持续计算与绘制；进一步降低该成本需图形剖析与等效方案的受控长测。

原先隐藏/最小化的部分尝试在取 accessibility snapshot 时重新打开并聚焦了 App，已从统计中剔除。有效隐藏与最小化采样期间没有获取 UI snapshot；最小化采样期间另有最终制品 smoke 启动，不能作为严控基线。未采集瓦数、续航、硬件 GPU 利用率、唤醒或 P95，不以 GPU 辅助进程 CPU 代替 GPU 硬件数据。

## 内存与代理连续性

一次 footprint 快照为 GPU 辅助进程约 129 MB、壳 WebContent 109 MB、主进程 39 MB、面板 31 MB、网络辅助进程约 5825 KB；共享内存有重叠，不能严格相加为应用总内存，不能与历史 Bun RSS/footprint 混用。

真实 GUI 验证了未编辑夹具面板离开超过配置的 300 秒后，其 WebContent 进程消失，HTTP 夹具与健康接口仍存活；重开恢复 `/web/nested#resume`，滚动条位置 `0.5002186`。输入 `PERF017 unsaved fixture` 后离开超过 413 秒再返回，文字仍在。它证明本轮回收与编辑保护在该夹具有效，不等于真实官方面板所有编辑流程已验收。

日常 App 与官方代理在验证期间保持运行，未安装替换或重启。只读健康/就绪核验和最终身份连续性记录见证据目录；这是运行边界核验，不把日常 0.1.6 的代理行为宣称为 0.1.7 接管后的实测。没有两小时、20 轮回收、固定持续请求或多设备测试，因此不宣称已排除内存泄漏或给出全应用内存降幅。
