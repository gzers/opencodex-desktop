## 3. 推导出的设计选择

| 设计建议 | 推导依据 | 尚待验证 |
|---|---|---|
| 共用发布清单、分别使用三类应用适配器 | 内容分别是模型策略、文件包、服务描述 | 每类生产目标的读取 / 写入 / 恢复 API |
| 所选策略携带精确模版依赖 | 前序模型方案已明确 templateId + revision | 命名空间映射、局部导出与跨源引用的生产 schema |
| 来源完整性与来源可信度分别展示 | 摘要只能核对固定内容，不能证明行为安全 | 首期认证下载与命名空间；未来签名、密钥轮换另定 |
| 自动检查与手动采用分开 | 三类内容都有依赖、本机条件和可能的执行影响 | 是否以后支持获授权的特定安全更新自动应用 |
| 内容权限独立于用量采集，复用团队身份 | 服务端包已补入团队与成员期，统计与内容的可见范围不同 | 源授权、成员变更撤销、重新加入与内容保留闭环 |

本轮所有接口、层次、默认值与分期均是派生建议。没有访问真实订阅源、注册账户、发布配置、安装 Skill、启动 MCP 或验证生产跨设备行为。
