# 0.2.21发布后同步与全局玻璃材质修复

2026-11-04，Asia/Shanghai。来源为[0.2.21问题清单第8节](../../04-项目资料/01-项目支撑资料/06-问题记录/0.2.21-bugs.md#8-0221-发布后新增反馈2026-11-04五项未关闭)。逐项状态与发现证据只维护原编号S21-POST-01至05；本DMD拥有修复范围与验收，[IMP-30](../../03-开发实施/IMP-OPENCODEX-DESKTOP-30.md)拥有顺序、分工与合并依赖。旧DMD-UI-021、IMP-29和发布证书保持完成，不重新挂靠。

用户本轮采用：先把清单/计划写好；Windows负责全局“透明而无玻璃”原因排查和修复，本机处理其余问题；Windows回交后统一合并处理发布。本轮交付为计划和Windows提示词，尚未开始产品实现。后续贡献线不得独立发布或抢先关闭整版。

## 基线与采用边界

- 发现版0.2.21；修复发行版本尚未定号，集成冻结时统一落实。不得覆盖v0.2.21、沿用其制品冒充新修复或自行把本批命名为0.2.22。
- 两线共同代码起点为origin/main / 7a8441f7e647e4b3540d5907e44ac4f186f90998，其Rust/UI产品源与已发布v0.2.21相同；已知验收辅助源b707c1fe8c4d7935246f13e0bb42ac0604c62687已在该主线历史内。开工须确认精确提交，不按本地陈旧origin/main推断版本。
- 视觉沿用旧DMD-UI-021已冻结的0.2.21采用集、UI规范及现有三档材质；总原型当前工作区含其它对话的未来功能，不整包采用。原型来源仍取旧DMD明确列出的采用摘要，不另造一套玻璃风格。
- POST-02从同步弹窗扩为生产全部共用玻璃表面，属于本轮明确采用的范围扩大。外壳/页面原本不应模糊的材质维持原分类，原生系统选择器、官方内嵌页面不强行套管理器材质。
- POST-05采用已配置连接启动只读检测，替代旧AC-021-05在本批范围内的“不新增自动联网”；不把这一授权扩成自动同步或日常真实WebDAV操作。无配置不请求，失败可重试；不得用会写业务/初始化范围的完整同步命令冒充只读版本检测。
- 首次全选、后续新增不自动选、13px正文字号及100%缩放语义、公共弹窗退出/焦点/任务守卫、真实内容保存时间、强ETag/CAS和连接修订隔离继续保留。

## 实施与验收解释

POST-01已发现首次初始化顺序缺口，但用户Windows“无需同步”现场根因仍需用所选范围和实际指针核对，不得只修首次入口就宣称所有误判解决。POST-03“提交后短暂缺ETag”仍是待验证现场假设，须先用隔离服务注入，再决定恢复实现。POST-02在macOS无头WebKit的实验仅证明CSS支持不等于实际渲染，不是Windows原生证据。

UI/状态若需新增表现，先在唯一活动原型按本DMD补齐适用状态并冻结本批差分，再接相应软件消费者；不修改原型迁就缺陷，也不采用并行全景概览、多Agent、额度等未来功能。Windows材质修复若只是恢复已采用配方，不要求重设计；若确需改变风格、交互或档位定义，先回交集成线处理采用差异。

隔离目录、合成凭据和测试WebDAV用于验证；不修改日常配置/凭据，不运行日常真实同步，不重启日常Codex。正式TASK开工时绑定本DMD适用AC与IMP-30，不复用旧已关闭TASK。当前仅计划就绪，所有验收待实现与实际取证。
