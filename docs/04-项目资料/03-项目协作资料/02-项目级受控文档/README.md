# 项目级受控文档

## 状态

**暂未启用。** 本目录是预留槽位，当前没有任何受控文档。

## 用途

保存 `CDOC-*` 项目级受控文档：正式方案、对外交付件、签署台账，以及需要版本控制的交付材料。

## 进入条件

只有同时具备下列要素时才在此建立受控文档：

- **受控主版本**（当前生效版本）与**父版本**（被替代的版本）关系明确；
- **原始件摘要**（如文件 SHA-256）；
- **审批状态**与审批责任主体；
- **存放位置**与**保留期责任**。

## 边界

- 一般材料、过程草稿、截图证据不放这里；它们属于协作包（`01-协作包/`）或项目支撑资料（`01-项目支撑资料/`）。
- 官方来源素材不随仓库分发，受控文档不得包含官方源码、构建产物、图标或界面素材。
