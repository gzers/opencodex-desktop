## 分析与结论

白屏与左键菜单无响应分别分析。故障时 AX 能读到页面、切换路由有效且脚本请求成功，用户仍看到白屏；完全重启恢复。原生绘制/合成状态异常是较强嫌疑，首次触发和准确组件责任尚未确定。左键不弹菜单有明确配置依据：showMenuOnLeftClick=false，右键成功与之吻合，不能归结为同一白屏根因。

源码另有窗口恢复、调用失败记录、WebGL 运行中上下文恢复、独立原生重载入口、启动错误覆盖、托盘前端桥接、原生面板并发与制品追溯等缺口。详见逐项分析，不把静态风险写成事故已证根因。当前可检查的 Tauri 实现已有 WebContent 终止自动重载，不能笼统说它没有崩溃恢复。
