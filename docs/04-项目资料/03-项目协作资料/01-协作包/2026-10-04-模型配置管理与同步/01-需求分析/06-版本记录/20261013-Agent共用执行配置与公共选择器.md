# Agent 共用执行配置与公共选择器

日期：2026-10-13（Asia/Shanghai）。项目 / 产品：OpenCodex 桌面管理器，Desktop。归属：COL-LOCAL-20261004-01。状态：总原型业务接线完成、源级检查通过，实屏待验，生产实现未开始。

用户询问 Agent 模型配置是否全局，指出全部更新和单个更新均涉及 Agent，并要求采用“渠道模型选择器原型专题”的弹窗组件选择模型和推理等级；该组件已明确在 0.2.0 开发范围内。

## 范围与唯一入口

唯一原型：[总原型 #models](../../../../../01-项目支撑资料/01-产品原型/原型/index.html#models)。公共专题：[同一总原型 #model-picker](../../../../../01-项目支撑资料/01-产品原型/原型/index.html?design=models#model-picker)。不另建可编辑副本，组件规范仍由 [公共渠道模型选择器交互方案](../../../../../01-项目支撑资料/01-产品原型/公共渠道模型选择器交互方案.md)维护。

共用范围是“本机模型模版 Agent”：所有模版的自动填充 / 持续纠偏、单个更新、勾选更新、全部更新共用同一执行渠道、型号、显式推理和 Fast 偏好。切换模版和更新范围不另建执行配置。它与 Codex 的命名、搜索和子 Agent 策略分开；外部 Agent / CLI 使用自身设置。当前仅内存保存，正式拟存 preferences.modelTemplateAgent 的本机分区，默认同步 / 导出过滤仍待实施。

## 各入口与行为

| 页面 / 流程 | 本轮修改 |
|---|---|
| 模型模版详情 / 编辑 → Agent 面板 → 顶部执行模型 | 标记“本机共用”，打开同一份共用设置 |
| 模型模版列表 → 全部 / 所选更新 → 首次配置 | 同一共用设置；保存后继续原请求范围，不另存批量专用模型 |
| 设置 → 模型配置 → 配置 / 调整 Agent | 同一共用设置，说明四类功能共用；不改模版规则和渠道草稿 |
| 共用设置 → 模型与推理 | 三个独立下拉替换为公共弹窗入口；左渠道 / 右模型，搜索排序、底部已选标签及推理玻璃浮层均复用专题 |
| 单选返回 | 返回 channelId + modelId 和可选 reasoningEffort 到设置缓冲；仍由保存共用设置提交。取消选择回原缓冲，取消设置保留之前保存值 |
| 默认推理 / 显式推理 | 显示执行模型已保存规则解析后的实际默认；未额外选档不固化该显示值，恢复默认清除覆盖，显式 none 与继承独立 |
| 可用性 / Fast | 执行连接来自已保存目录；无需加入 Codex 白名单。停用、无额度、端点待绑定 / 冲突、原生未绑定标明原因；选择返回和保存设置均再核对。Fast 仅明确支持时可选 |
| 任务执行中修改设置 | 自动填充与更新在开始时冻结执行参数和有效默认，改设置只影响下一个任务；取消 / 晚回和版本基准规则继续沿前序流程 |
| 公共组件专题状态 | 业务调用不切换到专题路由，不改专题已选、模式、场景及推理开关；离开业务页关闭选择，不重新打开旧设置 |

原型接线新增的 choose 接口由公共 model-picker.js 持有；model-config.js 只提供用途、当前引用、已保存有效规则与可选性，接收返回后完成业务缓冲 / 保存。选择器不承担真实执行模型调用、凭据读取、持久化或同步。
