## 本版交付口径

1. 当前渠道数据由实际官方 config.json 读取。编辑在内存，保存预览展示拟写内容，确认后备份并原子写回；旧管理器计划、运行目录是否一致不作为普通文件保存的资格。保留基础格式校验和真实写入冲突保护，不恢复用户核对工作流。
2. 已有 Key 在编辑器加载并默认掩码，眼睛切换明文；仅修改 Key 也可保存，保存不依赖清单请求成功。保持原值、替换、清空分别表达，秘密不得进入日志、公开快照或证据。
3. 测速与获取清单共用协议路径归一化。根地址、版本路径、完整清单地址和自定义前缀均处理；HTML/路径不存在时有限同源候选回退，成功必须是有效清单。
4. “立即重启”复用官方面板独立重启能力，解析真实 desktopApp 结果；缓存未改变也不能静默跳过用户重启请求。真实重启会中断当前对话，自动验证采用受控测试适配器，不在 agent 活跃宿主上强行重启。实际设备重启验收若未执行必须列明。
5. 通知统一作为本版必做项：同一铃铛入口、原型既有短提示/任务卡/通知列表、同一全局宿主和材质按钮配方。删除底部保存卡、额外展开入口、面板内自创清理确认卡；清理沿用已有确认弹窗。保存成功一次反馈，“稍后”即结束，无待重启/客户端核对状态复活。

## 写入分工与集成

| 范围 | 责任 | 约束 |
| --- | --- | --- |
| 文件权威读取、保存、Key 编辑与接口、命令接线 | 主集成线 | 负责 UI/后端合同及最终合并 |
| discovery 路径与响应处理 | 测速贡献者 | 仅修改 discovery 相关模块和对应测试；不修改命令接线与公开 api.ts |
| 通知前端、原型样式消费者 | 通知贡献者 | 不修改 ChannelsView、ChannelEditor、api.ts 与后端；提供主线调用合同 |
| 官方重启后端 | 重启贡献者 | cache_refresh、management 对应代码与测试；不修改命令注册 |
| 唯一原型 | 原型贡献者 | 只修改已分配原型文件和原型测试；不修改核心事实或共享索引 |

原型入口、model-config.js 和依赖属于一次独占写入范围，由原型贡献者修改、主线整体验收；不同贡献者不得编辑同一路径。

| 检查 | 通过判据 |
| --- | --- |

| review:key-save | 载入/眼睛/只改 Key/清空/离开重开正确，离线也可写；无凭据泄漏 |

| review:release | types、相关行为测试、后端 fmt/clippy/回归、原型回归、完整操作 QA、CI 与制品签名均有结果 |
