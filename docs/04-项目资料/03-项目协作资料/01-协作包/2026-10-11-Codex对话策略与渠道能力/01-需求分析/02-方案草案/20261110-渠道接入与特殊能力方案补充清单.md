## 核对发现

本轮主要规则已有原型专题记录，但协作包方案列表、旧接入方案、配置候选清单及实施输入缺少统一关联。旧资料的Ultrafast／WebSocket／笔记结论必须限定到对应版本、认证和链路；不能从最新mock画面反推真实服务状态，也不能从旧代理限制否定新域名原生直连结果。

## 已确认设计需要带入方案的内容

下表“原型已接入”仅指内存交互；每行生产接入均未完成。细节和历次验证继续归交互方案，不在这里另计测试完成率。

| 项 | 方案应保留的规则 | 原型／后续承接 |
|---|---|---|
| 1. 凭据与认证 | API Key／PAT／无需认证使用一个凭据类型，和输入框同组；选择站点或普通调用成功不自动证明原生身份成立 | 表单已接入；真实身份适配、秘密引用及允许接入方式待实现 |
| 2. 节点与地址 | 站点适配提供默认接口规则；模型基址／清单、原生服务前缀和可选压缩路径覆盖归同一节点；两处编辑互相保留，不维护两份配置 | 原型同源路径编辑已接入；正式Schema、迁移和适配器注册待定 |
| 3. 请求地址派生 | 模型协议继续来自模版／单模型；Fast、Ultrafast复用模型请求，WS复用响应接口；原生前缀派生多条history／notes接口，后台调度不虚构独立URL | 地址预览已接入；协议端点兼容及真实路由消费者待实现 |
| 4. 节点操作入口 | 备用行依次“设为当前／测速／特殊能力／删除”，当前节点删除受保护；名称进入编辑；无底部重复检测按钮 | 行内操作已接入；公共列表／原生客户端验收待迁移时核对 |
| 5. 特殊能力弹窗 | 从节点行进入后固定只读节点名称、地址和凭据类型，不再选节点；集中配置请求地址、身份与能力验证，详情显示实际地址和来源 | 已接入；不是节点传输偏好开关，不替代全局对话策略 |
| 6. 模型来源与结果归属 | 型号选择仅在型号能力分组，复用当前渠道唯一清单，包含尚未启用的型号；型号结果分别保留，节点／身份条件不因换型号重复丢失 | 已接入；实际解析协议、引擎条件的完整结果绑定仍未实现 |
| 7. 配置顺序与空清单 | 允许先建空渠道、配置节点／路径再读取模型；无型号可先认证或检查适用链路，型号项目禁用，手动加入后立即可引用 | 协作包原型已接入；普通模型范围保留原有创建规则 |
| 8. 状态分离 | 认证、支持依据、当前使用条件、配置是否保存及执行端是否采用分别表达；不支持／未知／服务失败不可混用 | 原型已分离；全策略消费者的实际激活校验待接入 |
| 9. 草稿与验证 | 地址先留弹窗本地，“加入草稿”才改节点，再保存渠道；取消／关闭丢弃未加入编辑；未确认地址修改期间不认证／验证，验证不自动保存、切节点或启用型号 | 已接入；正式事务、失败恢复及跨页长任务生命周期待实施 |
| 10. 失效与并发 | 地址、凭据、接入方式变化后对应结果需复验；名称变化不失效；停止后的迟到结果不得覆盖新轮次 | 节点连接和代际已模拟；模型最终协议、引擎／代理版本变化的失效维度仍待补 |
| 11. 实例接入与采用 | 依赖功能必须沿实际实例的同一渠道、节点、身份及远程状态；不能模型走A、笔记借B；绑定／保存／模拟重连不代表执行端已采用 | 绑定及共享来源提示已接入；所有策略入口的激活限制、实际采用读回未完成 |
| 12. 模型列表收简 | 型号下仅显示已确认支持的能力名称，不重复写支持／不支持；别名独立列按数据行居中；直接展示模型列表，移除重复能力结果Tab，完整结果归节点弹窗 | 已接入；不支持及未知原因仍可在节点弹窗查看，不能因无标记就断言不支持 |
| 13. 复制、同步与故障切换 | 复制设置不复制认证／实测结论；同步导入不能把源机器已运行、身份通过当目标机事实；故障切换不凭同站点名迁移笔记或原生压缩状态 | 复制观察隔离有原型；特殊设置同步、便携范围和远程状态延续仍是方案，未实现自动切换 |
| 14. 验证范围与失败 | 网络失败保留支持依据，404记录具体接口与时间；不把静态声明、公开目录200、本地空提示或重启当完整功能通过。生成验证可能产生用量，笔记实际写入需独立明确范围 | 原型仅模拟且不写笔记；真实用量、读写及完整续聊检查按专项授权与证据执行 |

## 后续实施必须保留的未完成项

这些是候选实施输入，不是已开工任务；没有新建DMD、IMP或TASK。

| 顺序 | 待实施事项与依赖 | 完成判断 |
|---|---|---|
| A | 正式接入契约：节点路径／凭据引用／协议解析／适配规则，复用模型配置保存与现有所有者；禁止把原型字段直接视为生产Schema | 在隔离环境核对真实目标地址、协议、身份；取消不写入、保存可读回，既有路径兼容明确 |
| B | 认证与能力观察：依赖A，区分支持依据和本机条件；按节点、身份、型号及最终协议、引擎／代理版本绑定结果 | 改动只使适用结果失效；网络失败、停止、晚回和新检查相互隔离；其他节点／型号结论保留 |
| C | 对话策略消费：依赖A／B与实际执行端连接；同一实例接入、功能启用条件、保存后待连接及实际采用读回 | 界面不能绕过缺失身份／服务条件新激活；模型和笔记不跨身份；有效配置与实际采用分别有记录 |
| D | 持久化／同步／导入：依赖A／B及既有同步owner，确定可携设置、本机绑定和可重建观察边界 | 新机器需本地核对，旧认证不冒充目标机事实；失败／取消／恢复保留原设置 |
| E | 故障切换与状态恢复：依赖C／D及实际服务能力，明确不可延续时的用户提示与恢复点 | 不兼容节点不能静默接续原生压缩或历史笔记；失败不删除用户策略和会话恢复信息 |
| F | 正式客户端验收：按采用设计迁移共享组件，覆盖宽窄窗、亮暗、键盘、取消／失败／重开及升级 | 真实配置写入、回读与代表执行流程通过；Chromium原型截图不能替代原生／WebKit和产品验收 |

以下尚未决：正式字段名和缓存保存策略、引擎／协议版本修订身份、特殊路径适配边界、原生状态跨节点迁移方式。当前不新增固定缓存有效期、不自动对全部功能付费探测，不把临时mock选项冻结为生产规则。
