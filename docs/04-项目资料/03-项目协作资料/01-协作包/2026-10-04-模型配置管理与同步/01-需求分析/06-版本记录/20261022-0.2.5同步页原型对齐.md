# 0.2.5：同步页按原型对齐、导出可选保存路径、Agent 配置页补完整态

2026-10-22，用户在 0.2.4 装机后连续反馈三组问题：导出不能选路径、文件同步与 WebDAV 页按钮位置与右栏结构偏离原型、Agent 配置页缺“已配置模型”的效果且本页留白过多。本文登记结论、改法与验证。

## 决策

用户明确：“完全按照原型，不要扩散思维，原型本身就是确认过的。”

因此同步页以原型 `sync-config.js` 的目标态为准，不做取舍讨论；原型没有的入口一律移除，原型已删的旧入口不自行加回（含恢复上次接收、重新读取范围目录、读取扩展目录、预览上传、查看原上传计划、导出来源）。

## 导出可选保存路径

- 确认导出对话框新增“保存位置”：默认导出目录，另有“选择目录…”与“恢复默认”；未选择时保存到默认导出目录。
- 后端 `model_transfer_export` 新增可选 `target_dir`：绝对路径校验、目录存在校验，非受管目录不覆盖同名文件；仍做读回校验。
- Tauri 能力清单补 `dialog:allow-save`。
- 附带修复：导入按钮原先被 `!hasScope` 禁用，导致未选导出范围时无法导入；改为只要求已读取工作区。

## Agent 配置页（原型侧）

- 工具板新增 `settings:models` 演示卡（页签标识是 models 而非 agent），可在“尚未配置 / 已配置模型”间切换内存投影。
- 已配置时铺开四项事实（执行渠道 / 型号 / 推理档位 / 快速模式）、适用范围与运行配置边界；未配置保留空态说明。
