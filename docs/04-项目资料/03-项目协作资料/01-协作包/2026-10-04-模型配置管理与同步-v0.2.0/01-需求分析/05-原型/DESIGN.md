## 组织与视觉

[完整主原型](../../../../../01-项目支撑资料/01-产品原型/原型/index.html) 复用现有桌面壳、主题、玻璃令牌、通知和弹窗。左侧增加两字菜单“模型”及三层叠片线框图标，位于面板之后；顶栏标题“模型配置”，两个同级 Tab 为“渠道模型”“模型模版”。图标、菜单短名仍是展示候选；当前布局已按“列表优先、详情按需打开”补绘。排序融入渠道页，历史、导入、生成和同步按需打开。

标准窗口 1180 × 760；紧凑窗口 900 × 600。渠道页首屏是全宽渠道表，不常驻渠道侧栏、模型表和选择器预览；点击渠道进入带可收起内部锚点导航的模型详情，返回回到列表。模版页首屏是全宽模板表，行内“编辑”直接进入候选表单；名称 / 已引用版本保留只读预览，编辑器右侧五区连续展示、共用主内容滚动；内部可收起锚点导航点击定位并随滚动高亮，左侧导航下独立按钮区依次提供“Agent 自动填充 / 匹配预览 / 与主版本比较 / 更多操作 / 设置”，收起保留图标、tooltip 和可读标签；返回图标、可编辑名称、候选状态及版本操作合并为一行标题；Tab 滚过后标题贴住主内容区顶部，左侧导航和锚点定位随实际标题高度调整。名称在标题直接编辑，基本信息只保留说明。Agent 由左侧首个文字按钮打开非模态对话面板；编辑页顶部不再重复放设置 / 更多或 Agent 条，也不显示右下启动器。窄窗口沿用同一列表和详情返回路径，收起次要表格列；模型 ID 在详情有全文。共用令牌沿用亮 / 暗和高 / 中 / 低档，无新增分栏竖线。

共享目录是用户确认的项目专属例外：全局设计流程默认把每次原型放入 COL，本项目只把持续维护的完整主原型 / 必要资源放在共享区，增量、评审和证据仍在对应 COL。责任、来源和保留策略见 [共享区说明](../../../../../01-项目支撑资料/01-产品原型/README.md)，迁移处置见 [执行记录](../06-版本记录/20261004-共享迁移与0.2.0补绘.md)。

全部下拉统一由 [Select 样式](../../../../../01-项目支撑资料/01-产品原型/原型/select-component.css) / [控制器](../../../../../01-项目支撑资料/01-产品原型/原型/select-component.js) 管理：原有 13 个自定义 Select 与 33 处原生单选声明（含动态表单）复用同一触发器和菜单，业务 CSS 只管布局。触发器使用 control-md、text-control、radius-sm 和 space 令牌；菜单材质继续由既有玻璃 / 低档规则控制。原生控件隐藏作为 value / change backing，不产生重复 Tab 入口。

菜单展开时挂到 body，支持时使用 manual Popover 的 top layer；兼容宿主使用原型专属 z-select 令牌，关闭还原原属主。菜单脱离卡片 / 模态内容滚动裁剪，而非在卡片内抬高层级。只开一个，支持边缘翻转、可用高度滚动、长 ID、禁用选项、方向键 / 首尾 / 文字查找、选值回调；Escape 先收下拉，Tab 收起后继续原生导航。路由 / 弹窗切换和属主移除收起菜单。当前 DOM 顶层方案不承诺覆盖独立原生 WebView；源码检查不能证明真实 CSS / 焦点表现。详见 [本轮记录](../06-版本记录/20261004-统一下拉组件与顶层浮层.md)。

## 渠道与选择器

示例渠道 NewApi 发现 30 / 选择 17，A6api 104 / 32，Aimami 12 / 8，原生来源 6 / 6。初始投影 89/100 由基础项 63、独立 Fast 项 24 和不可管理的隐藏项 2 组成。这是可重复的预算 fixture，不代表本机实时目录或真实模型能力。

列表层承载搜索、启用开关、独立可用性提示、数量、选择范围和进入详情；自定义行内“管理”同时覆盖渠道配置、模型默认与单模型设置，另有“删除”，原生只提供“查看”；详情层承载模型搜索勾选、族筛选、推理 / Fast / 共用设置和组内排序；完整选择器预览只在“预览选择器”中打开。该层级参考 NewAPI 源码中渠道表、搜索 / 批量操作、分区编辑和上游模型勾选，也参考 AiMaMi 只读检查到的简洁模型获取表单；两者只作为交互层级依据，不代表复制其实现或凭据流程。

列表工具栏采用左侧搜索、右侧紧凑操作组：渠道的“新增渠道 / 预览选择器”和条件出现的“清除选择”放在同一组，按钮按内容宽度排列，组内间距统一为 space-2（8px），搜索与操作组的最小间距为 space-3（12px）。模版列表共用该布局；空间不足时操作组右对齐换行，组内仍保持固定间距，不把剩余宽度分散到每个按钮之间。该响应式规则已写入 CSS，实际窗口布局待视觉验收。

启用列复用公共 Toggle，提供原生 button、switch 语义、渠道名可读标签及启用 / 停用文字；未保存状态由当前页统一表达，渠道详情移至左侧导航底部，行内不再重复，保存中禁用。切换进工作区草稿，支持撤销 / 重做 / 丢弃；页级保存差异单列启停，成功后仍须重启 / 核对。原生组显示“官方管理”，源码也阻止伪造原生切换动作。紧凑 CSS 保留该列，切换后尝试恢复开关焦点；视觉、键盘 / 焦点及辅助技术尚未验收。

模型选择与发布投影已分开：停用只改变 enabled，保留白名单数量 / 勾选、all / none 模式、顺序、引用与字段，仍可编辑；projection 仅展开启用渠道，停用贡献为 0（含独立 Fast 项）。再次启用完整恢复投影并重算全渠道预算，超限继续阻止保存，不自动裁剪或关闭 discovery。

可用性提示放名称下，候选为“未验证 / 连接检查通过 / 无额度 / 认证失败 / 连接失败 / 上游不可用”；A6api 固定“无额度（手工）”，其余示例为未验证，没有实际连接 / 额度检查。发现中的获取中 / 失败 / 空清单与可用性独立。该本机 availability 摘要从便携导出及模拟 baseline 剔除；检查时间 / 证据及绑定状态仍待正式实现。完整状态维度以 [交互契约](../02-方案草案/模型页交互细化.md#启用开关与状态分层) 为准，不把枚举展示当作生产 schema 冻结。

查看某渠道不会把它加入批量范围；渠道表复选框和条件出现的“清除选择”负责渠道操作范围，移除重复“全部渠道”按钮。模型复选框只选择批量目标，表头选择当前筛选结果并保留筛选外选择；清除过滤后表头可选当前渠道全部模型，启停使用独立开关。批量工具栏仅在存在勾选时出现，移除操作范围下拉和“0 项”；已选总数与筛选外数量仍用于明确真实影响。搜索原始 ID / 别名 / 显示名称、族筛选与“仅启用”不改策略。官方 / 原生只读。discovery 保持开启。原有 fixture 渠道刷新主要更新模拟发现元数据；新增演示渠道刷新合并完整 fixture，保留旧位置 / 启停、追加停用新项，不关闭发现。

渠道表头增加公共复选框，源码设置 checked / indeterminate 和 mixed 语义，支持未选 / 半选 / 全选；选择只作用当前结果，保留搜索外选择；清除搜索后表头可选全域，无重复全域按钮。无可管理结果时禁用，原生不参与，选择不改策略。已选范围显示总数及搜索外数量，批量栏紧凑排列启用 / 停用 / 删除 / 按族配置 / 套用模版。启停一次进入草稿并可一次撤销，同状态禁用且不加空记录；保存中锁定选择和批量改动。复选框重渲染后尝试返回焦点，实际键盘与辅助技术仍待验。

单行删除固定为当前行，不带入其他已选渠道；批量删除才取完整选择范围。两者共用已有 btn.danger 和公共确认弹窗，列完整渠道 / 模型数量及搜索外范围；涉及 Agent 时说明保存后的失效。确认冻结目标和配置摘要，过期拒绝；只删草稿渠道 / 模型策略，保留模版库和 Agent 偏好，清理已删范围并修复当前详情。撤销 / 重做 / 丢弃可恢复，保存列移除差异且待重启。保存后 Agent 提示执行渠道已删除或不存在，生成禁用；保存前仍依据 saved，不提前清空偏好或切换渠道。

成功记录的影响范围恢复现已补回被删除渠道的内存配置，按原相邻位置插入，保留无关渠道顺序和草稿；已存在同 ID 则保留现对象，正式接入需展示冲突。完整回到记录之前另选，恢复仍须页级保存。内存 connection 摘要恢复不证明真实凭据 / 绑定或运行注册可恢复；正式删除、清单晚回、多机删除合并与受管补偿未实现，仍承接既有保存 / 同步技术门。

渠道拖动 / 上下移移动整组；模型只调整当前组。选择器预览按渠道顺序逐组展开内部模型顺序，Fast 跟随父项。取消再勾选不丢排序位置；筛选不改变底层顺序。原生模型详情只读，不用虚构上游渠道写入能力。

## 新增渠道与渠道配置

渠道表顶部新增“新增渠道”。现有自定义渠道详情的“渠道配置”在正文直接展示连接表单，“协议端点”和“模型默认”分区连续可编辑；导航只定位、不把字段藏入入口弹窗。新增仍用两步向导，按公共表单组织名称 / 稳定 ID、默认接口协议 / Base URL、认证 / 密钥；两个新下拉沿用公共 Select 的 DOM 顶层菜单。协议范围为 Responses / Chat / Anthropic / Google AI Studio / Ollama，认证为 API Key / 无需认证，其他类型不冒充支持。

第二步用户点击“获取模型列表”后模拟完整 8 项，全部初始未选；可搜索、仅已选、结果勾选 / 取消、手动输入精确 ID 去重。失败 / 空 / 401 / 无清单接口有独立场景；正在获取时禁加入、可取消等待。关闭、变更目标和取消使晚回失效；同连接返回保留选择，编辑未变目标保留当前有效 all / 白名单集合。新渠道末尾追加，加入只改草稿，页级保存提交并标记待重启，超预算仅阻止保存，不截清单。

能力声明为空 / unknown，按 ID 的族提示不当支持证据；已有明确全局模板仍可能参与继承，来源须说明为模板。内存 connection 摘要只含虚构 URL、认证类型与已配置布尔，密码输入在前进 / 关闭清除且不存 state / timer / 记录；便携导出及其模拟 baseline 都剔除 connection / 演示新增标记。该聚合 mock 不等于双文件生产 schema / 持久凭据。

现有本机 API 不支持未保存连接获取完整 ID，正式 preview、真实凭据暂存与注册 / 白名单 / 绑定受管保存尚未实现。当前无实际渠道注册、模型请求或能力测试；UI / 焦点 / 密码可访问性待真实验收。完整契约与新增门见 [本轮记录](../06-版本记录/20261004-新增渠道与模型获取.md) / [G-09](../03-确认与评审/协作包逻辑审计.md#6-新增渠道范围与技术门追加2026-10-04)。

## 共用设置与推理

渠道、族、单模型与模板使用相同能力 / 推理 / 快速字段编辑方式，每个字段独立“继承 / 自定义”，并显示解析值与来源。字段包括上下文窗口、输入模态、可选推理档位、默认推理档位、Fast 能力和请求策略。恢复继承只改当前编辑缓冲，取消不提交。

“覆盖推理强度”不必选：可以继承可选档位列表，只把默认档设为中档。默认必须属于最终可选列表；未知能力保留未知。隐藏推理选择、强制请求和不传推理参数另放高级项，不能由默认档或名称推断。非法上下文 / 默认值就地阻止确定。

按族批量操作先明确全部或部分自定义渠道，预览差异；默认保留单模型例外。模板采用引用精确版本，渠道族 / 全局族引用分开；设主只改以后选版的默认指针，不自动改变现有渠道引用。

Fast 能力、Fast 请求策略和是否发布独立 Fast 选择器项分开。配套设置继续使用已有 Fast 开关语义，与渠道页共用草稿；独立 Fast 项跟父项并占预算，不以开启请求策略凭空增加能力。

## 草稿查看

渠道列表顶部、渠道详情左侧导航底部始终提供“查看草稿”，当前列表 / 详情就是正在编辑的工作区草稿。弹窗比较最近成功保存与当前草稿，不受搜索、族筛选或批量范围限制；按全局设置和渠道分组，以“配置项 / 已保存 / 当前草稿”呈现具体变化，涵盖新增 / 删除、连接摘要、启停、白名单、顺序、引用和各层推理 / Fast 字段。移除模型例外显示恢复“继承”；长清单可展开完整值，所有名称 / 精确 ID 转义。

现存渠道可从分组回“管理 / 查看”，删除项无失效链接。无改动时显示“暂无未保存改动”，待重启独立保留。“继续编辑”返回，合法且未保存中时“去保存”只打开原有确认；超预算仍可查看全量草稿，不提供提交。保存确认“查看逐项差异”复用同一对比。查看不写配置、不改变撤销或重启状态；窄弹窗按两列值加字段标题排版，CSS / 焦点待验。

连接差异只显示 URL、认证方式和密钥是否配置，不显示输入值。当前 mock 未保存秘密或密钥身份，不能比较两次均已配置的密钥更换；正式服务需要不含秘密的变更摘要。它是当前内存差异页，持久草稿仍待实现。

## 保存与状态

| 状态 | 页面表达与出口 |
|---|---|
| 草稿未保存 | 即时预览、全渠道激活数；“保存”进入差异 / 依赖 / 预算确认 |
| 100 项 / 超过 100 项 | 100 可提交；101 保留完整草稿并阻止保存，显示组成与收窄入口 |
| 保存进行中 | 冻结计划 / 模板快照、显示分步进度；关闭进度不取消，写前取消与写后停止分开 |
| 写入前失败 | 草稿保留，可查看原因后重试 |
| 部分写入 / 超时 | 不显示成功；提供核对和模拟补偿 / 停止出口，记录不是成功恢复点 |
| 已保存待重启 | 已提交策略与当前新草稿可并存；提示手动重启 Codex，不自动关闭会话 |
| 客户端核对 | 单独演示匹配 / 不匹配 / 待验证；目录读回不直接当作客户端已加载 |
| 基准漂移 | 原确认计划失效，重新查看差异和确认；不会无提示覆盖外部变化 |

本次保存、备份、读回、补偿及客户端核对全在内存模拟；没有实际 API 调用或进程操作。记录包含成功、partial 和模拟核对状态，恢复先生成草稿，再经同一保存流程。

## 模型模版、编辑内生成及外部 Agent

模版本身定义一个用户创建的族，以稳定 templateId 标识，名称自由填写；预置 GPT / Claude / Gemini / Qwen / DeepSeek / Grok 只是起始例子。首屏仅有搜索、多选、主版本 / 数量和“新建模版 / 外部 Agent 配置”。新建可空白起步或复制例子，未保存不产生空库对象；列表行内“编辑”直接打开候选表单，有缓冲则继续原编辑；名称 / 已引用版本入口保留只读详情及“编辑为新候选”。打开编辑不新增版本或改变采用引用，保存才入候选库。缓冲可返回列表再继续，编辑中先保存 / 取消才做版本操作。

编辑内容包括名称 / 说明、版本化匹配、协议、上下文 / 输入模态、可选 / 默认推理、Fast 能力和高级请求策略。字段独立继承 / 自定义。匹配包含精确 ID / 前缀 / 通配包含和排除、大小写、渠道全部 / 白名单 / 黑名单及整数优先级。全部包含未来渠道；空白名单不匹配任何渠道，空黑名单允许全部。切模式保留勾选，旧数据缺模式按非空白名单 / 空全部迁入；不与 selectedModels 发布白名单混同。匹配输出协议分开，通用协议展示 Responses / Chat / Anthropic / Google / Ollama，专用 registry 项列准确 ID 和禁用原因。

“预览匹配”打开可滚动表，显示命中规则及未选 / 停用 / 人工覆盖状态；排除、范围外和未命中对象折叠查看原因，零命中和重叠可解释。预览不选模型或启用渠道。只对已采用版本解析：同 ID 渠道引用替换全局，其他 ID 保留；单模型精确引用优先。多个最高优先级命中报告冲突并阻止受影响保存，不按表格顺序挑选。

当前编辑页从左侧首个“Agent 自动填充”文字按钮打开非模态助手，顶部条和右下启动器已收拢。助手默认悬浮尺寸为 360 × 480 px，受窗口可用高度约束；顶部实际执行模型与放大 / 还原、收起图标，中部聊天 / 待比较建议，底部资料 / 上下文锁 / 导出及输入发送。浮动模式无遮罩，页面操作和滚动继续可用；放大铺满应用窗口，切换尺寸保留输入、聊天和正文位置，收起再开记住本窗口尺寸偏好。未配置模型保留输入并提供配置入口；每轮冻结基准和人工锁，结果三方比较，冲突保留手动值，停止使晚回失效。真实 runner / 检索及模型请求未接入；完整当前行为见下文自由模版迭代，图形启动器只留在历史记录。

执行模型偏好建议保存在本机 preferences.json 的 modelTemplateAgent 分区；复用已保存启用渠道连接，不重复保存 Key。保存偏好不改模型策略 / 触发重启。依赖停用、删除和已知无额度等状态依据 saved 判定，未知不表示检查通过；A6api 无额度禁选，不进行付费探测。同步 / 全配置导出过滤与实际 runner 尚未接入。

“外部 Agent 配置”是独立入口，可选当前、已选、全部或仅新建；填写要求后查看文件角色并复制自包含提示词。任务携每个目标库与缓冲基准、版本规则、匹配契约、协议目录、锁 / 反馈、端点可用性和人工例外；不携地址、秘密或内部执行偏好。剪贴板复制仅在用户点击后执行，失败选中文本供手动复制。外部工具使用自己的模型与检索，不依赖此前对话。

返回可包含多个 create / revision。粘贴结果先校验整个批次，任一错误 / 旧基准全拒绝，逐项查看名称 / 说明 / 匹配 / 配置差异后再次复核，确认只保存候选。未实现真实外部 CLI、跨机版本、标准 digest / 去重或原子落盘服务。

保存候选、设主、采用和渠道保存有独立出口。保存不自动设主或改引用；采用直接多选目标渠道并选择保留例外，进入渠道草稿；随后“前往渠道模型 → 查看草稿 → 保存 → 待重启核对”。全局采用独立模式。版本比较 / 设主 / 归档 / 删除按需打开，已保存规则不原地覆盖，主版本及策略 / 草稿依赖保护删除。字段与匹配的权威候选见 [专项方案](../02-方案草案/模型模版与匹配规则方案.md)。

## 导入、导出、设置和同步

导入先校验示例结构并进入候选查看，接受后到草稿，不直接写运行态。导出可选已提交 / 明确标记未提交的草稿 / 模版；策略片段携实际解析到的精确模板依赖。

局部族导出不默认携带渠道默认、启停、全局 Fast 等更宽字段；保留相关顺序，合并仅重排匹配位置，不删除其他族选择。全量 / 渠道导出另保存来源顺序。JSON 形状用于演示，不冻结生产 schema，也不声称完成真实容器校验。

设置“模型配置”分开显示“自动生成 Agent”“全局 Fast”“配置文件”。Agent 执行偏好有独立保存；全局 Fast 和渠道策略仍返回模型页统一保存。文件职责：

| 文件 | 职责 |
|---|---|
| `manager-state/model-family-templates.json` | 可复用族模板库与版本 / 主指针 |
| `manager-state/model-policy.json` | 渠道 / 模型选择、顺序、引用与覆盖 |
| `manager-state/model-policy-bindings.json` | 本机渠道绑定，仅本地，不随同步 / 通用导出 |
| `manager-state/preferences.json` → `modelTemplateAgent`（拟扩展） | 内置 Agent 执行渠道 / 模型及其推理 / Fast 偏好，仅本机；不属于模板库或渠道策略 |

WebDAV 复用现有渠道配置，新增“族模版”“渠道模型策略”两项范围。下载成为待审候选，策略要求模板依赖齐备；不会直接替换本机草稿。当前冲突只演示整个涉及范围的“保留本机 / 使用传入”，不是逐字段完整冲突处理。

## 模版输出协议与渠道端点

本轮实现于共享 model-config.js / CSS 内存 mock：模版 rules.protocol、渠道默认、族与单模型覆盖使用独立协议优先级。能力层次保持既有规则；模板版本化包含 / 排除 / 渠道范围与输出协议分开，参考协议标签不参与匹配。统一编辑器加入协议继承 / 自定义；单模型指定端点独立于协议，显示最终协议 / 来源。采用默认保留人工字段、指定端点与精确引用；明确清除例外才移除前两项。

渠道详情“协议端点”按需管理默认 / 附加端点，新增 / 编辑 / 删除先改草稿，删除保留引用以解释错误。保存前检查无端点、同协议歧义、指定冲突及连接基本完整性；查看草稿列端点和最终协议变化，保存确认演示 modelAdapters 或受管分组。模型原始 ID、逻辑顺序与 Fast 父项位置保持。

## 版本或后缀、导航和浮动对话细化

右侧按基本信息、匹配范围、族通用配置、版本或后缀、来源与版本连续展示五区，用横向留白 / 分隔区分内容，共用主内容滚动，不新增内层滚动。左侧可收起锚点导航点击只滚到对应区，手动滚动同步高亮，不改变 #models 路由、不隐藏区或重建表单。展开 / 收起保持可见锚点、输入与对话；同对象配置 / Agent 重绘保留当前可见锚点，进入另一个模版从顶部基本信息开始。减弱动效时使用直接定位，导航不画分栏竖线。左侧导航下独立按钮区依次提供“Agent 自动填充 / 匹配预览 / 与主版本比较 / 更多操作 / 设置”，收起保留图标、tooltip 和可读标签；缺主版本比较禁用并解释；返回图标、可编辑名称、候选状态及版本操作合并为一行标题；Tab 滚过后标题贴住主内容区顶部，左侧导航和锚点定位随实际标题高度调整。名称直接在标题编辑，基本信息只留说明；标题实测高度、主内容顶部内边距与边框参与偏移计算，窄窗换行 / 缩放后更新，导航保持可用高度内滚动；页底取消 / 保存候选保持。只读版本页不展示内部导航，仍保留详情操作。通用配置集中协议 / 能力、推理、Fast 和高级字段。版本或后缀为空只显示新增入口，不产生字段墙；数量由用户自由添加，配置弹窗确定只改缓冲，删除先确认。
